# 1.0.0-beta2 完整更新记录

发布日期：2026-09-05

Beta2 是一次覆盖编辑器核心、动画时间轴、瓦片工作流、画布输入、首页和发布工程的版本。以下记录按 Beta1 之后仓库中的实际代码变化整理。

## 新增

- 新增动画循环节：可创建命名循环范围，设置起止帧、播放方向和重复方式；播放时可根据当前帧切换循环节，循环范围会随帧编辑更新。
- 新增停用帧：可通过右键或快捷键启用、停用和切换帧状态；停用帧在时间轴帧头显示斜线，动画播放时自动跳过，不改变其他帧的活动状态。
- 新增图层时间轴视觉状态模型，明确区分活动图层、活动帧、选中图层、选中帧、选中 cel、图层组和图层蒙版。
- 新增图层蒙版独立时间轴与独立编辑状态；蒙版可以单独选择、复制、移动、删除、链接和恢复，同时保持与所属图层的附着关系。
- 新增关联单元格和自动链接：同一图层的多个帧可以共享 cel 内容，编辑、绘制、擦除、填充、撤销和重做会同步刷新所有引用。
- 新增多图层、多帧和多 cel 的组合选择，可将框选内容与时间轴选择组合，用于统一移动、变换、镜像和批量编辑。
- 新增瓦片图层的绘制瓦片、选择瓦片和混合编辑模式；支持多个瓦片集、跨瓦片集绘制、单元格内覆盖和瓦片集实时预览。
- 新增自由瓦片源与实例编辑流程，支持源瓦片共享、重叠放置、独立位置、旋转、镜像、显隐、锁定和同源实例实时同步。
- 新增渐变自由调整弹窗：支持添加、删除、移动和编辑色标，双击色标修改颜色，拖出渐变条进入删除态，点击渐变条或下方区域新增色标，并可恢复为前景色到背景色。
- 新增抗锯齿命令，可从编辑菜单和快捷指令栏调用；支持手动颜色、自动识别周围颜色、画布/调色板颜色、中间明度颜色和可调不透明度，并可只作用于框选区域或整个图层。
- 新增方形笔刷和线条笔刷旋转角度，支持角度预览、整数角度输入、压力动态角度和以指针中心为基准旋转。
- 新增旋转笔刷优化算法选项，旋转线刷使用连续像素线算法，直线笔刷保持单像素宽度并避免快速绘制空洞。
- 新增四个固定快捷指令栏，可分别停靠在上、下、左、右侧；支持独立折叠、独立指令集合、拖拽移动、居中磁吸和批量显隐/锁定/自动链接操作。
- 新增像素级组件库资源，包括渐变色标、选区收缩、抗锯齿、自动链接、压感动态、旋转算法和瓦片相关图标。
- 更新默认调色板：加入用户提供的三个色板以及 Candy Pop、Forest Trail、Game Boy、Neon Night、NES、Ocean Depths、Paper Ink、PICO-8、Pixel Core、Warm Autumn 等通用风格色板。
- 新增跨工程画布取色：在同一视图包含多个工程时，吸管可以跨工程取色，并与所有工程共用当前工具、笔刷尺寸、旋转角度和指针状态。
- 新增首页作品横幅轮播、最近文件栏目管理、版本新闻入口和 Beta2 版本更新日志弹窗。

## 优化

- 统一普通图层、图层组、图层蒙版、瓦片图层和自由瓦片实例的选择、活动、悬浮、拖拽、排序、显隐、锁定和删除规则。
- 统一时间轴的活动列与高亮 cel 规则：多选图层或帧时，所有对应行、列和 cel 都保持活动显示；播放时活动帧随实际播放帧变化，停用帧不会抢占活动状态。
- 优化图层蒙版的状态刷新、播放刷新、停用帧刷新、空 cel 选择、单 cel 移动和多 cel 移动，避免普通图层状态错误传递给蒙版。
- 优化框选变换：支持选区属性直接变换内容、以轴心旋转和倾斜、框选内容移动出画布，以及变换后保留选中状态和活动图层/帧。
- 优化单元格复制、粘贴、覆盖、删除、跨帧粘贴和自动补帧；多选粘贴后保留选择，链接 cel 只在明确操作当前 cel 时删除。
- 优化撤销和重做边界，覆盖图层蒙版、关联 cel、瓦片源、自由瓦片实例、背景图层、填充、粘贴、停用帧和选区变换。
- 优化背景图层和画布尺寸调整：扩展区域按背景规则无限延伸，已绘制区域不会被刷新或覆盖，缩小画布时裁剪区域显示统一黑色遮罩。
- 优化普通瓦片图层的瓦片集切换：仅在真正按下绘制时切换到对应瓦片集所属的活动图层，选择瓦片集本身不会提前改变图层选择效果。
- 优化画布复合缓存、预览缓存、透明棋盘格、缩放、旋转视图、平铺视图和大倍率显示，减少错位、裂缝、过期预览和缩放后的非像素对齐。
- 优化画布输入和工具切换：工具按下或绘制期间禁止切换工具；吸管、抓手、缩放、旋转、移动和空格/鼠标中键操作在播放和多工程视图中保持一致。
- 优化橡皮与铅笔的快速切换、压感角度、笔刷尺寸预览和不同工程之间的指针预览同步，避免事件竞争导致操作被忽略或残留。
- 优化原生保存、导出和文件选择对话框的焦点与交互阻塞，避免重复触发多个后台弹窗，并保留应用内只使用原生对话框的行为。
- 优化首选项重置：未保存工程不会被关闭，重置只恢复首选项状态；同时补充界面动画、旋转算法、渐变拖动线和抗锯齿选项。
- 优化图层栏、属性栏、快捷指令栏、调色板、瓦片集、预览和首页布局，统一组件尺寸、间距、像素图标倍率、停靠方向和主题样式。
- 优化调色板记忆：新建工程默认使用用户上一次选择的调色板；首页无打开工程时自动隐藏标签栏。

## 修复

- 修复选中普通图层或帧后，所属图层蒙版错误出现活动背景或 cel 高亮的问题。
- 修复选中图层蒙版后再点击图层、帧或 cel 时活动状态粘连、切换延迟和错误继承的问题。
- 修复图层蒙版多选时只有最后一个帧活动、松开后活动帧跳回第一帧、活动列丢失和 cel 高亮错位的问题。
- 修复带图层蒙版的图层在播放、暂停、停用帧、启用帧和点击空白区域后丢失活动背景或高亮 cel 的问题。
- 修复单 cel 移动预览错误合并所属图层与蒙版两个 cel、预览超出已有帧，以及移动后源 cel 高亮消失的问题。
- 修复图层蒙版 cel 移动后被错误清空、不能跨图层蒙版移动和撤销删除图层时蒙版无法恢复的问题。
- 修复关联 cel 编辑后缩略图、时间轴预览和同源 cel 不实时刷新，填充及撤销/重做需要再次点击才能显示的问题。
- 修复删除 cel 时误删除整个图层，以及删除空 cel 后预览状态和选择状态错误的问题。
- 修复多选图层、帧、cel 与框选组合时活动效果遗留、镜像后选择消失、播放中多选状态错误和变换后绘制回到错误图层/帧的问题。
- 修复选区内容移出画布后居中导致内容被裁切，以及方向键无法将选区移出画布的问题。
- 修复停用帧在播放中被点击后，停用帧或其图层蒙版错误保留活动背景和高亮 cel 的问题。
- 修复旋转线刷快速绘制出现空洞、指针不在笔刷中心、角度显示小数和线条变粗的问题；旋转算法现在保持连续且不额外扩大线刷宽度。
- 修复渐变色标左右多出像素、边界颜色错误、颜色顺序改变后渐变错误、删除态不透明度错误、拖动不灵敏和双击色标跳动的问题。
- 修复抗锯齿只修改局部区域、漏掉内部颜色、自动选色明度错误、覆盖范围不足和画布/调色板中间态计算不正确的问题。
- 修复瓦片图层无法框选、指针显示禁止、复制移动后错误创建新瓦片、瓦片集缩略图不刷新和镜像后内容恢复原状的问题。
- 修复多个瓦片集之间切换时活动图层过早改变、绘制按下和松开后的活动状态不一致，以及单位瓦片内移动仍错误生成新瓦片的问题。
- 修复背景图层扩展画布后内容被刷新、扩展区域错误染色和背景无限延伸错位的问题。
- 修复多个工程视图中吸管点击后额外绘制像素、Ctrl 指针不切换、空格/中键移动失效和笔刷预览残留的问题。
- 修复父级锁定后子图层锁图标样式、悬浮效果和点击解锁逻辑错误；锁定图层仍可调整图层上下顺序。
- 修复图层组创建后空格/鼠标中键无法拖动画布，以及选中图层组后抓手、缩放和旋转工具被错误禁止的问题。
- 修复首页公告只显示单条、首页横幅切换黑屏、首页无工程时标签栏显示，以及默认调色板和最近选择状态丢失的问题。
- 修复发布检查、版本契约、CSP 精确校验、运行时诊断、恢复服务和本地工作区保存中的错误处理与状态同步问题。

## 工程与验证

- 工程文件格式继续保留图层蒙版、关联 cel、瓦片集、自由瓦片源与实例、动画循环节、停用帧和图层属性的持久化与迁移边界。
- 发布流程补充版本契约、更新日志索引、性能发布凭证、模块边界和按改动范围执行的开发/发布检查。
- 增加时间轴视觉状态、蒙版独立性、选区变换、瓦片编辑、背景图层、画布缓存、渐变、压感和播放状态的定向回归测试。
- 清理与当前交互契约不再匹配的旧测试，保留核心功能、发布门禁和高风险路径的有效覆盖。
