# MoonSprite DEV.3 完整更新记录

[返回更新日志索引](../../CHANGELOG.md)

本文件永久保存 `DEV.3` 的完整更新条目。除修正事实错误外不再改写。

## DEV.3
### 本批次进行中
- 修复 GIF 动画在高倍率导出、较大画面或复杂帧中跨越 LZW 位宽边界后产生碎裂像素的问题；新增 1000% 最近邻缩放与逐帧解码像素回归。
- 预览栏目改为保留完整画布像素源，不再把大画布预先压缩到 512 像素后再放大；缩放仍使用最近邻采样，确保像素边界无损。
- 重做连接单元格的视觉连接层：连接区域保持与普通单元格相同高度，缩略图固定为方形并统一尺寸，连接底板覆盖内部竖线且整体位于时间轴网格上层。
- 修复粘贴浮动选区在移动、连续镜像和再次移动时复用过期预览缓存，导致内容回弹、杂乱残留像素且无法完整撤销的问题。
- 开发工作流改为 `DEV.N` 连续开发与发布两阶段：当前目标标记为 `DEV.3`，新增轻量 `check:dev`、发布门禁、版本与模块边界检查；性能基准改为大版本或专项手动触发，高风险回归矩阵由 363 条 Debug 明细合并为 45 条长期契约，日常视觉验收交由用户完成。
- 最近列表检测到工程原路径不存在时会提示用户并自动移除失效记录；仍存在但无法解析的文件继续保留，避免误删记录。
- 修复图层设置弹窗被首选项弹窗的 620px 最小宽度规则误命中；恢复真正的窄版默认宽度并对齐洋葱皮帧数、不透明度和颜色控件。
- 修复连接单元格在紧凑密度下高度变小、缩略图被横向拉大及连接内容被网格竖线遮挡的问题。
- 粘贴内容到已连接单元格时改为更新共享 cel 源，全部连接格同步变化且连接关系保持不变，并支持整组撤销与重做。
- 修复浮动选区连续水平或垂直镜像后再次移动会恢复旧方向的问题；镜像现在同步重建掩码、像素偏移和移动快速路径缓存。
- 完成本批累计动画、弹窗与选区改动的 P3 画布性能复测；12 个场景帧 `p95` 均为约 3.70 ms，主绘制 `p95` 最高 0.70 ms，未发现稳定性能退化。
- 新增动画时间轴左右方向键切帧，输入框、弹窗和选区编辑仍保持原有键盘行为。
- 修复 `Ctrl+H`、`Ctrl+V` 后镜像并移动浮动选区时可能产生重复残留像素的问题。
- 调整调色板锁定逻辑：解锁时颜色编辑器实时同步当前前景色或背景色对应色块，锁定只禁止同步编辑。
- 调色板解锁不再展开或插入色块内编辑器；锁头只控制现有颜色编辑控件是否能实时回写对应前景色/背景色色块，色盘网格布局保持不变。
- 新增动画单元格“连接”，按图层共享单元格数据并支持撤销恢复。
- 预览栏动画播放改为独立的视图状态：播放速度、循环方式、停止回退帧和当前预览帧不会修改图层栏或画布播放状态。
- 新增动画单元格断开连接命令；断开时复制当前共享像素表面，连接区域在相邻帧中显示为连续块，并支持撤销/重做。
- HEX 颜色输入框在失去焦点时提交有效颜色，不需要额外按回车。
- 修复未移动的前景色/背景色临时弹窗在点击外部时先卸载而跳过 HEX 失焦提交的问题。
- 清空或删除已连接单元格时立即拆分连接关系；无可见内容的单元格不再允许建立连接。
- 动画单元格右键菜单改为按实际尺寸在窗口内定位，底部和右侧操作不再被裁切。
- 修复浮动选区移动后再次执行水平或垂直镜像时恢复旧像素方向的问题。
- 图层设置弹窗切换到新的窄版尺寸记忆，并让洋葱皮不透明度输入框始终填充对应列宽。
- 恢复早期图层设置弹窗的布局与尺寸比例。
- 修复框选后 `Ctrl+V` 与 `Ctrl+H` 组合操作的画布残留与撤销隔离问题；隐藏蚂蚁线只改变显示层，不改变像素或浮动粘贴历史。
- 修复调整画布尺寸时动画时间轴所有帧/cel 的画布偏移同步，扩大、裁切、撤销和重做均保持各帧内容的原位置关系。
- 修复调色板色块按钮未填满尺寸网格而显示成小方块的问题，并继续沿用用户已有的颜色格尺寸偏好。
- 修复画布尺寸提交后笔刷预览仍使用旧画布边界的问题，清理 resize 临时状态并重新计算当前指针预览。
- 修复画布扩大后活动图层尚未扩展时的铅笔预览：新增画布区域现在会显示完整替换色，落笔前后视觉保持一致。
- 回退洋葱皮覆盖当前帧的叠加顺序，恢复为当前帧内容绘制前的辅助层显示。
- 重新整理图层设置弹窗为窄版自适应排版，保留即时设置、滑块和重置操作，避免控件拥挤与底部空白。
- 修复调整画布尺寸后临时预览残留导致铅笔/橡皮擦预览错位的问题；确认或取消调整都会清理临时状态。
- 调色板新增锁定/解锁颜色编辑：解锁后可从已选颜色打开颜色编辑器，修改结果实时同步到共享调色板并支持撤销；移除调色板内直接新增/删除颜色的快捷按钮。
- 动画帧与单元格改为长按连续范围选择，空单元格也可参与选择；只有蓝色选中描边区域允许移动，拖放指示线贯穿完整动画网格。
- GIF 方向说明改为悬停提示，并统一移除选项内的示例帧数字。
- 修复帧和单元格长按范围选择的实时预览：拖动过程中只更新当前对象类型的临时选区，帧选区与单元格选区互斥；补强离开原按钮后的坐标命中。
- 图层设置弹窗改为紧凑自适应布局，不透明度滑块在失焦或点击其他设置区域后自动隐藏。
- 为颜色编辑模式排序增加抓手指针拖动入口，并修正图层颜色预设操作按钮间距。
- 明确帧和单元格显式选区互斥；选择其中一类时立即清除另一类，点击图层栏对象或动画栏外区域时统一清除。
- 修复多图层工程中洋葱皮被当前帧不透明内容完全遮住的问题，相邻帧合成结果改为覆盖显示；画布调整后立即重建笔刷指针坐标与预览。
- 选区新增方向键单像素微调；矩形与椭圆新建时 `Shift` 约束 1:1，已有选区时 `Shift` 自由加选、`Shift+Ctrl` 约束 1:1。
- 动画帧长按范围选择支持从帧头进入 cel 行继续按列扩展；帧与 cel 的蓝色选框描边悬停显示移动指针，并只允许从描边启动拖动。
- 重新排版图层设置弹窗，将显示密度、洋葱皮开关、帧范围、透明度与颜色拆为独立自适应分区。
- 首选项中的颜色编辑模式与图层属性颜色预设统一使用预设区布局；颜色模式拖动经过目标行时即时重排；图层设置弹窗改为紧凑宽度并统一洋葱皮不透明度滑块。
- 修复新建工程空首 cel 在图层栏不可见的问题，并调整动画帧/单元格拖拽为先选中、再从蓝色选中框启动移动。
- 修正调色板浮动窗口恢复方形时的停靠尺寸重算，并准备在前景色/背景色区域提供按当前颜色加入调色板的操作。
- 新增图层设置弹窗，集中调整动画栏显示密度与洋葱皮；洋葱皮使用相邻 cel 的独立缓存叠加，不进入文档撤销历史。
- 颜色编辑器新增 LAB 与 CMYK 通道，颜色模式可在首选项中启用、禁用和排序；前景色与背景色可分别加入当前调色板。
- 新增 GIF 动画导出，支持全部或区间帧、逐帧时长、五种帧顺序和百分比缩放，并增加 GIF89a 编码器与 Windows 文件过滤器。
### 新增功能
- 动画图层栏新增帧/单元格多选、单元格复制粘贴与移动、单元格属性不透明度，以及新增帧、新建空帧、删除帧和复制单元格快捷键。
- 动画帧新增整批复制粘贴与拖拽排序：帧时长和全部图层单元格一并移动或复制，粘贴到所选帧之后并保持独立像素数据。
- 预览栏关闭按钮左侧新增播放/暂停按钮，左键播放动画，右键复用图层栏的速度、播放模式和停止回退设置。
- 新增渐变工具，支持无抖动、抖动、棋盘格、横线、竖线、左右斜线等预设，预览按像素比例显示；支持 `Shift+G` 快捷键和按住 `Shift` 的 16 方位渐变。
- 新增像素网格与自定义网格：像素网格会在视图过密时自动隐藏，自定义网格默认 `16 x 16`，可配置起始位置、尺寸和颜色，并提供独立快捷键与首选项颜色。
- 新增缩时视频记录与导出：支持预览、MP4/WebM、按时长或按倍率导出、质量与整数放大倍数选择、进度反馈和项目缩时记录大小统计；默认开启绘画过程记录。
### 改进
- 首页项目列表改为固定首页布局、列表区域独立滚动，并复用组件库滚动条；更新内置示例工程迁移机制，`DEV.3` 启动时会更新旧版内置示例而保留用户主动删除状态。
- 首页品牌副标题更新为“像素艺术专业编辑器”，并收紧标题与副标题间距；恢复数量徽标改为自适应宽度和垂直居中布局。
- 缩时视频弹窗移除无说明选项的预留空白行，使预览、导出设置、摘要和底部操作区按实际内容紧凑排列。
- 完成动画与调整预览批次的 P3 画布性能复测并追加到性能历史；常规交互满足帧时间门禁，绘制场景的偶发长任务保留为桌面复核项。
- 动画帧整列选框拆分为 sticky 帧头边框和正文列边框，连续区间只绘制一个外框；帧头始终位于单元格选框之上，纵向滚动不会再互相覆盖。
- 多选动画单元格粘贴到时间轴末端时会按需追加空白帧，并将新增帧、全部目标 cel 与选择状态合并为一次撤销。
- 动画帧选中外框按连续区间分别绘制，正文外框避开顶部帧数栏；播放按钮取消蓝色边框，工具栏图标保持居中；分隔线拖动期间锁定横向缩放指针。
- 画布尺寸预览的 Shift 移动改用统一轴向约束；图层属性、帧属性、画布大小和图像大小弹窗打开后自动聚焦并全选第一个输入框。
- 本轮 P3 画布基准已记录：所有尺寸和场景帧 `p95` 为 3.70 ms，主绘制 `p95` 最高 0.70 ms，未发现稳定性能退化。
- 框选矩形和椭圆时改用 `Ctrl` 触发 1:1 约束，`Shift` 只保留加选语义；动画帧和单元格多选改为单个整体外框，选中帧列背景统一为 `#20242d`。
- 动画缩略图按当前帧实际内容边界显示，空内容帧不再显示实心状态；帧菜单选项单击立即生效并自动关闭。
- 多选动画单元格复制粘贴或拖动时以实际操作单元格为锚点，跨图层、跨帧保持原有行列布局，目标越界时不执行残缺移动。
- 帧头与单元格统一使用蓝色外描边选择反馈，播放时临时隐藏描边；二者均可双击打开属性，属性弹窗支持 `Enter` 完成和 `Esc` 退出，右键命令明确标注“帧”或“单元格”。
- 图层栏 `Ctrl+滚轮` 增加超大显示档，`Alt+滚轮` 可横向浏览帧；左右侧停靠会动态限制名称区宽度并保留帧操作区，活动帧背景统一为 `#20242d`。
- 弹窗及其他标题区域不再显示标题上方的蓝色英文眉题，减少中英文重复信息。
- 画布尺寸弹窗内部新增独立撤销/重做栈：连续输入多个尺寸后可完整回退到上一组值，边界线预览不会污染文档撤销历史。
- 调整弹窗中的选区移动、旋转、缩放和倾斜会先恢复计算基线再重绘预览，消除点击选区时的颜色闪烁。
- 动画帧与单元格只有命中蓝色选框外描边才会移动；普通点击替换选择，长按则追加到既有多选且不触发移动。
- 修复恢复数据目录不可写时 Tauri 启动钩子阻止主窗口打开的问题；恢复数据现在作为辅助能力失败时记录警告并继续启动编辑器。
- 空 cel 不再渲染空心占位标记；多帧工程打开导出设置时默认 GIF，GIF 方向收敛为正向、反向、正向往复和反向往复，并显示方向说明。
- 图层设置改为窄版即时控制，缩略图/帧信息大小使用滑块，不透明度输入支持点击展开滑块，并新增重置按钮；洋葱皮开关放入帧计数区且作为视图辅助状态处理。
- 首选项中的颜色模式改为拖拽排序，仍可用眼睛按钮启用或停用并至少保留一个模式；调色板变更纳入颜色面板渲染键，加入当前颜色后按钮即时消失。
- 导出弹窗按 PNG/GIF 内容变化清除固定高度，GIF 范围与方向控件展开后会重新按内容布局，底部操作保持可见。
- 帧选择改为覆盖帧头和全部单元格行的整列蓝色外描边，移除帧头右上角断线和旧 `#274b7c` 蓝色色块。
- 图层栏 `Ctrl+滚轮` 扩展为六档密度；详细、扩展、大型和巨型档显示方形 cel 缩略图，缩略图按完整画布边界取景并裁掉画布外内容。
- 单元格不透明度属性改用与图层不透明度一致的滑块、数值输入和百分比布局。
- 图层栏与预览栏共享编辑器公共层的唯一播放时钟，两个栏目同时显示时不会重复推进动画。
- 帧与 cel 拖动改用和图层一致的指针拖拽，拖动源半透明并显示明确落点；不再依赖桌面 WebView 中不稳定的 HTML5 原生拖放。
- cel 缩略图改为整块方形透明棋盘格背景，并按可见像素边界自适应放大、居中，小面积内容在大画布中也能辨认。
- 无内容 cel 的属性、复制和删除命令改为禁用；粘贴仍可将已有 cel 内容放入空格。
- 动画图层栏的名称区、帧头和 cel 网格统一使用同一列轨道，修正左右停靠及横向滚动时的空列、竖线和首帧错位；最大显示密度在底部保留可用滚动余量。
- 帧与单元格支持 `Ctrl` 离散多选和 `Shift` 范围选择；点击 cel 激活图层不会清空已有动画选择，点击其他区域会清除显式蓝框；动画拖动期间使用移动指针。
- 去除 cel 缩略图内部的人为画布边界线，空白背景与图层区域一致，避免缩略图出现异常边界。
- 统一可缩放弹窗的底部操作栏布局，弹窗拉高时按钮始终贴住底部，不再在按钮下方留下空白。

### 新功能

- 新增 Aseprite 式动画编辑：图层直接作为动画轨道，图层栏目内集成帧列与播放控制，支持逐层 cel、空白帧、复制帧、删除帧、毫秒帧时长、循环播放和首尾/前后帧切换。
- `.moonsprite` v2 新增独立 `cels/` 像素文件并兼容早期单帧 v1/v2 工程；`.ase/.aseprite` 导入与另存为支持多帧像素和原始帧持续时间。
- 铅笔、橡皮擦、选区、形状和油漆桶新增可组合的上下、左右与两条斜向对称轴；属性栏使用四个像素图标按钮并提供重置对称中心，绘制、选区和填充共享同一轴心反射算法并合并为一次撤销。
- “帮助”菜单新增“未来计划”，以中英文列表展示动画、蒙版、笔刷、工具和瓦片等长期方向及当前完成状态。
- “帮助”菜单新增“更新日志”，只展示最近一次正式打包版本 `DEV.2` 的归档摘要，不混入当前未发布改动。
- 选区四边中点外侧新增横向与纵向倾斜交互，分别保持高度或宽度不变；预览、像素内容、选区遮罩和撤销共享同一映射，并使用指针源第 1 行第 7、8 列的新指针。
- 新增完整英语界面：建立统一可用语言注册、类型化翻译键、具名变量插值、简体中文回退、语言偏好持久化和 React 实时更新入口；首页、编辑器、工具、弹窗、首选项、快捷键、图层、调色板、组件库、保存导出提示、Windows 原生文件对话框、撤销历史与 TypeScript 核心错误均支持 `zh-CN` 和 `en-US`，用户输入与工程内容保持原样。
- 画笔与橡皮擦的直线连接新增可自定义“约束直线方向”修饰键，默认 `Shift+Ctrl`；阶梯数值为 `1` 时约束到 8 个方向，更大数值增加约 30° 和 60° 斜向，共 12 个方向。

### 改进

- 动画图层栏重新贴近 Aseprite 的操作结构：第一帧紧邻可拖动的图层名称区，新增帧默认复制当前帧；帧时长移入逐帧右键属性，播放速度、单次/循环和停止返回起始帧移入播放按钮右键菜单。
- 图层栏新增 `Ctrl+滚轮` 三档信息密度并记忆选择；紧凑档保留名称与帧，标准档显示图层信息，详细档增加按当前帧更新的像素缩略图。
- 对称辅助轴改为品牌蓝色实线并允许直接拖动轴线或中心点调整位置；对称绘制时镜像侧不再重复显示笔刷预览，选区移动、缩放、旋转和倾斜同步生成镜像结果。
- 快捷键配置导入成功后会在设置弹窗内显示明确状态反馈；继续编辑或重置配置时自动清除旧提示。
- 图层显示颜色改为最外层已着色祖先优先，并同时作用于全部后代组和图层；外层组可用单一色条标识整棵层级树。
- 横向与纵向倾斜交互替换为用户提供的新像素指针，采用无插值最近邻放大并保持中心热点。
- 快捷键设置导出改用 Windows 原生 JSON 保存对话框和原子写入，不再依赖 Tauri WebView 中不可靠的浏览器下载链接。
- 复制和粘贴图层组时保留每个组的展开或折叠状态，粘贴完成后选中新组、嵌套组及全部后代图层。
- 图层组显示颜色会覆盖全部后代图层的左侧色条；批量属性中的显示颜色与混合模式第一次点击即实时预览，不再等待数值输入合并计时。
- 图层多选拖拽预览最多逐行展示四项，其余选中对象以 `+N` 汇总；折叠组中的不可见选中项也会计入汇总数量。
- 统一收紧可缩放弹窗的四边与四角命中带，避免快捷键内容区右下方误触缩放；快捷键设置正文现会随弹窗高度增长并保持底部操作栏贴底。
- 批量图层属性预览改为约 40 ms 合并更新，输入控件立即响应，停止操作或关闭弹窗时强制应用最后值，降低大画布、多图层实时合成造成的卡顿。
- 统一数值输入仅接受数字、小数、括号和四则运算表达式字符，键入或粘贴的字母、中文与其他无效符号会被过滤。
- 新建与粘贴图层、图层组或组合时，有选择则放在当前选中对象同级的正上方，无选择则放到根层最上方。
- 图层与图层组混合多选的属性面板现可统一覆盖名称、混合模式、不透明度、显示颜色和描述；五项修改均实时预览，关闭后整批变化合并为一次撤销。
- 多选拖拽悬浮预览按图层栏顺序展示多个被拖对象；拖入图层组时蓝框只覆盖组标题行，不再扩大行高或包住组内内容。
- 首选项默认使用 MoonSprite 指针和完整笔刷预览；启用系统本地指针时禁用无效的光标比例设置，“绘制时显示笔刷边缘”仅在完整预览并显示边缘模式下出现。
- 加宽新建画布弹窗并提高合理最小宽度，六个内置尺寸预设默认保持在同一行。
- 透明背景格大小由固定预设改为可直接输入的 `1-256 px` 整数；图层拖到图层组内容区域时使用整行蓝色容器框，不再显示容易混淆的插入位置指示线。

### 工程维护

- 将更新日志改为热区与按版本归档分离：根文件只保留未发布内容和索引，完整历史永久保存在独立版本文件中，降低长期开发时的 AI 上下文占用。
- 建立完整更新日志制度：后续每批功能、修复、交互、性能、重构、依赖、构建和平台变化均逐项保留；本地维护检查与 GitHub CI 会阻止代码变化未同步更新日志的提交。
- 开发流程改为快速 Debug、阶段集成和正式发布三段式验证；日常修改只运行受影响测试并保留本地，高风险修改自动提升检查范围。
- GitHub CI 改为按前端、Rust 和缩略图改动选择检查；PR 通过后合并到 `main` 只执行轻量维护审计，不再重复正式构建。
