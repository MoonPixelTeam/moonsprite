# MoonSprite 1.0.0-beta6 完整更新记录

发布日期：2026-09-23

本记录汇总相对 Beta5 的新增、优化与修复，包含本次覆盖打包前的全部功能更新。

## 新增

### 动画与素材导入

- 新增精灵表导入：从文件或当前工程切片生成动画，支持起点、帧尺寸、行列、水平／垂直间距和边缘不完整帧。
- 精灵表切片支持可视化拖动、缩放和平移预览，导入结果可一步撤销。
- 新增图片序列识别，可选择分别打开或合并为动画，设置帧时长并记住处理方式。
- 帧间动画新增形变补间与淡入淡出，在当前帧和下一帧之间生成中间帧，保留原始两帧。
- 补间支持当前图层、所选图层／组及全部可编辑图层；多个图层共用中间帧，支持图层蒙版及符合条件的组蒙版同步。
- 新增运动路径编辑器，支持像素路径绘制、直线连接、方向约束、移动锚点、缩放、平移、撤销和重做。
- 新增运动路径库，可命名保存并跨工程复用，重新打开软件后仍可载入。

### 参考图、触控与工作流

- 参考图支持直接添加到画布、从剪贴板粘贴、独立浮窗，以及随画布移动或独立浮动显示。
- 参考图支持缩放、旋转、水平／垂直镜像、不透明度、锁定、置顶和重置，并提供平滑／硬边缘显示设置。
- 新增平板辅助操作条，支持画笔／橡皮切换、按住取色、笔刷尺寸与不透明度、修饰键、选区模式、变换确认及逐像素微调。
- 支持双指轻点撤销、三指轻点重做、正角旋转吸附和导航模式长按取色；触控布局可自动启用或手动设置。
- 新增笔输入测试区，显示压力、倾斜、旋转和按键状态，试画不影响工程。
- 默认粘贴目标可设为当前单元格、新图层或新工程，也可通过选择性粘贴临时切换。
- 保存与导出位置支持最近使用的目录或固定目录。
- 放大图片导出新增可选的窄边缘柔化及细微噪点处理；不影响工程与普通保存，不能保证防盗。
- 界面光标与绘画十字可分别设置，支持系统光标及不同十字显示方式。

## 优化

### 动画、图层与选区

- 补间预览改为完整合成预览，包含图层顺序、可见性、蒙版、图层样式和混合效果。
- 优化补间的索引色处理、空白端点过渡与多图层共同轴心行为。
- 图层栏目提供普通／动画模式；动画设置即时生效，洋葱皮范围可选择当前图层或全部图层。
- 改进时间轴单元格、多帧、循环节、组范围选择、拖放及缩略图刷新。
- 图片粘贴为新图层后自动显示选区变换框，可直接移动、缩放和旋转，并支持撤销与重做。
- 加长选区指针四角并改善对比度，缩放画布时保持清晰。

### 栏目、绘画与性能

- 栏目按可用宽度分阶段精简标题和操作按钮，空间不足时通过“更多操作”保留完整入口，支持停靠与浮动面板。
- 统一颜色、调色板、预览、参考图、画笔与图块栏的紧凑操作入口，改善窄栏间距与标题布局。
- 默认预览适配随栏目当前尺寸更新，手动缩放保留设定倍率。
- 补充参考图操作提示、调色板上传与文件夹入口，调整默认工作区和快捷操作入口。
- 改进触摸与笔输入的协作，落笔时抑制画布触摸干扰，优化多指导航和手指绘画之间的切换。
- 优化大画布平移、缩放、绘画、选区预览及笔刷尺寸调整的刷新与缓存使用，减少复杂图层工程的重复计算。
- 改进图层和调色板列表更新、历史栏目滚动及连续手势响应。

## 修复

### 绘画与选区

- 修复改变图层混合模式后笔刷预览未体现混合效果的问题。
- 修复图层从组内移出并更改混合模式后，第一笔透明、第二笔才显示的问题。
- 修复未启用圆角时选区仍出现圆角的问题。
- 修复选区指针与绘画、拖拽等指针切换时重叠的问题；松开空格立即恢复选区指针，中键按下时仅显示拖拽指针。
- 修复套索单像素预览，并补齐选区起笔预览的调用连接。
- 修复选区、浮动粘贴和变换中的预览、合成缓存及撤销状态衔接问题。
- 隔离弹窗快捷键，避免路径编辑等窗口的操作同时触发主画布命令。

### 文件、栏目与稳定性

- 修复导入非 .moonsprite 工程后修改画布尺寸被错误内存估算拦截的问题，按实际需要裁剪或重建的图层估算资源开销。
- 修复栏目标题按钮区出现滚动条、灰色占位、按钮裁切，以及首次测量前操作入口缺失的问题。
- 修复预览栏目缩小后仍按首次打开尺寸适配，导致图像被裁剪的问题。
- 修复时间轴批量选区丢失及图层设置操作中的选择状态保留问题。
- 完善参考图变换、显示与取色，以及图片序列、保存和导出的边界处理。
- 加强扩展脚本结束标签处理及特殊标识符校验，改善扩展加载的稳定性。
