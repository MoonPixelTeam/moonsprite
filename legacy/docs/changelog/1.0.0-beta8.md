# MoonSprite 1.0.0-beta8 完整更新记录

发布日期：2026-10-03

本记录汇总相对 Beta7 的新增、优化与修复。

## 新增

- 新增吸管取色来源选项，可选择合成后的画布颜色或当前图层颜色，并同步应用到放大镜和取色流程。
- 新增渐变色标颜色编辑中的画布吸色支持，吸色期间保持渐变编辑器打开。

## 优化

- 动画时间轴减少布局和挂载开销，播放、反向播放、帧选择和链接单元格保持同步。
- 画布光标与笔刷预览减少重复取色、布局读取和无效刷新；开启大小压感时，悬停预览默认使用最小尺寸，落笔后仍按实际压力变化。
- 腾讯会议或直播场景下优化输入、预览和缓存路径，保留原生鼠标指针行为。
- 图层显隐改为只失效合成结果并保留未变化的图层样式缓存，减少复杂图层重新显示时的等待。
- 更新撤销、填充历史和事务补偿路径，降低错位、残留和无法撤销的概率。

## 修复

- 修复选区工具和魔棒工具的 Ctrl 临时移动行为冲突；选区内部 Ctrl 复制时保持复制指针。
- 修复数位板大小压感失效时笔刷被固定为 1px 的问题。
- 修复油漆桶智能闭合填色偏移以及填色后无法撤销的问题。
- 修复吸管、渐变色标和颜色编辑器在临时切换工具时弹窗被关闭的问题。
- 修复多图层、动画选择、图层显隐和撤销重做中的预览、缓存及状态同步问题。
