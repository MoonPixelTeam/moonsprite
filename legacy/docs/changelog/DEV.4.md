# MoonSprite DEV.4 完整更新记录

[返回更新日志索引](../../CHANGELOG.md)

本文件永久保存 `DEV.4` 的完整更新条目。除修正事实错误外不再改写。

## DEV.4

### 新增

- 新增 Aseprite 风格笔刷动态：铅笔和橡皮擦可分别把压力或速度映射到尺寸、绘制/擦除强度，铅笔还可把动态值映射到前景色与背景色渐变。
- 笔刷动态提供输入阈值、输出范围、柔和/线性/硬朗曲线、正反向和实时压力/速度预览；渐变支持与渐变工具一致的无抖动及抖动模式。
- 新增逐帧图层蒙版与图层组蒙版。蒙版使用黑白灰控制对应 cel 或组的透明度，支持独立编辑、显示/隐藏、复制粘贴、链接、断开、移动、多选与灰度粘贴。
- `.moonsprite` 工程格式升级到 v4，新增 `masks/` 灰度资源、逐帧图层组蒙版、蒙版链接、剪贴蒙版、累积混合以及调色板二维槽位数据，并兼容迁移 v1-v3 工程。
- 新增剪贴蒙版，图层或图层组可通过右键菜单或 `Ctrl+Alt+G` 让自身显示受同级下方对象的形状与最终透明度限制。
- 图层组新增“累积混合”，可先让组内内容与外部背景合成，再对完整结果额外应用一次组混合模式和不透明度。
- 调色板新增固定二维槽位：颜色与空槽位置由用户拖动决定，栏目宽度变化不再打乱排序，项目和本地色板都会保存列数、位置与空槽。
- 调色板颜色支持矩形范围选择、Ctrl 离散多选、描边拖动整组选区、交换占用槽位、双击空槽加入当前颜色，以及 `Alt+滚轮` 横向滚动和 `Ctrl+滚轮` 五档缩放。
- 本地色板格式升级到 schema v2，保存二维位置和空槽，同时继续读取旧版紧凑色板。
- 新增导出精灵表入口，可把当前动画全部帧排列到一个新工程的单图层中继续检查和编辑。
- 导出设置新增持久化预设、默认文件名与后缀同步、单独选择目录、本地展馆目录和最近导出路径。
- 新增默认保存位置和默认导出位置首选项，并在应用根目录准备默认图片导出目录。
- 预览栏目新增“跟随画布视窗”，平滑同步主画布查看位置且保留独立缩放；手动拖动预览会自动关闭跟随。
- 预览栏目支持左键按住直接平移，并在右键菜单中提供“查看相对明暗”。
- 移动工具自动选择图层时会展开父级组并滚动到对应图层；可显示短暂内容边框，按住 `Shift` 点击画布内容可追加选择其他图层。
- 新增吸色放大镜，按住吸色手势时显示当前颜色、上个颜色和硬边缘放大画面；可在首选项切换像素/线条外框、畸变与光学效果。
- 首选项新增界面百分比缩放、工具栏图标尺寸、滚轮缩放模式、吸色放大镜样式与效果、图层点击内容预览等设置。
- 工具栏新增正常尺寸像素图标资源，并将工具图标、状态图标和指针统一登记到组件库，支持名称与 ID 悬浮索引。
- 新增浅色粉色主题及多套分层配色主题，调整主题顺序并统一各主题的选中、悬浮、输入框、菜单和强调色对比。
- 框选工具支持双击快速选择当前像素格或自定义网格单元；新建矩形、椭圆选区与形状时支持 Ctrl 中心创建、Shift 1:1、Alt 调整旋转方向、空格移动预览。
- 已有选区变换支持 Alt 以中心为轴缩放；旋转时八个控制点跟随旋转，旋转指针根据控制点当前位置和上下方向动态选择。
- 铅笔工具栏新增“阶梯”输入框，直接控制直线斜向阶梯值并与首选项同步。
- 油漆桶和渐变工具新增容差与连续区域设置；橡皮擦右键可把当前图层中与前景色完全一致的像素替换为背景色。
- HEX 输入框支持右键读取系统剪贴板并直接粘贴合法颜色，不显示浏览器上下文菜单。
- 新增“替换颜色”弹窗，可分别选择初始颜色和替换颜色、使用吸管取色并实时预览，目标支持全局、选区、选择的图层、选择的帧、选中的单元格和调色板。
- 时间轴支持跨图层、跨帧多选单元格，移动工具可统一移动所选单元格内容；多选图层时自动映射到各图层当前帧的单元格。
- 图层栏的眼睛和锁支持按住划过批量切换，按住 Alt 操作时可一次作用于当前层级的全部对象。

### 优化

- 重做图层栏、预览栏、调色板、调色盘、首选项和弹窗按钮体系，统一 26px 通用按钮、像素图标倍数、文字间距、栏目外边距、描边和悬浮状态。
- 图层栏的眼睛、锁、文件夹、剪贴蒙版和图层蒙版图标重新对齐；图层蒙版轨道使用与普通图层一致的名称、选中背景、缩略图与单元格尺寸。
- 图层栏在紧凑密度下缩短帧格高度；详细视图起图层蒙版缩略图与普通 cel 使用相同尺寸和显示规则。
- 侧边停靠栏目按实际数量平均共享整列，一个、两个或三个栏目都不会留下中间空槽，移入移出后立即重新分配。
- 统一栏目交界描边、可拖动分隔线和调整占比时的悬浮反馈，修复预览、图层和颜色栏目外框被相邻区域覆盖的问题。
- 预览工具栏恢复紧凑按钮并居右，统一标题栏高度、内部分隔边框、缩放与播放图标。
- 颜色编辑器改为自适应高度，RGB/HSV/HSL/Gray/LAB/CMYK 切换时自动调整布局；通道滑块随窗口拉高并保持数值输入对齐。
- 颜色编辑器新增新旧颜色对比，确认后才更新旧颜色；右上角色块支持点击复制 HEX、按下反馈和复制成功提示。
- 不透明颜色统一显示六位 HEX，只有存在透明度时显示八位 HEX；HEX 输入框缩短并扩大右侧颜色样本。
- 前景色与背景色按钮改为完整色块，以自动黑白文本保证可读性，悬浮描边使用当前主题强调色。
- 调色板颜色默认描边改为主题对比色并与颜色交界线保持同一视觉粗细，选中外框在移动时同步跟随。
- 预览视图移动加入边界限制，保证作品不会完全离开预览窗口；主画布平移在高倍率下允许四周最多移出 50%。
- 画布始终显示清晰深色边缘描边，缩放工具改为以点击位置为基点并始终使用放大镜指针。
- 保存、另存为和导出统一使用紧凑进度弹窗；保存弹窗改窄、减少留白并更快关闭，保存动画图标保持硬边缘像素显示并适配主题颜色。
- 普通保存改为写入完成后立即落盘，降低调试闪退或重新打开时丢失最近保存内容的风险。
- 预览、图层、菜单、下拉框、滚动条、复选框、危险按钮和纯文字按钮统一复用组件库视觉与尺寸。
- 菜单、图层右键选项和组件库图标补充统一工具提示，说明图层蒙版、剪贴蒙版及常用图标的作用和操作方法。
- 组件库支持调整面板大小，并按正常/大号工具图标与指针分区对齐展示。
- 图层组普通 100% 正常模式使用穿透合成，组内图层继续与外部背景逐层计算；只有组属性需要时才隔离合成，创建普通组不再改变画面。
- 混合模式计算和动态 replacement 合成改为预编译采样栈，避免渐变预览对每个像素重复构建同一组合成结构。
- 大画布渐变拖动预览改用可复用设备像素缓冲和覆盖缓存；连续拖动不再每帧扫描整张 4000x4000 文档，并在结束或取消时释放缓存。
- 大画布快速绘制改进合并指针事件与路径采样，降低快速移动时线段被错误拉直和事件密度造成的不连续。
- 压感尺寸变化加入包络和按实际尺寸盖章策略，使粗细衔接更连续，并避免低压力下过早变粗或速度必须极慢才生效。
- 工具启用压感时，画布笔刷指针预览固定为 1px，不再随动态尺寸跳动。
- 画布粘贴位置改为优先放在画布中心；若内容在中心会越界，则从画布左上角放置。
- 保存路径、导出路径、最近导出位置、导出文件名与预设使用统一平台对话框和持久化数据流。
- 发布性能工具扩展 800/2048/4000 大画布、复杂动画、渐变、填充和 React profiling 场景，并强化生产构建、审计凭证和接受流程。
- 窗口尺寸变化时，浮动弹窗和栏目按画布中心到各边界的相对位置重新定位，同时保持自身宽高不变。
- 顶部菜单新增独立“选择”栏目，选区相关操作集中归类；“替换颜色”加入“编辑”菜单并支持快捷打开。
- Windows WebView 渲染参数调整为兼顾 OBS 窗口捕获与正式版安全保护，减少录制黑屏和软件交互卡顿。
- 大画布概览复用当前缩放级别的合成表面，平移时不再逐帧缩放完整 4000px 离屏图；无抖动渐变预览改为视窗自适应采样，正式性能复测收益超过噪声门槛且相邻指标无稳定退化。

### 修复

- 修复图层组设置混合模式后组内图层混合模式失效、改回正常模式后组属性不再生效，以及普通图层打组后合成结果变化的问题。
- 修复剪贴蒙版错误混入基底颜色的问题；基底透明度现在只限制上方对象最终透明度，不把基底 RGB 混入剪贴内容。
- 修复图层蒙版链接单元格尺寸、连接底板和选中颜色异常；链接样式与普通 cel 保持一致，缩略图始终使用蒙版本身的白/灰内容。
- 修复空 cel 仍可创建或粘贴图层蒙版的问题；无内容时相关命令禁用并显示明确原因。
- 修复进入或直接选择图层蒙版后，绘制、框选填充、粘贴和复制没有实时更新灰度合成的问题。
- 修复从外部粘贴或从 Aseprite 复制后取消浮动内容可能残留不可撤销像素，以及未选择图层时仍允许 `Ctrl+V` 的问题。
- 修复框选后按住 Ctrl 复制内容再旋转、移动后再旋转会逐次放大、错位、产生漏洞或抖动的问题。
- 修复 `Ctrl+T` 与 `Alt+点击 cel` 得到的内容选区旋转方向和像素结果不一致；空选区现在也可旋转选框本身。
- 修复旋转后的选框与八个控制点距离过大，控制框现在重新贴合旋转结果。
- 修复矩形与椭圆像素旋转四角偶发孤立像素，并将同一硬边缘旋转逻辑复用于形状工具。
- 修复绘制、吸色或其他指针手势中切换窗口后临时线条、放大镜、系统指针或不可撤销像素继续残留的问题。
- 修复从其他窗口返回 MoonSprite 后按 Alt 偶尔恢复系统本地指针，以及工具快捷键偶尔失效直至重新点击工具的问题。
- 修复吸色放大镜在高画布缩放下反而显示缩小内容、低缩放出现平滑像素、边缘线条瑕疵和失焦后不消失的问题。
- 修复渐变工具在 4000x4000 大画布拖动时连续卡顿；预览计算按屏幕设备像素和缓存覆盖范围执行。
- 修复大画布中框选内容连续按住移动、松开再移动产生卡顿的问题。
- 修复预览跟随开启后无法手动缩放、拖动不关闭跟随、位置跳跃以及内容可完全移出预览视窗的问题。
- 修复移动工具自动定位图层时滚动位置偏上或偏下，改为展开父组后精确滚动到目标行。
- 修复选区移动到画布外后消失或被裁切，以及不同主题下蚂蚁线和控制点颜色不一致的问题。
- 修复画布缩放和平移限制过严或可过量移出视图的问题，统一为四周最多保留 50% 的可移出范围。
- 修复调色板窗口宽度变化导致颜色重新换行、保存本地色板丢失空槽位置、多选移动时选框不跟随的问题。
- 修复颜色编辑器调整单一通道时其他通道一起变化、新颜色尚未确认就覆盖旧颜色、CMYK 模式默认换行和布局错位的问题。
- 修复实际六位 HEX 被错误显示为带 `FF` 的八位值。
- 修复主题中下拉选中、输入框、危险按钮、侧栏和调色盘区域对比不足或使用错误背景色的问题。
- 修复图层、预览、调色板等停靠栏目外层描边在两个栏目交界处缺失、重叠或粗细不一致的问题。
- 修复侧边磁吸区有三个栏目时移出最下方栏目后中间栏目错误补位并留下空格的问题。
- 修复播放、锁、眼睛、文件夹、撤销、重做、保存、导出、选择模式等像素图标缩放后模糊、消失、错位或未居中的问题。
- 修复保存预设无法持久化、导出设置名称与输入框样式不统一、保存路径选择与最近路径失效的问题。
- 修复切换到其他软件窗口再返回大画布时出现明显卡顿，减少恢复焦点时的无效重绘和临时状态恢复工作。
- 修复项目实时保存存在延迟，调试闪退或重开后读取到旧版本文件的问题。
- 修复油漆桶连续复选框右侧残留竖线、首选项恢复默认图标与工具选项图标错位等界面问题。
- 修复方向键移动已框选内容时误改选区外像素的问题，键盘移动现在与鼠标移动使用一致的选区边界。
- 修复菜单、工具属性弹窗和顶部菜单被停靠栏目遮挡，导致部分选项无法点击的问题。
- 修复跨图层、跨帧多选单元格后移动失效、取消选择仍残留高亮，以及帧列或图层列错误显示整行选中背景的问题。
- 修复大画布渐变预览在连续拖动或非整数缩放时出现条纹、错位和异常预览的问题。
- 修复拖动栏目分隔线时画布复用旧缓冲区而短暂产生弹性拉伸的问题。
