# 1.0.0-beta1 完整更新记录

发布日期：2026-08-26

## 新增

- 新增 ISO 视角绘制模式，支持实线网格、像素网格、网格单位、阶数、参考线位置、预览、颜色与透明度设置。
- 新增网格吸附、智能对齐、对齐参考线和阈值设置，移动图层与选区时可对齐画布或其他可见内容。
- 方形框选与形状工具新增圆角；渐变工具新增线性/径向模式和对应的 SVG 像素图标。
- 选区菜单新增转换为图案笔刷和背景预设；选区描边支持复用图层样式，并可在无选区时描边当前图层内容。
- 新增历史栏目，显示当前文档操作历史并与撤销、重做状态同步。
- 缩时视频导出新增 MP4、WebM、PNG、JPG 格式、导出倍率和切片范围，支持取消导出与导出后打开文件夹。
- 首选项新增界面动画级别、视图拖拽灵敏度、取色放大型尺寸、对齐、吸附和更多工具开关。
- 扩展通用 Lua/MSE API、能力探测、脚本事务与示例，补充多语言资源和 API 说明。
- 首页增加连续点击 Logo 后短暂旋转的彩蛋，并提供月相动画示例脚本。

## 优化

- 大画布色彩调整和导出改用可复用缓冲与异步预览，降低重复分配和内存峰值，并改善进度显示。
- 预览栏持续跟随画布的绘制、选区、变换、动画、洋葱皮和透明背景变化，避免显示过期内容。
- 统一弹窗、属性栏、滑块、下拉框和组件库控件的紧凑尺寸、间距、焦点层级与默认布局。
- 统一画布、视图和选区的坐标转换，改善旋转对称、ISO 转折、网格吸附和高 DPI 下的像素对齐。
- 图案笔刷、油漆笔刷、渐变和抖动模板共用覆盖顺序与透明像素规则，透明区域不再错误遮挡底层。
- 快捷指令栏、动画切帧、框选信息和图层多选状态可持久化，新增快捷键配置搜索、添加、修改和删除操作。
- 完善 PSD/GIF、切片、粘贴选区和索引颜色的工程处理，并加强大倍率导出、帧合成和撤销边界。
- 发布检查收敛为按改动范围执行的类型、边界、风险和性能门禁，补充 CSP 主机精确校验。

## 修复

- 修复智能闭合填充对断点判断不稳定、错误扩展到全画布或只生成方块的问题。
- 修复渐变工具在 `Shift`、`Ctrl+Shift`、首笔和转折时错误切换抓手、未按比例或未以中心绘制的问题。
- 修复框选移动、旋转、倾斜、复制和撤销后内容与选框脱离、影响原图层或产生变形的问题。
- 修复旋转对称框选移动时各侧内容分裂，以及多选帧、多选图层和洋葱皮未实时跟随的问题。
- 修复图案油漆笔刷按住 `Shift` 时预览与最终绘制顺序不一致、透明图案像素覆盖底层的问题。
- 修复颜色编辑器弹窗关闭或失焦后滑块失效、工具快捷键被持续拦截的问题。
- 修复数位板光标偏移、系统原生指针残留、窗口双击还原后的缩放指针和标题栏误拖动问题。
- 修复 GIF 导入/导出帧重叠、PNG 大倍率导出内存分配失败、进度停滞以及取消后仍在后台导出的问题。
- 修复 PSD 图层顺序、索引颜色转换撤销、帧删除目标和粘贴选区跨帧内容来源错误。
- 修复预览、棋盘格、画笔预览和画布边界在缩放、平铺或快速移动时出现裁切、裂缝或不同步的问题。
- 修复 Tauri 桌面冒烟检查对 CSP 的校验过宽的问题，现在只接受 `connect-src` 中精确的 `ipc.localhost` 主机。
