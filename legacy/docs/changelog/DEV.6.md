# DEV.6 完整更新记录

发布日期：2026-08-23

## 新增

- 新增自由瓦片图层：源瓦片可在任意像素位置重复、重叠放置，编辑任一源会实时同步全部实例，并支持实例显隐、锁定、排序、不透明度、混合模式、旋转、镜像和独立位置。
- 自由瓦片实例进入图层栏的专用子视图，复用普通图层的选择、多选、眼睛、锁、拖拽、右键、属性和批量删除交互；外层自由瓦片图层继续统一控制动画帧。
- 自由瓦片源编辑支持铅笔、橡皮擦、选区、移动和变换；普通栅格选区可粘贴为新源与实例，也可直接覆盖所选实例的共享源。
- 新建瓦片图层时可创建新瓦片集或复用项目内已有瓦片集；多个瓦片图层可共享同一 Tileset，并同步刷新瓦片编辑、撤销、重做和栅格缓存。
- 新增 PSD 另存为与导出，保留当前帧的图层和图层组层级、名称、显隐、不透明度、受支持混合模式、剪贴关系、锁、蒙版及可映射图层样式。
- 为油漆桶和魔棒新增智能闭合开关与缺口阈值，可在不改写原线条的前提下临时跨接小缺口。
- 多选图层和多选帧可组合成统一选区目标，移动和变换会同时作用于全部有效 cel，并以一个历史步骤撤销。
- 新增动画循环节，可从多选帧创建命名范围，设置起止帧、正反向和有限或无限重复，并以可嵌套括号轨道显示在时间轴标题区。
- 动画播放新增“播放标签并重复”，可跟随当前帧切换到最内层循环节；循环节内新建帧会自动扩展或保留所属范围。
- 基础笔刷新增棋盘、方向和 Bayer 抖动模板；方向模板统一为六个阶段，阶段由共边步进按钮切换，渐变工具同步支持相同阶段。
- 框选期间新增起点、终点和尺寸信息块，底部状态栏实时显示尺寸；首选项可控制信息块显隐和框选预览颜色。
- 画布大小弹窗新增“同步四边”，可让左、上、右、下边距保持同值调整。
- 图层样式新增复制、粘贴、清除和整体启用/停用；支持多选批量应用，以及按住 `Alt` 将样式拖到其他图层。
- 新增受限 Lua 5.4 脚本系统：程序根目录 `scripts` 中的脚本自动显示在“文件 > 脚本”，支持可撤销事务、像素与 Cel 编辑、新建图层或文档、通用对话框和已实现的 Aseprite API 兼容子集。
- 新增 MoonSprite `mse.*` 脚本命名空间、能力探测、文档与选区查询，并提供中英文 API 文档、LuaLS 类型定义和示例脚本。
- 新增可运行 `.msext` 扩展系统，支持安装、启用、禁用、卸载、双击或拖入安装，以及向现有菜单、新顶层菜单和浮动栏目贡献受限 Lua 命令。
- 首页新增版本新闻入口，并与“帮助 > 更新日志”共用最近一次正式打包版本的发布日期、摘要和完整内容。
- 新增关联图层：同组普通栅格图层在每个对应帧共享真实像素内容，任一成员编辑会同步到其余成员，同时保留各自独立的位置和图层属性。
- 动画 GIF 导入会按编码顺序创建时间轴帧与 cel，并尽可能保留帧时长、透明合成、处置方式和循环设置；单帧 GIF 仍可直接覆盖原文件保存。
- 前景色和背景色改为应用级共享偏好，新建、打开或切换项目后沿用最后一次使用的颜色。
- 图层设置新增左右停靠时自动隐藏次要按钮的开关，并提供移动工具点击闪烁时长预设。

## 优化

- 瓦片集栏目统一承载普通瓦片与自由瓦片页面，按活动工程和活动图层自动切换；只有当前工程不再包含任何瓦片类图层时才自动隐藏。
- 自由瓦片源与实例属性改为实时预览和单次历史提交，源尺寸按实际非透明内容动态裁切，实例变换保持显示锚点稳定，并在全部引用帧中同步刷新。
- 自由瓦片实例的选区移动、缩放、旋转、倾斜和复制统一复用正反坐标变换，非正方形源在旋转后使用正确边界，重叠实例可按明确选择避免命中错误。
- 图案笔刷取代“笔刷库”命名，默认基础笔刷合并为一个选择按钮；图案缩略图直接显示透明像素，选中、悬浮和拖动反馈与调色板风格统一。
- 油漆笔刷沿路径按覆盖顺序写入非透明图案像素，透明区域保留下层；`Shift` 直线预览与最终结果共用相同印章中心和覆盖顺序。
- 图层栏完善图层、图层组、帧和 cel 的组合选择，高亮所选图层与帧的交叉单元格，并支持批量属性、样式、排序、复制和删除。
- 图层栏密度预设补充悬浮说明，紧凑调节与设置区统一尺寸；源瓦片和实例属性面板移除保存、取消及重复摘要栏，改为与图层属性一致的即时编辑。
- 预览栏与图层栏共用动画播放状态和设置，播放期间手动切帧不会意外暂停；方向键、逗号和句号停止或切帧时保持单一当前选择。
- 色彩调整实时预览改为从不可变基线写入可复用目标缓冲，减少大画布逐像素对象、重复复制和历史噪声。
- 颜色编辑器分离连续预览与最终提交；脚本或宿主暂时忙碌时保留已打开的编辑器，恢复后可继续调整滑块。
- 快捷指令栏记忆最后一次展开或折叠状态，新项目和下次启动继续沿用，非活动画布的临时收起不会覆盖保存值。
- 弹窗设置区新增统一 `SettingsSection` 组件，标题栏高度、表面、边框、字段列宽、内边距和底部操作区收敛到组件库规范。
- 主窗口启动时先在隐藏状态恢复上次尺寸、位置和最大化状态，再显示最终窗口，避免默认几何到恢复几何的可见跳变。
- 界面缩放与画布缩放彻底解耦，主画布逻辑视口按物理设备像素补偿，`100%` 始终保持一个文档像素对应一个设备像素。
- 开发检查改为按本次文件定向执行类型、边界和风险测试；发布性能门禁覆盖标准画布、800/2048/4000 大画布、复杂动画、选区、工程格式、调整与 bundle。
- 工程格式升级到 v17，依次保存共享 Tileset、自由瓦片源与实例、动画循环节和关联图层共享栅格资源，并为旧版本提供迁移与损坏校验。
- README、贡献入口、脚本与扩展开发资料补充中英文版本，并明确运行时目录、API 能力与安全边界。

## 修复

- 修复最大化窗口调整界面缩放后退出最大化或移动到错误位置的问题。
- 修复界面缩放为 150% 时画布 `100%` 像素出现交替宽度、错位和平滑采样的问题。
- 修复从其他窗口点击 MoonSprite 标题栏时偶发松键后仍吸附鼠标并拖动窗口的问题。
- 修复双击最大化或还原后系统上下缩放指针残留到软件内容区的问题。
- 修复普通图层转换为背景图层后仍停留在原组或层级，现会自动移到根层最底部并与转换一起撤销。
- 修复选择图层组后按 `F` 或调用填充命令会错误写入组内最下方图层的问题。
- 修复多选帧后从画布开始框选或移动会清除帧选择、对应单元格不高亮，以及洋葱皮预览不跟随全部目标的问题。
- 修复帧头选中时 `Delete` / `Backspace` 删除对象错误；帧选择现在批量删除帧，图层多选则批量删除图层。
- 修复自由瓦片源擦除为透明后无法继续绘制、画布扩展区域不能放置实例，以及图像或画布尺寸变化后源与实例坐标不同步的问题。
- 修复自由瓦片源编辑的移动预览比指针落后一帧、选框与内容分离，以及旋转或镜像实例上的选区写回错误的问题。
- 修复自由瓦片预览、瓦片集缩略图和同源实例不能随画布绘制实时更新的问题。
- 修复自由瓦片重叠场景下选中实例后仍命中其他实例、外层移动工具错误选择单个实例，以及锁定或隐藏状态未按图层规则生效的问题。
- 修复普通图层内容不能粘贴到自由瓦片实例、粘贴到已选实例时错误创建新源，以及撤销重做未完整恢复资源引用的问题。
- 修复图案油漆笔刷按住 `Shift` 时预览正确但最终绘制顺序相反，以及透明图案像素错误遮住底层的问题。
- 修复图层样式文本图层调整期间不能实时显示，以及整体停用后样式图标消失的问题。
- 修复播放期间点击其他帧会暂停、按方向键停止后保留多重选择，以及循环节内新增帧落到范围外的问题。
- 修复脚本生成内容撤销或删除后持久对话框目标失效、颜色编辑滑块无法继续操作，以及工具快捷键被弹窗焦点长期占用的问题。
- 修复 PSD 输出图层顺序反转，并阻止 PSD/GIF 进入不支持的逐帧批量导出路径。
- 修复预览栏透明棋盘格在缩放后被降采样进作品缓存而变糊、出现条纹或摩尔纹的问题。
