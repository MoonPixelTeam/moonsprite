# 笔刷与颜色契约

中文 | [English](brush-color.en.md)

## 颜色

- 文档颜色模式固定为 RGBA、索引和灰度。RGBA 允许任意颜色和透明度；索引模式的画布像素只能引用当前调色板中的可见颜色，所有外部颜色按 RGBA 距离映射到最近色板颜色且不得隐式新增颜色；灰度模式保留透明度，并在所有绘制、粘贴、文本和转换写入时按感知亮度转成相等的 RGB 通道。
- 前景色和背景色是应用级独立状态，所有已打开工程共享；在任一工程或调色板修改后，切换到其他工程不得恢复为该工程旧颜色。
- 默认按 `X` 交换前景色与背景色；该命令可在“快捷键设置 > 颜色”中修改或清空。
- 画笔左键使用前景色，右键使用背景色；吸管与调色盘使用同样左右键语义。
- 橡皮擦左键保持透明擦除；右键拖动时仅将当前图层笔刷范围内与前景色 RGBA 完全一致的像素替换为背景色，其他颜色保持不变。该行为继续遵守选区、基础形状或 RGBA 图片笔刷、对称轴和单笔撤销规则，并支持 RGBA 与索引色图层。
- 拖动吸管时对应颜色实时更新。吸管工具也可以从调色板颜色格和调色盘/颜色滑条取色，左键写入前景色、右键写入背景色。
- “按住并点击添加颜色”快捷键默认是 `Alt+S`。单独按下快捷键不添加颜色；保持按住并用左键在画布、调色板或调色盘完成一次取色后，才把最终前景色加入调色板，右键背景色取样不添加。
- 吸管工具属性栏显示当前前景色和背景色，并提供“当前图层替换”和“全局替换”。替换按前景色到背景色的方向进行，只匹配 RGBA 完全一致的像素；全局范围包含全部未锁定图层和动画帧，整次操作只产生一个撤销步骤。
- 吸管工具取色后默认保持吸管；“首选项 > 编辑 > 吸管取色后切回铅笔”开启时，只在正式取色结束后切回铅笔，按住修饰键触发的临时吸色始终返回原工具。
- 调色盘和滑条右键调整背景色时，选择点、滑条和色盘显示必须同步，色相不得跳动。
- 色相吸附和颜色级数改变后，选择点归到当前颜色区域中心，同时保持等效颜色意图。
- 调色板颜色格同时反映前景色和背景色：前景色使用右上角角标，背景色使用左下角角标；左键选择前景色或右键选择背景色都会给被点击的颜色格增加临时蓝色描边，颜色格失焦后只隐藏描边，右键不会改变前景色。
- “调色板操作 > 同步颜色”默认关闭。开启后，编辑色板颜色会按 RGBA 完全一致匹配，替换全部未锁定图层和动画帧中的对应像素，并与色板修改合并为一次撤销；索引模式只修改色板颜色，不改写画布像素 ID。
- 前景色和背景色编辑器标题必须明确标注颜色角色。刚打开时属于临时弹窗，失去焦点自动关闭；标题栏发生真实拖动后转为常驻，可与另一颜色编辑器同时存在。两者分别记忆受最小/最大范围约束的尺寸，但关闭后再次打开必须回到触发按钮附近的默认位置；通道滑条与右侧数值输入框等高，并通过统一八向把手缩放。默认模式顺序为 HSV、RGB、LAB、GRAY、PLT，PLT 使用当前项目调色板；HSL 与 CMYK 可在首选项中启用。右侧吸管按钮取色期间保持弹窗打开，取色结束后恢复进入吸色前的工具。右键 HEX 输入框时读取系统文本剪贴板，合法的六位或八位 HEX 立即写入并应用，非法内容保持当前颜色不变。

## 笔刷类型

- 基础笔刷包括方形、圆形和线条，允许调整尺寸，默认快捷键依次为圆形 `Ctrl+1`、方形 `Ctrl+2`、线形 `Ctrl+3`。工具属性栏使用一个当前基础笔刷按钮，点击后在紧凑弹窗中选择三种形状；选择后立即关闭弹窗并沿用原有工具偏好。基础笔刷右侧提供抖动笔刷按钮，可选择棋盘、方向或 Bayer 模板，并通过共边的左右步进按钮按模板真实矩阵切换离散抖动阶段；左斜线、右斜线、横线和竖线统一使用 6 个阶段，再次点击当前模板会关闭抖动。模板面板初次打开属于临时浮层，拖动标题栏后转为常驻浮窗，点击画布不再关闭，并可通过标题栏关闭按钮收回。图案固定在像素坐标中并自动裁切到当前笔刷尺寸与形状，悬浮预览、直线预览和最终写入复用同一掩码。抖动设置随画笔、橡皮擦与直线各自保存，但只作用于没有选择图片笔刷的基础笔刷。圆形笔刷使用整数硬边缘椭圆扫描线生成掩码，预览与实际落笔复用同一行跨度结果，不使用会让小尺寸圆变成实心方块的连续距离阈值。
- 图片笔刷保留源图片的 RGBA 像素、透明度和原始宽高，不再转换为灰度覆盖率笔刷；宽或高超过 `256px` 时必须在导入或从选区创建阶段明确拒绝，不得静默缩小。
- 裂纹、木纹、颗粒和程序纹理都属于系统纹理，只在油漆桶中出现并按填充区域规则一次生成，避免重复堆叠。静态纹理的“纹理大小”和程序纹理各自的尺寸参数都以画布像素为单位，不能受其他工具残留的笔刷尺寸影响；程序纹理通过独立“抖动”开关在有序像素抖动与阈值硬边之间切换，抗锯齿仍作为单独设置。铅笔、橡皮擦和直线始终忽略系统纹理，但仍可使用图案笔刷中的 RGBA 图片笔刷。
- 油漆桶在矩形或非矩形选区中均只修改真实选区掩码包含的像素；连续与不连续模式遵守相同限制。
- 自定义笔刷可从图片文件导入，或由 `Ctrl+B` 从当前选区创建；两者都保存到程序根目录的 `brushes` 文件夹，不进入当前项目数据、不改变文档 dirty，并使用原始尺寸而不显示尺寸参数。旧工程内嵌的项目笔刷继续可读、可选和可删除。
- 画笔、橡皮擦和油漆桶分别保存基础笔刷设置；非基础笔刷和笔刷模式在可用工具间共享。

## 图案笔刷

- 图案笔刷是默认显示在右侧的正式栏目，可与其他栏目一样停靠到左、右、底部，浮出、调整尺寸、隐藏或通过可配置的弹窗式栏目快捷键呼出；默认弹窗快捷键为 `6`。工具属性栏中基础笔刷旁的图案笔刷按钮使用单击切换栏目显隐。
- 标题栏提供添加、删除和管理按钮。添加可多选 PNG、JPEG、WebP、BMP 或 GIF，也可把图片直接拖入栏目；管理菜单提供三档缩略图尺寸（`30 / 40 / 52 px`），支持 `Ctrl+滚轮` 调整并可打开本地笔刷文件夹。
- 笔刷格完整显示一个 RGBA 笔刷单位，透明像素直接透出栏目背景，不绘制灰白格或替代色；未悬浮时不显示额外底色，悬浮时显示主题悬浮背景，选中时使用与调色板颜色格一致的外框。普通单击替换选择，`Ctrl` 离散增减选，`Shift` 连续选择；当前用于绘制的笔刷在栏目失焦后继续保持选中高亮，只有再次点击该唯一选中笔刷或切换到基础笔刷时才取消。点击笔刷同时把它设为当前笔刷。
- 本地笔刷可按住拖动调整顺序，顺序写入 `brushes/.brush-order.json`；拖到网格末尾空白区域时移动到末尾。`Delete` 或 `Backspace` 删除当前临时选中的笔刷，删除磁盘文件前必须确认；项目内嵌的兼容笔刷按项目数据规则删除。

## 笔刷动态

- 铅笔和橡皮擦分别保存 Ase 风格笔刷动态；大小、绘制强度和颜色渐变可独立映射到压力或速度。铅笔强度表示不透明度，橡皮擦强度表示擦除强度；颜色渐变只应用于铅笔。
- 三类效果输出范围均为 `0..100%`；大小相对基础尺寸计算且最终至少为 `1px`。颜色渐变的 `0%` 是背景色，`100%` 是前景色，正向压力映射越用力越接近前景色。
- 压力设备判定遵循 Aseprite 的设备语义：标准 `pen`/`eraser` 及 Windows Ink、Wintab、stylus 等厂商笔类型可参与压力映射；触控和普通鼠标的兼容默认值（通常为 `0.5`）不参与。若设备被浏览器错误标记为 `mouse`，只有观测到非默认或连续变化的压力样本后，当前指针会话才升级为压感会话；压力轴缺失时按满强度绘制，不会把缺失值当成零压。当前压力曲线仍按既有 `100 * pow(clamp((p - 0.02) / 0.98, 0, 1), 1.7)` 校准，以保持已有笔刷设置和手感兼容。新建压力映射默认输入 `0..70` 并使用硬朗曲线。
- 速度以 client CSS 像素/秒计算，采用时间感知 EMA；首值和直线连接按 `0` 处理，零时间差沿用已有速度，停顿达到 `160ms` 时归零。速度输入硬上限为 `4000 CSS px/s`，新建映射默认使用 `50..2400`。
- 每个映射独立设置输入范围、输出范围、柔和/线性/硬朗曲线及正向/反向。缺失速度按 `0` 解析，因此正向取输出下限、反向取输出上限。
- 首次启用任一笔刷动态映射时自动打开绘制中的笔刷预览；若当前笔刷预览为“无”，切换为“完整预览并显示边缘”以便在绘制过程中观察动态尺寸。悬停时预览使用当前基础尺寸，绘制中实时使用当前动态采样尺寸，不再固定为 `1px`。用户之后手动关闭预览时，调整已有映射不会再次强制开启。
- 动态渐变可独立选择与渐变工具相同的九种抖动模式。方向类抖动统一使用 6 阶矩阵；每个最终文档像素按绝对坐标解析抖动阈值，`none` 直接插值 RGBA，其余模式在两个 RGBA 端点之间抖动。透明端点沿用 Aseprite 的非预乘颜色规则，并以当前目标像素为底进行 source-over 叠加；完全透明样本不会把底层像素直接替换成透明色，同一笔绘制自交时也不会用透明样本覆盖本笔已经留下的像素。
- 固有尺寸的自定义笔刷忽略大小映射，但仍应用强度和颜色渐变。启用渐变时保留 imageBrush 的形状、源 alpha 与 coverage，RGB 改用当前动态色；未启用时继续输出笔刷自身颜色。橡皮擦与右键前景色替换不受颜色渐变影响。
- 合并指针事件与完美像素路径保留大小、强度及渐变 amount/端点/抖动描述；长线段在起止采样之间插值。动态 size 在尺寸空间使用包络限制：每个栅格步最多变化 `max(1, ceil(baseSize / 6))`，跨多个栅格步时按距离成倍增加；首点直接使用目标尺寸。
- 动态 size 的盖章间距按每个候选点的实际尺寸和距上次盖章的累计路径步数判断；只要整数尺寸相对上次实际盖章发生变化，该候选点必须盖章，尺寸稳定后才应用 spacing。首尾必画、零长度只画一次，raster 与 balanced 使用相同规则。
- 除带透明 stop 的动态渐变外，同一笔中重复命中的像素始终基于笔触前颜色和已达到的 coverage 重算，事件密度不得导致透明度或动态颜色重复堆叠；带透明 stop 的动态渐变以当前目标像素 source-over，索引色模式复用相同调色板颜色，不持续生成重复色。
- 实时 pressure/speed telemetry 只通过每帧最多发布一次的内存通道传递，不进入 Workspace、session、dirty、撤销、恢复或保存数据；指针悬停与绘制均发布，离开画布或卸载时变为 inactive，停止 `160ms` 后速度显示为 `0`。
- 旧压感设置、v2 与 v3 动态设置自动迁移为 v4；v2/v3 的渐变抖动固定迁移为 `none`。v2 工厂压力/速度映射迁移到新默认输入范围，用户自定义映射保留；v4 的映射和抖动按铅笔、橡皮擦分别保存在本地工具偏好中，不进入 dirty 或撤销，一次完整笔触仍只提交一个像素编辑和一个撤销步骤。

## 对称绘制

- 铅笔、橡皮擦、形状和油漆桶共享上下、左右、右上到左下、左上到右下与旋转对称图标按钮；各模式可任意组合，并随工具设置持久化。
- 每个工程中的每种对称轴第一次由关闭切换为开启时，共享对称中心使用当前画布中心。该轴之后重复开关不会再次移动中心，首次启用另一种尚未使用的轴时会重新定位到当前画布中心。辅助轴使用可调整颜色、透明通道和粗细的实线；未锁定时，指针悬停在中心点或轴线上显示移动指针，拖动中心点可同时移动所有轴，拖动单条轴时沿该轴法线调整共享中心，位置吸附到半像素。更多菜单可锁定轴线、调整外观或将轴心重置到当前画布中心；轴心修改属于工具状态，不进入文档撤销历史。
- 水平轴反射上下内容，垂直轴反射左右内容，两条斜向轴分别沿右上到左下与左上到右下反射；矩形画布中斜向结果超出画布时直接丢弃。
- 笔刷像素、颜色、透明度、图案和形状先生成原始结果，再使用统一坐标映射反射。多个轴生成同一目标像素时必须去重；预览、缓存失效范围和最终写入使用同一组目标。
- 对称开启时，笔刷预览只显示鼠标所在的原始落点，不在镜像位置重复显示；实际绘制仍写入全部镜像位置。
- 油漆桶先对种子点生成去重后的镜像种子，再分别执行相同的连续或不连续填充规则；所有区域合并为一次像素编辑和一次撤销。

## 自定义笔刷颜色

- 普通导入图片始终保留源 RGBA，多色和半透明像素不得因前景色或背景色变化而重映射。
- 从选区创建的笔刷首先保留原始多色图案；之后用户改变颜色时，浅色映射为前景色，深色映射为背景色，透明像素保持透明。
- 从选区创建并成功写入本地图案笔刷后取消原选区、自动切换到铅笔并立即选择该笔刷；写入失败时保留原选区和当前工具。

## 选区转换

- 顶部“选择 > 转换为”在存在选区时提供“图案笔刷”和“背景预设”。图案笔刷沿用本地图案笔刷创建规则；背景预设捕获选区内当前画布的可见合成结果，非矩形选区外保持透明，并保存到程序根目录的 `BackgroundPresets` 文件夹。保存背景预设不清除选区、不修改工程 dirty，也不进入文档撤销历史。

## 图案模式

- 油漆笔刷是新建和重置工具配置的默认模式，并排列在模式列表首位；已有版本化配置中用户明确选择的模式继续保留。
- 三种模式使用统一主题下拉，并在选项内直接说明平铺原点或盖章行为；详情预览应显示自定义笔刷保存的原始多色像素，不得无条件改成单一前景色。
- 图案与来源对齐：平铺坐标固定在笔刷来源坐标系，同一画布位置始终得到同一图案。
- 图案与目标对齐：同样平铺，但第一笔落点作为平铺原点；预览必须与实际落点重合。
- 油漆笔刷：以覆盖模式沿路径依次替换每个落点的非透明图案像素，后落下的笔刷完全覆盖先前落点；图案中的全透明像素不修改底层。
- 使用 `Shift` 连接直线时，预览与确认必须复用相同的印章中心和覆盖顺序。

## 渐变工具

- 渐变属性栏使用相连按钮选择“线性”或“径向”，并与容差、连续区域和抖动设置一起保存到本地工具偏好；旧偏好默认迁移为线性。
- 线性渐变把起点到终点作为颜色投影方向。径向渐变把起点作为圆心、起点到终点的距离作为半径；同一距离的像素必须得到同一颜色，半径外固定使用终点颜色。
- 平滑插值与全部抖动模式共享同一线性或径向 amount。画布实时预览、自由瓦片源编辑和最终像素提交必须使用同一模式、端点和取样函数，并保持一次撤销。

## 喷枪

- 喷枪按下时立即产生一批粒子，持续按住时按“粒子频率”设定的毫秒间隔继续产生；指针静止时也必须持续喷涂。
- “粒子半径”控制单个粒子的像素半径，“散布半径”控制粒子围绕指针均匀随机出现的圆形范围，“粒子密度”控制每批粒子数量。
- 喷枪沿用前景色/背景色、选区、图层蒙版、索引色和对称轴规则。一次完整按住只提交一个像素编辑和一个撤销步骤；取消、窗口失焦或切换窗口时撤销尚未提交的整次喷涂。
- 定时喷涂使用单一帧调度器，不得按指针移动事件频率产生粒子，也不得在卡顿后无限补发积压批次。

## 预览

- 预览形状和实际写入掩码必须来自同一数据。
- 开启平铺模式后，铅笔、橡皮擦、直线、形状、渐变、喷枪和瓦片绘制的实时像素、边缘及操作线预览必须同步显示在全部可见平铺副本；笔刷轮廓保持原始连续几何跨过接缝，颜色采样按启用轴折回原画布，越界部分不得被裁断或错误重组。鼠标指针本身仍只显示一份。
- 笔刷预览样式由“首选项 > 工具预览”控制，默认使用完整预览，可选择无、仅显示边缘、完整预览或完整预览并显示边缘；只有选择“完整预览并显示边缘”时才显示“绘制时显示笔刷边缘”，用于控制按住绘制时是否继续显示边缘轮廓。
- 画笔和橡皮擦的直线连接修饰键在快捷键设置中配置；“首选项 > 编辑”的实时预览开关只控制按住修饰键时是否显示临时线段，不改变松开后实际绘制结果。翻转内容等已确认命令必须清除旧直线锚点和预览。
- “首选项 > 编辑 > 直线算法优化”默认开启。开启时，直线连接和多边形套索边界把主轴像素均匀分配到长度相近的阶梯段；反向连接必须得到同一像素集合，预览和最终结果必须复用同一算法。关闭后回退传统栅格直线。
- 直线连接期间触发“约束直线方向”组合（默认 `Shift+Ctrl`）时，终点吸附到离指针最近的允许方向。首选项中的“直线斜向阶梯数值”为 `1` 时提供水平、垂直和 45° 共 8 个方向；大于 `1` 时按 `N:1` 与 `1:N` 像素阶梯提供 12 个方向，其中数值 `2` 对应约 30°、60°斜向。约束终点必须落在完整阶梯周期上，使起始阶、所有中间阶和结束阶都严格包含 `N` 个主轴像素；预览与最终落笔使用同一个约束终点和点列。
- 铅笔工具选项栏中的“阶梯”输入框直接编辑同一个“直线斜向阶梯数值”，范围为 `1–16`；修改后立即作用于画布并持久化，与首选项中的设置双向同步。
- 已经绘制的直线锚点算作起始阶的第一个像素；例如阶梯数值为 `6` 时，锚点与其后五个主轴像素共同组成第一阶，不得额外生成第七格。
- 连续使用直线连接绘制半透明颜色时，各段共享同一笔触前的像素底色；连接点和后续交叉处不得因新线段再次叠加透明度，同时每段仍保持正确的撤销范围。
- 非基础笔刷调整参数时不得闪烁基础圆形或方形预览。
- 指针黑白对比依据指针下最终合成画面，包括预览颜色，而不是当前图层或准备绘制的颜色。
