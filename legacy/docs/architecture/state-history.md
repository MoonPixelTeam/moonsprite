# 状态与历史契约

中文 | [English](state-history.en.md)

## 状态分类

MoonSprite 状态分为五类：

| 类型 | 示例 | 持久化 | 进入撤销 |
| --- | --- | --- | --- |
| 文档内容 | 像素、图层、图层样式、图层蒙版、调色板、项目笔刷、动画循环节、Tileset、Tilemap 格子、自由瓦片源与实例 | 工程文件 | 是 |
| 临时编辑 | 浮动粘贴、正在绘制、变换预览 | 仅会话 | 确认后一次进入 |
| 项目显示元数据 | 像素网格开关、自定义网格开关与参数 | 工程文件 | 否 |
| 视图状态 | 平移、缩放、旋转、镜像、平铺预览、蚂蚁线显隐、快捷指令栏水平比例与展开状态 | 工作区或本地设置 | 否 |
| 应用状态 | 当前工具、弹窗、栏目布局、首页栏目 | 本地设置或工作区 | 否 |

前景色与背景色属于跨工程共享的应用状态；修改后写入本地设置，新建或打开任意工程时沿用最后一次使用的两种颜色，不写入工程文件或文档撤销。主窗口普通尺寸、位置和最大化状态同样写入本地设置；桌面启动时必须在原生窗口仍隐藏时完成恢复，再一次性显示最终窗口，避免默认尺寸到恢复尺寸的可见跳变。

已安装扩展列表、扩展目录、启用/禁用状态、声明式栏目显隐与位置和安装临时状态属于应用平台或本地界面状态，不属于任何 `.moonsprite` 文档；安装、替换、启用、禁用、栏目布局和卸载不得进入工程 dirty 或文档撤销历史。扩展安装失败时 staging 必须清理并保留旧版本。

动画帧、cel、每帧时长、全时间轴循环方式和命名循环节属于文档内容；循环节使用稳定帧 ID 保存端点，创建、编辑、删除以及因端点帧删除产生的范围收缩都进入文档历史。当前帧、播放/暂停、播放倍率、开始播放时的帧、停止返回开关、播放范围模式、当前循环节播放目标、标签强制重复标记和已完成次数属于会话状态。切帧与播放状态变化不得改变 dirty 或写入撤销历史；帧重排不重写循环节端点，删除端点帧时范围收缩到相邻存活帧，删除单帧循环节的唯一帧时移除该循环节。
图层可见性与锁定属于文档内容；活动图层、图层栏多选、选择锚点和组展开状态属于不进入撤销的界面上下文。界面上下文按工程路径即时写入本地存储，并在正常保存工程时作为可选元数据写入文件；本地记录优先恢复最近一次会话，失效图层或组 ID 必须过滤，且恢复过程不得改变 dirty。

关联图层使用稳定 `linkedContentId` 把普通栅格图层组成文档级关联组。每个对应帧只保留一份权威栅格存储，组内图层与其 cel surface 共享该存储；图层或 cel 的画布偏移、名称、父组、显隐、锁定、不透明度、混合模式、图层样式、描述和显示颜色仍由各成员独立持有。运行时同步必须按稳定存储原点保留每个成员自己的画布锚点，不能通过复制像素数组模拟同步，也不能把独立位置写回共享内容。像素历史只记录一次实际内容差量，但失效范围覆盖关联组全部成员；创建关联图层是一个结构历史条目，撤销同时移除新成员并恢复来源原关联身份，重做恢复每帧共享存储。普通重复与同工程粘贴沿用原 ID；跨工程粘贴按复制批次重映射新 ID。转换为背景、文本、Tilemap 或自由瓦片前必须先把目标成员的每帧内容克隆为独立存储，再移除关联身份，避免修改其他成员。

图层蒙版是附着在单个动画 cel 上的独立灰度文档表面，图层组蒙版则以 `groupId + frameId` 附着在图层组当前帧的合成结果上；透明像素表示未绘制且不改变所有者的显示。活动蒙版 ID 只属于会话选择状态。蒙版像素编辑进入文档历史并绑定所属 `frameId`，撤销、重做和渲染失效只针对该帧。新建和删除蒙版分别形成一个结构历史条目；切换帧或普通选择图层、图层组、cel 时退出蒙版编辑。

Tilemap cel 的 `tilemap.cells` 是可编辑源，`surface` 是供普通合成、预览和导出复用的派生栅格缓存；Tileset 由文档持有并通过稳定 Tileset/瓦片 ID 被格子引用，多个 Tilemap 图层可以通过同一个 `tilemapTilesetId` 共享它。新建 Tilemap 图层时，选择已有 Tileset 只新增图层和空白格子，不复制或重建 Tileset；未选择时才创建新的透明首瓦片 Tileset。Tileset 的 `tileSlots` 是允许空位的栏目布局文档数据，移动槽位形成一个只恢复布局、不重写图集像素或格子引用的历史条目。整格绘制记录首次修改前和最终修改后的格子值；新增瓦片与修改瓦片还会同时记录笔划前后的 Tileset 快照，并和格子引用合成一个内容历史条目。共享 Tileset 的编辑、撤销和重做必须同步恢复所有引用图层的栅格缓存；删除图层只在没有其他 Tilemap 或格子引用时清理 Tileset。当前 Tileset、瓦片与“原位编辑 / 变体创建 / 混合编辑 / 绘制瓦片”模式属于会话状态，平铺预览模式属于视图状态，均不进入文档历史。

自由瓦片图层通过 `freeTileSources` 拥有一组稳定源 ID；每个源独占一个只含单瓦片的 Tileset，并保存名称、描述、显示颜色、显隐、锁定、不透明度、混合模式和源偏移。cel 的 `freeTiles.instances` 按合成顺序保存稳定实例 ID、`sourceId`、本地像素锚点以及可选的 `visible`、`locked`、不透明度、混合模式、整 `90°` 旋转和水平/垂直镜像状态，`surface` 只是派生缓存。任意像素放置、擦除、删除单个实例、移动单个实例或修改实例属性都以实例列表的前后快照形成一个历史条目；旋转或镜像属性提交时同时保存维持显示外接框左上角所需的锚点补偿。“仅显示”使用当前 cel 实例列表的单个前后快照批量切换显隐；眼睛或锁的 `Alt` 批量切换及按住跨行手势通过图层面板复合事务把全部行变化合并为一个历史条目。锁定实例拒绝位置、排序、变换和删除操作，但允许显隐切换。源编辑以单个源的尺寸、像素和偏移前后快照形成一个历史条目，并在预览、撤销和重做时重绘同一自由瓦片集合中全部图层、全部帧的引用；当前实例选择只决定重叠场景下的源编辑坐标锚点与临时栅格朝向，不拆分源，也不改变全部同源实例同步刷新的语义。实例选区变换在按实例朝向生成的临时源栅格中执行，预览持续逆向写回同一个规范源；确认时将源快照、选区掩码和自定义轴心的前后状态合并为一个历史条目，取消时恢复源快照而不留下派生 surface 修改。新源第一次编辑与第一次实例放置合并为同一历史步骤。普通栅格选区粘贴在没有实例选择时把本次新增源、独占 Tileset 和实例列表合并成一个历史条目，撤销先恢复实例再移除新增资源，重做先恢复资源再恢复实例；存在实例选择时则复用单源像素与偏移快照，只更新该实例引用的共享源并保留实例列表和资源数量。普通动画 cel 不进入该转换路径。源属性与实例属性使用绑定文档 ID 的实时预览事务：输入期间只替换预览并刷新引用，不改变 dirty 或写入历史；实例属性事务允许持有同一活动 cel 中的多个稳定实例 ID，只对弹窗中实际修改的字段从同一份基线快照批量计算，关闭时以一份 cel 前后快照提交一个历史条目。关闭弹窗时先恢复打开前基线，再把最终状态提交，撤销必须恢复可选字段的缺省状态以及源 Tileset 的原名称；切换文档或意外卸载则无历史地恢复基线。当前源选择、当前主实例、实例多选 ID、范围选择锚点、前景/背景源与放置/源编辑模式属于会话状态，共用瓦片集栏目的页面与显隐属于应用状态，图层栏实例子视图的打开状态也属于界面状态，均不进入历史；实例子视图不拥有独立时间轴，行内容只来自外层自由瓦片图层的活动帧文档数据。删除、复制、跨文档粘贴或撤销自由瓦片图层时，必须同步维护每个源 Tileset、重映射所有 `sourceId` 并清理孤立资源，同一 `freeTileSetId` 集合的图层共享源与 Tileset，源修改须同步全部成员；集合之间和 Tilemap 之间不得共享源所有权。

图层样式是跨帧共享的图层或图层组文档属性。弹窗实时预览可以临时替换当前样式并刷新合成，但不得改变 dirty 或写入历史；应用时先恢复打开前基线，再把最终样式作为一个内容历史条目提交，取消、切换文档或意外卸载必须恢复基线。撤销和重做只切换样式参数并触发完整合成失效，不修改 cel 表面，也不触发活动帧表面同步。交互绘制的局部失效区域必须按当前所有者样式及祖先图层组样式逐级扩展。仅栅格化文本时沿用现有 cel 表面和蒙版，只移除文本元数据；栅格化启用了样式的图层时，历史只保存受影响图层、cel、样式和蒙版的领域快照，先为每帧生成包含当前蒙版结果的样式外观，再解除 cel 链接并移除文本、样式和蒙版数据，避免链接帧被重复烘焙。

项目显示元数据和缩时录制设置会随工程保存并改变 dirty，但不进入撤销历史。编辑统计和缩时快照只在已提交文档操作后更新；全程录制保留每次内容操作的等权画面，智能采样按时间分布和变化程度精简较早记录并保留近期变化。画面在操作提交时捕获，PNG 编码可以排队完成；不按现实时间给停顿加权。切换录制模式本身不删除旧记录，清空和智能采样均不回收本地录像库。视图导航、栏目操作、录像预览和导出不增加笔画数或生成缩时帧。

图层或蒙版轨道的 `autoLinkAnimationCels` 开关作为文档内容保存，用于自动关联动画单元格，与跨图层的 `linkedContentId` 不同；修改该属性使用对应 Store 历史命令。固定绘制锚点、显示状态和中心绘制开关属于工具偏好，不进入文档历史。

## 文档事务

- 所有文档写入和历史提交由 Store 领域命令或 `begin/update/commit/cancel` 事务拥有。组件不得直接修改 `SpriteDocument`、`DocumentSession`、像素、dirty、revision、invalidation 或缓存版本，也不得调用 `pushHistory` 或直接控制 `HistoryStack`。
- Lua VM 只操作活动普通像素图层、当前选区和 `mse` 结构数据的独立快照，并返回按执行顺序排列的像素差量、Cel 表面前后快照、受限的新图层/新文档结果或类型化 `mse` 操作。Renderer 在初始执行应用前校验原文档 ID、revision、活动图层、活动帧、格式、尺寸、位置和原始像素；持久对话框回调前先确认文档、图层和帧身份未变，再把 VM 与 Renderer 目标令牌同步到当前 Cel 表面、结构快照和 revision，因此同一目标上已经提交的编辑、撤销或重做可以成为下一次回调的新基线，但回调返回仍必须与该新基线完全匹配。每个 `app.transaction` 以复合历史把像素、选区、图层、调色板、循环节、瓦片、切片和样式等文档操作合并为一个历史条目，事务外修改按脚本名称形成批次；任一类型化文档操作失败时，已经应用的同批历史项必须逆序恢复且不得留下历史条目。新建或打开 Sprite、保存、导出、导入本地资源、通知和栏目布局属于明确的文档外操作，不承诺进入该撤销原子。脚本取消、未捕获错误、超限、无效结果、关闭会话或目标过期均不得改变原目标文档、dirty、revision 和历史。
- `begin` 捕获最小基线和目标身份；`update` 只维护事务预览；`commit` 统一生成一次历史、dirty、动画同步和缓存失效；`cancel` 无历史地恢复基线。
- 事务必须绑定文档 ID，并对确认、取消、文档切换和组件卸载都有确定结束路径。过期事务不得写入后来激活的文档。
- dirty、文档 revision、内容 revision、结构 revision 和失效提示由事务或领域命令集中推进，调用方不得手工拼接这些副作用。
- 组件直写、工程快照历史和根 Store 命令债务当前预算均为 0；`pnpm check:architecture` 对任何重新引入立即失败，不提供按文件豁免。

## 历史规则

- `HistoryStack` 对界面只暴露按时间顺序排列的操作标签、可到达总长度和当前位置；历史记录栏目必须通过 Store 领域命令跳转，并复用现有 Undo/Redo 的同步、失效和临时状态处理，不得在组件中直接调用历史条目的回调或修改历史栈。回到较早位置后，未来分支保留为可重做记录，直到新的文档编辑清除该分支。
- 每个历史条目必须包含恢复前后状态所需的最小领域数据；`encodeProject` 和 `decodeProject` 不得用于撤销快照，历史模型不得依赖工程格式版本。
- 关联图层的像素历史以共享存储为唯一内容权威，同一差量不得按成员数量重复记录或重复应用；撤销、重做、预览确认和结构恢复后必须重新建立对应帧的共享身份，并让渲染失效覆盖所有关联成员。
- 连续拖动、画笔笔划、复制并移动等一次手势只产生一个历史条目。
- 自由形状、多边形形状、自由套索和多边形套索在完成前使用独立的手势级 Undo/Redo 栈；手势仍存在时，中间路径点可回退和恢复，并优先于文档 Undo/Redo。最后一个路径点被撤销时视为取消该临时手势，下一次 Undo 继续处理文档历史。该临时栈不改变 dirty，完成后丢弃并只把最终结果作为一个文档历史条目提交。
- 调整画布尺寸弹窗打开期间，Undo/Redo 由该弹窗独占并且不得穿透到文档历史；只有本次弹窗内已经形成的画布边界线或数值预览位置可以撤销、重做。即使预览栈已到起点或终点，命令仍须被弹窗消费。确认后只把最终画布尺寸作为一个文档历史条目提交，取消则丢弃全部预览历史。
- 移动工具同时移动图层与已有选区时，两者属于同一次手势和同一个历史条目；Undo/Redo 必须同步恢复图层偏移和选区位置。
- 取消操作不得产生历史条目或 dirty 状态。
- 除进行中路径手势的临时栈外，Undo/Redo 仅改变文档历史，不能撤销平移、缩放、旋转、镜像或工具切换。
- 保存成功后记录当前历史位置为保存点；回到保存点时 dirty 应恢复为 false。
- 同一工程的保存请求必须串行写入；保存期间发生的新编辑不得被较早完成的写入误标为已保存，也不得删除这些新编辑对应的恢复数据。用户再次保存时必须在前一次写入完成后继续保存最新修订。
- 无历史可撤销或重做时，命令必须成为无副作用操作。

## 持久化与恢复

- 保存格式、恢复格式和撤销历史是三个独立边界。文件格式迁移不能改变历史语义，历史重构也不应要求重写工程容器。
- 一次工程打开只允许一次完整解码；初始合成、首帧缓存和缩略图准备必须复用该文档，不能再次读取同一归档做后台完整解码。
- 标记为异步的工程保存、恢复和编码任务不得在派发 Worker 前同步遍历、复制、预览合成或压缩整份文档。主线程只创建轻量请求和可转移资源描述。
- 未修改图层与 cel 的归档块应复用；变更资源单独准备。保存成功后才接受新基线，失败时旧基线和 dirty 状态保持有效。
- 恢复写入、读取和清理失败必须上报到日志、状态或调用方。后台恢复可以不中断当前编辑，但不得用空 `catch` 静默丢失失败信息。

## 临时状态提交

- 浮动粘贴在切换文档、保存或开始不兼容操作前必须明确提交或取消。
- 实时预览只改变派生显示，不反复写入历史。连续滑块输入按动画帧合并，同一帧最多计算一次，并在应用时使用最后一个输入值。大像素调整预览不得构造逐像素 `PixelEdit`/`Map` 或每帧重复复制基线；必须从不可变基线直接写入可复用目标，只在确认时捕获一次最终历史状态。
- 调整弹窗确认时写入一次历史；取消时恢复原数据。
- 调整快照可以包含多个目标图层及共享调色板；无选区时全部选中图层组成一个复合历史，有选区时只记录活动图层。选区加选或减选在手势提交前保持原预览，提交后才按新选区重算；移动、缩放、旋转和倾斜必须编辑未调整基线，同时用独立临时显示保持原调整参数的连续效果。数值和效果不得归零、闪回或在调整预览像素上重复叠加。
- 调整确认与其前后的画布操作必须分别写入历史队列并按时间顺序逐项撤销；只有同一次连续手势内部的像素、选区和结构变化允许组成单个复合条目。
- 画布尺寸弹窗的边界拖动只更新 `canvasResizePreview` 临时状态，不进入文档历史；确认尺寸后才创建一个包含画布尺寸、图层偏移和选区的历史条目。
- 带实时预览或草稿的调整弹窗必须区分提交与取消：`Enter` 或明确确认提交一次，`Esc`、关闭按钮和遮罩取消并恢复打开前状态。图层属性、自由瓦片源属性和实例属性属于实时属性面板：输入时无历史地预览，`Enter`、`Esc`、关闭按钮或遮罩关闭时保留最终值并只提交一个历史条目；切换文档或组件意外卸载才取消事务并恢复打开前状态。全局 `Esc` 使用定向关闭事件，每次只关闭当前最上层弹窗或浮层；未命中的笔刷、工具、项目标签和栏目浮层不得被顺带关闭。
- 快捷键设置在弹窗内使用草稿；只有点击“完成”才持久化，关闭或 `Esc` 不得保存未确认修改。首选项的“应用”是唯一保存但不关闭窗口的设置命令。
- 图层 Alt 拖动复制与最终移动共同组成一个事务。
- 跨文档粘贴多层或嵌套图层组时，整批新增结构组成一个历史条目；一次撤销必须同时移除所有新图层和新图层组并恢复原选择。
- 所有图层组只要具有有效 `panelOrder`，都优先以该锚点参与图层栏排序，不因组内是否有子图层而改变。拖拽更新与撤销必须同时恢复父组、组顺序、图层顺序和该锚点。
- 从首页恢复草稿成功后必须进入对应文档会话，并在会话中保留恢复来源标记；打开、关闭会话或选择放弃都不得删除原恢复记录，再次自动恢复使用同一恢复记录 ID 原子覆盖。只有恢复栏目的显式删除命令或对应项目完整保存成功后才能进入恢复清理队列；保存期间若又产生新编辑则继续保留恢复。恢复失败时保持恢复记录并停留在首页。恢复保留天数属于应用首选项，平台在每次启动读取恢复列表前按恢复记录更新时间成对清理过期元数据与工程数据；该清理与文档 dirty、撤销历史和上次会话是否异常退出无关。
- 普通保存、首次保存和另存为在文件路径确认后都显示紧凑进度反馈；保存成功后进度弹窗自动关闭，取消原生文件选择器时不显示进度。

修改历史模型时必须覆盖 dirty 保存点、跨文档隔离、Undo/Redo 边界和失败回滚测试。
## 历史实现不变量

`HistoryStack.memoryBytes` 必须始终等于当前 undo 栈中所有条目的 `bytes` 之和。成功 `undo` 后扣除条目大小，成功 `redo` 后重新计入；执行回调抛出异常时，两边的栈和内存计数都保持不变。

设置、窗口布局、栏目停靠、视图平移缩放旋转属于应用或视图状态，不得写入文档撤销历史。工程内容、图层、选区和会影响保存结果的编辑操作才进入历史。
