# ADR-0007：逐帧可编辑图层与图层组蒙版

中文 | [English](0007-attached-layer-masks.md)

## 状态

已接受

## 背景

MoonSprite 把动画像素保存在逐帧 Cel 中。蒙版必须遵循相同的帧所有权、可独立编辑、保留初始空表面，并复用现有栅格工具，同时不能成为图层树中的普通图层。

## 决策

- 为每个动画 Cel 附加可选蒙版表面。图层组使用逐帧 `groupMasks` 条目，使蒙版可以随帧变化而不成为普通图层。Cel 和图层组右键菜单负责创建或删除蒙版。
- 复用 RGBA 栅格管线，但把绘制像素规范化为不透明灰度。透明像素表示“未绘制”，在合成时为中性；白色显示、黑色隐藏、灰色按比例缩放源 alpha。
- 在工程 schema v4 中把完整的“灰度 + 透明”表面保存在 `masks/` 下。读取器也接受早期单字节灰度草案，并将其视为不透明蒙版，以保持开发期兼容。
- 活动蒙版 ID 保存在文档会话状态中。像素历史记录所属 Cel 的帧 ID，因此失效和撤销只作用于该帧。
- 帧与图层复制会分别克隆每个 Cel 蒙版并生成新蒙版 ID。蒙版可以通过 `linkedMaskId` 独立引用另一个蒙版；Cel 链接会创建对应蒙版链接，而仅蒙版的链接、取消链接、复制、粘贴和移动操作绝不改变图像 Cel 表面。

## 结果

绘制、填充、形状、选区变换和像素历史都可以通过共享的活动绘制表面解析器编辑蒙版。切换帧会退出蒙版编辑。时间轴保留原 Cel 或图层组行，并在其正上方插入专用蒙版轨道。蒙版轨道单元格与普通 Cel 使用相同的标记尺寸和间距。工程读取器会拒绝缺失、重复或格式错误的蒙版资源。

## 替代方案

拒绝在图层或图层组上使用静态蒙版，因为它们无法随帧变化。也拒绝把蒙版表示为普通图层，因为这会让蒙版受到不适用的图层排序、分组、混合和导出语义影响。
