# 0018：动画循环节使用稳定帧端点

中文 | [English](0018-animation-loop-sections.en.md)

## 状态

接受

## 背景

用户需要把时间轴中的连续帧保存为可命名、可反向、可限制重复次数并可独立播放的循环节。循环节必须承受帧重排、删除、撤销和工程重开，同时不能引入第二套播放计时器或把当前播放进度写入文档历史。

## 决定

- 循环节作为 `AnimationTimeline.loopSections` 文档数据保存，使用稳定循环节 ID、稳定起止帧 ID、名称、方向和重复次数描述。
- `.moonsprite` 升级到 schema v16；v1-v15 迁移为空循环节列表，不读取旧版本中的同名未知字段。
- 帧重排只改变端点在时间轴中的位置，不改写端点身份。删除端点帧时收缩到范围内最近的存活帧；单帧循环节失去唯一帧时删除。
- 创建、编辑、删除循环节以及包含循环节变化的帧删除进入最小文档历史；播放目标、开始播放前的帧和已完成次数保存在 `DocumentSession`，不改变 dirty。
- 独立播放复用公共动画播放时钟和现有帧持续时间。有限循环在终止帧完整显示后停止，无限循环持续回到方向对应的首帧。

## 结果

循环节可以跨帧结构变化保持稳定，并与工程保存、撤销和时间轴 UI 使用同一份数据。图层栏、预览栏和未来其他播放入口仍由唯一时钟推进，不会因新增循环节重复计时。

## 替代方案

保存帧下标会在插入、删除和排序后指向错误内容；为每个循环节创建独立计时器会导致多个栏目重复推进帧，因此均不采用。
