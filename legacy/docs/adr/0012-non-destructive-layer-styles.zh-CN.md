# ADR-0012：非破坏性图层样式

中文 | [English](0012-non-destructive-layer-styles.md)

## 状态

已接受

## 背景

描边、阴影、内发光、颜色叠加和渐变叠加必须跨动画帧保持可编辑，且不能改写 Cel 像素。MoonSprite 已把图层不透明度、混合、蒙版、剪贴和颜色模式视为合成器职责，而工程格式把 Cel 表面与共享图层元数据分开保存。

## 决策

- 工程 schema v11 在栅格图层与图层组上保存可选的规范化 `layerStyles` 对象。图层属性由该图层所有帧共享；图层组属性由其逐帧合成共享；单独 Cel 不拥有独立图层样式。
- 合成器在所属对象的图层或图层组蒙版之后计算样式。阴影与外描边形成背景层，随后颜色叠加、渐变叠加、内发光以及内描边修改可见源内容，最后再应用所属对象的不透明度、混合模式和剪贴。描边位置可以为内部、外部或两者；描边核与八方向滤镜复用破坏性“描边”命令的同一套规范化轮廓几何。智能色相为每个外描边像素解析最近的可见源像素，为每个内描边像素使用当前可见源像素，再统一降低 RGB 通道亮度以保留色相。智能阴影把暗度系数表示为黑色 alpha 叠加，因此普通合成会统一缩放每个实时背景 RGB 通道，并随背景变化而变化，无需持久化采样颜色。
- 渐变叠加复用渐变工具的纯颜色插值和抖动核心，包括相同的平滑、Bayer 与方向模式。UI 选择器和像素预览共用，不维护独立的图层样式模式列表。
- 索引和灰度文档通过普通画布写入所用的同一套文档颜色规则解析已存储和动态生成的样式颜色。样式计算绝不新增索引调色板条目或修改源栅格数据。
- 弹窗更改使用可逆预览路径，刷新派生合成但不把文档标记为 dirty，也不新增历史。应用时先恢复原始基线，再把最终设置提交为一次可撤销内容操作；取消时恢复基线。
- 启用效果的图层和图层组行显示样式标识，可重新打开弹窗。图层/图层组复制、内部图层剪贴板操作、动画预览和工程编码都会深拷贝样式设置。schema v1-v10 工程迁移时不带样式，也不会把未知草案字段解释为 v11 数据。
- 交互式画布失效区域会通过所属对象效果和每个带样式的祖先图层组扩展已编辑源区域，使绘制预览刷新完整受影响输出，而不强制无关的整画布重绘。

## 结果

一次样式编辑会更新所有动画帧，而 Cel 像素仍可独立编辑。带样式的图层和图层组会离开普通合成器快路径，需要对受影响输出使用样式感知合成。栅格化纯文本图层会删除可编辑文本，同时保留现有栅格表面和蒙版。栅格化带样式图层会把每帧当前的样式与蒙版结果烘焙为独立 Cel 像素、移除这些可编辑属性，并保持为一次可撤销操作。

## 替代方案

拒绝默认把效果烘焙到每个 Cel，因为这会破坏可编辑性、成倍增加历史和存储成本，并让后续参数变化在帧间不一致。拒绝逐 Cel 保存样式，因为用户所见功能属于图层或图层组，应与其他共享所属对象属性一致。拒绝把每种效果表示为隐藏辅助图层，因为这会使排序、剪贴、蒙版和工程结构复杂化。
