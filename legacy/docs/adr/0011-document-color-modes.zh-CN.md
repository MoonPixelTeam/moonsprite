# ADR-0011：文档颜色模式与栅格格式

中文 | [English](0011-document-color-modes.md)

## 状态

已接受

## 背景

文档颜色模式过去同时代表物理栅格格式。这对 RGBA 和索引存储可行，但加入灰度后，运行时代码会把所有非 RGBA 模式都当成索引模式。索引编辑还会从任意绘制颜色创建新调色板条目，因此画布实际上并未受可见调色板约束。

## 决策

- 工程 schema v10 保存 `rgba`、`indexed` 和 `grayscale` 文档模式。
- 物理栅格数据仍只有 `rgba` 或 `indexed`。灰度文档使用 RGB 通道相等且 alpha 独立的 RGBA 表面。
- 索引画布写入只针对当前 `paletteOrder` 中列出的颜色解析。精确匹配会复用；其他颜色映射到最近的可见 RGBA 条目，不新增调色板条目。
- 删除或替换可见调色板颜色时，在同一个可撤销调色板操作中重映射受影响的索引图层与动画 Cel 存储。
- RGBA 转索引会保留当前调色板，并映射每个图层和动画 Cel。转灰度使用感知亮度并保留 alpha。
- schema v1-v9 工程保留原有 RGBA 或索引解释，并迁移到 v10，不生成合成灰度数据。

## 结果

文档意图不再与字节布局混淆。运行时栅格编码保持向后兼容，灰度可以随工程完整往返，索引像素也不会静默依赖已隐藏的历史调色板条目。

## 替代方案

拒绝增加第三种物理稀疏栅格编码，因为灰度仍需要 alpha，独立字节布局也不能改善存储或合成。拒绝把每个绘制颜色自动加入索引调色板，因为这会破坏索引色约束，并让可见调色板失去可信来源地位。
