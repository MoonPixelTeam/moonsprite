# ADR-0009：可编辑文本样式区间

中文 | [English](0009-editable-text-style-runs.md)

## 状态

已接受

## 背景

可编辑文本需要在同一个 Cel 内使用不同字号、间距和颜色，并在保存和重新打开后保持可编辑。仅栅格化的格式会丢失源文本选择区间，也无法在内容编辑后重新应用样式。

## 决策

- 工程 schema v8 在每个可编辑文本 Cel 上保存可选、按序且互不重叠的 `styleRuns`。
- 每个区间使用 UTF-16 文本偏移，并可覆盖字号、行距、字距和 RGBA 颜色。未指定的属性继承 Cel 默认值。
- 文本编辑会围绕改动范围协调样式区间。渲染在字形栅格化前解析每个字符的最终样式。
- 实际间距在水平和垂直方向上使用最终可见 alpha 边界。零间距会让相邻可见字形或行像素直接相接。
- schema v7 文本迁移时不创建合成区间，因此保留原来的整段文本格式。

## 结果

混合格式保持可编辑，并可随工程完整往返。逐字符字形栅格化比每行一次 `fillText` 成本更高，因此每次栅格化期间会缓存字形 alpha 结果。字体系列与抗锯齿模式仍是整个 Cel 共用的属性。

## 替代方案

拒绝在文本字符串中嵌入标记，因为这会破坏选择偏移和复制文本。拒绝只保存栅格输出，因为后续文本编辑无法保留局部格式。
