# ADR-0004：动画导出与洋葱皮

中文 | [English](0004-animation-export-and-onion-skin.md)

## 状态

已接受

## 背景

动画预览辅助功能不得修改活动文档或进入文档撤销历史。GIF 导出还需要确定性的帧选择、方向排序和逐帧时长，并且格式实现不能依赖仅限浏览器的下载 API 或未纳入管理的二进制依赖。

## 决策

- 洋葱皮设置作为编辑器首选项持久化，并从相邻动画 Cel 渲染到独立缓存表面。
- 洋葱皮绝不改变图层像素、活动 Cel 数据、文档历史或序列化工程 schema。
- GIF 导出使用仓库内的小型 GIF89a 编码器。它为透明像素保留调色板索引 0，精确保留最多 255 种不透明颜色；动画超出该调色板容量时，回退到确定性的 `6 x 6 x 6` RGB 色立方。
- 导出帧范围在 UI 中从 1 开始，并限制在时间轴范围内。先选择范围，再展开播放方向，最后编码。

## 结果

GIF 输出具有确定性，并且无需新增运行时包即可在桌面 Renderer 中工作。GIF 只支持索引色和二值透明，因此导出时会对半透明像素应用阈值。洋葱皮只在启用时增加渲染工作，其表面会在文档 revision 或首选项变化时失效。
