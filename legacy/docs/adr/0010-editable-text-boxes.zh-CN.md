# ADR-0010：可编辑文本框

中文 | [English](0010-editable-text-boxes.md)

## 状态

已接受

## 背景

点文本会随内容增长，而段落文本需要一个持久的画布区域，才能让长内容按预期换行，并在重新打开工程后保持可编辑。

## 决策

- 工程 schema v9 在可编辑文本 Cel 上保存可选的 `boxWidth` 与 `boxHeight`。
- 单击创建不带文本框元数据的点文本。指针拖动则使用拖出的画布像素矩形创建区域文本。
- 换行仅属于视觉布局：不修改源文本与样式区间的字符偏移。
- 区域文本的栅格表面使用精确保存的文本框尺寸；下一个字形超出内部宽度时按字符换行，并裁掉保存高度之外的像素。
- schema v1-v8 文本迁移时不创建合成文本框尺寸，并保留点文本行为。

## 结果

文本框在编辑、变换、复制和工程往返后仍然保留，不需要插入人为换行符。逐字符换行也支持 CJK 文本和长单词，同时点文本保持向后兼容。

## 替代方案

拒绝把自动换行写入源文本，因为调整大小或样式后无法恢复原始内容。拒绝只在栅格表面保存矩形，因为编辑时会丢失预期换行边界。
