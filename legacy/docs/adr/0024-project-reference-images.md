# ADR 0024：参考图随工程保存

中文 | [English](0024-project-reference-images.en.md)

## 状态

已采纳，工程格式 v21。

## 背景

参考图只存于应用会话，关闭软件后重新打开工程会丢失，多个工程也共享同一组参考图。

## 决策

- 工程保存可选 `referenceImages` 清单，包含稳定 ID、尺寸与 `references/<id>.rgba` 路径。原始 RGBA 像素嵌入 ZIP，普通保存、另存为与恢复快照复用同一编解码边界。
- 从画布双击菜单添加的参考图另用 `canvasReferences` 清单保存顺序、名字、位置、尺寸、角度、镜像、透明度、锁定、独立浮动状态和初始布局。图片原始 data URL 存入 `references/canvas/<id>.dataurl`，不依赖外部文件；运行时 `documentId` 不写入工程。
- v1-v20 迁移为空参考图库，不采纳旧格式中的同名未知字段；v21 缺少清单时按空库处理。尺寸、ID、路径、资源长度或唯一性不合法时拒绝打开并显示错误。
- 参考图面板的增删通过 Store 元数据命令标记待保存，不改变绘画撤销栈。画布参考图的编辑继续使用既有撤销栈，提交、撤销、重做均更新工程元数据；取消手势不提交。两种参考图均不改变画作像素。
- 画布的缩放和平移不进入文档历史。参考图面板的浏览位置、视图导航、浮窗与亮度显示保留在工程会话里；画布参考图在画布预览帧内同步更新 DOM 和选中轮廓，独立浮动图保持屏幕位置。
- 工程切换恢复各自参考图库。剪贴板读取期间切换工程，取消本次粘贴，避免将图片写入其他工程。

## 后果与限制

保存后重新打开工程可恢复参考图，无需外部文件或剪贴板。工程体积随参考图增加；旧版软件不支持 v21。此前未保存过的会话参考图无法从旧工程中恢复。
