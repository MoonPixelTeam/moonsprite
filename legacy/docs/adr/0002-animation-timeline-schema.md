# 0002：动画时间轴与静态图层数据分离

中文 | [English](0002-animation-timeline-schema.en.md)

状态：接受

## 背景

MoonSprite 当前以单张像素画为核心，但后续需要支持接近 Aseprite 的帧动画。现有图层像素直接存放在 `layers/`，若直接在图层对象上堆叠帧和 cel 像素，会把图层树排序、时间轴、文件格式和渲染缓存绑死在一起。

## 决定

`.moonsprite` 升级为 schema v2。文档新增独立的动画时间轴元数据：帧、帧持续时间、当前帧、循环状态，以及 cel 对图层和帧的稳定关联。

现有 `layers/` 继续只表示静态图层位图。实际 cel 位图将在动画编辑器实现时写入独立文件；不得覆盖或复用静态层文件作为多帧数据容器。v1 工程迁移为包含默认单帧的 v2 工程，未来版本仍严格拒绝读取。

## 结果

- 图层栏、图层顺序和图层组不依赖时间轴状态。
- 时间轴可以作为独立栏目实现，播放和洋葱皮也能独立缓存。
- 当前阶段尚不暴露动画 UI，避免用户看到不能编辑的半成品能力。
- 后续加入 cel 像素文件时需新增下一份 ADR、迁移和格式回归测试。

## 替代方案

把每帧完整复制为独立 `SpriteDocument` 会造成图层身份不稳定、文件体积膨胀，并使图层操作、撤销和导入逻辑重复，因此不采用。
