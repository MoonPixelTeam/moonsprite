# 内置像素字体

中文 | [English](README.md)

MoonSprite 首次使用字体功能时，会将以下字体写入可执行文件根目录的 `Font` 文件夹。字体文件未经修改，并按照 SIL Open Font License 1.1 随软件分发。

| 字体 | 内置文件 | 上游地址 | 原生像素尺寸 |
| --- | --- | --- | --- |
| Fusion Pixel Font 10px Proportional，简体中文 | `moonsprite-builtin-fusion-pixel-10px-prop-zh-hans.woff2` | https://github.com/TakWolf/fusion-pixel-font | 10px |
| Silkscreen Regular | `moonsprite-builtin-silkscreen-regular.ttf` | https://fonts.google.com/specimen/Silkscreen | 8px |
| Tiny5 Regular | `moonsprite-builtin-tiny5-regular.ttf` | https://fonts.google.com/specimen/Tiny5 | 8px，MoonSprite 默认值 |

对应许可文本位于 `licenses/` 目录。
