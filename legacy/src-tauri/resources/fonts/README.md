# Bundled pixel fonts

English | [中文](README.zh-CN.md)

MoonSprite seeds these fonts into the executable-root `Font` directory on first use. They are bundled as unmodified font files under the SIL Open Font License 1.1.

| Font | Bundled file | Upstream | Native pixel size |
| --- | --- | --- | --- |
| Fusion Pixel Font 10px Proportional, Simplified Chinese | `moonsprite-builtin-fusion-pixel-10px-prop-zh-hans.woff2` | https://github.com/TakWolf/fusion-pixel-font | 10px |
| Silkscreen Regular | `moonsprite-builtin-silkscreen-regular.ttf` | https://fonts.google.com/specimen/Silkscreen | 8px |
| Tiny5 Regular | `moonsprite-builtin-tiny5-regular.ttf` | https://fonts.google.com/specimen/Tiny5 | 8px default in MoonSprite |

The corresponding license texts are in `licenses/`.
