# Website 内容布局审计

日期：2026-09-22。范围：路由、全部页面入口、公共 UI 组件与样式级联；本次为源码审计，不等同于逐页浏览器视觉验收。

| 页面范围 | 原问题 | 本次统一方式 |
| --- | --- | --- |
| 首页、市场、比赛展示 | 展示内容与功能页边距和区块间隔不一致 | 共享 1200px 内容边界和内容区按钮规范，保留作品展示版式 |
| 商品详情、购物车、结算弹窗 | 工具栏换行、内容列距与动作间距分散 | 共享列距、按钮、表单和溢出处理 |
| 文档、FAQ 及其子页 | 首页与子页命中不同的 secondary 样式；阅读宽度不统一 | 不再依赖 secondary 路由标识，使用同一阅读网格 |
| 博客及文章锚点 | 自建标题、与文档不同的布局 | 接入 PageHeader 和 reading-layout |
| 许可协议、隐私政策 | 两份相同模板，正文与目录错开，章节套卡片 | 共用 LegalPage，标题对齐正文，连续阅读式章节 |
| 登录、注册 | 独立的标题和间距尺寸 | 共用内容标题、控件与紧凑间距，保留窄表单 |
| 账号、购买记录、订单详情、收据 | 页面宽度和公共面板依赖多层覆盖 | 统一工作台宽度、PageHeader、Panel 与动作区 |
| 设置、客服 | 表单间距、标题层级与普通内容页不同 | 共用字段间距与分组层级 |
| 工作室概览、作品、销售、发布、编辑、结算 | 宽度与控件密度单独定义 | 接入共享内容规范，保留预览与业务分栏 |
| 管理概览、审核、工单、举报、提现、平台设置 | 管理组件另有局部尺寸 | 通过 WorkspacePage 与 Panel 统一，保留列表业务结构 |
| UI 组件展示页 | 与实际页面规则可能漂移 | 同一内容区规范直接作用于真实组件 |

布局尺寸以 ui-design-system.md 和 foundation.css 为准。导航、页脚、业务数据、授权与隐私文本不是本次改写对象。

验证：运行 TypeScript / CSS 类名 / 图标检查及现有 workspace-flow 页面流程测试。未执行全量构建、性能审计或浏览器自动验收。
