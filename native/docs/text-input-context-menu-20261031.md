# 多行文字框右键编辑菜单

## 旧版依据

旧版`TextAreaInput.tsx`直接转发textarea，`TextToolDialog.tsx`同步选择及文字，不提供自定义右键菜单；编辑菜单由浏览器提供。两份来源及`locales/zh-CN.ts`快照核对一致。此次承接文字编辑能力，复用现有PixelMenu／PixelMenuItem／PixelMenuSeparator和已锁定MIT UI菜单循环，使用现有像素字体与皮肤，没有新画图标或另做菜单外框。

`node native/scripts/capture-text-context.cjs`采集Edge 156.0.4314.50实际结果：144条右键按下／释放／Escape取消，加上18条菜单键／Shift+F10及取消后的范围，保存为`tests/fixtures/text_context_browser.h`。样本包含中英文、正反向选择、字符两侧点击和范围边界。

## 行为

- 右键按下按最近插入位置命中；位置在现有选择范围内或恰在任一端点时保留原选区及方向，范围外则移动光标。右键不开始文字拖选。
- 右键释放先解除捕获，再打开编辑菜单；焦点回来时保留选区。菜单键及Shift+F10在当前可见光标底端打开，不移动选区。
- 菜单包括撤销、重做、剪切、复制、粘贴、删除和全选，按历史、选区、剪贴板格式及内容状态禁用不适用项。
- 所有菜单动作进入已有键命令处理；复用本地历史、剪切写入失败保护、UTF16样式协调及共享剪贴板，不复制另一套文字算法。
- 文字菜单在Esc时关闭自身，不把Esc传给背景文字弹窗。菜单关闭后恢复文字焦点；取消不改变内容、剪贴板或历史。
- 菜单项只使用文字及现有快捷键标签。范围是textarea的编辑能力；浏览器提供的拼写、翻译、检查页面等服务不作为MoonSprite原生菜单项加入。

## 验证与边界

正式Release构建、`--text-tool-check`通过（退出码0）。实际菜单循环中的定时检查核对162条浏览器范围、菜单结构及禁用状态，七项动作对应内容、选区、剪贴板和一次本地撤销；取消及Esc检查确认背景文字弹窗保持打开。既有剪贴板、换行、按词、字素及输入法提交检查同次通过。原生剪贴板检查沿用注入后端，不改用户系统剪贴板。529文件来源／登记快照检查通过，覆盖不等于整体等价。

本次没有人工截图验收；菜单绘制、几何及素材直接复用现有组件。跨软换行／滚动后的右键命中、Shift右键、右键拖到框外和特殊输入法组合仍待补充运行对照。单行Entry的右键皮肤未在此改动，整体文字输入仍有已登记缺口。
