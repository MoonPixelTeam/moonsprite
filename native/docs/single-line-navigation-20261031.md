# 单行输入框键盘移动与只读选择

## 旧版行为与原生差异

旧版 TextInput／NumberInput 复用浏览器 input。原生 MIT Entry 的左右命令原来先丢掉选区，再从活动端移动一格；浏览器在不按 Shift／Ctrl 时先收起到对应边缘。底层 Entry 又把键盘编辑处理整体放在非只读条件内，使只读框无法按浏览器行为全选或扩展已有选择。

共享 PixelEntry 仅适配左右、Home／End、Ctrl+Home／End、各自的 Shift 扩选与 Ctrl+A。普通左右在有选区时直接收起到边缘，其余复用 MIT TextCmdProcessor 命令与 Entry 自身的锚点、字形框、滚动及输入法光标定位。只读按实测保留无可编辑光标的行为：普通移动不改变选区，Ctrl+A全选，Shift仅调整已有非空选区；修改命令保持既有只读保护。导航打断文字合并分组，不写作品历史。数值上下键、其他修饰键及业务回调保留原路径。

## 证据及范围

在既有 capture-entry-history.cjs 中新增312条浏览器观测，覆盖正反向选择、首尾／中间光标、空值、ASCII与简单中文，以及可编辑／只读状态。完整夹具447条，437条规范对照，10条浏览器旧历史异常继续排除。原生用实际裸输入控件键消息回放文字、选区方向及撤销／重做状态；原数值及菜单回归保持。

本批不声称完成跨词、组合字符／复杂字形框、双向文字、全部输入法或所有键盘操作等价性，不改变界面布局和素材。

## 验证

正式 Release 构建及最终 `--text-tool-check` 通过（退出码0），437条规范浏览器历史／焦点／导航对照与既有文字检查通过；537文件来源登记及证据快照检查通过。未进行人工截图验收。
