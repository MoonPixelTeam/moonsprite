# 颜色板专用快捷操作（2026-10-29）

## 旧版依据

`legacy/src/renderer/src/components/app/app-adjustment-palette-shortcuts.ts` 的24个颜色板命令及非重复按键派发；`components/panels/PalettePanel.tsx:989` 的完整命令处理、锁定／同步偏好、渐变选区和色板保存／目录入口；`store/workspace-palette.ts` 的排序、反转及内容历史。复用许可沿用 `legacy/LICENSE` 的内部修改和构建条款。

## 本批内容

接通已有的24个可配置命令：编辑锁、图像颜色提取、颜色同步、反转、普通渐变／色相渐变、色相／饱和度／亮度／明度／RGBA八种排序、升序／降序、五档色块尺寸、色板保存、打开色板目录、刷新色板库。不增加默认按键、菜单、图标和布局。

快捷键调用现有栏目方法及文档事务，保持色板槽位、颜色ID、颜色角色、选区、保存与撤销语义。反转改变目标颜色值，排序改变槽位顺序，二者不混淆；编辑锁继续仅约束直接编辑，不额外禁止旧版允许的排序和反转。渐变少于两个目标槽位时不操作。颜色板未显示及活动内容事务不直接执行；输入框、弹窗、重复键和手势排队沿用公共快捷路由。

打开目录复用原有目录按钮回调，仅在确有色板库弹窗时关闭弹窗，避免快捷操作错误执行模态收尾。检查模式不写用户的编辑锁和色块尺寸偏好；正式偏好行为保持原样。
