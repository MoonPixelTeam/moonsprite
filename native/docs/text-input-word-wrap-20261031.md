# 文字输入框按词换行

## 来源与证据

旧版`TextAreaInput.tsx`直接转发浏览器textarea，`TextToolDialog.tsx`同步文字及UTF16选区。`styles.css`中的`.text-area-input`未覆盖textarea默认的pre-wrap／break-word行为。三份来源快照核对一致。旧版没有独立的换行算法可以复制，本次是必要的原生输入适配。

`node native/scripts/capture-text-wrap.cjs`使用既有Playwright启动临时Edge 156.0.4314.50，在5、8、12个半宽单元的框宽下，对每个逻辑偏移发送Home及End，记录实际行边界。441条结果保存在`tests/fixtures/text_wrap_browser.h`，覆盖英文词组、连续／行尾空格、超长词、连字符／斜杠及其它标点、不换行空格、手动换行、中文及全角标点。

浏览器使用等宽拉丁字体，中文使用其回退字体；分别按实际advance归一到原生半宽5px／全宽10px。中文样本与拉丁样本独立，不以此声称混合字体塑形或逐像素等价。

## 承接行为

- 原先逐字素填满一行会把可完整放到下一行的单词拆开。现复用既有SkUnicode的行边界，在合法断点预判下一个不可断开片段，放不下时整体移到下一行。
- 超过整行宽度的片段继续按完整字素拆分；不拆开组合字符。连续及行尾ASCII空格保留在原行，允许尾部空白悬挂，不新增文字或硬换行。
- 保留原Fusion字模、行高、输入框间距和软换行双视觉位置。绘制、点击、拖选、上下／翻页、Home／End及滚动共用已有positions结果。
- 用字宽前缀和获取片段宽度，避免对同一剩余单词反复量宽；不引入新的运行库或浏览器。
- 仅改共享多行输入框，作品文字的保存内容、样式索引与实际排版渲染器不变。

## 验证及限制

正式Release构建、`--text-tool-check`通过（退出码0）。441条实际浏览器Home／End结果逐条一致；从记录行范围派生的原生鼠标行首命中、Shift+End选择及上下移动检查通过，文字与本地历史保持不变。原有字素、折行视觉位置、跨词、双击、按词拖选和滚动检查同次通过。来源检查覆盖524文件且证据快照一致；覆盖不代表行为全部等价。

本次未做人工截图验收。混合字体与复杂语言塑形、制表符布局、双向文字、输入法、三击、定时边缘滚动及其它浏览器／字典版本仍有缺口，不宣称整个文字输入模块已完成。
