# 文字拖动预览刷新范围

## 旧版依据

`legacy/src/renderer/src/components/canvas-input-text.ts` 的 `moveTextCreation` 先使用 `canvas-box-preview.ts` 的 `sameBoxPreview` 去重，再调度画布绘制；`moveTextTransform` 在目标变化后更新文字预览和画布缓存，然后调度绘制，不重新组织工作区布局。

## 原生承接

- 文字框缩放与框内移动的有效预览改用已有 `RefreshScope::Canvas`，保持共享视图状态和预览窗口同步，跳过全工作区重排。
- 新建文字框只在请求矩形变化时使画布失效。手势移动标记仍在比较之前累计，因此出去再回来的拖动仍创建文字框。
- 松手、取消和文字编辑器开关继续完整刷新，保留历史、最终缩略图与控件状态同步。

## 验证

正式Release构建、正式程序 `--text-tool-check`、515文件来源覆盖及证据快照检查、`git diff --check` 通过。真实输入检查确认链接旋转文字缩放与框内移动不增加整套工作区刷新计数；重复新建预览不改变布局或内容修订号。已有反向拖动、出去再回来、取消、链接所有者、提交及撤销重做检查同时通过。本批未增加人工图像验收或长期性能测试。

## 保留差异

已有核心文字草稿仍发布整幅画布为脏区；旧版按新旧文字范围精确失效合成缓存的行为尚未完整承接。本批不宣称文字性能完全等价，也未调整布局或素材。
