# 自由瓦片 Edit 模式喷枪

## 来源与承接

- `canvas-input-free-tile-edit.ts`：源编辑准备临时栅格，喷枪按下立即喷绘，并启动后续计时。
- `useCanvasStrokeClock.ts::sprayAirbrushRef`：喷点生成及粒子笔刷写入源局部栅格；选区、粒子形状／角度、普通混合，不使用主文档对称或重复绘制；无变化批次不发布源预览。
- `canvas-input-stroke.ts::endAirbrush`：结束时按喷枪历史标签一次性提交共享源。

开放 Edit 模式喷枪，复用现有随机喷点生成、参数、时钟和交互。将每批喷点及旋转粒子足迹转换到已有源临时栅格；提前增长临时画布，随后一次性映射全批坐标，避免增长后原点偏移导致错位。复用源发布的逆变换、透明裁边、共享层帧引用缓存及源历史。临时栅格修订未变化时跳过共享源发布。源光标预览不套用主文档对称。

鼠标释放提交一次并停止计时；Escape、焦点丢失、捕获丢失和失败复用现有取消流程。左右键仍对应前景／背景色。Paint模式保持禁用。没有新增公共接口、图标或布局。

源尺寸256px、临时画布16M像素等预算保持现状；源全引用重建／快照历史的性能限制仍保留，不宣称长期性能或整体迁移完成。

## 验收范围

执行结果见迁移计划。核心覆盖四种旋转×水平镜像×三种粒子形状、非零粒子角度、世界坐标足迹、临时画布增长、重复不变批次、无主文档对称、共享引用、选区孔洞、超限回滚、取消、保存重开与撤销重做。正式程序检查实际鼠标按下、移动、喷点、释放、计时器生命周期、Escape和右键焦点丢失取消；定时批次通过既有喷绘入口调用验证，不另做长时间定时性能测试。未新增图像验收。
