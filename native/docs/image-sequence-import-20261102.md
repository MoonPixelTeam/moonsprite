## FS-002-SEQ 功能语义

在文件→打开多选，或将多个普通文档文件拖入时，同目录、同前缀和同扩展名的尾部连续编号 PNG/JPEG/BMP/WebP 进入图片序列确认。目录分隔与大小写别名去重，批次保留首次出现的位置，批次内按数字排序；缺号、补零不一致和不同格式拆开。GIF 保持既有入口，不参与此识别。

默认勾选全部，时长100ms，合法范围1—60000ms并截断小数。用户可以分别打开或作为动画导入，选中顺序按文件原排序；零勾选不导入、不记忆设置。取消停止剩余批次。本次重复只影响本次后续批次；不再提醒将操作与时长持久化，写入失败单独反馈。

合并前逐个读取，要求尺寸相同且每个源只有一帧。各帧合成为全画布 RGBA，保留半透明；自动提取色板。新工程名称由首个选中文件去掉编号、后缀和尾部分隔符得到，空名为 Animation。新工程默认循环、标记未保存，没有工程保存路径或图片来源路径。每次创建独立工程身份，全部成功后才加入会话；失败不留下半成品，也不修改已有作品和历史。分别打开复用已有打开生命周期，坏文件不阻止后面的文件。
