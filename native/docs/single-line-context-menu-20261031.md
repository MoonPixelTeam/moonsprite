# 单行输入框右键编辑菜单

## 来源和范围

旧版 TextInput.tsx／NumberInput.tsx 使用 input[type=text]，编辑菜单由浏览器提供。旧原生控件继承的 MIT Entry 菜单直接调用底层剪贴板命令，绕过此前已迁移的键盘写入失败保护和换行处理。

本次保留原有 Entry 的文字存储、字形框、长度限制、选区删除／粘贴和 Change 通知，将键盘剪贴板逻辑提取为同一控件内部的 editClipboard，右键菜单与快捷键共用。

## 交互

- 右键按下按绘制所用的 Fusion 字模宽度及当前可见滚动偏移计算最近插入点；命中现有选区或端点时保留选区及方向，范围外移动光标。
- 右键释放先解除鼠标捕获，再打开现有 PixelMenu／PixelMenuItem／PixelMenuSeparator。菜单键及 Shift+F10 在可见光标底部打开，不更改选区。
- 菜单提供剪切、复制、粘贴、删除、全选，按选区、只读及剪贴板格式禁用。只读允许复制及全选。程序设为空值时清理底层哨兵框造成的过期选区；复制／剪切／删除资格以实际选中文字为准。
- 剪切写入失败或异常不删文字；粘贴读失败不编辑，多行内容沿用已确认的单行空格转换。有效空文本可删除选区。操作不改写系统剪贴板中的粘贴源。
- 菜单临时获得焦点期间保留输入草稿及选区，不触发数值框失焦提交或重新打开关联焦点浮层；关闭后恢复输入焦点。真正切换到其它字段仍走原有提交路径。
- 单行与多行共用提取出的 PixelInputMenu Esc 处理：只关闭菜单，保留背景弹窗。复用既有像素菜单素材，没有新增图标或外框。

## 验证

正式 Release 构建、最终 `--text-tool-check` 通过（退出码 0），534 文件来源登记及证据快照检查通过。capture-entry-context.cjs 采集 162 条 Edge 156.0.4314.50 实际输入范围与取消后方向，包含中英文、正反向选择、字符两侧、菜单键和 Shift+F10。原生实际弹窗循环逐条通过上述 162 条范围／方向对照。实际原生菜单检查同时核对剪切／复制／粘贴／删除／全选、禁用状态、异常后草稿及选择保留、失焦／聚焦回调计数。

原有 432 条单行剪贴板、162 条多行右键及既有文字输入检查同次通过。正常跨字段提交路径本次为源码核对；自动检查覆盖临时菜单焦点切换不触发提交。

检查使用注入内存剪贴板，不覆盖用户系统剪贴板。此次没有人工截图验收；组件沿用现有菜单皮肤。单行本地撤销／重做仍未迁移，浏览器拼写／翻译等服务未添加；未将单行文字编辑整体标为完成。特殊多键鼠标组合、跨进程剪贴板锁及真实输入法候选与菜单并用仍待验收。
