# 混合工程普通图层编辑入口（2026-11-17）

旧版依据：`workspace-edit-actions.ts` 的旋转及反色入口、`workspace-commands-layer-adjustment.ts` 的调整目标过滤、`workspace-history.ts` 的目标快照和 `workspace-commands-selection-move.ts` 的居中。

旧版颜色调整跳过特殊图层，旋转拒绝包含特殊图层的目标；这些限制针对目标，而非整个工程。原生原有全工程自由瓦片门禁导致普通图层也不能从菜单使用上述能力。本轮移除反色、五种颜色调整、三种内容旋转和三种居中菜单的全工程门禁，复用原有核心目标检查。

补齐默认颜色调整的多选目标：无像素选区时采用选中普通图层，有像素选区时只修改活动图层。特殊图层仍按旧版跳过／拒绝，不把资源像素缓存作为编辑权威，也不新增自由瓦片调色行为。

定向验收：真实菜单、多层反色、透明度、选区优先级、特殊资源与实例保持、调整弹窗取消、旋转／居中与普通图层路径一致、特殊目标拒绝及撤销重做。正式 Release 构建通过，`--free-tile-transform-check` 退出码 0。来源覆盖检查通过（1042 个文件），差异格式检查通过；不宣称新增人工图像验收。
