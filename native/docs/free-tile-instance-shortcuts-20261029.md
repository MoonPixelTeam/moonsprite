# 自由瓦片实例专用快捷操作（2026-10-29）

## 来源与范围

依据 Legacy `components/panels/FreeTileInstanceLayers.tsx::shortcutCommandHandlerRef`、`components/app/app-layers-shortcuts.ts::handleLayersShortcuts`、`core/shortcut-contracts.ts` 和 `store/workspace-commands-free-tile.ts`。沿用 `legacy/LICENSE` 的内部修改、构建许可。

实例右键已有仅显示、旋转、镜像和删除；本批将旧版五个对应快捷命令接入现有原生快捷键系统。配置项由“未迁移”变为可配置，不新增默认按键、菜单、图标或布局。

- 旋转90度、水平镜像和垂直镜像只作用于主选实例，不把多选集合一并变换；使用既有属性事务，一次操作一条历史，旋转／镜像时保持变换后的世界坐标左上角。自身锁定时不改动。
- 仅显示主选实例沿用既有显隐事务和单选行为；重复执行无改变不增加历史，不自行增加锁定限制。
- 删除作用于主选实例所在的已选范围，沿用已有删除命令的锁定保护、删除后选择和撤销语义；范围包含锁定实例时整体不删除。
- 空选择、未显示实例栏目、普通图层、没有工程和输入框接收文字时不会错误修改内容。键盘重复事件使用既有快捷路由抑制。

## 原生适配

使用当前 Document 与可见实例视图确定监听上下文，对应旧版挂载的实例列表及事件 documentId。继续调用既有 Document 属性、仅显示和删除方法，不增加另一套模型、历史或渲染路径；活动手势仍由现有快捷队列处理。独立实例栏目的现有视图准入限制保持，不借本批宣称其所有快捷上下文已等价。
