依据实际 legacy `store/workspace-magic-eraser.ts` 及测试、`core/selection.ts`、`tools-fill.ts`、`history.ts`、`document-model.ts`、`document-composite-sampling.ts`、`linked-layers.ts` 与输入调用链。内部复用按 `legacy/LICENSE` 的 MoonSprite Source-Available License 1.0 核对。本阶段仅功能迁移。

## 行为与原生适配

承接当前图层／可见图层取样、容差、连续／不连续、4／8 连通、闭合缝隙、选区交集及蒙版目标。先按完整源求匹配区域，再与选区求交；选区不能成为连通屏障。Indexed 匹配比较解析后的 RGBA，零容差也不按原始色号比较。重复色号取第一个资源颜色，未知色号透明；实际存储外始终透明，包括色板 ID0 不透明的情况。

修复原生此前把 indexed 字当作 RGBA 取样、可见合成缺少当前色板上下文，以及擦除范围没有按旧版原始可见内容边界裁切的问题。可见边界内的隐藏／未知非零字仍可擦除，边界外保留；透明层无有效编辑。复用现有 Wand 引擎、合成器和 PixelEdit 事务，没有另建算法。索引取消继续按旧版当前色板归一化；点历史与达到 256 点且包围面积不超过点数三倍的密集区域历史，复用此前已迁移的提交路径。滤镜预览精确取消的用户决定不扩大到本工具。

擦除只改已有存储，不扩张稀疏 Cel。保留负偏移、画布外字、存储原点、关联图层共享存储和链接帧。修正 pending lookup 初始化顺序，保存当前笔画的 indexed 色板上下文。鼠标按下预览、释放一次提交、Escape／右键取消、独立连续设置、Shift+E 入口沿用现有原生输入适配。

蒙版使用 RGBA 标量存储，并忽略“可见图层”取样。初版测试直接注入透明但带 RGB 的蒙版字，暴露取消差异；核对实际 `project-format-decode.ts` 和原生 `project_manifest.cpp` 后确认二者在打开时都会清除透明 RGB，且不透明字只接受灰度。夹具改为真实解码后的标量值，不据此更改通用蒙版历史语义。
