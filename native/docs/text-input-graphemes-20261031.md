# 文字输入的组合字符边界

## 来源

旧版 `legacy/src/renderer/src/components/TextAreaInput.tsx` 直接转发浏览器textarea，`TextToolDialog.tsx` 通过选择／内容回调更新UTF16样式。两份来源SHA256快照核对一致。旧版没有可复制的字符分段算法；此处为必要的原生输入适配。

原生先前按U32码点移动／删除，能保住补充平面单码点，却会拆开组合重音、国旗和连缀Emoji。使用现有已链接的SkUnicode/ICU字素边界，不手写字符范围或另加分词依赖。核对既有缓存Skia BSD及ICU Unicode许可，不复制其源文件／素材。

## 改动

- ICU接收UTF16，边界映射回原生U32偏移，样式仍走原有UTF16同步链路。
- 左右键与Shift跨越整个字素簇；已有选择范围的左右收起行为继续保留。
- 无选区的Backspace／Delete删除整个字素簇，保留本地撤销／重做与分组规则。
- 如果鼠标或上下移动把光标放进组合内部，无选区删除扩展到该簇完整边界，防止遗留半个序列。显式选择范围仍按其原范围替换，不擅自扩大用户选区。
- Unicode服务不可用时不回退成逐码点删除，而是保持该次无选区移动／删除位置。已有内容及保存格式不受影响。

## 验证

正式Release构建、`--text-tool-check`（退出码0）及516文件来源／证据快照检查通过。真实文字弹窗键消息覆盖e+组合重音、中国旗帜、女性技术人员连缀Emoji、拇指+肤色和韩文Jamo组合；每组检查移动、Shift、前后删除、内部光标删除及撤销／重做。换行仍可单独删除和撤销。

## 保留限制

未对旧版浏览器逐平台的Backspace特殊规则做实际等价对照，不能把ICU字素规则称为旧浏览器算法。按词移动／删除、输入法、双向文字、按字素排版换行及鼠标选区仍未完成。像素字体绘制仍按现有字模，不新增Emoji或字形替代，也不宣称支持上述字符的完整视觉塑形。
