# 单行文本框上下键与翻页键迁移（2026-11-01）

## 用户可见行为

普通可编辑单行框的上下键移动到行首／行尾，Ctrl 组合相同；Shift 组合保留锚点扩选。按键由输入框消费，不再交给底层进行焦点移动。数值框已有的上下键调节路径保持原状，本批不恢复已暂停的数值箭头界面。

只读输入框不因普通上下键改变选区；已有非空选区时，Shift+Up 和 Shift+Down 均向行首扩选，这是本次浏览器采样的实际结果。无选区时不扩选。PageUp／PageDown 及 Shift 组合不改变内容或选区，不切换焦点。

上下键打断连续输入历史分组，即使光标已在边界；翻页键保留分组。新增连续输入后执行这些按键、继续输入和撤销／重做的对照，避免仅比较单次位置。
