# 自由瓦片 Edit 模式渐变

## Legacy 依据

- `components/canvas-input-free-tile-edit.ts`：准备源临时画布，按颜色容差、连续性、采样和连通性计算渐变区域。
- `components/canvas-input-fill.ts`：源局部起终点、选区、径向几何、抖动及色标传入 `applyGradient`；有拖动才提交共享源，无变化取消临时放置。
- `core/free-tile-edit.ts`：源临时坐标、实例变换和选区偏移。
- `core/gradient.ts` 与 `core/gradient.test.ts`：源覆盖混合、透明无操作、径向几何及选区语义。

## 原生适配

复用已有源编辑临时栅格及渐变采样器。世界坐标起终点与径向中心转换到临时画布坐标；源局部区域和选区沿用现有渐变算法，不应用主文档对称。渐变按匹配区域绘制，区别于油漆桶无选区时的源矩形限制；透明匹配区域可能扩展源尺寸。

复用已有时间轴预览存储呈现源逆变换和共享层帧缓存，权威资源保持基线。预览阶段交换现有基线／预览像素缓冲，不额外复制整块栅格。确认时使用现有源发布和单次历史事务；取消、无拖动、全透明无变化不产生内容历史。活动源事务沿用现有保存准入保护，保存重开在提交或取消后验证。

通用渐变分派方法移到源编辑适配所在的 `document_tilemap.cpp`，以访问已有源事务内部状态；原有普通栅格、蒙版、瓦片渐变路径保留，不增加公共接口或新事务系统。默认工具参数、按钮、确认模式、快捷交互沿用既有渐变入口。Paint 模式仍禁用。

沿用256px源尺寸与16M临时画布预算，超出限制时取消，不放宽工程格式准入。全引用缓存重建仍是已有源事务的性能限制；此项不代表整体自由瓦片迁移或性能等价验收完成。

## 验收

执行结果记录在迁移计划。定向核心覆盖线性／径向与16种旋转镜像、预览基线保持、取消、无拖动、透明无操作、透明范围扩展及选区、锁定、Paint拒绝、共享引用、保存重开、撤销重做。正式程序通过现有图层上下文检查实际鼠标按下／拖动／释放、单条历史及撤销。未进行新增图像或长期性能验收。
