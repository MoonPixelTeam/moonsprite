# 图案笔刷栏目专用快捷操作（2026-10-29）

## 旧版依据

`components/panels/BrushLibraryPanel.tsx::shortcutCommandHandlerRef`、`components/app/app-layers-shortcuts.ts`、`components/app/useBrushLibrary.ts`、`core/shortcut-contracts.ts`、`core/brush-folder-tree.ts` 与 `src-tauri/src/platform_brushes.rs::open_brush_folder`。许可沿用 `legacy/LICENSE` 的内部修改、构建权限。

## 迁移范围

接通九个旧版已登记命令：导入图案图片、新建笔刷文件夹、打开本地笔刷根文件夹、刷新、返回上一级、小／中／大预览、删除所选图案。不新增默认键、菜单、图标或布局；快捷设置中的这些命令变为可配置。

导入复用已有多文件选择和导入流程；新建复用已有文件夹表单及取消／失败处理；删除复用已有确认弹窗、混合本地／工程资源删除和部分失败处理。返回上级按旧版最后一个斜杠规则解析，根目录不处理，并复用现有栏目导航回调。

尺寸菜单和快捷键共用原有30／40／52规格及原子偏好写入，写入失败保留现有尺寸并反馈错误。刷新不重设当前笔刷。资源操作经当前工程、可见栏目、未发生内容事务及未出现其它表单等原生准入条件，不为快捷键另建资源或历史模型；键盘重复、输入框避让及活动手势排队沿用现有快捷路由。

打开文件夹以 Windows ShellExecuteW 适配旧版通过 Explorer 打开笔刷根目录的行为；先使用现有 PatternBrushLibrary 确保目录存在，失败反馈错误。没有恢复 WebView2 或创建额外编译版本。
