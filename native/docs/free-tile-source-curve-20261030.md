# 自由瓦片 Edit 模式曲线

## Legacy 来源

- `canvas-input-free-tile-edit.ts`：源编辑的曲线初始拖动进入 endpoint 状态，并保留源临时画布与初始实例。
- `canvas-input-shape.ts::moveCurve/endCurve`：先确定终点，再依次确定控制点；当前控制点及后续控制点随鼠标移动，最后一个控制点后提交。
- `useCanvasShapeCommit.ts::curveShapePixelPoints/commitBrushPath`：复用贝塞尔像素路径、完美像素和源局部笔刷路径，禁用主文档对称，保留笔刷和墨水参数。
- `tools-shapes.ts::bezierCurvePixelPoints`：已有 De Casteljau、像素桥接、去重和采样上限算法。

## 实现

开放 Edit 模式曲线入口，直接沿用现有曲线交互状态机、1至8个控制点设置和源笔刷适配。不新增布局、图标或公共核心接口。源曲线确认时刷新并提交最后一次隔离预览，保留最初按下时的源锚点；不取消后重新选择源。普通栅格与蒙版曲线继续走原路径，Paint 模式仍禁用。

源预览、坐标变换、选区、共享引用、透明裁边、隐式放置、预算和历史复用上一轮源笔刷路径。一次完成只产生一条曲线历史，控制点中间阶段不提交，Escape取消。现有缓存重建和时间轴快照性能限制继续保留，不宣称整体迁移或性能等价完成。

## 定向验收

执行结果见迁移计划。核心覆盖1／2／8控制点、四种旋转×水平镜像、完美像素开关，逐像素检查世界路径和源变换、无主文档对称、权威预览基线、取消、共享引用、保存重开与撤销重做。正式程序检查实际鼠标终点／控制点阶段、单条提交、撤销重做和Escape取消。图像及长期性能本批未另行验收。
