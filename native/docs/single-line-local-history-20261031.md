# 单行输入框的本地撤销与重做

## 来源

旧版 TextInput.tsx 和 NumberInput.tsx 使用浏览器 input[type=text]，本地历史由浏览器管理。现有 MIT Entry 没有本地 Undo／Redo。此次承接输入框编辑能力，不使用作品文档历史替代。

capture-entry-history.cjs 记录 Edge 156.0.4314.50 的 114 条连续操作观测。99 条作为本次对照：连续英文输入与删除合并、正反向选区替换、粘贴／剪切、跨词删除、重做分支、中文直接提交，以及受控输入框的同值刷新。

其余 15 条保留实际结果而明确排除：只读 Undo 和程序替换值后的旧历史重放会产生不删字却消费历史、Redo 重复插字等浏览器问题；普通重新聚焦时的选择差异属于已存在的原生输入框缺口。它们不计入通过对照，不把复制这些异常当作迁移完成。

## 实现

- 使用 MIT Component 的既有 Property 所有权管理每个输入框的历史，控件销毁时释放；不新增全局历史表，不写入工程，不接入文档撤销栈。
- 记录每次真实文字编辑前后的内容、锚点／光标及滚动位置。连续英文输入、同向字符删除按观测合并；粘贴、剪切、跨词删除和直接 Unicode 提交独立记录。导航／选择会分隔后续分组，新编辑清除重做分支。
- Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z 和右键菜单的撤销／重做使用相同历史；空历史仍消费快捷键，避免落入作品撤销。菜单按历史及只读状态禁用。
- 复用 Entry 的编辑命令、字形框、长度限制和变更通知。恢复选区方向，并通过既有光标定位显露内容；未承诺所有窄视口的滚动像素完全一致。
- 复制、失败剪切／粘贴及真正无操作不增加记录；同值替换选区仍记录历史，撤销／重做恢复选区但不发送内容 Change；只读撤销不改文字或消费历史。延迟提交数值框继续使用原来的 onChange，不因本地撤销提前提交作品。
- 正式构建从只读 MIT Entry 源生成最小 setter 适配：程序刷新为不同内容时立即清空旧历史，同值刷新保留；真实输入和撤销事务用作用域标记保留记录。生成物位于正式 build 中，依赖缓存不修改。

## 验证

正式 Release 构建及最终 `--text-tool-check` 通过（退出码 0）；99 条规范浏览器历史对照全部通过，537 文件来源登记及证据快照检查通过。检查通过真实控件键消息及现有弹窗菜单循环执行浏览器序列；记录区分规范对照和异常证据。额外覆盖只读安全行为、程序值先变更又恢复、菜单撤销／重做与反向选区、延迟数值框不提交。剪贴板仍使用注入内存后端。

本次没有人工截图验收，菜单复用现有皮肤。真实 IME 预编辑／取消和组合撤销分组、全部复杂字符导航、普通聚焦选择、同值内容换宿主但无身份通知，以及所有窄视口的滚动等价性仍未验收；不声称整个文字模块迁移完成。
