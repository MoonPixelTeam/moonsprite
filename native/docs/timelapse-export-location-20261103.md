# 缩时图片导出的文件名与目录

依据 legacy `TimelapseExportDialog.tsx`、`platform/export-location.ts`、`core/document-files.ts` 和 `store/document-file-service.ts`。旧版表单先填写名称、显示所选目录，选择路径只改变草稿，提交时解析所有帧目的地并处理冲突。取消选路径或冲突不能丢失草稿。

原生图片导出增加文件名输入、所选目录提示和复用旧版folderOpen图标的选择按钮。默认目录沿用现有输出目录偏好，默认名称为清理后的作品名加-timelapse.png；切换PNG/JPG按旧版替换末尾视频／图片扩展名。选择器返回不匹配的扩展名时附加所选格式，不能因“所有文件”切换实际编码器。

导出按钮直接使用表单目录和名称，仅在目录空缺时选路径；依次解析编号目的地后才启动既有后台编码。取消路径或冲突保留格式、名称和缩放。复用现有冲突菜单、最少三位编号、缩放保护、取消与原子写入。选择和解析期间防止重复提交，不引入第二套导出器。

带多重扩展名的名称不能被反复去后缀：将完整输出文件名交给现有序列规划器去除最后的格式扩展名，保留其前的名称。例如自定义.jpg.png导出为自定义.jpg-001.png。

控件继续使用共享PixelDialog、PixelEntry、PixelDropdown和按钮素材，增加的正文行和最小高度按DialogLayout计算。目录提示在自身范围裁切，不挤压其他组件。

验证：在正式--timeline-gif-drop-check中操作实际表单，用注入的路径选择结果覆盖PNG/JPG切换、选择取消与成功、中文和多重扩展名，并实际导出PNG重新解码对照，检查作品和内嵌录像保持。沿用已有真实Win32打开选择器取消回归。验收结果：唯一正式Release构建、正式--timeline-gif-drop-check返回0；555文件来源覆盖和git diff --check通过。取消冲突沿用既有规划器与表单生命周期，本批未新增实际冲突菜单操作回归；未做人工界面或截图验收。

保留缺口：本批只承接已实现的PNG/JPG图片序列设置；MP4/WebM编码与视频专有选项仍未迁移。
