# 普通文件后台读取与解码

来源：legacy `workspace-commands-document-io.ts` 的 openPath、`document-file-service.ts` 的 openDocumentFile，以及 `open-progress.ts`、`OpenProgressOverlay.tsx`。旧版先异步读取和解码，完成后才加入会话；失败不发布半成品。

本次将原生 openPath 既有 ASE、GIF、静态图片、工程与备份读取／构造移入后台。复用现有图片序列等待组件，仍由界面线程检测已打开路径、发布候选、切换工程、记录最近文件和显示错误；工作线程只持有路径／格式和新候选，不访问 Editor 或当前作品。不改解码算法、默认值、预算或工程格式。

后台等待复用 PixelDialog 和 sheet，事件循环继续处理重绘、窗口操作与定时器。阻止 Escape 提前结束等待后在 future.get 上阻塞；系统关闭请求在读取完成、成功或错误处理后重投给原有保存关闭流程，不强退，不删除恢复数据。

必要原生适配：调用入口仍保持串行批次与前景等待合同。旧版进度关闭按钮允许隐藏遮罩而读取继续；该能力尚未迁移。本次没有增加取消读取、并行打开编辑或百分比进度，不宣称完整进度交互等价。

验收：正式程序 --timeline-gif-drop-check 增加由界面定时器释放真实 GIF 解码任务的检查，验证工作线程与界面线程不同、两个界面 tick 持续运行、Escape 不提前退出、原工程身份／像素／历史／dirty 不变。沿用现有普通文件、备份、PSD／缺失文件失败、图片序列、多文件部分成功、重复路径和另存工程场景。唯一正式 Release 构建与 --timeline-gif-drop-check 均返回0；550文件来源覆盖检查与 git diff --check 通过。未做人工操作、截图外观验收和耗时基准。


## 后续：隐藏进度后继续操作

本节取代上一批“关闭提示尚未迁移”的当前状态说明；前文保留为历史记录。直接来源是 OpenProgressOverlay 关闭按钮调用 openProgress.dismiss，以及 open-progress.test.ts 中关闭后再次复用的场景。关闭提示不会取消读取或抛弃已读入内容。

普通打开和图片序列共用标题关闭按钮，复用 legacy close 图标、通用按钮和 sheet。关闭前沿用前景窗口，关闭后沿用 LAF MessageLoop 继续泵送事件并等待私有候选；原工程可继续编辑。候选就绪后等当前内嵌表单／保存状态、笔画和鼠标抓取操作结束，再走原有成功或失败处理；普通打开再次检查路径，复用期间已打开的相同文件。

原生生命周期适配：等待仍保持现有栈上调用与串行批次合同，不分离线程，不让后台线程接触 Editor。嵌套打开先完成内层调用，不宣称任意并发读取按完成时间发布；旧版下一动画帧才显示进度的短任务抑制没有迁移。退出菜单请求和系统关闭请求延后到最外层读取完成，再交还既有保存／退出流程；未保存作品与恢复数据保留。

新增验收按成功／缺失文件失败／再次成功三组，用四次界面定时器 tick 控制隐藏、实际像素编辑、工作线程释放和候选发布，验证隐藏后 Editor 可点击、历史与像素编辑保留且可撤销、失败回传、进度可复用、退出回调延后与 guard 释放。唯一正式 Release 构建与 --timeline-gif-drop-check 返回0；550文件来源覆盖及 git diff --check 通过。未宣称人工鼠标或外观验收。


## 后续：快速打开不闪进度窗口

来源是 open-progress.ts 的 begin：把 running 的发布放到 scheduleFrame 回调，完成先于回调时不显示。此次普通文件与图片序列共同调用 DocumentLoadingDialog.run；已完成的读取或在首个界面刷新周期内完成的读取直接返回候选或错误，不打开窗口，仍未完成时才显示现有前景加载提示。隐藏后编辑、失败回传、候选发布保护与退出延后继续复用。

原生适配以一次16ms LAF Timer及既有MessageLoop代替浏览器requestAnimationFrame；不宣称与显示器垂直同步时序精确等价。等待期间遇到已有表单、笔画或抓取时不插入新的加载弹窗。任务完成后仍等待这些操作结束，沿用既有候选发布规则。没有新增解码线程池、并发批次模型、素材或设置项。

正式程序回归使用真实GIF候选／缺失文件错误和Window.Open事件，覆盖已就绪成功、已就绪失败、首次UI定时器内完成、持续未完成直至提示打开四组；检查前三组零次打开、慢任务一次打开，以及原作品身份／像素／历史／dirty保持。控制任务完成顺序，不以机器耗时作为通过标准。唯一正式 Release 构建与 --timeline-gif-drop-check 返回0；550文件来源覆盖及 git diff --check 通过。未做人工操作或截图外观验收。

LAF生命周期适配：Window::setDisplay 即注册窗口，Manager::_closeWindow 对从未加入父窗口的实例直接返回；因此未显示的栈上提示在析构时显式解除借用的display注册，避免快速读取留下失效窗口指针。回归同时检查每组完成析构后窗口列表数量恢复到原值。
