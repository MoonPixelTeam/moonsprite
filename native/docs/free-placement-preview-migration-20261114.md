# 自由瓦片 Paint 放置预览迁移

旧版依据：`canvas-render-free-tile-brush.ts::renderCanvasFreeTileBrush`，及其调用方 `canvas-render-frame.ts`、自由瓦片源解析与变换几何、`useCanvasViewportGeometry.ts` 的邻接平铺映射、`canvas-adaptive-outline.ts` / `canvas-adaptive-contrast.ts` 和 `canvas-render-plan.ts::deviceAlignedCoordinate`。

原生接入 Paint 的铅笔放置和橡皮擦命中预览，沿用四种显示模式与绘制期间显示偏好。悬停忽略像素选区；绘制期间按指针是否在选区内决定是否显示，无选区允许显示。放置预览使用选中源，绘制期间使用手势捕获的源；没有有效源时不显示。源图像按原始 RGBA 像素覆盖当前层后再进行图层合成，保留旧版预览不应用源的显隐、锁定、透明度及混合模式的行为。正式放置和擦除事务未更改。

橡皮擦逆绘制顺序命中可见实例的变换矩形，含透明像素、锁定实例和隐藏／锁定源；没有命中时无放置源回退。绘制时抑制完整像素预览，轮廓模式仍显示；透明源在完整模式下也显示轮廓。轮廓按已渲染背景的 145 亮度阈值选择黑白。各平铺副本独立裁切；放置预览的损伤包含完整画布视口，避免源大于普通笔刷时留下残影。原 Edit 预览移除内外两层平铺循环导致的重复覆盖，继续使用原有局部替换合成。

旧版直接执行脚本 `native/scripts/check-legacy-free-placement-preview.cjs` 通过 23 组决策／颜色检查。它执行实际旧版渲染函数、源解析和实例几何，Canvas 为记录适配器，图层合成为明确的普通 RGBA32 夹具；不代表浏览器像素渲染或完整合成器验收。

原生新增实际程序 `free-placement-preview` 定向检查：四种平铺及显示模式、精确不透明／半透明颜色、跳过透明像素、相对亮度、源样式与网格对齐独立、链接帧、选区、平移／采样／缩放／锁定门禁、指针移出清理、橡皮擦变换矩形、绘制与取消、无选区绘制、透明源轮廓，以及预览期间像素、资源、实例、链接、history、revision、dirty 和 renderer upload 不变。唯一正式 Release 构建及最终增量确认成功；实际进程四组全部通过（trace 最后一组 1141ms），无选区绘制与透明源悬停／绘制轮廓也通过。free-source-preview 八组、shift-lines 十二组实际进程退出 0；brush-preview CTest 通过（0.81 秒）。首次半透明断言失败源于夹具只链接活动层，导致新帧底层为空；夹具现先显源以建立真实链接、链接全部层后隐藏源，并明确断言链接存在，没有放宽颜色预期或修改生产合成器。人工查看 Both 模式画布截图，九个副本均显示独立预览、透明处保留底色；截图仅画布，不代表完整桌面和全部显示器验收。

范围仍有限：其它文档颜色格式、隔离蒙版组合、分数缩放／旋转轮廓的逐像素等价及全部迁移未完成。已有完整 `free-tile-project` 在特殊合并撤销断言处失败，尚未证明基线是否也失败；本阶段不弱化该断言、不称整套测试通过。
