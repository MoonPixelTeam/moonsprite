# 单行输入框双击选词与按词拖选

旧版 TextInput／NumberInput 依赖浏览器 input。原生 Entry 的简单单词规则和拖动范围不能直接等价。本批复用多行输入框已迁移的浏览器词边界、尾部空白和向左／右扩展规则，通过 inputWordRange 共享，未引入第二套分词算法。

双击按Fusion字模和可见滚动定位最近插入点，选择词及尾随水平空白；单独记录原词边界，拖动中沿用Entry定位／边缘滚动后按词扩展，向左选择保留反向锚点。鼠标释放仅释放捕获，保留选区；新按下、键盘、失焦及捕获丢失清理手势。手势状态由既有Component Property所有权管理，控件销毁释放。复杂字形框数量和码点不一致时保留旧路径，明确仍有映射缺口。

实际Edge 156.0.4314.50新增200条观测，覆盖英文／中文／标点／空格左右侧、正反向按词拖选、替换及本地撤销重做；完整2053条观测，2043条规范对照，10条先前异常排除。原生通过真实控件鼠标消息和自身字模位置回放。

正式Release构建、最终 `--text-tool-check` 通过（退出码0），2043条规范对照及既有文字检查通过；538文件来源登记与证据快照检查通过。未人工截图验收；未验证系统物理双击计时、复杂字形、双向文字、所有只读／焦点组合及边缘滚动等价性；不将整个输入模块标为完成。
