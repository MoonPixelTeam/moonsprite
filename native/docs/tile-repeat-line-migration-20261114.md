# 平铺 Shift 连线迁移

本阶段承接旧版 `canvas-input-line-connection.ts:138–145`、`canvas-render-shape-preview.ts:230–245` 和 `tilemap.ts:349–404`，补齐输入与预览选择最近平铺锚点副本的计算。保持先选副本再执行现有普通／ISO／网格约束的顺序；只对 Shift 连接线入口生效，不改变直线工具的起点。锚点按旧版保存为文档内坐标，持续拖动仍保留重复坐标。

`nearestEquivalent` 保留 JS `Math.round` 正负半周期向正侧取整，尺寸无效或未重复的轴保持原坐标。自由瓦片按旧版先生成 raster／balanced 路径、逐点折回、在接缝处分段，再在临时源画布分别栅格化每段。图像图案仍以原始未折回起点为原点，段之间保持同一像素基线和资源事务，最后一次发布并提交；源选择使用折回后的点击端点，沿用共享资源、实例、链接、选区以及异常回滚路径。普通自由瓦片指针笔画仍沿旧版逐样本折回语义。

原生适配只涉及 C++ 点和段类型、既有临时 raster 的动态增长，以及将平铺模式传入现有资源事务。不新增历史或资源模型，无入口、素材和布局变动。本阶段不包含性能优化。

生成器执行实际旧版 `tilemap.ts`、`selection.ts` 和 `pixel-line.ts` 得到 608 组最近锚点（含四模式、正负半周期、多个副本、无效尺寸）和 256 组两种算法的路径、段端点／进度与分段重新栅格化像素。几何测试 `tile-repeat`（0.04 秒）及资源事务 `tile-repeat-stroke`（0.19 秒）已通过。`free-tile-project-tests source-lines` 最终通过，含 12 组 X／Y／Both × 动态开关 × 橡皮擦的共享源像素、单事务、实例、存活链接、保存重开与撤销重做；并保留原有普通连线、算法与颜色替换检查。50% 橡皮擦依照实际 `tools-brush.ts` 的 coverage=round(255×0.5)=128，alpha 为 127；修正了测试原先误写的 128。
