# 文字输入框的选区与多行导航

## 来源与适配边界

`legacy/src/renderer/src/components/TextAreaInput.tsx` 转发浏览器 `<textarea>`；`TextToolDialog.tsx` 使用该组件、读取 selectionStart/selectionEnd 更新局部文字样式。旧版没有自定义方向键算法。原生没有 DOM，以下为必要的输入组件适配，不能称为复制了旧版键盘实现。

## 本次改动

- 不按 Shift 时，左／右键分别收起到选区左／右端；支持反向选区。按 Shift 保留锚点，继续调整活动端。
- 上／下键按可见文字行移动，记住期望横坐标，穿过短行再到长行时恢复原列；横向移动、编辑、焦点切换、鼠标定位及设置选区后重置该坐标。
- PageUp／PageDown 使用输入框可见高度换算行数，Shift 保留锚点；越过首末行时到文档起止。Ctrl+Home／End 继续使用原有起止定位。
- 粘贴将 CRLF 和单独 CR 都转换为 LF，避免原来直接删除 CR 导致两行连在一起。其余字符保留。
- 导航不新增文字历史或触发文字内容回调；沿用原有 selectionChanged 更新局部样式显示。

共享 PixelTextArea 同时用于文字工具与图层属性输入，没有新增布局、图标或皮肤。

## 验证

正式 Release 构建及 `--text-tool-check`（退出码0）通过，515文件来源覆盖及证据快照检查通过。实际弹窗键消息覆盖正反选区收起、Shift、长短长行上下导航、横移后列重置、首尾、翻页及导航不写文字历史。粘贴换行仅核对源码，未操作系统剪贴板，避免覆盖用户剪贴板内容。

## 保留缺口

跨词分词、组合字符簇移动／删除、软换行 Home／End 的浏览器等价性仍未完成。本次不新增近似分词算法，也不把整个文字输入模块标记为完成。中文输入法及剪贴板格式组合需要单独运行验收。
