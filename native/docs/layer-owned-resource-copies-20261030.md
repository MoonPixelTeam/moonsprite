# 图层及图层组的独立资源复制

本批承接自由瓦片层和网格瓦片层的复制，沿用现有“复制图层”、所选图层／组及拖动复制入口，不增加菜单、布局或素材。

## 旧版依据

- `legacy/src/renderer/src/store/workspace-commands-layer-structure.ts`：`cloneOwnedLayerTilesets`、`duplicateActiveLayer`、`duplicateLayers`、`duplicateSelectedLayerRows`。资源随副本独立复制；撤销只移除副本新增资源。
- `legacy/src/renderer/src/core/animation.ts`：`cloneAnimationCelsForLayer`。每帧复制已解析内容、文本、网格、自由实例和不透明度，复用现有蒙版与链接层规则；复制 Cel 的 zIndex 保持旧版默认值。
- `legacy/src/renderer/src/core/free-tile.ts`：自由源、实例数据结构及克隆语义。

## 承接行为

网格副本创建独立资源，保留原 tile ID、槽位、像素及格子方向，仅重映射属于原 owner 的资源引用。自由瓦片副本创建新源集合、源 ID 和每源资源，保留名称、源元数据、各帧实例 ID、位置、旋转、镜像及其它属性，重映射实例源引用并清理旧 tile 引用。修改副本不影响原共享源。

复用现有图层／组结构事务、蒙版复制、插入位置和选中状态处理；新增资源按索引进入历史，整次复制一条记录，撤销与重做恢复相同副本身份。复制前像素预算计入原资源和待复制资源，沿用现有256层／256MiB像素限制；不是全面的元数据或瞬时内存上限。

## 验证范围

核心 `free-tile-project-tests` 覆盖活动层复制、所选层复制、组复制和拖动复制，检查资源身份、所有帧实例引用、像素、源元数据、副本独立编辑、保存重开、撤销与重做；网格样本检查owner与格子引用。副本编辑样本先移开实例，保留旧版“先检测其它自由层”的跨层命中优先级，避免重叠源误命中。

正式程序定向检查复用 `--free-tile-transform-check`，调用实际复制菜单并核对可用性、资源增量、像素和撤销重做。实际执行结果记录在迁移计划中。本批没有新增视觉或长时间性能验收。

## 保留边界

自由瓦片整层／Cel／帧剪贴板、链接自由 Cel、网格与自由层共用同一资源的导入兼容，以及其它既有迁移缺口仍保留。此批不开放旧版拒绝的特殊层固定角度旋转。继续复用现有缓存与历史结构，不宣称所有架构及性能已等价。
