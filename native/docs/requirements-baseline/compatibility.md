## API 兼容登记规则

每条公开接口登记：旧命名空间与版本、真实效果、输入/返回/错误、读写对象、帧索引单位、同步/异步与事件顺序、权限、历史边界、新版状态及对应需求/用例。状态仅使用“行为兼容、有限兼容、需迁移、不支持、未验证”。

具体种子：Point/Rectangle/Color/Image/Palette/Sprite/Layer/Cel/Frame/Selection/Range、Dialog、app.transaction、app.useTool 直线/橡皮；MSE 专属对象；Runtime 命令/菜单/工作区/文档/颜色/存储/资源/剪贴板/网络/通知/诊断；窗口与编辑器事件。详尽成员来源记录于 inventory.json 中的 API 文档行，暂非原生支持声明。

当前源码已核实 `io` 权限对应 `runtime.setFileDropTypes`，不等于任意文件读写能力；旧 API 索引“io 暂无方法”过时，不能沿用；派发成功不代表业务执行成功；能力发现必须只报告真实实现。文档修改进事务，安装/网络/保存/通知等外部副作用不能声称可由文档 Undo 回滚。

## 参数提取规则

精确参数以类型、默认设置、归一化函数、入口和断言共同核对。记录“当前默认”与“旧配置迁移后的默认”的区别；像素、毫秒、秒、角度、0–1 与0–255等单位不得含混。

已直接定位：颜色模式 rgba/indexed/grayscale；16 个 ToolId；6 种 ShapeKind；渐变 linear/radial 与九种 GradientDither；快捷键绑定与全部静态命令见入口台账。仅存在枚举不代表工具完全可用。具体滑条上下限、恢复与文件限制、滤镜参数和笔刷映射仍按 GAP-008逐项冻结。

任何未决项必须有来源、影响需求、下一次核对方法。源码能回答的先查源码；涉及删功能、降低兼容或改变创作语义才交用户裁定。
