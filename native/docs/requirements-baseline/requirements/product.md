## NX-001 原生产品与独立实现

- **目的与前置**：新版应用启动。
- **输入、参数与范围**：原生窗口和原生编辑器；优先验证 MIT UI/laf。
- **作用对象**：整个桌面产品与扩展 UI。
- **成功结果与不变量**：退出 WebView2；保留作品能力；旧版作证据，不照搬旧模块；第三方许可逐项核对。
- **预览、确认、取消与历史**：核心保持 CO-001；不以更换语言破坏行为。
- **保存重开**：用户后续已要求双目录，保留原仓库；legacy 与 native 独立组织。
- **失败与边界**：原生候选底座不合格先停止功能迁移。
- **验收 AC-NX-001**：独立原生程序无需旧前端运行；中文/压感/DPI 验证先通过。再按验收协议检查适用的取消、失败、撤销、重做和保存重开维度。
- **新版承接**：用户已确认的新产品约束；不是旧版能力证明。
- **证据状态**：用户确认；已有 Windows 原生原型，具体实现和未验收边界见[首个原型](../../native-milestone-01.md)，不代表本需求整体通过。

<a id="nx-002"></a>
## NX-002 Fusion 10px 统一像素界面

- **目的与前置**：所有应用页面、菜单、对话框和扩展 UI。
- **输入、参数与范围**：统一 Fusion Pixel 10px 字体、默认整体 2×（显示20px）、整数整体倍率、像素图标/边框。
- **作用对象**：软件界面，不含用户作品文字。
- **成功结果与不变量**：行高与内边距统一另定；组件不私改字号；标题用位置/颜色区分；布局允许重构，基础组件少且可组合。
- **预览、确认、取消与历史**：字体或主题切换不影响 dirty/历史；未完成编辑不丢。
- **保存重开**：全局倍率和主题为应用配置。
- **失败与边界**：九语言缺字或辨识度不足列决策项，不能悄悄用其他字号或删除语言。
- **验收 AC-NX-002**：九种语言样张、中文输入/候选定位、长标签、整数倍及系统125/150%DPI。再按验收协议检查适用的取消、失败、撤销、重做和保存重开维度。
- **新版承接**：用户已确认的新产品约束；不是旧版能力证明。
- **证据状态**：用户确认；已有 Windows 原生原型，具体实现和未验收边界见[首个原型](../../native-milestone-01.md)，不代表本需求整体通过。

<a id="nx-003"></a>
## NX-003 独立皮肤编辑器与运行时主题

用户最新决定：皮肤编辑器为独立工具，主程序不提供内嵌编辑器或窗口→皮肤入口。本批仅移除旧入口，独立编辑器尚未实现。运行时仍加载PNG/XML主题。

- **目的与前置**：有内置安全主题。
- **输入、参数与范围**：颜色、图标图集、边框/九宫格、组件状态、符合Fusion 10px规格的字体资源。
- **作用对象**：皮肤资产与同一生产组件预览。
- **成功结果与不变量**：只开放皮肤，布局和命令行为由软件定义；预览与主程序用同一组件；无效主题保留旧主题。
- **预览、确认、取消与历史**：编辑器自己的撤销与作品历史分离；取消不改当前作品。
- **保存重开**：主题包有版本与资源校验；不携带改变作品的脚本。
- **失败与边界**：缺资源有默认回退；主题不能改变快捷键命令或注入布局。
- **验收 AC-NX-003**：编辑按钮五种状态并切换主题；损坏图集/缺字检测；布局和作品保持不变。再按验收协议检查适用的取消、失败、撤销、重做和保存重开维度。
- **新版承接**：用户已确认的新产品约束；不是旧版能力证明。
- **证据状态**：用户确认；已有 Windows 原生原型，具体实现和未验收边界见[首个原型](../../native-milestone-01.md)，不代表本需求整体通过。

## NX-004 功能覆盖与替换门槛

- **目的与前置**：任何迁移阶段。
- **输入、参数与范围**：功能目录、需求ID、证据、用例、迁移状态。
- **作用对象**：旧版实际可用能力。
- **成功结果与不变量**：默认承接全部已登记能力；删除/降级由用户明确取舍；未验证不标完成；占位与缺陷不能变正确需求。
- **预览、确认、取消与历史**：数据/历史安全优先，UI入口可重排。
- **保存重开**：工程副本验证，旧版留至替换门槛满足。
- **失败与边界**：缺功能不得以扩展化让用户自行补齐。
- **验收 AC-NX-004**：所有入口有需求或分类；所有正式需求有验收；关键缺口关闭才替换旧版。再按验收协议检查适用的取消、失败、撤销、重做和保存重开维度。
