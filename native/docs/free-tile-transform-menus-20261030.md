# 自由瓦片实例的变换与自由变换菜单

本批接通现有“编辑 → 变换”（Ctrl+T）和“选择 → 自由变换”，不增加菜单选项、图标或皮肤素材。

## 迁移语义

- 当前可编辑自由瓦片主实例存在时，“变换”使用其世界坐标边界，裁到文档范围后建立矩形选区并激活选区工具。进入命令不修改源、实例或内容历史；全在画布外时保持不可用。
- “自由变换”要求像素选区；先确认已有浮动，再围绕当前选区建立四角几何，保留既有旋转中心。初始矩形四角只改变浮动几何，不发布源、不裁透明边、不增加内容修订号，也不产生内容历史。
- 四角拖动继续使用既有凸四边形约束、单应映射和源捕获事务。源像素、实例逆变换、共享层帧缓存、透明裁边、确认／取消与历史沿用上一批接通的实现。
- 松手保留浮动，Escape 恢复原源及选区，工具切换确认一次。菜单和快捷键复用同一执行路径。
- Paint、隐藏／锁定目标、组、多帧及不同图层／帧的显式选择不接入这些源变换入口；界面保持禁用，直接调用也检查目标。

## 来源与适配

`legacy/src/renderer/src/store/workspace-commands-selection-transform.ts` 的 `beginLayerTransform`／`beginFreeTransform` 决定命令语义；`useCanvasSelectionTransform.ts` 与 `canvas-input-selection-begin.ts` 决定源捕获和手势；`core/selection.ts` 决定四角几何；`workspace-commands-selection-floating.ts` 决定确认、取消与历史。

原生将自由变换初始四角保存在现有浮动事务中，初始矩形不发布源。原生已有单应采样、源事务及 256px 单源／16M 临时栅格预算继续复用，未重新设计业务算法。

## 保留缺口

本批只接当前可编辑主实例。未选实例时的整层内容边界、多图层／多帧、独立水平／垂直翻转和固定角度旋转菜单仍未迁移；这些不能因四角变形可用而算作完成。
