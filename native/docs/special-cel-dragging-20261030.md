# 网格瓦片与文字Cel拖动

## 来源与问题

`legacy/src/renderer/src/store/workspace-commands-animation-cel-clipboard.ts`的`moveSelectedAnimationCels`，配合`legacy/src/renderer/src/core/animation.ts`的`mapAnimationCelBlock`，先捕获整个源块、按锚点映射目标、拒绝类型不匹配，然后清空移动源并写入表面、opacity、zIndex、text、tilemap。复制保留源，重叠按捕获数据覆盖。`workspace-animation-drag-copy.test.ts`提供多格复制、源保持及撤销选择证据；`workspace-layer-mask-independence.test.ts`要求普通Cel搬动不改变蒙版位置或内容。

原生已有拖动路径只赋值表面与属性，网格引用和文字编辑数据仍停留在原格，导致内容和可编辑数据不一致。

## 本批承接

复用`moveTimelineCels`原有锚点映射、共享链接幸存者和Cel增量历史，补充网格及文字内容捕获、清空、目标写入与链接幸存者元数据移交。全块先捕获后写入，重叠不会读到被覆盖的数据；空网格保留原生必需模板、清空cells，对应旧版删除metadata后刷新规范化。源／目标类型必须相同；目标锁定拒绝，移动还保护锁定源。类型不匹配或越界不产生历史。原格蒙版、源集合与资源不搬移、不重建。

特殊元数据候选在发布前经过现有Timeline验证，以拒绝不同瓦片尺寸的无效引用；普通RGBA块不额外构造全量验证候选。正式内容历史仍只有受影响Cel增量。选择先在局部准备，验证成功后再发布；编辑器捕获错误并完成手势收尾。撤销／重做同时恢复内容、活动上下文和源／目标选择。

## 必须保留的冲突

旧版`moveSelectedAnimationCels`虽然允许free-tile类型，却没有对freeTiles进行源清空或目标写入，与该类型的权威实例模型冲突。该缺陷不作为新版应复现的行为。本批明确拒绝涉及自由层的Cel拖动，防止只搬动派生像素造成实例／缓存不一致；自由Cel复制、剪切、粘贴及整帧拖动不受影响。自由Cel拖动正确语义仍待裁定，未标为已完成。

## 验证边界

核心专项覆盖网格／文字、移动／复制、重叠两格、源清空／保留、文字内容及原点、网格引用、资源保持、蒙版驻留、保存重开、一次撤销重做、跨类型拒绝和自由Cel拒绝不变性。已有时间轴交互测试继续覆盖普通像素块、链接幸存者、越界、选择与历史。

不新增UI、素材或布局；本批没有针对网格／文字新增实际鼠标或图像验收。正式程序复用已有自由瓦片专项运行作回归检查。执行结果见迁移计划，整体迁移未完成。
