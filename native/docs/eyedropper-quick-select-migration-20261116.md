## 行为与原生适配

接入已有“快速选择颜色”偏好 tools.eyedropperQuickSelect，默认关闭，沿用通用偏好控件、编码和持久化。沿用可配置 tool.eyedropper.quick（默认 Alt）及现有精确匹配、冲突校验；不增加工具入口或图标。

第一次非重复按键在活动画布指针处立即采集前景色；保持按键移动时，沿用镜头 pending paint 合并，在绘制时刷新最近颜色。关闭镜头仍正常刷新颜色。松开任一已配置绑定的组成键时，刷新最后一个待取色并清理镜头，保留最终颜色。连续按键不重复开启取色。

非匹配组合键先取消待取色，恢复本次开始前的前景色，并抑制后续快速取色。新的非重复 Alt 或焦点重置解除抑制；自定义 F8 绑定遭组合键取消后，单独再次按 F8 不解除抑制，这是实际旧版行为。失焦／重新获焦清理瞬时状态，不恢复前景色。原生 Manager 过滤器在输入框／弹窗截获按键前执行组合键回滚；全局 keyup 观察器处理释放。文档身份限制待取色的投递，防止切换工程后应用旧样本或恢复旧工程原色。

十项旧版条件直接复用为纯判定：偏好、精确绑定、repeat、可见指针、活动文档、拖动、空格、调整笔刷组合键、画布上下文及输入框／模态阻塞。原生复用已有文档手势、平移、旋转、播放、移动工具、自由变换、画布尺寸预览和笔刷调整状态；不另造输入状态机。镜头现有 Property 保存快速取色瞬态，普通捕获取色继续使用既有 gesture。按鼠标接管时刷新待取色并建立独立镜头原色，释放后可继续快速悬停；快速取色的组合键回滚原色仍保留。

读色复用当前层／合成、活动蒙版及有限重复画布的已有采样器；范围外为透明 RGBA。快速悬停读取颜色，不执行普通点击的瓦片资源选择；不产生鼠标捕获、切回铅笔或最近颜色插入。共用 setSharedColor 的既有色板锁定／同步规则，因此锁定色板时的内容隔离验收不能扩展为所有色板设置都绝不改资源。

本阶段完成画布快速取色生命周期。跨画布、桌面全局取色与旧版画布参考图覆盖取色仍是单独缺口，现有参考图面板不等同于旧版覆盖层。生产 indexed 新建／转换／可编辑导入继续关闭；全仓迁移仍 INCOMPLETE。
