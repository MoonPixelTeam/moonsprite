# 自由瓦片：选区工具入口与创建

本批承接 legacy 的 Edit 模式选区建立流程，不改变布局、图标或默认参数。

- Edit 模式开放左侧选区按钮及矩形、椭圆、套索、多边形套索、魔棒、选择画笔。Paint 模式保持旧版禁用规则。
- 实际开始操作要求主选实例及其源可见且未锁定，图层可见且未锁定；没有主选目标时不会误编辑派生画布。
- 复用原生已有选区手势：替换、添加、减去、交集、多边形确认、Escape 取消、选框移动和选区历史。矩形及套索允许覆盖实例周围透明区域，不裁成实例边框。
- 魔棒使用主选源的旋转／镜像结果，忽略其他实例、实例透明度和图层效果；沿用 legacy 非紧凑编辑栅格的透明补边和文档坐标映射。起点在目标边界外时忽略，结果裁到文档范围。
- 现有 Copy、Cut 和 Delete 接续前批已迁移的源像素事务。

## 来源

`workspace-session.ts` 的工具矩阵；`deriveCanvasEditTargets.ts` 的创建资格；`useCanvasTileTarget.ts::selectedFreeTileSelectionTarget`；`canvas-input-selection-begin.ts` 与 `canvas-input-selection.ts` 的建立／取消／组合；`magic-wand-operation.ts`、`free-tile-edit.ts` 的源独立取样与坐标转换。

## 原生适配与剩余边界

魔棒沿用现有异步 worker，在请求时捕获只读源快照；临时栅格仍受原生 16M 像素限制。自由瓦片选区的内容提起、复制拖动、缩放、旋转、斜切尚未迁移，相关鼠标操作明确拦截并提示，禁止进入普通栅格内容变换。此项不代表自由瓦片选区全部功能已经等价。

## 验证范围

定向核心测试覆盖旋转／镜像、源独立取样、锁定与 Paint 限制；正式程序 `--layer-context-check` 覆盖实际按钮与鼠标操作。两项检查均已通过；Release 正式构建成功，来源覆盖 515 个文件，Git 差异格式检查通过。本批不涉及布局和素材变更，未额外进行图像外观验收。
