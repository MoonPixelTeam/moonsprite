# 单行输入框修饰键删除保护

旧版 TextInput／NumberInput 使用 Windows 浏览器 input。实际 Edge 156.0.4314.50 对 Ctrl+Shift+Backspace、Ctrl+Shift+Delete、Alt+Delete 不执行文字删除；Alt+Backspace 则是本地撤销快捷键，必须在有编辑历史时才能观察到。MIT Entry 则分别映射到删前词、删至行尾、删前词、删后字，可能在用户按组合键时误删内容。

PixelEntry 将Alt+Backspace接入现有安全本地撤销；其余三个组合在修改文字及创建历史事务之前消费，不改变文字、选区、变更通知、输入合并分组或重做分支。现有 Ctrl 单独跨词删除及 Shift+Delete 剪切保持既有路径；不改变弹窗、皮肤或素材。

采集新增680条浏览器观测，包含可编辑／只读、折叠／正反向选择、英文、中文、标点、空格和空值；连续输入中插入无效组合仍合并、已有重做分支仍可恢复，以及有历史时Alt+Backspace真正撤销。完整夹具1721条，1711条规范对照和10条先前浏览器异常排除。原生回放补入实际Alt修饰键。

正式Release构建与最终 `--text-tool-check` 通过（退出码0），1711条规范对照及既有文字检查通过；538文件来源登记与证据快照检查通过。来源覆盖不代表整体行为等价；本批不包含真实输入法、复杂字形框、系统级菜单／导航或其他操作系统快捷键。未进行人工截图验收。
