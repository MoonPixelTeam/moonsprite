# 首个原生绘图原型

2026-10-12；[返回原生目录](../README.md)。本轮从需求阶段进入实际原型开发；不修改 legacy 业务源码，不代表完整重构或替换验收完成。

最新界面状态见 [README](../README.md)：已按用户提供的深色参考图简化，未接入板块暂时移除。以下保留首轮原型记录。

## 产品决定

用户后续明确选择 Fusion 10px 并整体 2×；最初的 9×9 约束退役。使用 Fusion Pixel 2026.09.25 的原始 zh_hans BDF（25,314 字形）。10px 是字号而非强制每字10像素宽；常规拉丁前进5px、中文10px，整体2×分别为10px／20px，避免改变字体设计。特殊符号按其原始超宽／超高边界绘制；缺字用字体自带缺字框，不静默换系统字体。

当前仅接简中地区字形版本；其他语言不能因这一版本有对应码点就算排版／字形合格。IME 编译开关已开启，但尚无文本编辑入口，不声称中文输入和候选定位已验证。

用户最新要求排版布局按重构前的来，取代此前允许自由重设计布局的决定。当前依据 `legacy/src/renderer/src/components/app/useAppWorkspaceLayout.ts` 的 `createBuiltInDefaultWorkspace`、`core/workspace-layout-preferences.ts` 的默认停靠位置及 `App.tsx`／`EditorWorkspaceShell.tsx` 的结构：顶部菜单／标签、左侧调色板／参考图／颜色、中央工具参数／画布／底部图层、右侧历史／预览、最右工具栏、底部状态栏。不是浏览器试用的 `workspace-normal.json` 预设，也尚未导入用户自定义布局。沿用侧栏宽度比例，按原生字体和当前窗口调整间距；不声称旧 CSS 像素完全一致。

## 实现边界

| 模块 | 已实现 | 后续边界 |
| --- | --- | --- |
| 文档 | 独立 C++ 核心，像素只读访问；笔画预览／提交／取消；差量历史；保存状态独立身份 | 当前32×32、单层、无选区、无半透明混合、无工程读写；不得原样当完整生产文档 |
| UI | 真正使用 MIT ui::Manager、Window、Button 与 laf 系统；按旧桌面默认工作区排列，预览实时反映画布 | 画布与8色、六命令；菜单／参考图／完整拾色器待迁移；图层区只展示真实单层单帧；无停靠交互；Windows 系统标题栏保持系统字体，不属于自绘客户区 |
| 字体 | 原 BDF 按像素绘制；laf 使用同源 ASCII 图集测量；window scale=2、theme scale=1 | 未做九语言可读性、IME、125/150% DPI 和多屏验收 |
| 皮肤 | 两个颜色包，严格拒绝未知键、缺键和重复键；候选完整加载成功才替换 | 未实现图标／九宫格、用户皮肤编辑器和配置持久化 |
| 数据保护 | 保存不存在时明确提示内存原型；新建／关闭可取消；失焦取消活动笔 | 尚无磁盘持久化与异常恢复，禁止承载实际生产工程 |

预览期间 Undo/Redo、工具切换、换色、新建、失焦先取消当前笔画。这是当前原型的显式交互决定；没有声称旧版所有入口都如此。界面从不直接写像素／dirty／历史；保存点标记只存在核心测试接口，未向用户提供虚假的保存按钮。

## 构建与许可

固定依赖见[第三方清单](../THIRD_PARTY.md)。只编译 Aseprite src/ui 的 MIT 部分，未使用应用源文件或默认皮肤。源码和预编译依赖在忽略目录 `.cache/`，克隆不改变主仓库的 dev 分支或 Git 历史。

Visual Studio 2022、MSVC 19.44、Windows SDK 10.0.26100.0；Release /MT，与上游 Skia 包保持一致。laf 的 ICU 复制命令对含 `&` 路径未加 VERBATIM：在配置阶段预置对应输出，应用侧使用带 VERBATIM 的复制命令；不修改上游源码。Windows OpenGL 链接显式使用 SDK 的 opengl32。
