# 文字图层转换为普通层

Text-to-raster migration uses actual legacy rasterizeLayer and editable-text regressions: commit pending text draft before conversion so stale cancellation does not restore precreation state; remove target layer kind and all target frame cel text, retain exact cached raster bytes (including transparent RGB), dimensions/offset and same-layer animation owner links, current selection/frame/group metadata. Existing text dialog ignores stale preview/accept after target was rasterized. One conversion history entry plus a separate draft-creation entry; first raster stroke/move undo separately. Existing encoder/import/recovery remove absent text/kind. Linked-layer detachment appends into same metadata/surface transaction and only detaches target. Native metadata/textChanges adapt legacy layer-content snapshot without rerendering text. Tile/free-tile/style rasterization remains unsupported and gated. Actual opened check invokes the menu while real text dialog is previewing, then closes and verifies conversion survives cancellation and undo/redo. Native font raster bytes may differ across platform font providers, so conversion preserves current native render exactly rather than claiming cross-platform font equivalence.

来源具体路径与哈希见legacy-provenance.json；运行检查和视觉检查分开记录。
