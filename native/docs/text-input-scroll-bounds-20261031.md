# 文字输入框滚动边界

## 旧版依据

`legacy/src/renderer/src/components/TextAreaInput.tsx`直接使用浏览器textarea，`TextToolDialog.tsx`同步文字与选区。旧版没有可以直接复制的滚动边界算法，原生控件需要适配浏览器提供的行为。两份来源SHA256与登记快照一致。

使用既有Playwright和本机Edge 156.0.4314.50运行临时textarea：空文本和短文本设极大scrollTop后仍为0；30行文本、20px行距、60px高度时最大scrollTop为540，重复设置不再增加；扩大高度到800px后回到0，负scrollTop也归零。这是范围与尺寸变化证据，不是字体、滚轮速度或逐像素等价证据。

## 实现

- 共享PixelTextArea原先仅限制滚动上端，短文本也可滚到空白；现按既有行坐标、10px字模高度及内边距计算内容下限。
- 滚轮计算使用64位中间值，极大正负输入不会发生int溢出，保留既有滚轮步长。
- 绘制与鼠标定位使用相同有效范围。控件放大后，即使尚未重绘，点击也不使用过期滚动偏移；重绘同步限制实际滚动状态。
- 不改变文字、选区规则、本地历史、作品渲染、界面布局或素材。

## 验证及边界

正式Release构建及`--text-tool-check`通过（退出码0）。实际控件消息与渲染面逐像素比较覆盖空／短文本不滚空、长文本实际滚动、底部饱和、返回顶部、极大正负滚轮、尺寸变化前后的点击与显示一致，以及内容和本地历史不变。现有跨词、双击、拖选及其它文字检查同次通过。来源检查覆盖522文件，覆盖通过不代表完整行为等价。

本次没有人工截图验收。指针静止在输入框外的持续自动滚动在无头浏览器采样中未复现，继续保留为待验证项；三击、输入法、双向和整体文字输入等价性仍未完成。
