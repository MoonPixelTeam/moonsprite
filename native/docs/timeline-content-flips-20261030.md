# 时间轴所选内容批量翻转

## 旧版语义

依据 `store/workspace-selection-timeline-flip.ts` 及其测试，接通已有水平／垂直翻转菜单与 Shift+H／V。

- 有选中实例、像素选区或浮动时保持原来的更具体操作；不扩大到时间轴范围。
- 明确选择 Cel 时只处理这些格子；否则对已选图层／图层组与所选帧取交叉范围。仅选图层／组则包含所有帧，仅选帧则包含可编辑层。
- 跳过隐藏、锁定、文字层与蒙版目标。链接栅格依据原内容身份去重，每份内容翻转一次。
- 普通栅格在各自存储矩形内翻转，包括透明像素；保持稀疏表面坐标、存储原点和链接关系。
- 瓦片层反射格子位置并计算原瓦片方向映射，不修改瓦片资源。方向候选次序及字段覆盖沿用 `core/tilemap-document.ts::mirroredTilemapCell`。
- 自由瓦片反转未锁定实例的相应镜像字段，保留位置、旋转、源与其它实例元数据。
- 整批一条历史，撤销／重做恢复内容；保持活动层、帧、时间轴范围和组选择。先计算全部变更，通过既有内存预算后才发布；失败回滚。

## 适配及真实边界

复用原生像素地址历史、Cel 元数据历史和链接栅格缓存，不建立另一套命令系统或界面。共享方向帮助函数也用于既有 Paint 选区翻转，避免两套候选规则。

原生当前模型仍要求自由瓦片每个 Cel 独立拥有实例，工程导入也拒绝网格／自由瓦片共用同一资源。因此旧版测试里的“链接自由瓦片 Cel”和“网格／自由瓦片共用同一源”仍不算已承接，本轮混合测试使用独立资源和独立实例 Cel，栅格链接内容继续参与测试。

核对 `store/workspace-edit-actions.ts::rotateWorkspaceContent` 后确认其拒绝特殊图层类型。自由瓦片固定角度旋转菜单保持禁用，不能视作需要自行开放的功能缺口。四角浮动翻转和无显式范围的自由瓦片整层翻转另保留。
