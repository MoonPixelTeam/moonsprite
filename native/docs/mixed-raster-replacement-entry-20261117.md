# 混合工程普通图层替色入口（2026-11-17）

依据旧版 `workspace-commands-color.ts` 的目标收集与替色命令、`core/tools-fill.ts` 的 `replaceLayerColor` 和 `core/history.ts` 的像素编辑提交。

移除替色菜单的全工程自由瓦片限制，使混合工程的普通图层和色板能够使用既有替色实现。正式 Release 构建通过，`--free-tile-transform-check` 退出码 0，新增真实菜单检查覆盖普通图层独立预览、取消、提交、撤销重做和自由瓦片资源保持。来源覆盖与差异格式检查通过；无新增人工图像验收。

尚未完成：旧版特殊图层替色直接改图层像素缓存，此路径没有更新瓦片资源。原生继续拒绝特殊图层目标；涉及特殊目标的整批替色也仍拒绝。不能据此将特殊图层替色或所有替色范围标为迁移完成，后续需确定缓存／资源权威行为。
