# 文字框边缘缩放与松开行为

## 旧版依据

`legacy/src/renderer/src/components/canvas-input-text.ts::moveTextTransform` 仅在没有边缘手柄时检查 `selectionGestureMoved`，内部移动需超过3px；边缘缩放直接预览。

同文件 `endTextTransform` 仅在没有手柄且没有拖动时打开文字编辑器。边缘操作始终进入 `commitTextBoxTransform`，包括没有移动的手柄点击；旧版该事务会记录一次历史。

原生此前把内部移动门槛应用到边缘缩放，低倍率下的小幅拖动不生效，松开边缘还可能误开编辑弹窗。

## 承接

在既有文字事件分派中区分内部拖动和边缘手柄。内部移动仍使用原来的3px阈值；手柄立即预览，松开提交文字草稿，Escape仍取消。复用现有坐标几何、位置校正、重排和历史，无新控件或素材。

## 验证

唯一正式Release构建及 `--text-tool-check` 通过。扩展既有检查，在画布倍率0.5、UI倍率2下发送实际指针事件：2个物理像素的手柄移动低于内部拖动门槛，但能预览和提交2px尺寸变化；撤销／重做正确；静止边缘点击不打开弹窗并沿用旧版历史行为；Escape恢复尺寸且不增加历史。既有文字检查同次通过。

来源覆盖515文件及快照检查通过。无布局变化，未新增图像或长期性能验收；本项不代表整个文字模块迁移完成。
