# 修饰键调整笔刷的性能优化

日期：2026-10-15。范围：Ctrl+滚轮、Ctrl+Alt+鼠标移动，以及共用尺寸更新路径的方括号快捷键。

## 对照依据

直接阅读本地 Aseprite 源码：`src/app/ui/editor/dragging_value_state.cpp`（起点尺寸与位移）、`state_with_wheel_behavior.cpp`（BrushSize 分支）、`context_bar.cpp`（尺寸观察者）和 `brush_preview.cpp`（旧预览移除、新预览显示）。这些 app 文件受 Aseprite EULA 约束，仅研究行为与开销边界，没有复制代码。Aseprite 参数是内存中的偏好对象，事件路径不会逐次写配置文件；预览有自身的区域更新生命周期。

旧版实际依据：`legacy/src/renderer/src/components/canvas-pointer-move.ts`、`canvas-brush-size-update.ts` 及对应测试。沿用起始尺寸加水平位移 / 4、四舍五入、1–64 范围、无须按鼠标的修饰键手势、捕获拖动与后续画笔立即使用新尺寸。旧版通过局部预览及 rAF 合并避免每次移动触发全局状态工作；原生版直接更新轻量内存模型，交给现有 laf 重绘调度合并区域。

## 修改

- 尺寸变化前记录旧预览范围，变化后只使新旧范围失效；保留 Shift 连线、对称的保守全画布回退。
- 仅更新尺寸文本与已打开的尺寸滑块，普通尺寸变化不重新布局工具栏。选区笔刷从 1 跨到 2 或反向时，非圆形笔刷的角度栏显隐仍按现有规则布局。
- 偏好文件写入合并到连续输入空闲 250ms、手势结束、失焦、正常关闭或析构。内存尺寸和预览不等待计时器。达到上下限且尺寸未变时，不安排写入。
- 工具栏局部重绘只恢复其工作层背景，避免遍历无关图层和时间轴。
- 橡皮边界仍由旧版整数行跨度生成，用 64×64 小掩码查询四邻域，避免每个像素重复扫描所有行；绘制结果由原始逐像素路径校验。

## 验证方式与范围

`--modifier-brush-performance-check` / CTest `modifier-brush-performance` 打开真实原生窗口，重放 Ctrl+滚轮和 Ctrl+Alt 移动，包含铅笔、橡皮、1/64 上下限、预览收缩、尺寸字段和选区角度栏。局部重绘后的完整原生 framebuffer 与强制全重绘逐像素对照；检查画布像素版本、历史、dirty、缩放、上传计数均不变。记录布局、chrome 绘制次数，验证一串输入只在 flush 时写入一次。

对照基线在同一版本中重新启用每事件工具栏布局与全画布重绘；不包含逐事件磁盘写入，因此属于保守的渲染耗时比较。报告位于 `native/build/test-tmp/modifier-brush-performance.txt`。这不是端到端鼠标到显示器的延迟测量，也没有声称实际运行速度已与 Aseprite 相同。
