# 组合字符的鼠标选区与折行

## 旧版来源与运行证据

`legacy/src/renderer/src/components/TextAreaInput.tsx` 转发浏览器textarea；`TextToolDialog.tsx` 通过选择／鼠标释放／键盘回调同步UTF16选区及样式。两份来源快照核对一致，没有可直接移植的浏览器光标实现。

本机Edge 156.0.4314.50的内存textarea，24px Arial，在文字横向0到160px每2px发送一次真实点击，读取selectionStart并转换为U32偏移：

| 内容（A和B之间为一个组合） | 能点击到的U32偏移 |
| --- | --- |
| A + e与组合重音 + B | 0、1、3、4 |
| A + 女性技术人员连缀Emoji + B | 0、1、4、5 |
| A + 中国国旗 + B | 0、1、3、4 |
| A + 拇指与肤色 + B | 0、1、3、4 |
| A + 韩文Jamo组合 + B | 0、1、4、5 |

测量脚本通过旧版Playwright启动临时无头Edge，不连接用户浏览器或修改legacy。字形宽度不与原生字体比较；提取的是鼠标不会停进组合内部这一可观察规则。

## 本次承接

- 像素输入框按ICU字素边界组织布局，组合宽度沿用现有字模advance之和，整组折行；宽于输入框的组合单行溢出裁剪，不逐码点拆成多行。
- 可停靠位置仅保留完整字素的两端；鼠标点击／拖选、Shift选区、上下／翻页与Home／End共用该集合。
- 软换行处仍保留前行末尾／后行起点两个视觉位置，文字逻辑偏移和UTF16样式索引不变；光标绘制及滚动显露沿用同一坐标。
- geometry函数移入既有`pixel_text_area.cpp`，减少后续修改共享头文件造成的重编译。组件、字体、皮肤、布局和作品文字渲染器不变。
- 编程设置的明确逻辑选区仍可表达内部码点，不擅自扩展或修改已保存的样式范围；用户输入路径使用完整边界。

## 验证

正式Release构建、`--text-tool-check`（退出码0）和518文件来源／证据快照检查通过。新增实际输入框鼠标扫点覆盖每个显示行，以及正向／反向拖选、Shift点击、上下和Shift上下、Home／End及窄框整组折行；断言输入内容、历史不变。现有680条浏览器跨词结果和草稿／字素／可见行检查同次运行。

## 限制

像素字模仍逐字绘制，不能据此宣称实现浏览器的组合字形塑形或Emoji字体。按词换行、双击／三击选择、输入法、双向排版及浏览器版本间差异仍未完成；未进行人工截图验收。Unicode服务失败时保留全部文字显示，可停靠位置退为首尾，不创建破坏内容的内部边界。
