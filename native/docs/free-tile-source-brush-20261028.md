# 自由瓦片源笔刷编辑（2026-10-28）

本批承接 TI-004 的 Edit 模式笔刷、橡皮擦、Shift 连线与右键橡皮擦替色，不代表整个自由瓦片编辑器已经完成。

## 实际来源

- `core/free-tile-edit.ts`：源按实例方向呈现在临时普通栅格；原始源范围与累计脏区内裁透明边；空源规范化为1×1、offset=0；逆实例方向得到共享源像素与锚点。
- `core/free-tile-stroke-raster.ts`：对角线笔刷边距、四分之一/至少128的预留空间、跨步长迁移像素历史/覆盖缓存/选择及局部几何。
- `components/canvas-pointer-down.ts::prepareFreeTileSourceEdit`：跨层命中、命中源优先、所选源回退、源/实例锁定、缺实例时隐式放置及选区映射。
- `components/canvas-input-free-tile.ts`、`canvas-input-free-tile-edit.ts`：普通笔刷与动态路径在临时栅格执行，预览更新共享源。
- `core/free-tile-document.ts`、`store/workspace-free-tile-transaction.ts`：共享源写回、所有图层/帧引用刷新，源和隐式实例放置合并为一条历史。

以上路径均相对 `legacy/src/renderer/src/`，源文件及快照已登记于 provenance。

## 原生承接

复用 Document 的普通笔刷、动态笔刷、完美像素、图像笔刷、选择约束、混合和取消入口。临时栅格按旧版 compact 起点及16..128画布尺寸补边创建，按旧版增长公式扩展；迁移 pending/baseline、墨水与擦除覆盖、完美像素尾部、图案原点及选择，不重写一套笔刷算法。裁边扫描限制为原源范围加累计笔刷脏区，而非每次扫描整个临时画布。Shift 连线独立使用点击目标处源快照，以普通原生动态路径画线，保留前一笔，自己的线可单独撤销。右键橡皮擦按 legacy 完全匹配主色 RGBA 才替换为副色，按笔刷/动态覆盖插值且笔划重叠取最大覆盖。

源按实例旋转/翻转呈现；写回时逆变换回源坐标。保留源ID、像素资源ID、实例ID与布局、样式、额外字段。共享源更新传播至所有持有它的图层及帧；缺少可编辑实例时，隐式放置和源绘制一次提交/撤销。取消恢复源资源、实例和缓存；无变化不消耗历史与重做栈。

首次真实消息检查发现，普通画布入口在 `Document::beginStroke` 前使用 `rasterToolsAvailable()` 排除了自由瓦片层，导致 Edit 笔刷看似已开放但没有进入源编辑事务。现在仅对无蒙版、存在现代源集合且处于 Edit 模式的层放行普通笔划入口；隐藏、锁定、失效实例等条件仍由 `beginFreeTileSourceStroke` 原有检查处理。

现有瓦片栏目开放 Edit 按钮；源缩略图点击仍按旧版进入 Paint，可用原 Edit 按钮切回绘图。复用原图标、皮肤和布局。图层/源锁定等原因拒绝笔划时释放鼠标捕获，提交后刷新源缩略图。

## 原生限制与未承接项

- 继承当前原生工程格式的源每边256像素限制，临时编辑栅格预算16M像素；超限明确报错并取消，不截断或保存损坏源。
- 仅现代单源资源集合开放 Edit；旧单 tileset 兼容形式仍只准入既有 Paint 路径。
- 所选实例优先上下文、源专用 UI 连线方向约束/平铺重复连接、平滑/喷枪/形状/滤镜及选择变换等还未完整承接；不把普通工具已可用解释为所有源工具等价。
- 源/实例属性、实例移动和多选、跨工程剪贴板等仍有缺口。
- 源历史沿用现有原生 timeline 快照；引用缓存暂重新渲染，尚未承接 Legacy 全部区域增量性能策略。源缩略图在提交后刷新，未声明全部预览性能及UI等价。
