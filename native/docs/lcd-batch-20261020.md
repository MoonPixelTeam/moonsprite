# 2026-10-20 快捷键、图层移动与文字基础

本轮用户入口：原生快捷键设置；移动工具（V）。构建与实际窗口验收结果另见 build/current-batch-final-20261020.json，本文不代替运行验收。

图层移动来源：legacy canvas-input-layer-move.ts、canvas-move-selection.ts、workspace-layer-move.ts、layer-move-state.ts、animation.ts、shortcuts.ts，以及 canvas-click-flash.ts/useCanvasLayerFeedback.ts。原生捕获输入并修改 linked owner 放置偏移，不复制每个预览帧的 raster；存储 revision 保留，内容 revision 用于现有原生 renderer 的旧/新区域重绘。采用既有轴约束、网格、智能对齐和结构历史。移动选择遮罩与轴心一起变化，复制仅在首个非零位移创建。

已知差异：原生尚无旧版图层/组蒙版、自由瓦片实例和可编辑文字图层，因此这些移动语义未迁移。点击黑白闪烁保留原始 alpha 与亮度阈值和缩小覆盖，缓存仅本次点击，尚未承接旧版跨点击 LRU；未把它称为完整性能等价。内容边界和闪烁独立于选择轮廓。

文字仅基础阶段；工具入口和文字项目导入门禁保持关闭。已落盘 UTF16 样式索引、规范化、字形布局、栅格混合和原始字体资源/许可，Skia/DirectWrite 适配字体解码与本机文件服务。fixture 只证明确定性布局及本机字体加载、阈值、导入、偏好行为，不代表文字工具完成或浏览器像素等价。

文字遗留项：
- TextCelData 的 boxed 布尔尚不能表达旧 JSON 缺省 layoutMode；未来解析须按缺省且同时有 box 宽高推导 box，显式 free 丢弃旧 box。
- 字体服务目前按 family 管理，旧版 file id、同 family 多字体稳定排序/删除和大小写 usage key 语义尚需承接。
- Skia/DirectWrite 字形尚未与浏览器逐像素证明等价。
- Document 草稿/撤销生命周期、可编辑项目 IO、对话框与画布文字交互尚未开发。
