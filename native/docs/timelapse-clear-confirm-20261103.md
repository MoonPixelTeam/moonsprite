# 清空当前工程缩时记录前确认

旧版依据：`components/app/useAppDocumentDialogs.tsx`通过requestDialog提供取消／确认清空选择；`TimelapseDialog.tsx`先停止播放并回到首帧；`workspace-commands-history.ts::clearTimelapse`取消待处理捕获、重置采样状态并只清空当前工程快照。中文原文来自`locales/zh-CN.ts`。

原生清空按钮此前直接调用Session::clear。本批增加复用PixelDialog的确认窗口，说明“清空当前工程的全部缩时记录？此操作不能撤销，不影响画作，也不会删除本地录像库中的数据或释放其磁盘空间。”只有确认调用原有清空事务；取消、Esc和标题关闭按取消处理。清空前暂停并回到首帧，取消时不丢弃已加载图像缓存或录像引用。

正文复用既有按字体测量逐字换行方案，边距、正文起点、按钮与最小高度使用DialogLayout；关闭按钮使用已有legacy素材。清空入口文案更新为旧版“清空当前工程记录”，按钮按文案宽度容纳图标，不压缩字体。

确认保留原录制开关、撤销步骤选项、模式、速度等设置；当前工程元数据标记dirty且不新增画作撤销历史。现有Session代次机制继续取消旧任务发布，已落盘的录像块保持不动，不删除用户数据。

验证：正式--timeline-gif-drop-check通过嵌套实际窗口依次操作取消、Esc和确认，检查画作像素／历史、设置、元数据修订和本地录像字节；原预览状态回归继续验证清空后的控件与缓存。验收结果：唯一正式Release构建、正式--timeline-gif-drop-check返回0；555文件来源覆盖和git diff --check通过。重复执行时上一轮命名导出测试会命中已有输出，已改为进程专用的测试输出目录，保留旧样本不删除。未人工操作或截图验收。
