# 按住鼠标拖选时混用键盘（2026-11-01）

## 本批承接的行为

输入框正在拖选、鼠标尚未释放时，键盘操作会影响后续拖动方式。旧版不是所有按键都重置拖选，也不是只要内容发生变化就重置。

- 有效的非Shift导航、全选、输入／粘贴、撤销／重做后，继续移动鼠标会跟随新的折叠位置，不从旧锚点重新拉出选区。
- Shift扩选继续保留拖选锚点。删除或剪切后则从删除后的插入位置继续拖选。
- 复制、翻页、空历史、只读中被禁止的编辑以及其他无操作，不改变拖选延续方式。
- 只读输入框实际拖动后又回到锚点时，释放保留该内部位置；只有静止单击才沿用此前的点击归零规则。通过既有Component属性记录按下位置和真实移动，不建立另一套鼠标捕获。
- 释放、新按下、真正失焦或丢失捕获继续使用原有清理路径。数值拖动调节与右键菜单捕获保持各自的状态机，不套用普通文本拖选适配。

此前实现只枚举了几个方向键和普通字符，导致Shift扩选被误当成复位，粘贴／全选／有效历史恢复又没有正确复位；只读或边界无操作也可能误置标记。

## 来源和必要适配

`legacy/src/renderer/src/components/TextInput.tsx` 直接使用浏览器input。`native/scripts/capture-entry-history.cjs` 使用实际Edge156.0.4314.50，新增682条观测，包含正反拖选、只读、上下键、Shift／Ctrl左右键、全选、删除、跨词删除、复制剪切粘贴、空历史、有效撤销重做、翻页与禁止删除组合。后续连续移动两次，避免只在第一次恰好折叠时误判为一致；之后释放并检查替换与撤销重做。

全部3615条观测中3605条为规范对照，原有10条浏览器历史缺陷证据仍不作为新版正确行为。

`native/src/native_widgets.cpp` 复用现有 `EntryEditHistory::state` 和MIT Component属性生命周期，在已采样的命令实际完成后比较内容、锚点与光标。只有应复位的命令确实改变状态，才设置原有 `pointer-after-key` 标记。退出命令的提前返回（例如历史恢复）也经过同一作用域收尾。MIT来源为 `native/.cache/aseprite/src/ui/entry.cpp` 与相邻 `LICENSE.txt`；不修改依赖原文件，不另造编辑历史或捕获状态机。

另外在实际浏览器核对了四种边界无操作（开头Left／Up、末尾Right／Down），分别检查可编辑和只读状态；它们保持原拖选锚点，没有因按键名称就复位。此补充采样未纳入固定fixture计数。

## 验证与限制

正式 Release 构建成功；同一正式程序 `--text-tool-check` 实际退出码0，3605条规范观测回放通过。来源登记覆盖542个文件通过，`git diff --check` 通过；来源覆盖不代表整体迁移等价。沿用裸PixelEntry逐条回放，保持原数值框、剪贴板、聚焦、扩宽和缩放几何检查。

本批没有验证任意多次交错的键盘操作、词拖选与键盘的全部组合、复杂字形、窗口级取消或真实IME预编辑。没有人工截图验收；不得据此宣告文字模块整体已完成。
