# 瓦片模式专用快捷操作（2026-10-29）

## 范围和来源

对应 Legacy `components/panels/TilesetPanel.tsx` 两类面板的 `shortcutCommandHandlerRef`、`components/app/app-layers-shortcuts.ts` 的瓦片命令发布、`core/shortcut-contracts.ts` 空默认绑定，以及 `store/workspace-commands-tilemap.ts::setTilemapMode`、`store/workspace-commands-free-tile.ts::setFreeTileMode`。旧版模式工具可用性证据见 `store/workspace-tilemap.test.ts`；本批不据此宣称其它源绘图工具已迁移。

沿用 `legacy/LICENSE` 内部修改、构建许可。接通旧版六个已登记的模式快捷命令：普通瓦片原位编辑、变体创建、混合编辑、绘制；自由瓦片编辑源、放置实例。不增加默认按键、菜单、组件、图标或布局。

## 行为与原生适配

- 普通瓦片模式直接调用现有模式设置函数，不改变图层／帧焦点、主副瓦片或作品像素。
- 自由瓦片复用现有按钮使用的模式设置函数。进入放置实例清空实例选择；进入编辑源沿用旧版可编辑实例筛选和源选择同步。
- 模式属于会话状态，不新增历史、不影响重做、不自行取消文档事务。活动手势仍由现有按文档身份记录的快捷队列处理。
- 两类命令只送达对应的可见目录和有效资源，防止普通瓦片命令修改自由瓦片上下文、反向误触及隐藏栏目继续接收。当前原生事务和面板准入沿用已有按钮，不额外开放未迁移能力。
- 复用快捷设置界面、文字输入避让及长按重复抑制，切换后使用现有刷新更新模式按钮和工具可用性。

## 验证

- 唯一正式 Release 程序构建成功，路径仍为 `native/build/Release/moonsprite-native.exe`。
- 正式程序 `--layer-context-check` 退出0。通过实际重新绑定F8和按键路由验证六个模式命令；检查自由瓦片放置清空选择、源编辑恢复可编辑实例，以及模式切换不改变像素、历史、内容修订和重做可用性。
- 普通瓦片四种模式逐项检查，同时保护主副瓦片、当前图层／帧和像素；两类面板互不接收另一类命令。隐藏目录及长按重复键无效。
- 既有实例／源属性、列表、画布和剪贴板入口检查继续通过。来源覆盖514文件及证据快照、diff空白检查通过。
