# 颜色编辑复制反馈与色板滚动迁移（2026-11-16）

本阶段依据实际 `legacy/src/renderer/src/components/ColorValueControl.tsx` 的 `copyHexToClipboard`、`copySwatch`、对照色块和完整色板列表，以及 `styles.css` 的 copied 状态、pointer-transparent 提示和 overflow。复用既有原生颜色换算、色块、PixelScrollBar、Fusion10px、皮肤与选择轮廓；属于功能迁移。

## 行为与适配

- 复制前色／当前色输出大写 HEX：不透明为六位，其余保留八位。成功执行复制路径后标记对应色块，重复复制重新计时，900ms 后清除；复制不提交颜色。
- 提示按旧版保存复制种类，文字反映该种类当前颜色；关闭弹窗不等于销毁组件，定时器在组件销毁时清理。浏览器异步 API／textarea fallback 由现有原生同步剪贴板后端替代。
- `PixelStatusToast` 使用现有主题、字体和间距，在父窗口及相交子控件内容后绘制同一状态层，承接 CSS `pointer-events:none`；不增加可截获鼠标或焦点的浮层控件。
- 紧凑色板保留全部条目，超出可见高度时显示共用原生滚动条，滚轮、滑块拖动及轨道翻页均沿用既有控件。工具行固定；扩大后自动移除不必要的滚动条并夹紧滚动位置，空色板显示旧版空状态。
- 原生条目保留输入顺序和键盘焦点顺序；不可见条目使用空裁切矩形，聚焦时滚入视口。模式切换重新挂载色板时回到顶部，承接旧版 DOM 生命周期。
- 色板鼠标按住不提前选色，释放在条目内才应用；外部释放、Escape 或失焦取消。沿用普通按钮键盘激活。
- 相邻同色选中条目按用户已确认的统一选择素材规则绘制外轮廓。提取既有主色板的边界合并、凹角拼接和绘制／命中归属代码供共用；使用 `Skin::selectionMaterialBounds`、`drawSelectionBorder`、`selectionContains`，不另画选择素材。
- 色板与吸管共享同一鼠标过滤器所有权，避免退出吸管时移除仍需要的色板边框输入路由；过滤器关闭／销毁时清理。

已核对 `legacy/LICENSE` 的内部开发许可；复用现有 Aseprite MIT `ui/ScrollBar`、`Timer`、`Manager` 与相应许可，不复制 app 层商业许可代码。
