# 自由瓦片实例剪贴板菜单接通（2026-10-29）

## 范围与来源

本批修正已有实例剪贴板的顶栏入口，承接 TI-004 的实例复制／剪切／粘贴，不代表整个自由瓦片模块完成。

- `legacy/src/renderer/src/components/app/app-document-shortcuts.ts`：实例栏目上下文中使用实例复制和剪切，粘贴由统一剪贴板入口处理。
- `legacy/src/renderer/src/store/workspace-cut.ts`：先成功复制，再调用已有实例删除命令；锁定保护沿用删除命令。
- `legacy/src/renderer/src/store/workspace-free-tile-instance-clipboard.ts`：捕获实例及其源资源，同集合复用，其他集合导入并重映射，保留世界坐标；粘贴产生一条历史并支持恢复选择。

旧版许可沿用 `legacy/LICENSE`；本批仅在本仓库修改与内部构建，不改变许可归属。

## 修正

原生已有应用剪贴板、资源复制和历史事务，但 `createTilesetPanel` 附加的自由瓦片统一禁用条件仍阻断三个真实菜单项。旧运行断言调用 `menuCommands_`，绕过了该条件，因此不能证明顶栏可用。

现仅在实例视图下为已经接通的实例剪贴板开放菜单。复制和剪切要求有实例选择且没有像素选区；粘贴要求应用实例剪贴板非空且目标层未被有效锁定。活动事务期间不开放。色板路径保持原有条件，普通自由瓦片视图及未迁移的像素剪贴板不因此开放。

继续复用现有命令路由和实例剪贴板，不新增系统格式、按钮、图标、窗口或布局。本批不解决外部图像优先级与自由瓦片像素剪贴板等其余缺口。

## 验证

正式 Release 构建成功，产物为既有的 `native/build/Release/moonsprite-native.exe`。

正式程序 `--layer-context-check` exit0：通过真实 `PixelMenuItem::available` 和 `Click` 检查实例复制、剪切、粘贴入口；断言粘贴只增加一条历史、撤销恢复内容和实例选择、重做，以及剪切先复制再删除和撤销。锁定目标的粘贴菜单不可用，强制调用其点击回调也不修改内容；退出实例视图、空实例选择继续使用禁用保护。

来源登记覆盖513文件、证据快照和本批 diff whitespace 检查通过。未新增视觉或性能验收，不声明所有剪贴板上下文已等价。
