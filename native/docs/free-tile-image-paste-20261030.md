# 自由瓦片图片粘贴与实例剪贴板优先级

## Legacy 来源

- `store/workspace-commands-clipboard.ts`：`pasteClipboard`、`pasteSelection`、`selectionClipboardSurface`、两条自由瓦片图片粘贴分支。
- `store/clipboard-service.ts` 及其测试：内部复制时记录系统图像基线；比较完整像素和掩码，而非仅比较尺寸或系统序号。系统不可读或无图像时回退内部内容。
- `core/free-tile-document.ts::rasterSurfaceToFreeTileStamps` 及 `core/free-tile.test.ts`：内容边界起算的256px分块、逐块透明裁边和原世界位置。
- `core/free-tile-edit.ts::createFreeTileSourceEditRaster`：选中实例按方向转成临时栅格，保留画布与粘贴起点范围及16–128px留白；仅写入临时栅格内的图片像素，随后逆变换裁边。

上述路径均相对 `legacy/src/renderer/src/`，哈希在来源登记中核对。

## 承接行为

选中实例时，图片逐像素覆盖共享源，遵守图片掩码，半透明像素直接替换而非 source-over；透明且被显式选中的像素可以擦除源。实例与源的隐藏／锁定约束保留，目标层锁定拒绝修改。共享源更新会刷新同源层帧缓存。粘贴不会进入普通浮动选区，不套用现有选区或主文档对称轴。

没有选中实例时，图像有效内容按256px网格分块，每块裁掉透明外围，生成唯一命名的源资源与实例，同集合图层共享新增源。实例位置保留图片位置和目标Cel偏移，只选中最后一个新增实例并切换Edit。整次操作一条历史，撤销移除新增资源并恢复模式与选择，重做保留身份。

自由瓦片实例复制时只读获取系统图像基线。统一粘贴在旧内部实例内容之前检查系统图像：未变化则粘贴内部实例，同尺寸但像素改变则粘贴外部图像；无图像或读取失败继续使用内部实例。该基线本批只用于实例剪贴板，不宣称图层／帧／Cel的全部外部优先级已统一。

原生适配复用Document资源、派生渲染、TilemapSelection、实例选择和现有原子时间轴历史；暂存候选状态后才发布，错误不会留下部分源或实例。保留现有256px单源、16M图像／临时栅格预算和固定画布派生缓存限制；历史仍是现有Native时间轴快照，尚未等价迁移旧版细粒度闭包内存方案。没有新图标、布局或软件内皮肤编辑器。

## 验证

实际执行结果记录于迁移计划。定向核心覆盖全部16种旋转／镜像、原始alpha替换、掩码、共享缓存、保存重开、撤销重做、锁定、透明无操作、分块、位置和超限原子拒绝。程序检查使用真实菜单与已有粘贴入口，系统图像读取采用注入，不改写用户系统剪贴板；不将其称为真实跨应用剪贴板验收。未做新增图像或长期性能验收。自由瓦片像素复制／剪切、整层移动及其余迁移缺口继续保留。
