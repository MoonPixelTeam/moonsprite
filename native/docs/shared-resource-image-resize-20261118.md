# 网格与自由瓦片共享资源的图像缩放

## 用户决定与旧版依据

2026-11-18 用户明确选择“采用预乘透明度，保留共享资源”：同一资源同时由网格和自由瓦片引用时，只缩放一次，统一使用自由瓦片的预乘透明度采样，保持资源 ID 和全部引用。

实际来源为 `legacy/src/renderer/src/core/free-tile.ts` 的 `resizeFreeTileTileset`、`free-tile-document.ts` 的 `resizeFreeTileDocumentImage` 和历史图集迁移、`project-format-decode.ts` 的资源校验，以及 `workspace-commands-document-io.ts` 的图像大小事务。旧版原本隔离网格与自由资源，此共享行为是用户批准的差异，不能将其声明为旧版等价。

## 原生实现

- `Document::resizeResourceImage` 复用既有按 tileset ID 的计划，每个资源只采样一次；被自由层引用的资源选择预乘透明度路径，纯网格资源仍用既有普通 RGBA 插值。
- 既有事务同步网格瓦片尺寸、自由资源偏移和实例位置，重新生成两类 Cel 缓存；图层和帧身份、资源和 tile ID、布局、单元格及链接保留。提交仍是一条历史，撤销重做使用原有完整资源快照。
- 可编辑导入接受共享引用，继续检查现代自由资源的单瓦片表结构、重复源和自由资源集归属。其他畸形数据不因此放行。
- 历史自由图集被网格图层或单元格引用时，不再拆成新资源。schema21 读取时仅对确有网格引用的 atlas ID 接受已有历史元数据，从而让这类原生文件保存后重开；没有新增 schema 号。这是原生共享扩展，不保证旧版软件能读取这种共享历史图集。
