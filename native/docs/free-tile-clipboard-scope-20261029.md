# 自由瓦片实例复制／剪切的栏目上下文（2026-10-29）

## 来源

`legacy/src/renderer/src/components/app/app-document-shortcuts.ts` 在 layers 命令范围、实例视图且已有实例选择时，优先调用实例复制／剪切，不让像素选区抢占；`store/workspace-free-tile-instance-clipboard.test.ts` 首个用例明确保留无关画布选区并复制实例。`store/workspace-cut.ts` 定义先复制成功、再按已有删除命令删除。`components/app/useAppCommandScope.ts` 记忆最后一个有效编辑表面，菜单不替换该范围。许可沿用 `legacy/LICENSE` 的内部修改和构建条款。

## 原生承接

原生的像素选区检查和自由瓦片菜单禁用条件先于实例复制，导致旧版允许的操作被拦截。本批将实例栏目拥有上下文时的复制／剪切置于像素选区之前，并允许对应菜单项。

上下文使用既有全局焦点通知和实例面板焦点／鼠标按下事件记忆。转入画布或其他栏目时退出实例范围；菜单没有编辑表面，保留原范围。该状态属于界面会话，不改变作品、文档历史或存储。仍检查实例视图、选中实例、色板上下文及活动事务；回到画布时不将未迁移的自由瓦片像素复制错误开放。

内容操作复用既有实例捕获、应用剪贴板替换、共享源记录和删除事务。复制保留画布选区与作品；剪切先捕获再删除，一次删除历史，画布选区不变。锁定实例的删除保护继续由原命令承担，不自行改变复制行为。

没有修改图标、布局、系统剪贴板格式或外部图像优先级，不宣称整个自由瓦片剪贴板已等价。
