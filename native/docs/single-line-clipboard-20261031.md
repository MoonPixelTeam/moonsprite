# 单行输入框剪贴板快捷键

## 来源与迁移范围

旧版 `TextInput.tsx` 的默认类型是 `text`，`NumberInput.tsx` 也使用 `input type="text"`。复制、剪切、粘贴由浏览器处理。此次迁移共用 PixelEntry 的键盘路径，覆盖普通名称框及数值输入框；不改变数值提交、字体、皮肤或排版。

`node native/scripts/capture-entry-clipboard.cjs` 在 Edge 156.0.4314.50 采集 432 条实际输入结果：六种快捷键、可编辑／只读、空／正反向选区、英文／中文／Emoji、空及带换行的剪贴板。保存内容、选区及剪贴板文本，原生检查使用相同输入与预期。

## 行为及实现

- Ctrl+C／Ctrl+Insert 复制，Ctrl+X／Shift+Delete 剪切，Ctrl+V／Shift+Insert 粘贴。
- 空选区复制和剪切不写剪贴板，也不删除光标后的字符。只读输入框允许复制，禁止剪切和粘贴。
- 剪切写入成功才调用现有 Entry 的选区删除命令；写入失败、抛出运行异常或缺少 delegate 均保留文字及选区。
- 粘贴先读取一次，再按实际浏览器行为将每个 CR、LF、CRLF 换行为一个空格。有效空文本可删除选区；读取失败不变更输入。
- 通过作用域内的内存 clipboard delegate 快照调用现有 Entry Paste；不重写其字形框、长度限制、选区替换和 Change 通知，也不将规范化文本写回系统剪贴板。调用结束恢复原 delegate。
- 粘贴前清除底层 Entry 的零长度选择锚点，避免把刚插入的文字误选中；可见光标及内容仍由 Entry 管理。
- 无内容变化不发送 Change；实际文字变化只发送一次，继续使用数值框原有的草稿与提交回调。

## 验证与边界

正式 Release 构建及 `--text-tool-check` 通过（退出码 0）。实际单行控件逐条通过 432 条浏览器对照，验证每次操作的内容、选区、剪贴板和 Change 次数，并覆盖写入失败／异常、读取失败／异常和缺少 delegate。既有多行文字菜单及文字输入检查同次通过。531 文件来源登记／证据快照核对通过；来源覆盖不代表整体行为等价。原生控件检查使用注入内存后端，不覆盖用户真实系统剪贴板；没有人工截图验收，UI素材与布局未修改。

本次范围是键盘剪贴板命令。继承的 MIT Entry 右键菜单仍直接执行其原有命令，尚未接入这批剪切失败保护与单行换行规范化，不能据此宣称整个剪贴板或文字模块迁移完成。系统跨进程写入、真实锁竞争和输入法组合仍未人工验收。
