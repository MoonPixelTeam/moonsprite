# Native 全代码 legacy 对照审查

2026-10-12。结论：**不是完整 legacy 迁移，当前不能通过完全一致性验收。** 本轮已修明确算法与缓存偏差，但不能以原型测试通过替代完整功能承接。

## 范围与追溯

逐文件登记见 [legacy-provenance.json](legacy-provenance.json)，覆盖 `src/`、`tests/`、`scripts/`、需求提取脚本、CMake 及两个启动入口，共 34 个代码文件。来源保留 SHA-256；变更来源或新增未登记代码会使检查失败。依赖缓存与编译产物不属于自有业务源码，固定依赖及许可见 [THIRD_PARTY](../THIRD_PARTY.md)。素材不按数量声称代码覆盖率。

```powershell
python native/scripts/check-legacy-provenance.py
python native/scripts/check-legacy-provenance.py --strict
```

第一条只检查登记与来源完整性，**不证明语义等价**；第二条在已知缺口存在时返回失败，这是正确结果，禁止修改分类来制造通过。

## 已发现并修正

| 问题 | legacy 依据 | 当前修正 |
| --- | --- | --- |
| 自写直线算法强求正反向相同，导致 tie 像素不同 | `core/selection.ts::forEachRasterLinePoint` | 保留 strict Bresenham 的方向相关落点；使用等价有界公式避免极远越界点产生长循环；删除错误的正反向相同断言 |
| 每笔复制整幅像素、dirty 比较整图、提交扫描整图 | `core/history.ts::PixelEdit/recordPixelKnownCurrent` | 修改时增量记录 before/after；事务提交只遍历变更点；取消/撤销/重做产生修订及脏矩形 |
| 撤销历史无限增长 | `core/history.ts::HistoryStack/trimOldestUndoEntries` | 默认 256 MiB、最多 10000 项，按变更载荷计量，超预算淘汰最早项且保留最新操作；不是进程总内存上限 |
| UI refresh 直接使作品缓存失效 | `components/canvas-composite-cache.ts` | 渲染器用文档身份和内容修订判断；连续修订只上传脏矩形，跨过修订则整图同步保证正确 |
| 棋盘格写入作品缓存，非零 alpha 当成不透明 | `components/canvas-render-background.ts` 与合成缓存 | `CanvasRenderer` 独立管理透明 RGBA 源与 2×2 背景 tile；背景先画，作品使用 source-over 合成，画布/预览共用源 |
| 缩放漏档位 | `core/canvas-input-navigation.ts::CANVAS_ZOOM_LEVELS/steppedCanvasZoom` | 采用完整 23 档及 epsilon，范围 6.25%–6400%；8× 下一档为 10× |
| 源码残留自创二进制 `.moonskin` 格式 | 当前用户要求 PNG/XML 外部素材 | 删除未接入运行界面的编码/存盘路径及对应旧测试；不删除用户文件，不修改图集 |
| 手绘占位图标生成器仍可使用 | 所有图标必须复用 legacy | 退役生成器，原文件入口清楚报错；已有用户图集保留 |
| 皮肤检查器把未使用槽位标为已接入 | 当前真实绘制调用 | 缩减实际接入名单；旧 `canvas_frame`、`tab_active`、皮肤内工具图标及时间轴等不再伪标为已接入 |

当前绘制职责为：文档事务维护像素/历史/修订/脏区 → `CanvasRenderer` 更新内容表面 → 背景/作品分层绘制 → 现有 laf UI 调度合并失效区域。平移更新视图并请求画布区域，不另建渲染循环。UI、文档历史和渲染资源各自持有状态，不允许 UI 直接写像素、修订、历史或缓存版本。

## 不能认定已经迁移完成的部分

| 范围 | 当前限制 |
| --- | --- |
| 文档/命令 | 仅单层单帧内存像素，缺少 legacy 的 `SpriteDocument`、会话 Store 领域命令、结构事务、链接像素、完整笔刷语义；`main.cpp` 仍集中持有输入/UI/命令接线 |
| 渲染 | 没有多层混合/效果、动画源缓存、选区与预览覆盖层、画外内容、完整预算回收及预览后台策略；单层修订适配不能代表完整旧合成架构 |
| 视图/输入 | 仍在物理像素处取整原点与目标矩形；尚无连续精度、旋转/镜像、平滑缩放、拖动灵敏度、视图偏好；当前 zoom 与 2× 外观关系仍需独立 DPI/坐标验收 |
| 工具 | 13组29项目录及原图标匹配；仅铅笔/橡皮/抓手部分功能可用；组弹出仍用原生菜单，未迁移横向布局、400ms长按、组记忆、自定义顺序和快捷键偏好 |
| 菜单/工作区 | 只有已明确展示的子集，原生窗口固定尺寸；不代表旧菜单命令、停靠、工程标签、多工程已完成 |
| 持久化与平台 | 没有工程保存/导出、恢复、崩溃恢复、平台集成及扩展运行；不得用原型替代用户生产工程 |
| 皮肤/字体 | 用户明确要求的 Fusion 10px、2×、Aseprite PNG/XML 图集、九宫格和栏目外观，是新设计及原生适配；不存在应强行复用的 legacy DOM/CSS 对等实现。IME和多语言验收仍未完成 |
| 生命周期/错误 | 尚无完整旧异步任务/错误通道的承接和长时间交互性能证据；渲染器分离与单元检查不能证明长期卡顿已彻底解决 |

上述缺口必须继续保留在需求覆盖中，不能用“技术适配”掩盖功能/语义减少。后续逐个迁移时沿用这里的证据来源及旧测试，而不是以当前原型的新写法为标准。

## 本轮验证

- 原生程序及三个定向测试目标编译通过；CTest 文档事务、PNG皮肤、XML图集三项通过。
- 20,736 组有向端点按 legacy 原函数逐点验证，覆盖八象限、tie、负坐标、越界和重合点；保留极远坐标检查。
- 原生消息层 smoke 验证半透明 RGBA 合成、缓存修订、取消、文档替换、界面刷新不上传内容、1设备像素平移、组菜单及已有操作。
- 清单覆盖检查通过；完全一致性检查预期失败，原因是上表尚未完成项。
- 没有进行真实操作系统鼠标/触控/数位板、DPI、多显示器或长期压力测试。
