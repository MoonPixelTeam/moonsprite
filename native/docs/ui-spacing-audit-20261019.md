# UI 间距审计与统一（2026-10-19）

依据：[UI设计规范](ui-design-spec.md)。以下均为1×逻辑像素。本文记录本轮源码审计和运行验收，不代表旧版业务功能已全部迁移。

## 根因

标题组件更新后，各业务正文仍按原来的20/22/24/25px绝对起点排列；正文内边距混用5/6/8px；表单控件统一20px后，旧的18px高度、21/23/24px行距仍保留；模态按钮底部距离从皮肤底边厚度间接推算。相邻组件、最小尺寸和文字绘制分别计算，导致局部修改会牵动其它区域。

## 本轮统一

UiSpacing和DialogLayout位于src/native_widgets.h：关联2、分组6、正文边距6、标签10、表单20、操作图标15。正文从标题21之后留6，即27开始；标签到控件12（10+2）；完整分组推进38（10+2+20+6）；同类关联控件推进22；底部按钮距离外框6。正文底部、最小高度和底部操作间至少6。

## 验收记录

Release正式产物构建通过。静态检查不能代替运行截图。当前uiScale编译常量为2；1×只进行逻辑尺寸关系核对，不声称完成1×真实桌面运行。

新增检查复用--modal-components-check：18类模态弹窗在最小尺寸下检查正文不侵入标题、不越界、不覆盖底部操作，底部6px；导出、首选项与图层属性生成图像。--dialog-geometry-check增加共享布局关系检查，--new-document-check增加正文与分组间距检查。

### 实际结果

- 正式Release构建通过（唯一产物build/Release/moonsprite-native.exe）。迁移来源覆盖检查通过320个文件；仍有登记中的功能迁移缺口，不声称行为全部等价。
- 布局相关检查通过：dialog-geometry、new-document、modal-components（18类最小尺寸）、docking、color-editor、export-dialog、adjustment-components、custom-grid、animation-settings、about、canvas-resize、preferences。
- 目视核对生成的2×图像：新建画布、颜色编辑、静态/动画导出、悬浮栏目。直接设置Pending生成的图层属性/首选项截图有隐藏控件，不作为完整视觉验收依据。
- 扩大回归未全部通过：panel-scroll报“Palette Space pan not captured”；palette-mouse/workspace报“Legacy gradient controls”；modal-layout报“Floating preview title detached from its frame”。这些结果保留，当前不能宣称工作区全部交互验收通过。滚动条综合检查在palette-mouse进入后已执行，但后续工具属性断言失败，不能将整个检查计为通过。
- 本轮统一普通表单、栏目工具行和共用组件的间距；没有改写上述失败所涉及的拖动/渐变工具状态机，也未把业务交互缺口解释为已修复。
