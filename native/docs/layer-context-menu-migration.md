# 图层时间轴右键菜单迁移

直接来源：legacy 的 panels/useLayerContextActions.tsx、useTimelineContextActions.tsx、LayerContextMenuItem.tsx；中文来自 locales/zh-CN.ts、gradient-map.ts，快捷键来自 core/shortcut-contracts.ts。图标来自 PixelUtilityIcon.tsx 的原始主路径和半透明路径；正交多边形按像素中心转换，不平滑或重画。

- 空白图层区域：6项新建菜单（普通图层、组、渐变映射调整层、瓦片层、自由瓦片层、背景层）。普通图层可用，其余灰显。
- 普通图层：新建子菜单、复制、关联图层、转换子菜单、三类合并、剪贴蒙版、图层蒙版、样式子菜单、属性、删除，共23个叶项。当前可用新建、已有不透明度属性及删除（最后一层/锁定层禁用删除）。没有伪造组、蒙版或样式对象，相关对象存在时才适用的旧版条件项仍是迁移缺口。
- 帧头：创建循环节、生成补间、帧属性、启停帧、复制、粘贴、反转、新增帧、新建空白帧、删除当前帧，共10项。循环节编辑、帧时长、复制新增、空白新增和删除接入；其余灰显。右键已选帧保留多帧选择；执行动作时使用被右键的帧，不能删除全部帧。
- 单元格：补间、创建蒙版、粘贴蒙版、单元格属性、复制、粘贴、反转、连接、断开连接、删除，共10项。仅已有单cel断开链接可用，未接入灰显；不把新增链接帧当成连接所选cel的近似替代。

图层名称、眼睛、锁及自动链接所在行区域均可打开图层菜单，帧头和cel使用自己的菜单；背景空区打开新建菜单。上方按钮行为沿用当前实现。

验证：layer-context-menu检查四类叶项数和可用状态、旧版图标加载、最后帧保护、新建图层、断开链接及撤销，并生成菜单绘制图片。来源覆盖检查通过；此项只迁移入口与已接入功能，不表示其余功能已完成。
