# 单行输入框鼠标选择与编辑历史

旧版 TextInput／NumberInput 使用浏览器 input。MIT Entry 原有鼠标按下会重置锚点，不能承接 Shift 点击已有选区；本地输入历史也需区分真正改变选择和同位置点击。

PixelEntry 保留 MIT Entry 原有鼠标定位、滚动、捕获与释放，在 Shift 左键按下后恢复原锚点。Shift按住拖动按当前浏览器实际观测收起至移动终点；普通正反向拖选沿用底层状态机。实际改变光标或锚点才打断输入历史分组，同位置点击继续合并。快照仅用于按下、双击及捕获中的移动，普通悬停不增加文字状态快照。数值拖动、焦点和右键菜单路径保留。

新增132条实际Edge 156.0.4314.50观测，包含正反向初始选区、Shift点击、普通／Shift拖动、替换后撤销重做，以及同位置点击和改位置后的历史分组。浏览器输入使用固定等宽字体保证插入位置可重复；原生使用自己的字模及真实控件鼠标消息。完整夹具1853条，1843条规范对照，10条先前异常排除。

正式Release构建与最终 `--text-tool-check` 通过（退出码0），1843条规范历史／焦点／键盘／鼠标对照和既有文字检查通过；538文件来源登记与证据快照检查通过。本次只对照简单ASCII、无水平滚动场景；复杂字形、视口边缘持续拖动、系统双击／三击、只读与全部焦点组合不声明等价。未进行人工截图验收；布局与素材未改。
