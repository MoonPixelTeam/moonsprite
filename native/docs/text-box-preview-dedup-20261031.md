# 文字框拖动预览去重

## 旧版行为

`legacy/src/renderer/src/components/canvas-input-text.ts` 在开始文字框移动／缩放时分别保存起始矩形和最近请求预览的矩形。`moveTextTransform` 调用 `canvas-box-preview.ts` 的 `sameBoxPreview` 比较 x、y、width、height；目标没有变化就跳过文字重排、缓存失效和绘制调度。文字内部拖动仍需跨过原有手势阈值，边缘缩放立即预览。

## 原生承接

- 文字手势增加专用的最近请求矩形，开始新手势时从起始矩形初始化。它不使用栅格化后已校正的文字元数据，以免旋转文字重复生成像素。
- 缩放与内部拖动统一先比较目标矩形，变化后才调用既有文字草稿或移动事务。重复指针事件和同坐标松手不再重新预览。
- 比较最终矩形，指针坐标相同但比例／中心修饰变化时仍更新预览。
- 松手、取消和新手势仍由既有生命周期处理；静止边缘点击维持旧版一次提交，内部静止点击维持打开文字编辑器。

## 验证范围

正式Release构建、正式程序 `--text-tool-check`、515文件来源覆盖及证据快照检查、`git diff --check` 均通过。实际输入覆盖初始静止手柄、重复的链接旋转文字预览（像素缓存地址及文档修订号保持）、重复框内移动、同指针位置切换比例修饰、取消、单次提交、撤销和重做。已有文字工具检查同时通过。未新增人工图像验收或长期性能测试，没有改变布局、素材、字体或工程协议。

## 保留差异

变化的文字目标仍调用现有 `refresh`；尚未整体承接旧版按新旧文字范围失效缓存的优化，本批不宣称文字工具性能完全等价，也不宣称整体迁移完成。
