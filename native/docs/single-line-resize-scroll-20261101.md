# 单行输入框扩宽时更新显示范围（2026-11-01）

## 修复的行为

长文字输入框原本在编辑后会修正横向滚动，但窗口或栏目拉宽时不会立即应用同一纠正。即使已能放下全部内容，左侧文字仍可能被旧滚动位置隐藏，直到下一次输入事件才恢复。

现在共享纠正也由输入框的尺寸事件调用。扩宽到足以显示全部内容时，立即清除旧偏移；保留光标、正反向选区、只读状态、内容与本地撤销／重做，不产生内容通知。不引入第二套滚动状态或后台定时器，继续复用 MIT Entry 的光标／滚动与输入法位置更新路径。带单位的输入框仍扣除原有单位区域。

## 来源与适配

- `legacy/src/renderer/src/components/TextInput.tsx` 直接转发浏览器 input。
- `native/scripts/capture-entry-resize.cjs` 在实际 Edge156.0.4314.50 采集24组扩宽行为；`native/tests/fixtures/entry_resize_browser.h` 保留窄态滚动、扩宽后滚动和选区。覆盖英文长文、中文长文、短文、空值、正反选和只读。
- `native/.cache/aseprite/src/ui/entry.cpp` 中 `setCaretPos` 持有滚动、光标状态和系统文本输入位置；许可见同目录 `LICENSE.txt`。本批不修改依赖源码，使用其公开接口。
- `native/src/native_widgets.cpp` 中原有两处全内容可见纠正提取为共享函数，并在 `onResize` 复用；没有改字体、布局规格、素材或数值箭头。

## 检查范围和限制

正式 Release 构建成功；同一正式程序 `--text-tool-check` 实际退出码0，新增48组扩宽检查及原有2923条规范历史回放通过。来源登记检查覆盖540个文件通过，`git diff --check` 通过；来源覆盖不代表整体迁移等价。新增原生检查对24组浏览器观测分别测试无单位和px单位，共48组；在尺寸事件后立即核对滚动、选区、方向、Change通知、历史数量与分组，并重复缩窄／扩宽。历史检查先制造真实删除记录，避免仅验证空历史。

窄态浏览器是像素偏移，当前 MIT Entry 使用字符框索引，因此保留窄态数值作来源证据，不将二者数值直接等同。只承接扩宽到全部内容可见的场景；部分扩宽时的最小偏移、缩窄后光标跟随、边缘拖选速度、复杂字形及完整 IME 仍未宣告等价。本批无人工截图验收。
