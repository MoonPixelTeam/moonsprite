# 自由瓦片实例栏目布局迁移（2026-10-29）

## Legacy 依据

- `WorkspacePanels.tsx` 与 `layer-panel-preferences.ts`：布局默认 separate；手动隐藏后，仅在 active layer/cel key 改变、布局切回 separate、实例从空变非空或实例数增加时自动打开。
- `FreeTileInstancesPanel.tsx` 与 `FreeTileInstancePanelSettings.tsx`：实例列表可独立于普通时间轴显示，设置立即保存并生效；栏目操作复用已有 settings 图标。
- `LayersPanel.tsx`：集成模式在图层栏目中切换到实例列表。

## 原生承接

- 默认使用独立停靠栏目，也可在设置中切换为合并到图层栏目。独立模式允许普通图层时间轴继续显示。
- 设置使用原生偏好文件，应用层继续由共享停靠/悬浮模型管理；栏目素材和操作图标复用既有皮肤与 legacy 对应图标。
- 列表项激活实例编辑上下文。切换到普通图层、cel 或帧选择时退出该上下文，避免后续键盘和画布命令落到实例列表。
- 实例栏目拥有独立显示状态；显式隐藏后，相同目标及实例数量的刷新不会自动重新打开。

## 尚未等价承接

- 偏好存储从浏览器存储适配为本地文件；旧版设置不会自动导入。
- 尚不声明完整 TI-004、长期运行、性能或逐像素视觉等价。
