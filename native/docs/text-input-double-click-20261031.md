# 文字输入框双击选择

## 来源与证据

旧版`TextAreaInput.tsx`转发浏览器textarea，`TextToolDialog.tsx`按onSelect/onKeyUp/onPointerUp同步文字样式。来源快照核对一致。

`node native/scripts/capture-text-double-click.cjs`使用旧版Playwright和本机Windows Edge 156.0.4314.50，在临时内存页面对字符左右两侧发送真实双击。124条结果存入`tests/fixtures/text_double_click_browser.h`，包括中英文、连续空白、单／连续标点、下划线、字母间句点、撇号与小数。旧版源码、用户浏览器、作品和剪贴板未修改。

## 本次承接

- 双击选中所指词及后续水平空白；直接双击空白只选择该空白段。
- 双击连续标点时分别选择所指标点，不能套用Ctrl跨词操作的成组标点边界。
- 按最近插入点定位，词尾字形右侧可选择后续空白，与浏览器样本一致；原有完整字素和软换行位置继续承接。
- 第二次按下由工具包发出DoubleClick消息，后续鼠标释放保留选区；选择不修改文字或撤销历史。选中后删除／替换走原有文字变更与UTF16样式同步链路。
- 复用已有Windows系统ICU接口及现有组件，无新运行依赖、布局、字体或图标。

## 验证

正式Release构建、`--text-tool-check`（退出码0，124条双击及原有680条跨词对照均通过）和520文件来源／证据快照检查通过。真实原生鼠标消息覆盖首次单击、第二次双击和释放，逐条核对124个范围，并执行删除与本地撤销，确认原文字和选区恢复。原有680条Ctrl跨词对照及字素／折行检查同次运行。

## 明确限制

本次只接通双击选词至后续编辑链路。浏览器双击按住后的按词扩展拖选具有另一套边界规则，三击选段、输入法、双向排版仍未迁移；本次未用普通字符拖选近似它们，双击后移动鼠标不会扩展范围。不同系统／浏览器词典版本及未列语言未证明等价。未做人工截图验收。
