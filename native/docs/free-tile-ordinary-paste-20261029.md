# 自由瓦片普通图层视图粘贴（2026-10-29）

## 来源与行为

旧版 `store/workspace-commands-clipboard.ts::pasteLayersFromClipboard` 将实例载荷交给 `workspace-free-tile-instance-clipboard.ts::pasteFreeTileInstances`。该方法使用 `core/free-tile-document.ts::activeFreeTileCelTarget` 取得目标，没有要求打开实例列表；`workspace-free-tile-instance-clipboard.test.ts` 提供同集合资源复用、堆叠顺序、选择恢复与跨工程资源导入证据。许可沿用 `legacy/LICENSE` 内部修改及构建条款。

原生已有实例载荷、源引用、偏移补偿、导入及历史，但模型、统一粘贴入口和顶栏菜单同时限定 `freeTileInstanceView()`，导致退出实例视图后无法粘贴。本批移除粘贴对该视图的依赖，目标仍须是有源模型和当前Cel数据、未锁定、未隔离蒙版的自由瓦片层，活动事务拒绝。

普通图层视图和实例视图均复用相同粘贴事务：同文档同集合复用源；跨集合／跨工程导入源及tileset并分配新身份；保留世界坐标和实例内容，选中新实例、清除像素选区和变换中心，一次历史支持撤销重做，保存重开保留内容。粘贴及其历史回放不强制打开实例视图。

没有新增菜单、图标或组件，也没有放宽复制／剪切和普通自由瓦片像素剪贴板的准入。系统外部图像与内部实例载荷的优先级仍为既有缺口，不因本批宣称整个剪贴板或TI-004完成。
