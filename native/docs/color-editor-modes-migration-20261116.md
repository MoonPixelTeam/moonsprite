# 颜色编辑模式与顺序迁移（2026-11-16）

本阶段为功能迁移，依据实际旧版 `file-preferences.ts` 的模式默认值、旧默认值识别和 `parseColorEditorModes`，`PreferencesDialog.tsx` 的颜色模式行、恢复默认、通用指针排序，以及 `ColorValueControl.tsx` 的可用模式、初始化、偏好变更和模式切换。七种颜色换算复用原生已有的 `color_value_model.h`，其来源为实际旧版 `core/color-values.ts`，不另造算法。已核对 `legacy/LICENSE` 内部开发和测试许可。

## 行为及原生适配

- 默认 HSV、RGB、Lab、灰度、调色板开启，HSL、CMYK 关闭；恢复默认同时恢复顺序与开启状态。
- 开启状态与顺序独立；关闭的模式也能拖动，切换开关不重新排序。至少保留一种模式，最后一个已启用开关禁用，其他模式仍可开启。
- 沿用实际旧版的首项重复去重、缺失模式补齐、全部关闭时开启首项，以及六模式旧默认配置升级。
- 原生已有首选项使用带引号的行记录，本阶段增加有序模式记录；不引入浏览器 JSON／localStorage 或通用测试的 WinRT 链接依赖。读写继续使用已有原子保存及错误反馈。
- 所有共用 ColorEditorPopup 的调用方均使用同一设置。新实例从首个已启用模式开始，已存在实例保留仍有效的模式；当前模式关闭时切到首个可用模式。应用设置同步刷新实例，取消设置保留当前配置。
- 采用现有 QuickCommandDragHandle 和旧版 move／restore 素材，复用捕获、释放、模态路由、视口裁切和边缘滚动。没有新增入口或图标。
- 七个动态页签、HSL 四字段和 CMYK 五字段沿用共享布局、20px控件、2px关联间距、6px正文内边距和内容最小尺寸；尺寸恢复沿用已有文件。
- 切换模式只更新表示，不调用颜色回调；正常 HEX 失焦提交保留，未变化的 HEX 不重复提交。
