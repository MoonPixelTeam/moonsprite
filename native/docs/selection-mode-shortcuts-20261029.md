# 选区模式快捷操作（2026-10-29）

## 旧版来源

- `legacy/src/renderer/src/components/app/app-selection-shortcuts.ts::handleSelectionShortcuts`：替换、添加、减去、相交四个快捷命令先切至选区工具，再设置模式，重复按键不执行。
- `store/workspace-commands-tool.ts::setTool`：切换工具提交浮动粘贴，保留已选选区工具种类。
- `store/workspace-commands-selection-properties.ts::setSelectionMode`：保存工具偏好，不创建内容历史。
- `core/selection.ts`、`core/selection.test.ts`：复用已有模式组合实现及并集、差集、交集语义。
- 内部修改和构建权限沿用 `legacy/LICENSE`。

## 完成范围

接通四个已登记的选区模式命令，不增加默认快捷键、菜单、图标或布局。调用现有选区工具设置与模式按钮回调，保留矩形、椭圆、套索、多边形套索、魔棒、选区笔刷的当前种类，并同步已有工具栏模式状态及持久化。已有浮动粘贴通过同一工具切换函数提交，可按已有历史撤销／重做。

原生旋转视图使用独立角色标记，成功切至选区时清除该标记，避免工具状态仍被视为旋转；没有引入新的选区状态机。活动手势排队、无工程、输入框、弹窗和重复键处理沿用公共快捷系统。单独改变模式不改像素、保存状态、内容历史或已有重做记录。
