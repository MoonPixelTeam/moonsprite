# 自由瓦片源排序（2026-10-29）

## 需求与来源

本批承接 TI-004 的源排序完整操作，依据 legacy 的 `workspace-commands-free-tile.ts:reorderFreeTileSource`、`workspace-free-tile-source-reorder.test.ts`、`free-tile-document.ts:replaceFreeTileSetSources` 及 `TilesetPanel.tsx:FreeTileSourcesPanel`。名称来自 zh-CN 的 freeTiles.sources；许可沿用 legacy/LICENSE。不将源属性、密度或未使用源清理标成完成。

## 可观察行为

- 已选源上按住右键并拖到另一个源，松开提交。移动达到3个逻辑像素后进入拖动；源之间空隙不作为目标；离开网格保留最后有效目标，随后松开仍使用该目标，沿用旧版行为。
- 在目标的原始列表索引插入：向后移动位于目标之后，向前移动位于目标之前。拖动时列表与文档保持原样，只标识落点；松开产生一条“源瓦片”历史。拖动结束不弹出右键菜单，未拖动的右键仍打开源菜单。
- 同集合所有成员同步顺序。源身份、属性、资源、实例顺序、像素缓存与关联关系不改变；不修改主副瓦片、Edit/Paint模式或实例选择。不以源锁或所在层锁阻止资源列表排序。
- 同源或无效ID不修改文档和历史，保留重做。撤销、重做恢复源顺序，保持当前活动层帧与会话状态；保存重开保持源顺序及未知元数据。
- Escape、失焦、捕获丢失、栏目隐藏或尺寸变化以及文档/层/帧/内容版本变化取消手势。活动事务期间拒绝排序，避免覆盖其他正在预览的编辑。

## 必要原生适配

复用现有 TilesetPanel 网格、焦点/捕获/取消处理、主题 accent 状态及 Timeline/Edit 快照历史；右键菜单在选中源的松开时显示，适配浏览器contextmenu发生在右键释放的语义。逻辑像素阈值按整体倍率转成物理像素。源列表数据只有松开后提交，不对画布实例重新排序或重算未变化像素。不引入额外UI素材或架构；不是重新设计源属性。
