# 原生颜色板

颜色板是色卡网格，预览是同一栏目的另一页。去掉前景色大色块与重复的调色盘栏目。

- 左键色卡选择画笔前景色。
- 工具按钮复用 legacy 的 properties 图标，点击选择较小、小、中、大、较大尺寸。
- 对应 legacy 的 22、30、40、52、64 显示像素；默认小尺寸。原生基础格为 11、15、20、26、32，统一 2× 显示，间距 2 显示像素。按参考图将内容边缘留白压缩至 1 个基础像素。
- Ctrl／Meta＋滚轮：向上放大、向下缩小；横向输入取绝对值较大分量。尺寸到端点保持不变，不影响作品、撤销历史或画布缩放。
- 自动换行；当前固定窗口中最大尺寸可容纳全部八个样本色卡。
- 偏好存于 `%LOCALAPPDATA%/MoonSprite/Native/palette-swatch-size.txt`，与 legacy 设置隔离；读取或写入失败在底部状态栏显示。

## 素材

保留用户主题 sheet.png。栏目边框仍用 panel_outer / panel_content，按钮仍用 button。可在 theme.xml 增加 palette 样式，以 normal、mouse、selected 背景边框分别控制色卡轮廓；轮廓素材中心应透明，以显示真实色值。旧 color_well 不再标为接入。

属性图标来自 legacy/src/renderer/src/components/PixelUtilityIcon.tsx，逐字提取路径，SVG 与 PNG 位于 native/assets/utility-icons；使用现有矩形 SVG 转换器转换，未重画。

本次完成色卡区域、尺寸和基础选色。当前八色仍是原型样本，不是完整工程色卡数据模型。色卡库、导入导出、编辑锁、添加删除、次色、框选／多选、手动布局与拖动排序未迁移，相关入口暂不展示。不将这些差异登记为完整迁移。
