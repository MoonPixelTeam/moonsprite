# TI-004：自由瓦片像素选区复制与剪切

## Legacy 依据

以下路径相对 `legacy/src/renderer/src/`，实际来源哈希在 `legacy-provenance.json` 核对。

- `store/workspace-commands-clipboard.ts::copySelection/cutSelection`：活动图层可见像素、画布裁切、透明跳过、掩码与世界原点；先复制再删除，最后完成选区；实例复制与像素复制使用不同上下文。
- `store/workspace-commands-selection-effects.ts::deleteSelection` 及 `workspace-selection-effects-support.ts::deleteFreeTileSourceSelectionInSession`：Edit 模式针对主选实例的共享源，在实例方向下将选区映射到临时源栅格后清除，再逆变换裁边；源／实例锁定或隐藏时拒绝源删除。
- `core/tools-fill.ts::clearSelection`：只在 alpha 内容外接框内清除选中像素，透明RGB洞也属于框内数据。
- `core/free-tile-edit.ts`、`store/workspace-free-tile-transaction.ts`：源裁边与偏移、同源层帧更新和单次源历史；无变化不产生历史。

## 本批承接

复用原有 `Document::copyPixels` 的派生图层取样，不重写颜色混合。复制按当前像素选区掩码和画布范围输出RGBA与原点，不修改资源、像素、选区和历史。画布获得焦点时菜单允许像素复制／剪切；实例列表拥有上下文时继续优先复制／剪切实例。普通自由图层没有像素选区时，整层剪贴板仍未开放。

Edit 模式有主选实例时，剪切先取得剪贴板，再删除该实例所引用共享源的选中像素。同源其他实例、图层和帧会随源更新；实例身份、位置及多选状态不变。复用上一批图片粘贴的逆变换、裁边、资源写回和引用缓存算法，在隔离的文档候选中生成结果，再提交一条原有时间轴历史，避免沿用图片粘贴的选源／模式副作用。Delete 复用同一源删除路径。失败或无变化不提交半成品。

成功删除清除像素选区；剪切即使因锁定或内容为空无法删除，也完成选区。撤销／重做恢复共享源，已经结束的选区不随源像素历史重建。

## 边界

- Paint 或没有主选实例时，源像素删除仍未接入。剪切只复制并结束选区，不改变实例或共享源；没有迁移旧路径直接清理派生缓存的非持久化行为，不将其宣称为完整源删除。
- 保留锁定拥有者图层的原生保护、256px源与16M临时栅格预算、固定画布派生缓存、时间轴快照历史。这不代表旧版全部性能方案已等价迁移。
- 本批不开放尚未迁移的自由瓦片选区内容变换、整层／整Cel／整帧剪贴板，也不改变选区工具的既有开放范围。可使用已有选区或全选入口。
- 没有修改布局、字体、皮肤、图标或软件内UI编辑器。

## 验证范围

实际结果见迁移计划。定向核心覆盖全部16种旋转镜像、像素原点和掩码、复制不变性、共享引用、单条剪切历史、保存重开、撤销重做、锁定、空内容及Paint保护。正式程序检查菜单可用性、实例与画布焦点切换、实际Delete及撤销、空内容Copy／Cut；空内容不写系统图片，因此不覆盖用户剪贴板。非空像素剪贴板写入继续复用既有后端，本批未执行跨应用系统剪贴板验收或新增视觉／长期性能测试。
