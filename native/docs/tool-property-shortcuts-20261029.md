# 工具属性快捷操作（2026-10-29）

## 旧版依据

`legacy/src/renderer/src/components/app/app-tools-shortcuts.ts` 定义六类开关的工具上下文、长按抑制和固定比例启用值；`store/workspace-commands-tool.ts` 与 `store/workspace-commands-selection-properties.ts` 定义属性设置、持久化和不创建内容历史的语义。旧版没有检索到这些命令的专用测试，本批按上述实际分支增加原生快捷路由检查。复用权限沿用 `legacy/LICENSE` 的内部修改和构建条款。

## 完成范围

| 命令 | 按旧版支持的上下文 |
| --- | --- |
| 完美像素 | 铅笔、普通橡皮擦、直线、曲线 |
| 连续 | 魔棒、魔术橡皮擦、油漆桶、渐变，各自切换对应设置 |
| 智能闭合 | 启用连续模式的魔棒、魔术橡皮擦、油漆桶 |
| 圆角 | 矩形选区、填充矩形、矩形轮廓 |
| 固定比例 | 填充／轮廓矩形和椭圆；关闭后再次开启设为1:1 |
| 移动自动选择图层 | 有活动工程时可切换，不要求当前选择移动工具 |

六个原有命令在快捷设置中接通，不增加默认键、菜单、图标或布局。直接调用现有工具属性按钮回调，复用既有偏好保存、勾选同步和布局刷新；固定比例快捷开启前按旧版重设为1:1，不改变现有按钮本身的行为。移除旧有但不可达的魔术橡皮擦连续快捷分支，统一从本组路由分派，避免后续落入通用取消手势处理。

原生适配沿用公共快捷系统的输入框避让、弹窗保护、重复键抑制、活动手势按工程排队；没有工程时不修改属性。设置操作不自行取消笔画、不增添内容事务。工程像素、保存状态、撤销／重做不因这些工具开关改变。
