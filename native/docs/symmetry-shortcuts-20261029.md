# 对称轴快捷操作与可见性修正（2026-10-29）

## 旧版依据

- `legacy/src/renderer/src/components/app/app-tools-shortcuts.ts`：五个轴开关与复位中心的快捷路由，长按不重复切换。
- `legacy/src/renderer/src/store/workspace-commands-tool.ts`：共用轴设置、首次开启和轴离开视口时重新定位、中心元数据持久化。
- `legacy/src/renderer/src/core/symmetry.ts::symmetryAxisSegment`、`core/view-geometry.ts::viewportSegmentVisible`：画布内有限轴线段与视口相交判断。
- `legacy/src/renderer/src/store/workspace.test.ts`：首次开启、可见轴保持、离屏轴重定位的行为证据。复用许可沿用 `legacy/LICENSE` 的内部修改、构建权限。

## 本批完成

接通水平、垂直、两条斜轴、旋转对称五个切换命令和复位中心，共六个已有命令；快捷设置可配置，不新增默认按键。快捷键与既有工具属性按钮共用 `toggleSymmetry`，复位复用已有默认中心及文档元数据设置。输入框避让、弹窗保护、长按抑制和活动手势排队沿用原有快捷框架。

公共开关不再仅检查中心点是否在屏幕内，而是移植旧版有限轴线段与视口相交算法。原生技术适配使用已有旋转／镜像视图正变换处理连续坐标；旋转对称按中心点可见性判断。轴线仍可见时保留中心，首次开启或整个轴线离屏时使用视口中心，经已有半像素吸附和画布范围限制；中心未变时不额外标记元数据修改。

没有新增菜单、图标、默认键或布局，没有引入额外内容事务。
