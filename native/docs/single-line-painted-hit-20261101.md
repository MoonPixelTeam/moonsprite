# 单行输入框绘制与鼠标定位统一

旧版 TextInput／NumberInput 由浏览器保证文字绘制与最近插入位置一致。原生PixelEntry自行绘制Fusion字模，但普通点击仍使用MIT Entry内部字形框；原有双击与右键另按Fusion计算，导致点击同一字符的左右侧可能出现不同结果。

本批将已有Fusion字宽／可见滚动的最近光标计算共用于普通左键点击／拖选、双击、按词拖选及右键。仍先复用Entry捕获和边缘滚动，仅修正文本视口内且字形框与码点一一对应的左键终点。普通按下重设锚点、Shift按下保留锚点，拖动保留原锚点，原有Shift拖动与历史分组规则不变。只读普通点击释放后若没有选择，按浏览器无内部可编辑光标语义收起到0，命中文本末尾则保留末尾；处理延后到释放，避免破坏拖选锚点，Shift扩选仍保留实际范围。数值拖动及单位区域和视口外处理保留原路径。

新增400条实际Edge 156.0.4314.50观测，覆盖英文／中文字符的1/4及3/4位置、可编辑／只读、正反向初始选区、点击／Shift点击与替换撤销；另含四种带小数位置的拖选／按词拖选。完整2453条观测，2443条规范对照，10条先前异常排除。原生鼠标回放使用自身字模宽度。

正式Release构建与最终 `--text-tool-check` 通过（退出码0），2443条规范对照及既有文字检查通过；538文件来源登记与证据快照检查通过。未进行人工截图验收；不声称中点平局、复杂字形／双向文字、全部水平滚动／捕获丢失和操作系统焦点组合等价。无布局／素材变更。
