# PSD 当前帧分层导出（2026-11-03）

## 来源与实现

按 legacy `core/psd.ts::encodePsd/scaledRaster/psdChildren/psdMask/psdLayerEffects` 迁移。当前动画帧导出为PSD图层，保留像素偏移、Unicode名称、隐藏、锁定、透明度、混合、剪贴、嵌套／空组和图层／组蒙版。普通组无效果、蒙版及背景混合时导出穿透组。文字和背景沿旧版作为栅格层；PSD不承接动画编辑。

图层按照内容边界，缩放后的坐标取ceil，像素最近邻采样，再去透明外边。画布尺寸按旧版四舍五入，比例1–6400%；最大30000像素，另有原生256MiB输出／展开预算。溢出拒绝，不裁掉原作品。PSD版本1，不写PSB。

旧版导出的五类效果承接为可编辑PSD效果：描边、投影、内发光、颜色叠加、渐变叠加；参数包括缩放后的尺寸、阴影角度／距离、颜色透明度、渐变端点与抖动。全局关闭效果时不写效果块。智能描边／智能阴影及渐变映射的PSD映射不额外发明，沿旧版固定参数导出规则，不声称Photoshop和MoonSprite算法视觉完全一致。

使用MIT ag-psd的PSD写入、action descriptor子集与PackBits RLE算法适配C++，应用无JS运行时。保留其许可原文；背景合并图沿旧版写白色matte并保留透明通道。

## 操作

普通导出格式列表及默认导出首选项的PSD已接通，图片序列模式不开放单帧分层PSD。复用现有ASE导出弹窗、比例输入、原生路径选择／覆盖提示、分时快照、后台编码和原子输出。成功才记住目录、最近导出路径、统计并播放已配置提示音；取消／错误不将源工程标为已保存。导出失败保留表单供重试。

沿旧版 `document-save-policy.ts` 和 `document-save-format.test.ts` 补齐PSD源文件保存及另存：沿用原格式偏好开启时保存回PSD；默认保存格式首选项允许选择PSD；PSD只能保存当前帧，动画帧／循环／可编辑文字等局限必须经兼容选择确认；取消不写文件，仍存PSD不移除当前会话的动画，选MoonSprite则完整保存原生工程。兼容确认后重新检查能力，后台保存继承现有串行队列／较新修订保护及失败重试，PSD不创建原生工程备份。对于原生尚未承接PSD转换的特殊图层类型明确拒绝，不自动合并或虚报兼容。

## 验证范围

原生测试覆盖分层保存回读、当前帧、蒙版、组、尺寸、半透明、PackBits包边界、超限与作品状态保护。Node脚本使用旧版实际ag-psd读器独立核对原生输出的层序、空组、Unicode、所有五类效果参数、尺寸和像素；仅用于开发验证。

正式程序 `--aseprite-io-check` 已返回0：通过已有导出格式选择进入PSD弹窗，注入系统路径选择后经过真实快照／后台编码／原子写入，重开核对当前帧像素及源文档状态；实际PSD源文件修改后保存、兼容确认取消保护源字节、确认单帧保存且保留会话动画、PSD另存及改存完整MoonSprite均通过。PSD同时纳入最近工程记录／重开和已有缓存缩略图流程。
