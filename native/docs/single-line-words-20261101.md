# 单行输入框跨词移动与删除

## 来源与承接

旧版 TextInput／NumberInput 依赖浏览器 input 的跨词操作。原生 Entry 使用另一套词边界，Ctrl删除还会忽略当前选择重新选择单词。本批直接复用多行文字框已按浏览器结果迁移的 `textWordStep`，通过一个共享函数声明承接单行输入，不重新实现分词。

Ctrl+左右移动和 Ctrl+Shift+左右选择使用相同词边界、既有光标与锚点。Ctrl+Backspace／Delete 有选区时删除该选区，无选区时选择对应词范围，再调用原有 Entry 删除命令；一次操作对应一次本地历史，撤销恢复原文字和选择。只读延续上批无可编辑光标的选择规则，不允许删除。

原生 Entry 存在将多个码点合并成字形框的情况。当前仅在框数量等于码点数量时应用此路径，复杂字形框保留旧路径并明确未完成映射，不用错误的 Unicode 坐标破坏文字。

## 证据与验证

实际 Edge 156.0.4314.50 新增594条连续观测，覆盖英文、标点、多重／前后空格、中文词典边界、空文字、正反向选择、只读及删除的撤销／重做。总夹具1041条，其中1031条规范对照、10条先前浏览器异常排除。正式 Release 构建与最终 `--text-tool-check` 通过（退出码0），1031条规范历史／焦点／导航对照及既有文字检查通过；538文件来源登记及证据快照检查通过。

未进行人工截图验收。其他语言／词典版本、复杂字形框坐标、Ctrl+Shift+Delete和真实输入法仍有缺口，本批不代表输入模块整体完成。
