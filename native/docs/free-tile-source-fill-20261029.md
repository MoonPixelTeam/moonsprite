# 自由瓦片源油漆桶填充

## 来源与语义

- `legacy/src/renderer/src/components/canvas-pointer-down.ts`：Edit 模式进入源编辑，并将画布选区转换为源临时画布坐标。
- `legacy/src/renderer/src/components/canvas-input-free-tile-edit.ts`：填充使用 `selection ?? sourceRegion`，不传主文档对称轴；立即填充后提交，无变化则回滚。
- `legacy/src/renderer/src/core/tools-fill.ts`：复用已迁移的普通／图案填充算法，不另写泛洪算法。

## 原生承接

Edit 模式油漆桶接入现有源临时栅格事务。无选区时，填充范围为变换后的完整源矩形，包含透明像素，不扩散至临时画布留白。存在选区时沿用选区。普通与图案填充共用既有容差、连续性、闭合及采样选项；源临时画布本身作为可见层采样对象，不使用主文档对称轴。

复用源坐标转换、逆变换、透明裁边、共享资源发布、引用缓存更新及提交／取消。一次点击只产生一次可撤销操作；无变化不创建历史。沿用当前源尺寸上限256px和临时画布16M像素预算，未扩大导入或编辑边界。

Paint 模式和渐变工具仍不开放。此项不代表所有自由瓦片工具或整体迁移完成，不改变布局和素材。

## 验收范围

定向检查包括16种旋转／镜像组合、共享层帧缓存、实例数据保持、透明源范围、选区限制、图案填充、无变化、锁定、保存重开和撤销重做；正式程序检查实际鼠标油漆桶入口及历史、捕获释放。具体执行结果记录于迁移计划。本批不进行新增视觉或长期性能验收。
