# 2026-11-20 用户范围决定

## 取消独立皮肤编辑器

直接依据用户指令：“取消独立皮肤编辑器”。停止独立工具的规划、实现及验收，不再计入剩余重构工作；此前已移除的主程序内嵌皮肤编辑器也不恢复。

主程序现有 Skin 绘制、PNG/XML 主题加载、外部修改主题素材后重启及 --theme 入口继续保留。主题资源、模板、许可、历史资料和用户文件不删除。NX-003 保留原 ID，仅验收运行时主题，原编辑器专属预览、撤销和主题包编辑流程退出当前需求。

## 扩展采用宿主原生组件

直接依据用户澄清：“我想要的扩展效果应该和aseprite一样，基本复用软件自身的组件界面”。

扩展以脚本调用宿主 API、组合软件自身的按钮、输入框、下拉框、滑块、颜色选择和对话框为目标，继续遵循已明确的 Aseprite 兼容子集。当前 QuickJS＋原生表单窗口沿此路线实施。

旧 Demo 的“HTML 设置页”是原实现载体。配置字段、读写、应用/取消、动作和错误等实际功能仍按旧版证据迁移为宿主组件；不要求按原样显示 HTML，也不把 DOM、浏览器 Canvas、媒体标签、CSS 或任意网页执行环境列为默认待实现功能。覆盖层、绘制或附属窗口只有在承接实际功能时才落实对应宿主 API，不因旧包使用了某个浏览器对象就补全该浏览器对象。旧包不承诺无需修改即可直接运行。

本决定不删除已登记的实际扩展功能；功能是否完成仍按具体宿主 API、控件和真实扩展用例验收。此前按浏览器能力罗列的工作量估算不能直接当作当前范围的完成百分比。

本次范围调整是文档与需求变更，不是新增功能的运行验收。
