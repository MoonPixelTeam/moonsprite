# 自由瓦片 Edit 模式直线与形状

## 实际来源

- `canvas-input-free-tile-edit.ts`：Edit 模式准备源临时画布，接入形状、直线、多边形和自由形状状态机。
- `canvas-input-shape.ts::endShape/endLine/endFreeform`：世界边界减源原点；源选区与角度、圆角、笔刷宽度传入既有算法；源编辑不使用主文档对称。
- `useCanvasShapeCommit.ts::commitShapePoints/commitBrushPath/lineShapeBrushPoints`：局部像素路径、平衡直线、完美像素和图像笔刷，最后提交共享源。
- `tools-shapes.ts`、`free-tile-edit.ts`：复用已迁移的形状几何、笔刷路径、临时栅格与源逆变换。

## 承接范围

Edit 模式开放直线、矩形及矩形轮廓、椭圆及椭圆轮廓、多边形、自由形状。复用现有形状交互、参数、确认／取消和历史标签。直线复用平衡／完美像素路径和真实笔刷，包括图像笔刷；曲线的独立多步流程保持禁用。矩形和椭圆按旧版 `paintShape` 使用普通覆盖混合，不套用笔刷墨水模式；直线保留墨水模式。Paint 模式不开放上述工具。

采用已有几何笔刷的隔离时间轴预览方式。临时草稿执行现有源事务及普通形状／笔刷算法，逆变换后更新预览中的共享资源和引用缓存，权威文档保持原样。确认时沿用源编辑的时间轴前后快照历史表示，一次手势只提交一条操作；取消或失败丢弃预览，无变化保留历史与重做。

形状接口补充可选的初始点击位置，使中心绘制改变几何起点时仍按原始点击选择源及放置锚点。普通栅格、蒙版和瓦片默认调用保持原路径。多边形和自由形状的最终填充点先按主画布范围裁剪，再映射到源，承接旧版 `commitShapePoints` 的规则。选区转换、源旋转镜像、透明裁边、隐式放置和共享引用沿用既有源事务。

沿用256px源尺寸、16M临时画布及已有几何笔刷预览预算。源引用缓存和历史快照策略尚未完成整体性能等价迁移；本批不将其标为优化完成，不增加图标或布局。

## 验收范围

实际结果记录于迁移计划。核心针对七类几何与16种实例旋转镜像，对照已有普通栅格形状算法的结果，并检查预览／取消、共享引用、单条历史、保存重开、撤销重做、选区孔洞、临时画布增长、尺寸失败回滚、隐式放置及图像笔刷路径。正式入口检查鼠标绘制直线及矩形／椭圆的实心和轮廓、Escape取消。未进行新增图像或长期性能验收。
