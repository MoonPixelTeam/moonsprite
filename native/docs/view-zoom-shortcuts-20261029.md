# 固定倍率视图快捷操作（2026-10-29）

## 旧版依据

`legacy/src/renderer/src/components/app/app-selection-shortcuts.ts::handleSelectionShortcuts` 定义1、2、4、8、32倍率及指针目标优先级；`core/view-geometry.ts` 定义指针锚定及旋转／镜像变换；`components/panels/PreviewPanel.tsx` 定义预览独立缩放和跟随模式处理，`PreviewPanel.view.test.tsx` 提供预览倍率与平移保留的行为证据。复用许可沿用 `legacy/LICENSE` 的内部修改、构建条款。

## 迁移内容

接通100%、200%、400%、800%、3200%五个已有命令，不增加默认键、菜单、图标或布局。指针位于未被其它控件覆盖的预览栏目时只缩放预览；位于主画布时围绕指针缩放；其它位置或没有记录到指针时保留画布显示中心位置，适配旧版只更新zoom、不修改pan的行为。

主画布复用既有 `setCanvasZoom`，包括旋转／镜像变换、边界约束、视图保存、局部重绘和百分比更新。原生默认2×为UI整体缩放，1倍视图仍沿用现有 `canvasScale=zoom×uiScale`，没有重新解释倍率。

预览新增共用的精确倍率设置入口，已有滚轮／缩放按钮也调用此入口，继续使用原有预览视图模型、初始视口尺寸、指针锚定和跟随模式。相同倍率不改变平移；预览缩放不修改主画布或工程内容。目标识别沿用现有显示器相对物理像素指针和前景控件命中，不移动系统指针。
