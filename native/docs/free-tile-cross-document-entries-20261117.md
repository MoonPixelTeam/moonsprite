# 自由瓦片跨工程帧与 Cel 入口补齐

状态：本阶段入口迁移完成，唯一正式 Release 构建及 `--free-tile-transform-check` 专项退出 0。整体迁移仍未完成。

旧版入口与范围依据 animation-cel/frame-clipboard、animation-cel-target 和 clipboard-service。旧版跨工程载荷不完整的问题沿用用户明确批准的修复：完整实例与资源迁移，标识重映射、保留存活链接及撤销重做。

既有核心 pasteTilemapFrames／pasteTilemapCels 已经调用 transferFreeCelSources。原生菜单仍额外拒绝来自其它工程的自由瓦片载荷，本阶段移除这两处残留条件，直接复用已有事务、资源去重、历史和保存链路。保持帧／Cel／实例／图层的作用域、锁定及部分选区门禁、新系统图片优先和失败报告。

现有正式程序自由瓦片专项改为实际跨工程入口验收：源文档被替换后，Cel 使用 Ctrl+V、帧使用现有粘贴菜单；检查实例、缺失资源及标识重映射，一次撤销恢复目标原资源，重做恢复同一标识，重复 Cel 粘贴复用已迁移资源，并从实际保存文件重开核对像素及实例。

不新增界面或素材，不重跑已通过的核心资源迁移矩阵，不把本阶段视为整个索引色、跨类型目标转换或全部功能迁移完成。
