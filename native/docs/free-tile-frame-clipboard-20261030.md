# 自由瓦片整帧剪贴板（同工程）

本批接通现有整帧复制、剪切和粘贴入口，承接含自由瓦片工程的帧数据；不新增界面、图标或素材。

## 旧版来源

- `legacy/src/renderer/src/store/workspace-commands-animation-frame-clipboard.ts`：`copySelectedAnimationFrames`、`pasteAnimationFrames`。按时间轴顺序捕获所选帧，保留时长、禁用状态、全部层Cel以及图层／组蒙版；插在所选帧最末端之后。
- `legacy/src/renderer/src/store/workspace-animation-clipboard.test.ts`：统一粘贴入口与所选帧后插入的旧版测试证据。
- `legacy/src/renderer/src/store/workspace-cut.ts`、`workspace-cut.test.ts`：复制后删除、保留载荷及撤销路径；自由瓦片专项断言依据实际源码契约转写。
- `legacy/src/renderer/src/core/animation.ts`：帧和空Cel、活动帧刷新及链接继承。
- `legacy/src/renderer/src/store/clipboard-service.ts`：动画复制的系统图像基线和新图片优先级。

## 承接行为

帧复制按工程时间轴排序，不依赖用户反向点选的顺序。自由瓦片源资源保持原引用，所有层的实例身份、位置、方向、属性和元数据均复制；不新建资源集合。帧时长和禁用状态、Cel属性及存储坐标、图层与组蒙版一起保留。粘贴时根据当前权威源刷新自由缓存，源在复制后发生变化也不会恢复过期缓存。

单帧粘贴选中活动层的新Cel，多帧粘贴选中新帧范围；整次一条历史。剪切删除所选帧并保留至少一帧，修整现有循环段的幸存端点，保留所有共享资源。复制或剪切不会复制循环段本身。已有快照载荷在原帧被删除、撤销或重做后仍可粘贴，撤销重做恢复原身份、蒙版和帧范围。只有一帧时，剪切仍捕获载荷，不修改内容。

菜单保留帧、Cel、图层、像素和实例的作用域。帧复制／剪切清理其它内部载荷，仅只读系统图片基线；新外部图片优先，相同、缺失或读取失败的系统图片沿用内部帧载荷。专项界面检查使用注入读取，不改写用户系统剪贴板。

## 原生适配与边界

复用已有特殊图层帧结构事务、链接栅格幸存者处理、蒙版及循环段历史，原生空自由Cel必须显式具有空实例数据。沿用现有256MiB像素预算、层／帧上限和快照历史；不宣称全面元数据或瞬时内存限制。

跨工程动画帧载荷未提供自由源集合／资源导入协议，因此自由瓦片帧跨工程传递保持明确禁用；可用已迁移的整层／组剪贴板传递资源。需要自由Cel自动链接的插帧、活动预览、像素选区／蒙版目标粘贴以及其它既有模型限制仍保留，不以近似实现代替链接语义。独立删除帧／Cel等入口不在本批开放。

## 检查

核心覆盖单帧和多帧、反向选帧顺序、时长及禁用、所有层实例、共享资源、图层和组蒙版、循环段、源修改后的缓存、最后一帧保护、原帧删除后的载荷、保存重开与撤销重做、跨工程原子拒绝。正式菜单检查覆盖Copy／Cut／Paste、插入位置和选中状态、源资源保持、历史和新外部图片优先。执行结果见迁移计划；本批未新增图像或长期性能验收。

新外部图片转发在调用图片粘贴期间暂时绕过原生UI的帧作用域门禁，随后通过作用域恢复；文档中的帧选择始终保留，不添加额外系统剪贴板轮询。此适配对应旧版统一粘贴中外部图像优先调用pasteSelection的路径。
