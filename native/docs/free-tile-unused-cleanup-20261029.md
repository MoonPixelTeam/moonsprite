# 自由瓦片闲置源清理（2026-10-29）

## 来源与范围

按 legacy/src/renderer/src/store/workspace-unused-tiles.ts 的 clearUnusedFreeTileSources、workspace-tilemap.test.ts 的共享集合与全闲置清理用例、core/free-tile-document.ts 和 core/tilemap-document.ts 的引用捕获，以及 TilesetPanel.tsx 的栏目菜单承接 TI-004。本批只完成闲置源清理，源属性与密度仍未完成。许可沿用 legacy/LICENSE。

## 行为

- 从瓦片栏目原有“清空未使用瓦片”菜单执行，作用于显示的自由瓦片共享集合。菜单在活动内容事务期间禁用；点击前取消尚未提交的网格手势。
- 检查全部图层、全部帧的自由瓦片实例与规则瓦片引用，不因隐藏、锁定或禁用而忽略。存在引用的源保留；其他源从同集合成员列表同步移除。
- 全部闲置时保留原首源并把其像素资源清为透明，而不是删除所有源或替换其身份/尺寸/元数据。清理已经为空的首源时不新增历史。
- 删除源资源前保留其他集合仍持有的存储。未移除所选资源时保持主副角色；所选资源被删除时主副回退保留首源。保持当前 Edit/Paint 模式、实例选择和层帧。
- 一次操作产生一条“清空未使用瓦片”历史。撤销恢复源顺序、原始像素、资源身份和角色；重做重现清理，均保持当时编辑焦点和绘制模式。保存重开保留清理结果。
- 不改任何已有实例、其顺序或未改变的 cel 像素缓存。不因清理重绘无关源。不改变普通瓦片的既有清理分支。

## 原生适配

继续通过既有 clearUnusedTilesetTiles 方法接线，自由瓦片分支使用当前源资源ID定位活动集合，普通分支保持原实现；不复制UI或添加新菜单。继续使用 Timeline/Edit 的资源快照历史及现有源列表元数据焦点策略（freeTileSourceReorder），此标志在本批用于同类源列表事务，不表示清理会排序。

原生已接受的资源ID别名、sourceId为空时的tileId回退、旧格式源集合都计入引用。保留源或其他有效元数据所有者（含规则瓦片层）仍持有的资源不能删除；这是避免原生合法工程失效的必要适配。合法的多个源共享一个资源时，清理多余源仍保留首源存储。与旧版仅检查source数组的资源释放差异显式记录于此。
