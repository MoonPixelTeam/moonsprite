## 素材与对比

直接裁取用户图5两个 4×4 状态，保留不同的角 alpha。三个标记都从独立 `assets/color-picker/marker-light.png` 与 `marker-dark.png` 读取，未改共享 sheet。替换后可调用 `loadMarkers`，或重启加载。

明暗选择沿用 `legacy/components/ColorValueControl.tsx` 取样指针的亮度计算：`r*0.2126+g*0.7152+b*0.0722 < 145` 用白色，其余黑色。依据标记中心实际显示像素决定；透明度条从已合成的棋盘缓存读取，不能用原始 RGB 或透明黑替代背景。

## 几何与状态

控件新增 `regionBounds(Region)` 返回 SV／Hue／Alpha 的绝对物理矩形，供输入验收使用。所有命中区域与实际绘制区域完全相同；共享边界属于下一块，不重复命中。

新的无内边区域按首末可见像素映射 0..1，移除旧范围控件的 4.5 物理像素拇指内缩。该几何适配使渐变、点击和标记使用同一坐标跨度；HSV／alpha 转换、舍入、左右角色和锁定命令未改。标记外框在区域边缘夹取，0／1 时四角完整可见，不改变真实值。

SV 缓存键补齐宽与高，避免纵向布局调整后复用错误尺寸。两条缓存均包含宽与高；alpha 缓存仍受 RGB 与主题棋盘色控制，拖动 alpha 只移动标记，不重建颜色条。标记颜色直接读取已有缓存，不复制整块像素。

## 验证

现有颜色模型测试增加连续布局、首末像素映射、四角 marker 不裁切、过小区域、亮度阈值和不同棋盘合成背景的明暗选择。集成还需验证：图层锁与色卡命令不变；三块精确相接；端点点击不串区；修改 alpha 时实际透明度改变；左右键仍分别写前景／背景；长宽变化后缓存尺寸正确。
