# 文字弹窗字体选择与字号偏好

## 旧版依据

`legacy/src/renderer/src/components/TextToolDialog.tsx` 的字号输入在调用 `updateRangeStyle` 前立即 `recordLastTextFontSize`，包括只修改局部文字。`selectFont` 与 `addFont` 都选择字体默认字号，未定义默认时沿用当前基础字号，再记住字号。删除字体使用刷新后目录的第一个字体作为替代，保持字号。提交时记录字体使用频次，不重新用基础字号覆盖最后一次交互的字号。

`legacy/src/renderer/src/platform/font-service.ts` 提供字号记忆和字体目录排序；原生继续复用已有 `TextFontService`，未新增偏好格式。

## 原生承接

- 字号输入在修改基础或选区样式时记住有效字号；取消文档编辑不撤销独立的用户偏好。
- 字体下拉、文件导入和系统字体导入共用选择处理，应用默认字号或保留当前字号，不改已有选区样式覆盖。
- 删除字体后按现有目录（含使用频次排序）选择第一项，空目录才回退默认字体；不重设字号。
- 确认仍记录字体使用频次，去掉原先确认时基础字号覆盖，避免局部字号修改被覆盖。

## 验证

正式Release构建、`--text-tool-check`、515文件来源及快照检查、差异检查通过。弹窗内部检查覆盖局部／基础字号即时记忆、Tiny5默认字号、无默认字号时保留当前值、选区覆盖不变以及目录顺序回退；检查结束恢复原字号偏好。既有取消／确认、文字本地历史、文档撤销重做检查同时通过。文件导入／系统导入／实际删除入口完成源码接线核对，未另做系统选择器人工点击或删除用户字体；未进行人工图像验收。
