# 单行输入框焦点与选区承接

旧版 `TextInput.tsx` 直接转发浏览器 input 属性；`NumberInput.tsx` 转发 onFocus/onBlur，并另行提交数值草稿。没有公共的重新聚焦自动全选策略。原生 MIT Entry 默认失焦清除选择、聚焦全选，导致返回字段后覆盖整段文字。

共享 PixelEntry 直接启用 MIT Entry 已有的 `setPersistSelection(true)`。普通失焦及程序重新聚焦保留折叠光标、正反向选区；业务显式 focus 回调仍可设置自己的选择，数值提交与右键菜单临时焦点规则保持原路径。焦点切换仍打断连续文字历史分组。

`capture-entry-history.cjs` 重新采集 Edge 156.0.4314.50 的135条连续观测，其中125条规范对照、10条浏览器只读／外部值旧历史异常证据。上批排除的5条普通焦点结果改为正式对照；新增21条覆盖正反向替换、中间光标及离开后继续输入的撤销分组。原生回放在真实的独立 PixelEntry 和按钮间转移焦点，避免弹窗排队的字号样式同步覆盖夹具文字；已有数值字段及右键菜单检查仍使用原来的控件和回调。
