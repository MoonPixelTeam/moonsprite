# 文字工具修饰键指针优先级

## 旧版依据

`legacy/src/renderer/src/components/useCanvasCursor.ts` 的 `textCopyAvailable` 由 Alt 与 `textLayerAt` 命中共同决定，复制指针优先于临时移动、取色和文字框边缘反馈；临时移动读取可配置快捷键并根据选中可移动对象提示不可用。`canvas-pointer-down.ts` 与 `useCanvasToolSession.ts` 定义对应的按下分支和临时工具配置。

## 原生承接

- 文字Alt复制悬停复用已迁移的 `textLayerAtPoint`，跳过隐藏／锁定文字，优先于临时取色和普通框内移动／缩放反馈。
- 临时移动复用已按下键集合和 `quickToolMatch`，支持自定义组合；无可移动选择时显示现有不可用指针。
- 修饰键悬停仅在画布拥有指针、无活动文档事务、非导航且快捷键未被输入控件阻挡时处理。捕获中的文字手势保持既有优先级。
- 全部指针仍使用现有legacy素材；没有新增图标、界面布局或写入偏好。

## 验证与边界

正式Release构建、`--text-tool-check`、515文件来源及证据快照检查、差异检查通过。检查覆盖Alt复制压过取色、隐藏／锁定命中排除、把临时移动改为Ctrl+Shift后压过边缘缩放、锁定选择提示不可用、释放后恢复缩放。已有真实Alt复制及临时移动的预览、取消、历史检查同次通过。本批未全面验收所有工具／焦点组合，未进行人工图像验收。
