# 带样式文字预览的影响范围

## 旧版依据

`legacy/src/renderer/src/core/layer-styles.ts` 的 `layerStyleAffectedRect` 从原始变化矩形分别扩展描边、内发光、带偏移与模糊的阴影，再求并集；与仅表示可见输出的 `layerStyleOutputBounds` 不同，内描边也扩展依赖范围。

`core/document-composite-plan.ts` 的 `expandLayerStyleInvalidationRect` 在调用方未提供目标ID时遍历所有图层分支，逐级扩展祖先组样式，再合并结果。`components/canvas-composite-cache.ts` 把扩展范围加入待修复缓存。本批沿用文字输入路径未传目标ID的语义，不自行改成只判断活动层。

## 原生承接

文字草稿分别对变化前后完整表面应用上述影响范围，再合并并裁剪到画布。坐标扩展过程使用64位整数，裁剪后才转回原生脏区。继续使用现有合成和上传通道。带普通样式的图层、嵌套样式组不再一律完整刷新，关闭的样式不扩展范围。

图层组渐变依赖其他子层共同构成的几何，本批保持完整刷新；调整层、独立链接图层同步和空越界脏区也保留原回退。尚未宣称所有复杂堆叠均完成局部优化。取消与历史事务沿用现有逻辑。

## 验证

正式Release构建、`text-document-tests`、正式程序 `--text-tool-check`、515文件来源及证据快照检查通过。核心测试把局部合成补入旧缓存，并逐像素对照完整合成，覆盖三种描边位置、正负阴影偏移／模糊、内发光、组合效果、两级样式组、关闭样式、负坐标与组渐变完整回退；既有链接、取消、历史及保存重开测试通过。未增加人工图像验收或长期性能测试。

此记录承接并更新上一批 `text-preview-damage-20261031.md` 中普通样式和图层组仍完整回退的限制。
