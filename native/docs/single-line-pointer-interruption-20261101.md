# 单行输入框拖选中断

旧版TextInput／NumberInput使用浏览器input。本批实际采样显示：按住鼠标选择时切换焦点，原范围保留，此后的移动／释放不再改动该范围；重新聚焦后替换及撤销仍恢复原选择。若在保持焦点和鼠标按下时按方向键或提交文字，随后鼠标移动使用新的折叠光标端点，不继续套用旧的拖选锚点。

PixelEntry失焦时释放既有捕获并清理数值拖动、右键选择、按词拖选及键盘后指针继续状态。键盘导航／文字输入后继续按住鼠标的标记使用现有Component Property，释放、新按下、捕获丢失时清除；定位、内容编辑与历史继续复用原路径，不增加计时器或后台循环。

新增24条顺序浏览器观测，回放真实控件按下／移动、焦点切换或按键／输入、释放、重新聚焦和替换撤销，并断言失焦释放捕获；额外用真实右键按下后切换焦点验证释放捕获和一次真实表单blur，清除临时菜单回焦标记，避免误抑制表单提交。完整2477条观测，2467条规范对照，10条先前异常排除。

正式Release构建及最终 `--text-tool-check` 通过（退出码0），2467条规范对照、右键失焦捕获／blur断言及既有文字检查通过；538文件来源登记及证据快照检查通过。未人工截图验收；本批没有完成整个水平滚动、操作系统窗口取消／失活、任意修饰键／删除／按词手势中断及复杂字形等价性。
