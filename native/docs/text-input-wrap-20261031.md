# 文字输入框自动换行定位

## 依据与适配

来源：`legacy/src/renderer/src/components/TextAreaInput.tsx` 的浏览器 textarea，以及 `TextToolDialog.tsx` 中 onSelect/onKeyUp/onPointerUp 同步选区。快照核对通过。旧版没有自行实现键盘行定位；原生需承接浏览器提供的可见行行为。

原生之前按换行符定位 Home/End，自动折行后会跳出当前显示行。布局还只登记每个文字偏移的后一行位置，缺少前一行末尾的同一插入位置，导致鼠标和上下键无法到达该行完整行尾。

## 实现范围

- 自动换行的同一逻辑偏移登记前一行末尾和后一行起点两个可见位置；不插入换行符，不改变文字或UTF16样式索引。
- Home/End 在当前显示行内定位；Ctrl+Home/End 保留全文起止。Shift 保留原锚点。
- 鼠标点击／拖选、上下／翻页共用可见插入位置集合，行尾不再少一个字符；鼠标先比较行距离，再比较横向距离。
- 光标绘制、滚动显露使用同一可见位置；本地撤销记录换行处的视觉方向，恢复文字后仍停在原行。
- 输入处理与绘制函数从共享头文件移到 `pixel_text_area.cpp`，注册到原有正式程序目标。数据、撤销和组件归属均不变。

## 验证

正式Release构建及最后增量构建通过，`--text-tool-check`退出码0；516文件来源及证据快照检查通过。现有文字弹窗检查新增窄输入框用例，覆盖 Home/End、Shift选到整行及左右收起、上下行尾、相同逻辑偏移的两个位置、输入后撤销及真实鼠标消息。恢复输入框原尺寸和草稿，保留原有文档历史检查。
