# Native UI 统一规范

父目录仓库规则继续适用。

- 任何原生界面新增、修改或修复，先读取并遵循 [UI 设计规范](docs/ui-design-spec.md)。此文件为统一布局基准；用户最新明确要求优先。
- 关联间距2px、分组与弹窗正文内边距6px，均为1×。标题与正文使用公共组件边界，不在业务弹窗重新写固定起点。
- 弹窗复用PixelDialog及共享标题布局；停靠/悬浮栏目分别遵循规范中的层次和工具行规则。不得复制一套背景、标题、关闭按钮或间距。
- 先改共享组件再改调用方，素材保留在sheet，切片变更同步PNG/XML/索引。已有差异见规范第9节；不得把未整改部分称为已统一。
- 同类界面存在差异时回到规范定位，不能用单控件加减1px掩盖布局或坐标错误。完成后分别报告源码/文档核对、自动检查、图像验收的实际范围。
