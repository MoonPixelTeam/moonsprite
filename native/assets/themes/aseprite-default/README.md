# 直接改这张图

1. 用 Aseprite 打开本文件夹的 `sheet.png`，直接在原位置改画并保存。
2. 启动 native 目录的 `start-aseprite-theme.bat`，自动加载这里的图片。
3. 修改保存后，重新启动软件加载。

不需要修改 XML 或逐张上传。保留原图尺寸和素材位置即可。
要调整切片位置，可在 Aseprite 的切片工具中编辑，保持旁边的 theme.xml 与 sheet.aseprite-data。
原图 304×304，保留全部 345 个原切片。当前仅已有原型控件的映射生效。
共享修改后的主题时，请保留 LICENSE.txt、ATTRIBUTION.md，并补充你的修改说明。
