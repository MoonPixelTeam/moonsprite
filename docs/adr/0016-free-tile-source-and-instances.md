# 0016：自由瓦片源库与任意位置实例分离

中文 | [English](0016-free-tile-source-and-instances.en.md)

> 本文记录 v15 决定。源所有权已由 [ADR 0022](0022-shared-free-tile-sets.md) 扩展为共享集合；当前实例界面可使用独立栏目或图层栏目内视图，见 [工作区契约](../interactions/workspace-docking.md)。

## 状态

接受

## 背景

Tilemap 以固定单元格保存瓦片引用，不能表达互相重叠或位于任意像素位置的可复用对象。自由瓦片仍需要源图修改后同步更新全部引用，并继续支持现有图层属性、动画、合成、缩略图、导出、撤销和工程持久化。

## 决定

- 自由瓦片图层使用 `layer.kind = "free-tile"`，并在 `freeTileSources` 中保存多个稳定源。每个源独占一个单瓦片 Tileset，源尺寸由实际绘制内容决定，不在新建图层时预设；源同时保存图层式名称、描述、显示颜色、显隐、锁定、不透明度、混合模式和整数偏移。
- 每个非链接源 cel 使用 `FreeTileCelData.instances` 保存按后到前排列的稳定实例 ID、`sourceId`、cel surface 本地整数像素锚点，以及可选的整 `90°` 旋转、水平/垂直镜像、显隐、锁定、不透明度和混合模式。实例没有网格，不保存任意角度旋转或缩放，允许重叠和越出画布；实例变换不改写共享源像素。
- cel `surface` 是由源瓦片和实例列表生成的栅格缓存。普通合成、图层样式、预览、缩略图和导出只读取该缓存，不直接解释实例。
- 放置或擦除手势使用实例列表的最小前后快照并只提交一次历史。源编辑在带透明扩展区的隔离临时栅格中复用普通笔刷算法，预览时按非透明内容裁切源尺寸并重绘全部引用，确认后以源尺寸、像素和偏移前后快照提交一次历史，取消恢复基线。尚未放置的新源在首次绘制时同时创建一个实例，这两个变化必须合并为单个历史条目。
- 普通 Tilemap 与自由瓦片共用瓦片集栏目；栏目根据活动图层切换源页面。新建自由瓦片图层自动创建透明源并进入源编辑，新增其他源由栏目按钮显式触发。自由瓦片图层右侧图标打开该图层专属的“实例图层”子视图，实例行位于图层栏并复用普通图层的选择、显隐、锁定、属性、排序和删除交互；眼睛与锁进一步复用同一套 `Alt` 批量和按住跨行手势。实例选择属于会话状态，实例删除、移动和变换仍通过 Store 领域命令提交。
- `.moonsprite` v15 保存 `freeTileSources` 和每个非链接源 cel 的实例列表；读取时验证源 ID 与实例 ID 唯一、`sourceId` 有效、坐标有界、旋转与镜像字段合法及每个 Tileset 所有权唯一，并从源数据和实例变换重新生成 surface。v14 的单 `freeTileTilesetId` 多瓦片源库读取时拆分成多个独立 v15 源并重映射实例。
- 画布尺寸变化重映射实例和 surface 偏移，裁切只移除完全落在新画布外的实例。图像尺寸变化同时缩放全部源瓦片、源偏移、实例文档坐标和派生 surface，并由同一历史快照恢复。

## 结果

- 用户可以像普通图层一样移动和设置自由瓦片图层，同时在任意像素位置重复使用并重叠同一源瓦片。
- 修改一个源瓦片会稳定更新当前图层全部帧中的引用，且不会把重复像素写入每个实例。
- 所有修改自由瓦片内容的路径都必须先更新源数据再重建缓存；直接把自由瓦片 surface 当普通像素写入会破坏可编辑性，必须拒绝或显式转换为普通图层。
- 自由瓦片源与实例的分离保持不变；图层之间的源所有权规则已由 [ADR 0022](0022-shared-free-tile-sets.md) 扩展为显式 `freeTileSetId` 集合共享。复制或跨文档粘贴仍必须为粘贴批次创建新的集合身份，不得引用来源工程资源。

## 替代方案

- 复用 Tilemap 格子：无法任意重叠，也会把所有位置强制吸附到固定网格。
- 每个实例保存完整像素：源编辑无法自然同步，并使工程和历史随重复次数线性膨胀。
- 渲染时直接遍历实例而不保留 surface：会迫使合成、图层样式、缩略图和导出维护第二套渲染路径。
