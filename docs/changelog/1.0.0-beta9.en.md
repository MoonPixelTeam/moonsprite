# MoonSprite 1.0.0-beta9 complete release notes

[中文](1.0.0-beta9.md) | English

Release date: 2026-10-12

Changes since Beta8. This release retains Beta8 features and fixes and incorporates subsequent dev improvements.

## Added

- Default, random and regular pattern-bucket fill modes with density, count, spacing and overlap controls.
- Fill presets and multiple pattern brushes with balanced distribution; each random fill creates a fresh arrangement.
- Independent fill-settings dialog with numeric, range and toggle controls, saved settings and continued editing across tool changes.
- GIMP `.gpl` palette import, duplicate colors, and copying/pasting individual colors or ranges to replace slots.
- Adaptive palette resize handle: drag to add black slots and drag back later to remove slots.
- Built-in Markd221 palette and editable color names, with improved local palette previews and actions.
- Project reference images and their display state persist across reopening.
- Native WebView2 circular traces capture input, latency and related frame feedback, with automatic and manual exports.
- Host diagnostics record the actual WebView2 Runtime version; a native visibility diagnostic channel reads back state and limits interventions.

## Improved

- Reuse cel indexes, derive only visible timeline cells, and avoid repeated layer-control and development-diagnostic work in large animations.
- Skip empty raster composition and reduce sparse-animation selection, frame-switch and playback overhead.
- Update timeline visibility during middle-button panning, wheel and scrollbar movement; populate newly visible cells before paint.
- Use native mouse updates for the simple crosshair without pixel alignment and reduce hover layout reads and duplicate previews.
- Reuse local drawing refreshes on large canvases, avoiding full bitmap-bound scans and duplicate live composition.
- Reduce redundant complex-brush previews and reuse backdrop, geometry and raster data during continuous selection transforms.
- Improve invalidation and capacity management for composite, style, thumbnail and selection caches and reduce retained snapshots.
- Improve memory lifecycles, asynchronous preparation and budgets in export, recovery, timelapse and script tasks.
- Share palette/tile selection borders and corner marks: 85% opacity normally, full opacity on hover, and live updates while dragging.
- Thicken palette borders and share swatch sizing; improve local palette layout, previews and name editing.
- Display sprite-sheet import shortcuts on the corresponding child commands instead of the parent menu.
- Disable procedural bucket dithering by default; Esc exits the selected pattern brush while keeping the bucket tool active.

## Fixed

- Fix disappearing content, misplaced transforms and out-of-canvas previews in older projects or after enabling layer styles; remove unreliable experimental rendering paths.
- Fix offsets, jumping and stale frame state during animation playback.
- Fix rendering after background resume and preview-view resets when moving between docks.
- Delete moved selection contents at their current location and clear the selection after deletion.
- Convert linked layers into ordinary layers with detached content and synchronized animation cels.
- Constrain layer-style colors to indexed palettes and correct translucent layer shadows.
- Fix pattern-bucket content and hover previews, including previews reduced to one pixel.
- Fix duplicated, uneditable or unclosable pattern-settings dialogs.
- Fix sparse single-pixel random stamps caused by fractional placement; arrange random/regular stamps within the actual fill region and add undo, redo and symmetry regression coverage.
- Fix palette-handle placement, complete resize previews, reverse shrinking and cursor retention; generated slots are no longer automatically selected.
- Fix outside-click deselection, left/right-button drag selection and repeated corner marks.
- Fix grab-cursor SVG URL escaping and appearance and selection/guide stacking.
- Prevent CPU-triggered native trace exports from exhausting evidence early: allow one CPU capture and two automatic captures, reserve manual capacity and use separate cooldowns.

- Propagate native visibility readback errors instead of silently treating a failed probe as a valid result; normalize Rust formatting and fallible palette-test setup.

## Known issues

- Long-running WebView2 frame-statistics/feedback retention and input lag remain unresolved. Diagnostic and experimental recovery channels do not establish a permanent fix; see the [unresolved performance issue register](../architecture/unresolved-performance-issues.en.md).
- Performance tests were skipped at the user's request. Optimization descriptions are not performance acceptance results for this release.
