# 1.0.0-beta3 完整更新记录

发布日期：2026-09-12

相较于 Beta2 对动画时间轴、图层和瓦片工作流的完善，Beta3 主要带来新的绘画工具和工程恢复能力。

## 重磅更新

- 新增液化工具：支持推移、膨胀、收缩、顺时针扭转和逆时针扭转。
- 新增平滑笔刷：用于快速整理像素边缘和线条。
- 新增工程回档：从工程备份中选择任意历史版本恢复，回档支持撤销、重做和历史记录跳转。
- 新增魔棒工具：支持容差选择、预览，以及按当前图层或可见图层取样。
- 油漆桶、渐变和魔棒支持 4 方/8 方连接，设置会自动记忆。
- 新增扩展工具：支持在铅笔工具组中使用远程像素笔刷。
- 优化选区旋转和旋转笔刷算法，减少旋转后的空洞、凹槽和线条变粗。

## 工作流更新

- 快捷键支持鼠标左键、右键、中键、双击和滚轮，并可组合 Ctrl、Alt、Shift、Win。
- 新增“图层快捷操作”设置，可自定义图层面板中的常用命令和顺序。
- 颜色编辑按钮支持拖出实时全局吸管，放大镜等相关交互同步支持。
- 缩时视频新增“记录撤销步骤”，默认关闭；关闭后只记录有效绘画步骤。
- 魔棒预览与选区显示规则统一，并受首选项控制。
