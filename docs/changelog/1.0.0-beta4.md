# 1.0.0-beta4 完整更新记录

发布日期：2026-09-17

Beta4 聚焦复杂动画、多工程编辑、缩时录像与扩展生态，并持续修复像素绘制和预览稳定性问题。

## 新增

- 新增本地缩时录像库：日常保存不再反复打包录像帧；“另存为”可选择携带录像，以便在其他电脑预览或导出。
- 新增内置“宠物伴侣”扩展：支持多宠物、动画、拖动、工程信息气泡以及报时、保存和休息提醒；该功能仍按普通 `.msext` 扩展运行，可停用或卸载。
- 扩展运行时新增独立窗口、资源访问、菜单、设置、组件库控件和光标策略接口，扩展可独立提供完整工具界面。
- 画布新增横向与纵向滚动条，会随缩放范围变化，并可在首选项中关闭。
- 项目标签右键新增关闭左侧、关闭右侧和关闭其他标签，且不会关闭合并画面或浮出项目。

## 优化

- 动画循环节完善嵌套播放、重复次数、循环内切帧、洋葱皮和 GIF 导出，导出顺序与实际播放一致。
- 多选图层、帧和单元格支持共同执行填充、删除、移动、缩放、旋转、镜像等选区操作，完成后保留多选状态。
- 多工程标签、分屏合并画面和浮出项目的切换与关闭逻辑更稳定；关闭主项目时可正确保留已合并的项目视图。
- 背景图层预设及预览更新，修复图案显示、对齐和嵌套菱形预设问题，背景继续以可编辑像素图层保存。
- 扩展安装的版本冲突提示更清晰；扩展可复用 MoonSprite 组件库的按钮、复选框、输入和选择控件。
- 图层快捷操作、快捷指令栏和相关设置界面统一为组件库样式，时间轴隐藏时图层快捷操作会自动调整位置。
- 油漆桶、渐变、魔棒及笔刷尺寸调节快捷键的跨工具行为进一步统一；相关工具设置会继续记忆。
- 宠物素材导出会裁切透明边缘，并保持整数倍率的像素缩放、透明命中、拖动和气泡定位。

## 修复

- 修复循环节交叉、嵌套、无限重复及 GIF 导出时的重复次数错误。
- 修复洋葱皮在橡皮擦 Shift 直线擦除预览中被错误修改的问题。
- 修复图层样式拆分后描边周围出现黑色区域的问题。
- 修复项目回档及其历史记录撤销、重做时的加载提示与画布刷新时机。
- 修复宠物扩展的透明区域、动画帧显示、拖动位置持久化、缩放、指针和失焦行为。
- 修复选择性粘贴为新图层时未插入当前活动图层上方的问题。
- 移除废弃的远程像素工具及其本体残留。
