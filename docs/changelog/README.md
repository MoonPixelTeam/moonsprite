## 归档约束

- 每次发布都把根目录“未发布”区的全部条目原样移动到新的版本文件。
- 归档完成后在根目录和本索引中增加版本链接。
- 已归档条目不得压缩、删除或移出仓库；事实错误可以更正并在提交说明中注明。
- 单个版本文件只包含对应版本，AI 不需要为普通开发读取全部历史。
