# MoonSprite 1.0.0-beta9 完整更新记录

中文 | [English](1.0.0-beta9.en.md)

发布日期：2026-10-12

本记录汇总相对 Beta8 的变化，保留 Beta8 的功能与修复，并整合 dev 分支的后续改进。

## 新增

- 油漆桶图案笔刷新增默认、随机和规则填充模式，支持密度、数量、间距和是否重叠等参数。
- 图案填充新增参数预设与多笔刷选择，支持多个图案均衡分布；随机填充每次生成新的分布。
- 图案填充参数使用独立弹窗和合适的数值、范围及开关控件，支持保存设置，切换工具后仍可继续编辑。
- 颜色板支持导入 GIMP `.gpl` 文件、重复颜色、单个或多个颜色的复制与粘贴替换。
- 自适应颜色板新增槽位手柄，可拖动添加黑色槽位，也可再次反向拖动缩减槽位。
- 新增 Markd221 内置颜色板和颜色名称编辑，改进本地颜色板的预览与操作。
- 工程支持保存参考图像及其显示状态，重新打开后恢复参考图像。
- 卡顿现场采集接入当前 WebView2 的原生循环 trace，记录输入、延迟与相关帧反馈，支持自动触发和手动保存。
- 宿主诊断记录实际 WebView2 Runtime 版本，提供带状态回读与单次干预限制的原生可见性诊断通道。

## 优化

- 多帧、多 cel 工程复用 cel 索引，仅派生可见时间轴单元格状态，减少重复的图层控件和开发诊断计算。
- 跳过空栅格内容的无效合成，减少稀疏动画中的点击、帧切换与播放开销。
- 时间轴中键平移、滚轮和滚动条移动及时更新可见窗口，在绘制前填充进入视口的单元格。
- 未对齐像素的简单十字鼠标光标使用系统更新路径，减少悬停布局读取与重复预览。
- 大画布绘画复用局部刷新，避免实时绘制中的完整位图边界扫描和重复合成。
- 复杂笔刷预览减少重复重绘；选区连续变换复用背景、几何及栅格缓存。
- 合成、样式、缩略图与选区缓存改进失效和容量管理，减少重复内容计算与多份快照保留。
- 改进工程导出、恢复、延时摄影与脚本任务的内存生命周期、异步准备及预算控制。
- 颜色板和瓦片统一选中边框及角标，未悬浮时不透明度为 85%，悬浮时完整显示；拖动时角标随选择范围更新。
- 颜色格描边加粗，统一颜色板预览尺寸和边框，改进本地颜色板布局、预览及名称编辑。
- 精灵表导入快捷键显示到对应子菜单，父菜单不再显示快捷键。
- 油漆桶程序纹理默认关闭抖动，Esc 取消图案笔刷选择并保留油漆桶工具。

## 修复

- 修复旧工程或开启图层样式后画布内容消失、变换错位及预览超出画布的问题，撤回不可靠的实验性渲染路径。
- 修复动画播放内容偏移、跳动与帧内容状态不同步的问题。
- 修复后台恢复后的渲染异常，以及预览面板在栏目间移动时视图被重置的问题。
- 修复移动选区后删除导致选区回到原位的问题；删除选区内容后同时清除选区。
- 关联图层可转换为普通图层，正确分离内容并同步动画 cel。
- 修复索引颜色模式下图层样式颜色不受颜色板约束的问题，并修正半透明图层阴影效果。
- 修复图案笔刷填充内容及悬停预览错误、预览退化为单像素的问题。
- 修复图案填充参数弹窗重复出现、不能编辑或关闭的问题。
- 修复随机图案印章浮点位置导致的稀疏单像素结果；随机与规则填充按实际填充区域布局，并补充撤销、重做与对称填充回归覆盖。
- 修复颜色板槽位手柄位置、扩展预览、反向缩减和指针保持问题；生成槽位不再自动添加选中效果。
- 修复颜色板点击外部不清除选择、左右键拖动选择及重复角标问题。
- 修复抓手光标 SVG 地址转义与外观问题，调整选区和参考线的显示层级。
- 修复原生 trace 导出额度过早被 CPU 触发耗尽的问题：CPU 最多一次、自动合计最多两次，为手动保存预留额度，并分别计算触发冷却。

- 原生可见性诊断读回失败时返回可观测错误，避免误记为有效结果；同步 Rust 格式及颜色板测试错误处理。

## 已知问题

- 长时间运行后 WebView2 帧统计与反馈队列堆积导致输入延迟的问题仍未根治。新增诊断与恢复实验通道不代表已证明长期修复；持续维护的证据见[未溯源性能问题清单](../architecture/unresolved-performance-issues.md)。
- 本次按用户要求跳过性能测试，更新日志中的优化描述不构成本次发布的性能验收结论。
