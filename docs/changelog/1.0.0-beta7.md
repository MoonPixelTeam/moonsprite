# MoonSprite 1.0.0-beta7 完整更新记录

发布日期：2026-09-27

本记录汇总相对 Beta6 的新增、优化与修复。

## 新增

- 新增渐变映射调整和渐变映射调整图层：可编辑渐变色标、使用预设、预览映射结果，并将效果随工程保存；图层面板与“图层”菜单均提供创建入口。
- 动画补间新增缓动选择与曲线编辑器，支持线性、缓入、缓出、缓入缓出和自定义曲线，并按中间帧数量预览变化。
- 动画新增反向处理命令，便于将现有帧序列倒序使用。
- 颜色面板新增最近使用颜色，可从记录快速设为前景色或背景色，并可在偏好设置中控制显示。
- 首页作品轮换新增《石狮》（线框）和《蔑视》（月猫），作品作者可跳转至对应 Moonpx 主页。
- 诊断设置新增卡顿记录模式及运行时卡顿采集能力，用于定位交互延迟；扩展运行时补充资源访问与文件拖放处理。

## 优化

- 首页作品在每次启动时打乱展示顺序，轮换点支持悬浮切换，同时保留点击、触屏和键盘操作。
- 工程保存改用可转移数据的工作线程通道，减少保存时在界面线程复制整份工程的开销；工程解码错误的展示路径也得到完善。
- 大画布的绘画、导航和选区移动进一步降低整画布分配与重复绘制；延迟选区预览在平移时复用已有蒙版几何，避免逐步重建像素。
- 画布合成、图层属性预览、时间轴缩略图和洋葱皮缓存按实际可见区域与容量管理；动画画面缓存上限由 32 帧／128 MiB 收紧到 12 帧／64 MiB，以控制长时间使用的内存增长。
- 画布导航滚动条移出分栏拖动时被冻结的画布表面，分栏尺寸变化时可及时更新滚动条和新露出的画面。
- 笔刷尺寸调整、笔刷预览、光标及图层缩略图更新减少不必要的主画布刷新；笔刷在画布边缘时仍显示完整轮廓。
- 图层样式与合成路径按内容边界处理描边、阴影、裁剪及预览，减少属性调整时的重复合成工作。
- 图层重排只重绘交换顺序的图层之间实际重叠的区域；互不相交的图层无需刷新像素，图层组重排与撤销、重做也保持正确。4000×4000 定向场景中，重绘像素由约 1100 万降至 419 万，同机三次主绘制耗时的中位数由 185.9 ms 降至 99.1 ms。
- 图层组显隐对分散的普通图层分别标记重绘区域，避免把大片空白夹在一个失效矩形中。4000×4000 定向场景中，标记重绘像素由约 988 万降至 332 万，三次主绘制耗时的中位数由 151.3 ms 降至 87.7 ms。
- 新建图层和选区相关操作缩减不必要的文档快照与历史数据复制；多图层操作继续保持可撤销的原有编辑结构。
- 窄栏目操作区按实际按钮尺寸和可用宽度折叠标题与操作，减少按钮被裁切的情况。
- 偏好设置新增绘画光标形状、像素对齐和笔刷边缘粗细等控制；新用户默认关闭选区十字，已有用户的显式设置仍按保存值读取。
- 官网首页功能展示更新为逐帧蒙版、实时图层样式、补间、自由瓦片、图案笔刷等当前能力，并加入部分功能动图；媒体预览、导航和网站资源组装同步调整。
- 宠物扩展包的导出与本地化流程、扩展运行时文档和网站构建脚本得到整理，方便维护内置扩展与展示资源。

## 修复

- 修复缩小稀疏选区时反向采样可能跳过单个不透明像素、导致选中内容消失的问题。
- 修复 Beta7 更新日志条目变多后，弹窗底部“完成”按钮可能被挤出视口的问题。
- 补齐七种非中英文界面中“记住上次选择的颜色”设置的文案键，并修正动画选择命令的类型依赖声明，恢复本地化目录检查与 Web 类型检查。
- 修复动画播放开始后仍保留旧图层、帧或单元格选中高亮的问题；停止播放不会重建这些过期选区。
- 修复文字图层转为普通像素层时，未提交的编辑草稿或当前帧单元格可能覆盖栅格化结果的问题。
- 修复选区移动、翻转、变换、焦点与轴心在部分多图层或超出画布场景下的预览、对齐和撤销状态问题。
- 修复图层显隐、属性调整、组内合并、自由瓦片来源重排及跨图层操作中的历史记录或预览不一致问题。
- 修复部分动画导入、补间蒙版和时间轴选择场景的状态同步问题；补间预算与预览加入边界处理。
- 修复参考图菜单探测可能改动剪贴板、扩展资源拖放处理以及部分界面缩放和分栏拖动时的状态错误。
