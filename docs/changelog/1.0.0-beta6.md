# MoonSprite 1.0.0-beta6

发布日期：2026-09-22

## 优化

- 栏目按可用宽度分阶段显示标题与操作按钮；空间不足时通过“更多操作”访问完整按钮组，支持停靠和浮动面板。
- 统一颜色、调色板、预览、参考图、画笔和图块栏的紧凑操作入口，调整窄栏间距及标题布局。
- 预览默认适配随栏目当前尺寸更新；手动缩放继续保留用户设定的倍率。
- 改进时间轴选区和图层设置交互。

## 修复

- 修复栏目标题按钮区出现滚动条、灰色占位及按钮裁切的问题。
- 修复预览栏目缩小后仍使用首次打开尺寸计算适配比例，导致图像被裁剪的问题。
- 修复时间轴批量选区保留问题，并补充定向回归测试。
- 加强扩展脚本提取对 script 结束标签变体的处理。
