# 1.0.0-beta2 完整更新记录

发布日期：2026-09-05

## 新增

- 新增图层时间轴焦点模型，区分图层、图层组、普通 cel、蒙版和帧选择，统一当前帧、选中范围与播放中的视觉反馈。
- 新增图层面板高风险交互回归覆盖，验证蒙版独立选择、播放推进、画布选区切换、批量图层操作和停靠布局行为。
- 首页与“帮助 > 更新日志”共用最新版本摘要和归档数据，发布版本信息可从首页新闻直接打开完整更新内容。

## 优化

- 图层与动画面板的选择、拖拽、可见性/锁定手势、批量属性和撤销边界进一步统一；蒙版行与蒙版 cel 保持独立但可按帧联动。
- 播放、禁用帧、画布选区和隐式活动图层之间的时间轴状态改为显式推导，避免 stale selection 泄漏到无关蒙版行，同时保留播放时整列活动语义。
- 完善发布与开发门禁、版本契约、模块边界和按改动范围的定向验证；同步更新中文发布周期、更新日志索引与 Beta2 摘要。
- 官网与编辑器首页文案、版本标识和视觉资源继续统一，保留 Windows Beta 通道与源码可见许可说明。

## 修复

- 修复画布选区开始后蒙版当前帧错误高亮、蒙版活动被普通图层选择遮挡，以及暂停/播放切换时活动帧标记丢失的问题。
- 修复空白点击清除显式图层选择后无法恢复隐式活动图层与蒙版当前帧指示的问题。
- 修复图层面板外部点击、标记弹窗和画布交互误清除时间轴选择的问题，并补齐蒙版与普通 cel 的选择样式边界。
- 清理与当前交互契约不再匹配的旧失败测试，保留并通过本周期新增的正确交互回归测试。
