# 1.0.0-beta5 完整更新记录

发布日期：2026-09-19

Beta5 聚焦动画创作、参考图辅助、选区定位与扩展创作体验，并进一步收紧导出和复杂工程编辑的稳定性。

## 新增

- 新增帧间动画编辑与预览，可直接在时间轴中创建、调整和检查补间结果。
- 新增参考图面板，支持独立停靠、缩放、移动和显示控制；参考图不写入工程像素内容。
- 选区和变换新增九宫格锚点与以锚点绘制，居中绘制、对齐和变换操作更直观。
- 扩展开发文档补齐清单、运行时、组件库控件和示例；内置宠物伴侣继续作为独立 `.msext` 扩展包发布。

## 优化

- 图层快捷操作会在动画帧轨道延伸至对应区域时逐个收起，避免遮挡循环节标题和编辑视线。
- 优化时间轴缩略图、循环节、帧间动画和多帧编辑的预览与交互反馈。
- 优化画布复合、面板停靠、光标、快捷键和选择性编辑的协作行为，复杂工程编辑更稳定。
- 导出、保存和文件格式处理进一步完善，预览、裁切及跨格式边界行为更加一致。
- 扩展运行时继续完善菜单、浮层、设置和组件库复用能力，扩展界面可保持与软件本体一致的交互样式。

## 修复

- 修复画布复合缓存、时间轴活动状态和缩略图刷新中的边缘问题。
- 修复选区、锚点、变换和对称绘制在不同工具与多帧目标下的状态同步问题。
- 修复扩展窗口、内置宠物资源和平台弹窗的加载与本地化边界问题。
- 修复项目保存、导入导出及不同图像格式处理中的兼容性问题。
