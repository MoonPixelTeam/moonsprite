# 开发版本周期

本文件只描述当前开发周期，不代表最近一次已打包版本。

## 当前状态

- 当前目标：`1.0.0-beta5`
- 内部技术版本：`1.0.0-beta5`
- 阶段：`1.0.0-beta5` 发布准备
- 本周期基线提交：`01e364d`（beta4 发布提交）
- 最近一次已打包版本：`1.0.0-beta5`
- 正式版本号：Beta 验证通过后再由用户确认

## 版本语义

- `DEV.N` 是功能尚未完整时的开发里程碑，不承诺正式版本的兼容性或功能完整度。
- Beta 使用合法的 SemVer（当前为 `1.0.0-beta5`），显示、更新日志和归档使用完整 Beta 版本号。
- 开发期间当前目标可以与最近一次已打包版本不同；“帮助 > 更新日志”只显示最近一次已打包归档。
- Beta 验证通过后，由用户决定是否发布对应的正式版本号；不得由 AI 擅自决定正式版本号。

## 周期基线

开发周期开始时记录基线提交。发布后若有维护提交，应在下一个周期开始时重新记录新的基线；不能机械使用更早的发布提交作为 diff 起点。
