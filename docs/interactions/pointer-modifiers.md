# 指针与修饰键契约

中文 | [English](pointer-modifiers.en.md)

指针表达“当前按下会发生什么”，不得只依据当前工具名称。工具切换、按键按下或松开时应立即更新指针，不要求鼠标再次移动。

标准 CSS 光标类型（例如 `pointer`、`text`、`move` 和各方向 `resize`）由全局语义映射层统一转为组件库光标变量。新组件无需绑定光标图片；样式表、动态插入的样式、内联样式和弹出层使用相同映射。映射保留选择器优先级、`!important`、`none` 和画布专用光标，不在鼠标移动时扫描页面或读取布局。指针比例和系统光标偏好仍由统一主题控制。系统文件对话框等原生界面不属于此 DOM 映射范围。

## 通用优先级

1. 弹窗、输入框和菜单交互。
2. 禁止操作状态，例如当前图层隐藏或锁定。
3. 正在进行的拖动、绘制或变换。
4. 临时修饰键行为。
5. 当前工具默认行为。
6. 默认指针。

同一时刻只允许一个自定义指针生效，不得与系统指针或另一个工具指针叠加闪烁。
选区内容进入缩放或旋转拖拽后统一显示移动指针，松开后再恢复当前命中区域对应的缩放或旋转指针。
首选项可关闭本地像素指针并回退到系统指针，也可按 100%、125%、150% 或 200% 等比缩放像素指针；缩放时图像与热点必须使用同一比例，不能改变实际落点。

## 修饰键

每个真实工具都必须在“快捷键设置 > 工具”中紧跟一条同名的“（快速选择）”项。快速选择允许仅修饰键、普通键或多修饰键组合；按住完整组合时临时覆盖当前工具，任一组成键松开后恢复。默认录入为“移动工具（快速选择）=`Ctrl`”“吸管（快速选择）=`Alt`”“抓手（快速选择）=`Space`”，其余快速选择默认留空。笔刷尺寸和其他上下文修饰命令继续显示在“工具修饰”分类中，修改后指针、提示和实际操作必须读取同一份配置。

快速选择生效期间，工具栏必须同步显示对应工具为选中状态；原工具只被暂时覆盖，不写入工具设置，也不进入撤销历史。未开始拖动时，除框选和形状工具外的当前工具可以进入快速移动工具；框选和形状始终保留自身操作，先按默认 `Ctrl` 再按下指针也不得切换成移动工具，其中矩形和椭圆使用中心创建语义。径向渐变中的 `Ctrl` 中心创建同样优先于绑定到 `Ctrl` 的快速移动，其他不包含 `Ctrl` 的快速移动绑定仍按普通规则生效。进入绘制或变换等拖动过程后，该过程自身的组合修饰键语义优先。只要快速移动组合仍被按住，后续按下其他修饰键不得退出临时移动，除非完整命中更具体的快速选择组合或当前工具更高优先级的组合操作。任一组成键松开、窗口失焦或页面隐藏后立即恢复原工具的选中状态与行为。

快捷键录入以一次按键会话为单位：先按下的 `Ctrl`、`Alt`、`Shift`、`Meta` 只更新预览，普通键按下后再提交完整组合；只绑定修饰键时在修饰键松开或输入框失焦时提交。录入器支持鼠标左键、右键、中键、侧键、左键双击、滚轮上下，以及它们与修饰键的组合。需要持续按住的快速选择和工具修饰命令不接受左键、右键、左键双击或滚轮；普通命令可使用这些输入。录入框拥有高于应用命令分发的优先级，`Ctrl+Shift+V` 等组合不得被 MoonSprite 自身的粘贴命令提前截断。`Escape` 放弃本次录入，`Delete` 或 `Backspace` 清空绑定。

| 场景 | Alt | Ctrl | Shift |
| --- | --- | --- | --- |
| 非框选、非形状、非径向渐变工具（未开始拖动） | 由当前工具定义 | 临时移动工具；拖动开始后由当前过程的组合修饰键优先 | 约束由工具定义 |
| 框选或形状工具（未开始拖动） | 由当前工具定义 | 保留当前工具；矩形、椭圆下一次拖动从首次按下位置向两侧创建 | 约束由工具定义 |
| 鼠标按住新建矩形、椭圆框选或形状 | 调整当前框选或形状的旋转方向 | 以首次按下位置为中心向两侧创建 | 保持 1:1 比例；可与 Ctrl 同时使用 |
| 径向渐变拖动 | 无 | 以首次落点为中心向四周扩展 | 锁定为 1:1 圆形；可与 Ctrl 同时使用 |
| 选区内部移动内容 | 临时吸色 | 复制选区内容 | 水平或垂直约束 |
| 选区边缘移动选框 | 临时吸色 | 不复制像素 | 水平或垂直约束 |
| 选区缩放点变换 | 以当前轴心为原点向两侧同步变换 | 整数硬边缘倍数缩放 | 固定原始宽高比；与 Ctrl 同时使用时按原比例整数倍缩放 |
| 选区旋转 | 临时吸色 | 不改变旋转语义 | 每 45° 吸附到八个方向 |
| 移动工具点击或拖动图层 | 复制图层 | 工具定义 | 点击其他图层内容时加选；继续拖动时水平或垂直约束 |
| 图层栏目拖动 | 显示复制意图并复制 | 无 | 保持排序语义 |
| 缩放工具拖动 | 无 | 无 | 临时使用百分比级数缩放，不进入抓手平移；松开后恢复首选项中的默认缩放模式 |
| 旋转视图工具 | 临时吸色 | 保持或复位原始方向 | 八方向单位旋转 |

鼠标仍按住并正在新建矩形、椭圆框选或形状时，按住 `Space` 临时移动当前框选或形状。移动以按下 `Space` 时的指针位置为基点，当前工具指针保持不变；松开后从新位置继续调整，不得跳变。

## 直线连接模式

“直线连接模式”是画笔和橡皮擦的可配置修饰键行为，默认由 `Shift` 触发。它位于“快捷键设置 > 修饰键”，不再放在首选项中。关闭后，`Shift` 只保留其他工具定义的约束行为，不会连接上一落笔点。

画笔或橡皮擦已有上一落笔锚点时，完整命中的直线连接组合键优先于临时移动工具。默认设置下，`Ctrl+Shift` 必须继续显示受方向约束的直线预览并完成绘制，工具栏也不得临时切换为移动工具。直线连接预览只在没有正在进行的画布拖动时显示；已经按住指针连续绘制后再误按 `Shift`，不得显示上一落笔锚点的直线预览或打断当前笔画。

ISO视角开启且“强制线条对齐”生效时，该约束高于普通直线方向修饰键：直线工具以及铅笔、橡皮擦的单次拖动画线和直线连接始终以首次落点为锚点，实时吸附到水平、垂直或 ISO 绘制视角设置中的 `N:1` 阶梯方向，并使用平衡阶梯算法生成像素路径。关闭强制对齐后恢复现有自由手绘与修饰键规则。

按键松开后必须立即恢复原行为和指针。窗口失焦、指针离开窗口或释放捕获时必须结束临时状态；每次画布或图层栏目指针事件都要用事件自身的 `Alt/Ctrl` 状态校正缓存，避免热更新或焦点切换漏掉 `keyup` 后永久进入吸色或复制状态。

锁定对称轴后，普通指针拖动不得移动轴线；按住 `Ctrl` 可临时绕过锁定并拖动对称轴，释放 `Ctrl` 后立即停止该次移动。

画布滚轮输入统一兼容标准 `wheel`、旧式 `mousewheel` 和仅提供横向增量的外设事件。TourBox 等外设不需要先由普通鼠标滚轮激活；事件只作用于指针所在的活动画布，输入框、栏目滚动区和正式弹窗保持自身滚动语义。

## 热点规则

- 画笔类指针热点对应实际落笔像素；偶数尺寸按当前产品规则落在右下中心像素。
- 吸管热点位于图形有效内容的左下角。
- 移动和复制指针热点位于视觉图形最左上角。
- 框选的四角角标属于画布预览，不改变鼠标热点；默认隐藏鼠标本体，偏好开启后使用热点位于中心的真正十字鼠标指针，不能把十字画进四角角标内部。
- 框选工具位于画布内容边界外时仍保持选区创建指针和四角角标，不显示禁止指针；只有真实的图层不可编辑状态才显示禁止指针。
- 旋转手柄使用对应四角指针，命中区不得与缩放手柄重叠。

“首选项 > 光标 > 使用软件指针”默认开启，开启时所有状态使用 MoonSprite 内置像素指针并允许调整光标比例；关闭时普通操作使用电脑系统指针，系统没有对应语义的缩放、旋转视图和选区旋转等特殊状态继续使用 MoonSprite 指针。任何资源加载失败都必须保留有效 CSS 回退，不得显示空白或错误的禁止指针。位置 5,2 的 16×16 源格为移动指针，导出后使用 32×32 资源。
