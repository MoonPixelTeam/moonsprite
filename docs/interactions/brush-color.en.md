# Brush and Color Contract

[中文](brush-color.md) | English

## Color

- Document color modes are fixed to RGBA, indexed, and grayscale. RGBA permits arbitrary color and alpha. Indexed canvas pixels may reference only visible colors in the current palette; every external color maps to the nearest palette color by RGBA distance and must not add a color implicitly. Grayscale preserves alpha and converts every drawing, paste, text, and conversion write to equal RGB channels using perceptual luminance.
- Foreground and background colors are independent application-level state shared by every open project. Changing either in any project or palette and switching to another project must not restore that project's older color.
- `X` swaps foreground and background by default. The command can be changed or cleared under Shortcut Settings > Color.
- Brush left button uses foreground and right button uses background. Eyedropper and color picker use the same left/right semantics.
- Eraser left button performs transparent erase. Right-button drag replaces only pixels in the active layer and brush range whose RGBA exactly matches foreground with background; every other color remains unchanged. This continues to honor selection, basic shape or RGBA image brush, symmetry axis, and one-stroke undo rules, and works on RGBA and indexed layers.
- Dragging the eyedropper updates the corresponding color in real time. The eyedropper can also sample palette swatches and color-wheel or slider values. Left writes foreground; right writes background.
- Hold and Click to Add Color defaults to `Alt+S`. Pressing the shortcut alone adds nothing. While held, completing one left-button sample on canvas, palette, or color wheel adds the final foreground color to the palette. A right-button background sample does not add.
- Eyedropper tool options show the current foreground and background and provide Replace in Current Layer and Replace Globally. Replacement runs from foreground to background and matches exact RGBA only. Global scope includes every unlocked layer and animation frame, and the whole operation creates one undo step.
- After sampling, Eyedropper remains active by default. When Preferences > Editing > Return to Pencil After Eyedropper is enabled, it returns only after a completed explicit sample. Modifier-triggered temporary color picking always returns to the original tool.
- When right-clicking the color wheel or sliders to adjust background, the selection point, sliders, and wheel display update together without hue jumps.
- After hue snapping or color-level changes, the selection point returns to the center of the current color region while preserving equivalent color intent.
- Palette swatches indicate both foreground and background. Foreground uses an upper-right marker and background a lower-left marker. Left-click foreground selection or right-click background selection adds a temporary blue outline to the clicked swatch. Losing swatch focus hides only the outline. Right-click never changes foreground.
- Palette Actions > Synchronize Colors is off by default. When enabled, editing a palette color exact-matches RGBA and replaces corresponding pixels across every unlocked layer and animation frame, combined with the palette change as one undo. Indexed mode changes only the palette color and does not rewrite canvas pixel IDs.
- Foreground and background color-editor titles explicitly identify the color role. On first open they are temporary popups and close on blur. A real title-bar drag converts one into a persistent window that may coexist with the other editor. Each remembers a size constrained by minimum and maximum, but reopening after close must return to the default position near its trigger button. Channel sliders and the right-side value inputs are equal height and resize through shared eight-direction handles. Default mode order is HSV, RGB, LAB, GRAY, PLT, where PLT uses the current project palette. HSL and CMYK may be enabled in Preferences. The right-side eyedropper keeps the dialog open while sampling and restores the pre-sampling tool afterward. Right-clicking the HEX field reads the system text clipboard; a valid six- or eight-digit HEX applies immediately, while invalid content leaves the current color unchanged.

## Brush Types

- Basic brushes are square, circle, and line and support size changes, with default shortcuts `Ctrl+1` for circle, `Ctrl+2` for square, and `Ctrl+3` for line. Tool options use one current-basic-brush button; clicking opens a compact popup with the three shapes. Selection closes the popup immediately and retains existing tool preferences. A dithering-brush button to the right of the basic brush selects checker, directional, or Bayer templates and switches discrete dither phases through joined left and right steppers according to the real template matrix. Left diagonal, right diagonal, horizontal, and vertical each use six phases. Clicking the current template again disables dithering. The template panel first opens as a temporary overlay; dragging its title bar converts it into a persistent floating window that no longer closes on canvas click and can be retracted through its title-bar close button. The pattern is fixed in pixel coordinates and automatically clipped to the current brush size and shape. Hover preview, straight-line preview, and final write share one mask. Dithering settings persist separately for Pencil, Eraser, and Line, but affect only basic brushes when no image brush is selected. Circle masks use integer hard-edge ellipse scanlines shared by preview and painting, not a continuous-distance threshold that turns small circles into solid squares.
- Image brushes preserve source RGBA pixels, transparency, and original dimensions and are no longer converted into grayscale coverage brushes. Width or height above `256px` must be explicitly rejected during import or selection creation and must not be silently resized.
- Crack, wood, grain, and procedural textures are system textures available only to Paint Bucket and generated once according to fill-region rules to avoid repeated accumulation. Static Texture Size and each procedural texture size parameter are in canvas pixels and must not inherit brush size left over from another tool. An independent Dither toggle switches procedural textures between ordered pixel dithering and a hard threshold; antialiasing remains a separate setting. Pencil, Eraser, and Line always ignore system textures but may still use RGBA image brushes from the Pattern Brush panel.
- Paint Bucket modifies only pixels in the real selection mask for both rectangular and non-rectangular selections. Contiguous and non-contiguous modes obey the same restriction.
- Custom brushes can be imported from image files or created from the current selection with `Ctrl+B`. Both save to the `brushes` folder beside the executable, do not enter current project data, do not change document dirty state, and use intrinsic size without showing a size parameter. Embedded project brushes from old projects remain readable, selectable, and deletable.
- Pencil, Eraser, and Paint Bucket each store basic-brush settings. Non-basic brushes and brush mode are shared across the tools that support them.

## Pattern Brush Panel

- Pattern Brush is a normal panel shown on the right by default. Like other panels it can dock left, right, or bottom, float, resize, hide, or be summoned by a configurable popup-panel shortcut, default `6`. The Pattern Brush button beside the basic brush in tool options toggles panel visibility with one click.
- The title bar provides Add, Delete, and Manage. Add can multi-select PNG, JPEG, WebP, BMP, or GIF, and images can also be dragged directly into the panel. Manage offers three thumbnail sizes, `30 / 40 / 52 px`, supports `Ctrl+wheel` adjustment, and can open the local brush folder.
- A brush cell shows one complete RGBA brush unit. Transparent pixels reveal the panel background directly and do not draw a checkerboard or substitute color. No extra surface appears when idle; hover shows the theme hover surface; selection uses the same outline as palette swatches. Ordinary click replaces selection, `Ctrl` toggles discontiguous selection, and `Shift` selects a range. The brush currently used for drawing remains highlighted after the panel loses focus and is canceled only by clicking that sole selected brush again or switching to a basic brush. Clicking a brush also makes it the current brush.
- Local brushes can be press-dragged to reorder, stored in `brushes/.brush-order.json`. Dropping in the blank space after the grid moves to the end. `Delete` or `Backspace` deletes the temporarily selected brushes and must confirm before removing disk files. Embedded compatibility brushes follow project-data deletion rules.

## Brush Dynamics

- Pencil and Eraser store Ase-style brush dynamics separately. Size, drawing strength, and color gradient may independently map to pressure or speed. Pencil strength means opacity; Eraser strength means erase amount; color gradient applies only to Pencil.
- All three effects output `0..100%`. Size is relative to base size and ends at least `1px`. Gradient `0%` is background and `100%` foreground; a forward pressure map approaches foreground as pressure increases.
- Pressure-device detection follows Aseprite device semantics: standard `pen`/`eraser` plus vendor pen types such as Windows Ink, Wintab, and stylus may participate in pressure mapping, while touch and ordinary mouse compatibility defaults (usually `0.5`) do not. If the browser mislabels a device as `mouse`, the current pointer session upgrades to a pressure session only after a non-default or continuously changing pressure sample is observed. When the pressure axis is missing, draw at full strength and never treat the missing value as zero pressure. The pressure curve is still calibrated as `100 * pow(clamp((p - 0.02) / 0.98, 0, 1), 1.7)` to keep existing brush settings and feel compatible. A new pressure map defaults to input `0..70` with a hard curve.
- Speed is client CSS pixels per second with a time-aware EMA. First value and straight-line connection use `0`; zero elapsed time reuses existing speed; a pause of `160ms` resets to zero. Speed input is hard-limited to `4000 CSS px/s`, with new mappings defaulting to `50..2400`.
- Every mapping independently sets input range, output range, soft/linear/hard curve, and forward/reverse direction. Missing speed resolves as `0`, so forward uses the output minimum and reverse the maximum.
- The first time any brush-dynamics mapping is enabled, the in-drawing brush preview opens automatically. If the current brush preview is None, it switches to Full Preview with Edge so dynamic size is visible while drawing. Hover preview uses the current base size, and drawing uses the current dynamic sampled size in real time instead of being fixed at `1px`. If the user later closes the preview manually, adjusting an existing mapping must not force it open again.
- Dynamic gradient independently selects the same nine dither modes as the Gradient tool. Directional dithers use six-stage matrices. Every final document pixel resolves its threshold from absolute coordinates. `none` interpolates RGBA directly; other modes dither between the two RGBA endpoints. Transparent endpoints follow Aseprite's non-premultiplied color rule and composite source-over onto the current target pixel, so a fully transparent sample never replaces the underlying pixel with transparent color, and a self-crossing stroke never overwrites pixels already laid down by the same stroke with a transparent sample.
- Intrinsic-size custom brushes ignore size mapping but still apply strength and color gradient. With gradient enabled, preserve imageBrush shape, source alpha, and coverage while RGB uses the current dynamic color. With gradient disabled, keep outputting the brush's own color. Eraser and right-button foreground replacement are unaffected by color gradient.
- Coalesced pointer events and perfect-pixel paths retain size, strength, and gradient amount, endpoints, and dither description. Long segments interpolate between start and end samples. Dynamic size uses an envelope in size space: each raster step changes by at most `max(1, ceil(baseSize / 6))`, multiplied by distance when crossing multiple raster steps. The first point uses the target size directly.
- Dynamic-size stamp spacing uses each candidate's actual size and the accumulated path steps since the previous stamp. Whenever the integer size differs from the previous actual stamp, that candidate must be stamped; spacing applies only after size stabilizes. Always draw first and last, draw zero length once, and use the same rules for raster and balanced paths.
- Apart from dynamic gradients with a transparent stop, repeated hits on a pixel within one stroke always recompute from the pre-stroke color and the coverage achieved so far, and event density must not accumulate opacity or dynamic color repeatedly. Dynamic gradients with a transparent stop composite source-over onto the current target pixel, indexed mode reuses the same palette color, and no duplicate color is generated continuously.
- Live pressure and speed telemetry travels only through an in-memory channel published at most once per frame. It never enters Workspace, session, dirty state, undo, recovery, or saved data. Both hover and drawing publish. Leaving the canvas or unmounting becomes inactive, and speed displays `0` after `160ms` stopped.
- Legacy pressure settings and v2/v3 dynamics migrate automatically to v4; v2/v3 gradient dithering migrates to `none`. v2 factory pressure and speed mappings migrate to the new default input ranges, while user-custom mappings are preserved. v4 mappings and dithering persist locally per Pencil and Eraser, do not affect dirty state or undo, and one complete stroke still commits one pixel edit and one undo step.

## Symmetry Drawing

- Pencil, Eraser, shapes, and Paint Bucket share horizontal, vertical, upper-right-to-lower-left, upper-left-to-lower-right, and rotational symmetry icon buttons. Modes combine freely and persist with tool settings.
- The first time each symmetry axis in a project changes from off to on, the shared symmetry center uses the current canvas center. Repeated toggles of that axis do not move the center again. First enabling another not-yet-used axis relocates to the current canvas center. Guides are solid lines with configurable color, alpha, and thickness. When unlocked, hovering the center point or an axis line shows the move pointer; dragging the center moves every axis at once, while dragging a single axis adjusts the shared center along that axis's normal, snapping to half pixels. The More menu can lock guides, adjust appearance, or reset the pivot to the current canvas center. Pivot changes are tool state and do not enter document undo history.
- The horizontal axis reflects top and bottom, the vertical axis left and right, and the two diagonals reflect along upper-right-to-lower-left and upper-left-to-lower-right. Diagonal results that fall outside a rectangular canvas are discarded.
- Brush pixels, color, alpha, pattern, and shape generate an original result first and are then reflected through shared coordinate mapping. When multiple axes produce the same target pixel it must be deduplicated. Preview, cache invalidation range, and final write use the same target set.
- With symmetry enabled, brush preview shows only the original point under the mouse and does not repeat at mirrored positions. Actual drawing still writes every mirrored position.
- Paint Bucket first generates deduplicated mirrored seeds from the seed point, then applies identical contiguous or non-contiguous fill rules to each. All regions merge into one pixel edit and one undo.

## Custom Brush Color

- An ordinarily imported image always retains source RGBA, and multicolor or translucent pixels must not be remapped when foreground or background changes.
- A brush created from a selection first preserves its original multicolor pattern. Afterward, when the user changes colors, light pixels map to foreground, dark pixels to background, and transparent pixels stay transparent.
- After a selection brush is written successfully to the local Pattern Brush library, clear the original selection, switch to Pencil, and select that brush immediately. On write failure, retain the original selection and the current tool.

## Selection Conversion

- The top-level Selection > Convert To menu offers Pattern Brush and Background Preset whenever a selection exists. Pattern Brush follows the local pattern-brush creation rules. Background Preset captures the current visible composite inside the selection, keeps everything outside a non-rectangular selection transparent, and saves it to the `BackgroundPresets` folder beside the executable. Saving a background preset does not clear the selection, does not change project dirty state, and does not enter document undo history.

## Pattern Modes

- Paint Brush is the default mode for new and reset tool configuration and appears first in the mode list. In existing versioned configuration, a mode the user explicitly chose is preserved.
- All three modes use the shared themed select and describe tiling origin or stamping behavior directly inside each option. The detail preview must show the custom brush's saved original multicolor pixels and must not unconditionally force them to a single foreground color.
- Pattern Aligned to Source: tiling coordinates are fixed in the brush source coordinate system, so the same canvas position always receives the same pattern.
- Pattern Aligned to Target: also tiles, but the first paint point becomes the tiling origin. Preview must coincide with the actual placement.
- Paint Brush: in overwrite mode, every non-transparent pattern pixel replaces the target along the path in order, and later stamps fully cover earlier stamp pixels. Fully transparent pattern pixels do not modify the layer underneath.
- When `Shift` connects a straight line, preview and confirmation must reuse the same stamp centers and overwrite order.

## Gradient Tool

- The Gradient options bar uses joined buttons to choose Linear or Radial and saves that choice together with tolerance, contiguous region, and dithering settings in local tool preferences. Legacy preferences migrate to Linear by default.
- Linear gradient treats the start-to-end vector as the color projection direction. Radial gradient treats the start point as the center and the start-to-end distance as the radius; pixels at the same distance must receive the same color, and everything outside the radius uses the end color.
- Smooth interpolation and every dither mode share the same linear or radial amount. The live canvas preview, free-tile source editing, and final pixel commit must use the same mode, endpoints, and sampling function, and produce one undo step.

## Airbrush

- Airbrush emits one particle batch immediately on press and continues at the Particle Frequency interval in milliseconds while held. It must keep spraying while the pointer is stationary.
- Particle Radius controls each particle's pixel radius, Scatter Radius controls a circular region in which particles appear uniformly at random around the pointer, and Particle Density controls particles per batch.
- Airbrush follows foreground/background, selection, layer mask, indexed-color, and symmetry-axis rules. One complete hold commits one pixel edit and one undo step; cancel, window blur, or window switch undoes the entire uncommitted spray.
- Timed spraying uses a single frame scheduler. Particle generation must not follow pointer-move event frequency and must not emit an unbounded backlog after a stall.

## Preview

- Preview shape and actual write mask must come from the same data.
- With tiled preview enabled, live pixels, edges, and operation-line previews for Pencil, Eraser, Line, shapes, Gradient, Airbrush, and tile painting must appear in every visible tiled copy. The brush outline keeps one continuous original geometry across seams, color sampling folds back onto the original canvas through the enabled axes, and out-of-bounds parts must not be clipped or reassembled incorrectly. The mouse pointer itself still appears only once.
- Preferences > Tool Preview controls brush preview style. The default is Full Preview, with None, Edge Only, Full Preview, or Full Preview with Edge available. Show Brush Edge While Drawing appears only for Full Preview with Edge and controls whether the edge outline keeps showing while drawing with the button held.
- Pencil and Eraser line-connection modifiers are configured in Shortcut Settings. The live-preview toggle under Preferences > Editing controls only whether a temporary segment appears while the modifier is held and does not change the final drawing result after release. Confirmed commands such as Flip Content must clear old line anchors and previews.
- Preferences > Editing > Optimized Line Algorithm is enabled by default. When enabled, line connection and polygon-lasso edges distribute major-axis pixels into even staircase steps of similar length. Reverse connection must produce the same pixel set, and preview and final result must reuse the same algorithm. When disabled, fall back to the traditional raster line.
- During line connection, triggering Constrain Line Direction, default `Shift+Ctrl`, snaps the endpoint to the allowed direction closest to the pointer. A Line Diagonal Step value of `1` provides horizontal, vertical, and 45° for eight directions. Values above `1` provide 12 directions through `N:1` and `1:N` pixel steps, where `2` corresponds to roughly 30° and 60° diagonals. The constrained endpoint must land on a complete step period so the starting step, every intermediate step, and the ending step each contain exactly `N` major-axis pixels. Preview and final painting use the same constrained endpoint and point sequence.
- The Step field in the Pencil tool options bar edits the same Line Diagonal Step value, ranging from `1` to `16`. Changes apply to the canvas immediately, persist, and stay synchronized both ways with the Preferences value.
- An existing line anchor counts as the first pixel of the starting step. For a step value of `6`, the anchor and the following five major-axis pixels form the first step, and no seventh pixel may be generated.
- When repeatedly connecting straight segments with translucent color, all segments share the same pre-stroke underlying pixel color. Junction points and later crossings must not accumulate alpha again because of a new segment, while each segment still keeps the correct undo range.
- Adjusting parameters of a non-basic brush must not flash a basic circle or square preview.
- Pointer black-or-white contrast is based on the final composite under the pointer, including preview color, not on the active layer or the color about to be painted.
