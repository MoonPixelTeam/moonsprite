# 选区与变换契约

中文 | [English](selection-transform.en.md)

## 创建选区

- 矩形、椭圆、自由套索、多边形套索和魔棒共享新建、加选、减选、交集四种模式。
- 五种选区工具共享上下、左右、右上到左下、左上到右下四个对称轴。每次新建的原始掩码先按全部启用轴和当前可移动轴心计算闭包并去重，再与旧选区执行新建、加选、减选或交集；路径预览、魔棒预览和提交结果必须一致。矩形画布中斜向镜像越界像素不进入掩码。
- 开启对称后，移动、缩放、旋转和倾斜选区时只变换每个对称轨道中的一个代表区域，再按当前轴心生成镜像闭包；移动可以从任意镜像区域开始，按下的区域必须跟随指针，其他区域实时执行对应方向的镜像移动。选框、像素预览、实际写入和一次撤销必须一致，不得把已经对称的源内容重复复制成额外副本。
- 多边形套索单击增加顶点，点击第一个顶点、双击末点或按 `Enter` 闭合并提交，按 `Esc` 取消；未闭合时可用中键或 `Space` 临时平移画布，平移期间和松开后都必须持续显示已有边与指针末段，并保留已有顶点、组合模式和原选区继续建立边界。“首选项 > 编辑 > 直线算法优化”开启时，顶点之间的预览和最终边界都使用长度相近的均匀像素阶梯。自由套索拖动预览是否默认闭合由“首选项 > 编辑”控制。
- 右键拖动默认执行减选。按住 `Shift` 开始选择时绕过已有选区的移动、缩放和旋转命中，从选区内部也能继续加选；属性栏在按住 `Shift` 或右键时临时切换到加选或减选反馈，松开后恢复用户原本选择的组合模式。变换已经开始后，`Shift` 仍作为比例或角度约束键。
- 创建矩形、椭圆或套索选区期间只显示画布内的新路径像素预览，不显示新选区蚂蚁线和变换点；已有选区的蚂蚁线在新建、加选、减选和交集期间保持显示，松开后再一次性显示组合结果。矩形和椭圆的路径预览默认按底色自动选择黑色或白色，也可在首选项中改为固定自定义颜色。
- 创建矩形或椭圆选区，或使用矩形/椭圆形状、直线、曲线工具拖动时，软件底部状态栏的尺寸信息实时显示当前“宽 x 高”，手势结束或取消后恢复原有状态；画布内部原有的左下角画布尺寸保持不变。同时在当前绘制范围左上角起点上方显示固定屏幕尺寸的两行信息块：第一行并排显示包含式起点与终点坐标，第二行显示“宽 × 高”。信息块跟随旋转、镜像和视图变换保持水平可读，使用半透明灰色背景与白色文字；顶部或右侧空间不足时收进视口内，仍以左上角为定位基准，松开后隐藏。首选项中的“显示框选尺寸”只控制绘制范围旁的浮动信息块，不关闭底部状态栏的实时尺寸。
- 新建模式在已有选区外按下并松开且没有真实拖动时取消选区；按下本身不得提前取消。是否属于单击按 CSS 指针移动距离判断。即使按下与松开仍落在同一个文档像素，只要发生真实拖动，也必须提交该 1 像素选区。
- 使用矩形框选工具双击画布时快速选择指针所在单元：第二次按下时立即显示完整单元的实线选择预览，不等待鼠标松开，预览阶段不显示蚂蚁线；保持第二次按下并拖动时，预览范围按指针经过的完整单元扩展并吸附到单元边界，不创建像素级自由矩形；新增、加选、减选和交集模式始终以操作前的选区为组合基底，松开提交后才显示最终选区蚂蚁线。自定义网格开启时使用当前网格原点与单元宽高，未开启时使用透明棋盘格尺寸；画布边缘的不完整单元裁切到有效画布范围。
- 工具栏明确选择加选模式时，已有选区内部仍可移动内容，缩放点、旋转区和边缘移动保持可用；减选与交集从选区内部开始时优先执行组合选择。临时按住 `Shift` 加选或使用右键减选始终绕过变换命中。套索组合期间继续显示像素预览。
- 指针允许从画布外开始并继续按文档像素网格拖动，但创建路径预览只绘制在有效画布范围内；最终选区掩码不得包含画布外像素。
- 开启平铺预览后，矩形与椭圆框选在按住拖动期间使用当前副本的连续文档坐标，跨副本边界不得跳回或偏离指针；同一实时预览必须显示在全部可见平铺副本中。选框超出原画布时仍绘制一条连续完整的外边界，不得把平铺接缝显示成内部边线；松开后才把周期折回的结果提交到原画布选区，平铺副本不保存额外选区状态。
- 魔棒按住时预览全部将被选中的像素；深色像素使用浅色预览，浅色像素使用深色预览。
- 椭圆框选旋转时直接在旋转后的局部坐标系中栅格化椭圆，不得先生成水平椭圆蒙版再做最近邻旋转；斜向椭圆边界应保持连续、对称且厚度稳定。
- 矩形框选旋转时使用严格的像素中心边界规则；有厚度的斜向矩形应移除四角仅通过一个正交相邻像素连接的孤立尖点，水平、垂直及细线矩形不执行该清理。
- 矩形框选属性栏提供“圆角”开关与像素半径输入。关闭或半径为 `0` 时保持原矩形掩码；开启后按像素中心生成圆角矩形，半径超过当前短边一半时自动收敛。旋转框选必须在矩形局部坐标中判断圆角，实时路径、组合预览和最终选区使用同一掩码。
- 套索路径经过的像素属于最终选区边界；闭合后的右侧和下侧不得因多边形半开判断固定缺少一列或一行。
- `Ctrl+A` 选择整个画布范围。
- 在时间轴中按住 `Alt` 左键点击动画单元格，会切换到对应图层与帧，并按该单元格内所有非透明像素创建选区；按住 `Shift+Alt` 点击时与现有选区相加。替换选择空单元格会清除选区，加选空单元格保持原选区不变，选区变化可撤销。
- 选区工具悬停时在当前文档像素格四角绘制紧凑直角角标，包括指针位于画布内容边界外时；此时不得改成禁止指针。角标使用固定 CSS 像素线宽，不随视图缩放变粗或变细；视觉范围最小为 `8 x 8 CSS px`，像素格更小时围绕其中心扩展。默认隐藏鼠标本体，只显示四角角标；“首选项 > 光标 > 框选时显示十字指针”开启后显示真正的鼠标十字指针，不得在角标内部额外绘制十字。按住 `Shift` 加选时保持四角角标；进入缩放、旋转或边缘移动命中区时不显示角标。
- `Ctrl+Shift+I` 反选画布范围内的当前选区并生成一个可撤销历史步骤；没有选区时只提示用户，不创建历史。
- `Ctrl+H` 只隐藏或显示蚂蚁线，八个变换控制点保持显示和可交互；真实选区仍参与绘制、调整和移动，该视图状态不进入文档撤销历史。

## 命中与移动

- 没有画布选区或浮动变换时，`Shift+H` / `Shift+V` 对显式选中的时间轴内容批量水平/垂直镜像：选中单元格只处理这些格子；仅选图层或图层组处理其全部帧；普通单击帧头会替换原图层选择（包括粘贴后的自动选择），处理所选帧中的全部可编辑图层；选中图层后按 Ctrl/Shift 追加帧时只处理两者交集。隐式活动图层仍只处理当前帧。普通像素按各 cel 自身表面镜像，保持位置；Tilemap 镜像格子与瓦片朝向，自由瓦片沿用逐实例镜像且不改共享源。关联内容只处理一次，跳过隐藏、锁定和文本图层；不清空选择、不切换活动帧，整批操作统一撤销/重做。已有画布选区、浮动变换与明确选择的自由瓦片实例继续使用原有优先级。
- 顶部“选择 > 自由变换”仅在已有选区时可用。进入后选框只显示四个角点；拖动角点按自由比例缩放选区内容，边中点、旋转区和斜切区不启动变换。预览、确认、取消和撤销沿用浮动选区的一次性事务。

- 选区内部默认移动选中内容，只有真实蚂蚁线边界扩展命中区用于移动选框；非矩形选区的包围矩形空边不得触发移动选框。
- 选框边缘的内外命中宽度应视觉对称，四边均可稳定触发；命中距离按连续文档坐标计算，不得因像素取整整体向右或向下偏移。
- 创建、移动或变换选区时，指针进入或超过画布视口边缘会连续平移视图以继续操作；该平移属于视图状态，不进入文档撤销历史。
- 已有选区的移动、缩放、旋转和倾斜允许选框与遮罩部分或完全超出画布；只有新建选区会裁切到画布范围，越界变换不得提前裁掉选区遮罩。
- 开启平铺预览后，已有选区及其浮动内容可从任一可见副本命中；移动使用指针所在副本的连续文档坐标，跨越副本接缝或最外侧副本时不得反向跳变、停止或裁掉浮动内容，即使内部目标坐标已经跨过一个或多个画布周期，实时预览也必须与最终结果一致；确认纯移动时，越过边界的像素与选区按启用的平铺轴折回原画布，最终仍只保存一份选区与一次历史。
- 变换命中优先级固定为八个白色缩放点、四角紧凑旋转区、选框边缘移动带、选区内部和普通套索区域；四个边中点使用 12 CSS px 命中半径。四个角在选区内侧保留 18 CSS px 易点击范围，在外侧象限只保留 5 CSS px（覆盖可见 `8×8` 手柄和紧邻容差），越过手柄外缘后立即旋转。旋转区到角点的最远距离为 28 CSS px，超过后必须恢复普通套索输入。所有半径严格按 CSS 像素随缩放换算，不得强制最小为一个文档像素。
- 只有选区工具显示缩放控制点；切换画笔等绘制工具后只保留蚂蚁线，并继续把绘制限制在选区内。
- 指针进入缩放、边缘移动或旋转交互区时隐藏像素预览，避免两个操作提示重叠。
- 完整选择整个画布时仍允许移动内容。
- 选区内容第一次开始移动时进入浮动状态并捕获稳定的内容与背景来源；只要选区尚未确认或取消，后续任意次数移动都从第一次来源重建并恢复经过区域的原背景，不得把移动后的目标区域重新采入来源。
- 同时选择多个普通像素图层或图层组后，框选与 `Ctrl+T` 使用一份共享选区：`Ctrl+T` 的初始边界取全部目标图层内容边界的并集，图层组展开为全部后代图层，原图层多选状态保持不变。移动、缩放、旋转、倾斜、复制和镜像对每个图层分别捕获与写回像素，不合并图层、不改变层级或顺序；确认后全部图层与选区只生成一次撤销，取消时一次恢复全部图层。多图层目标中包含文本或 Tilemap 图层时整体阻止变换，不得只修改其中的普通像素图层。
- 时间轴同时选择多个帧时，选区内容移动和后续浮动变换作用于全部已选普通像素图层与全部已选帧的组合；图层组展开为其全部后代图层，帧选择和图层选择都保持不变，不转换为 cel 选择。每个目标 cel 独立捕获并写回，关联 cel 共享同一真实源时在所属图层内只处理一次。任一目标图层为文本、Tilemap、自由瓦片、隐藏或锁定状态时整体阻止，不得部分修改。框选或移动工具从画布开始交互时保持原有图层与帧多选，受影响的前后帧洋葱皮必须在移动预览中同步刷新；确认、取消、撤销和重做必须覆盖全部目标，并且整次操作只生成一个历史步骤。
- 自由瓦片图层只有在选中一个可见、未锁定实例且其源未锁定时允许使用选区工具。矩形、椭圆、套索和多边形套索可在画布任意区域建立选区，不按实例可见边界裁切；魔棒仍从当前实例的临时源栅格取样，`Ctrl+T` 仍以当前实例边界建立初始选区。部分选区的移动、缩放、旋转、倾斜或复制保持文档坐标，并在按当前实例显示朝向生成的临时源栅格中执行后逆向写回共享源。若当前选区完整覆盖所选实例，拖动内容只平移该实例坐标、选区和轴心，不改共享源，也不移动其他同源实例。移动预览在同一次指针更新中刷新画布，不额外等待下一帧；共享源发生变化时全部同源实例只刷新像素，并按各自实例变换显示，不复制选区、蚂蚁线、轴心或控制点。确认后实例位置或源像素与选区几何各自作为一次撤销提交，取消后共同恢复。
- 浮动选区执行水平或垂直镜像时，像素值、非矩形掩码、选中偏移和移动预览缓存必须同步翻转；原始清除范围保持独立不变，因此连续镜像后再次移动不得恢复镜像前内容。
- 移动工具移动当前图层或多选图层时，已有选区与图层使用同一位移；一次撤销或重做必须同时恢复图层偏移和选区位置。
- 开启网格对齐时，移动图层、选框或选区内容的可见外边缘吸附到当前显示的自定义网格线；隐藏网格后立即停止网格吸附。开启智能对齐时，移动整体的外边缘与中心可吸附到画布边缘和中心，以及其他可见图层内容边界的外边缘和中心；多选图层以各图层原始内容边界及其整体并集参与命中，样式扩展脏区不得替代语义边界。阈值按 CSS 像素配置并随缩放换算；由于拖拽最终位移是整数文档像素，换算结果最低覆盖相邻 `1` 个文档像素，避免默认高倍缩放下吸附永远无法触发。命中辅助线只属于拖动预览，可独立隐藏而不关闭吸附；取消、确认或结束拖动后清除，不进入文档历史。Tilemap 选区内容和选框继续遵守原有整格移动，不叠加像素级吸附。
- `Shift` 约束水平或垂直方向，并根据相对位移动态选择主轴。
- `Shift` 已锁定主轴时只允许该轴参与网格或智能吸附，另一轴不得因吸附重新产生位移；切换主轴后辅助线同步更新。
- `Ctrl` 拖动选区内容进行复制；普通移动或已经复制出的浮动内容都可再次按住 `Ctrl`，先确认当前位置，再从该位置开始新一次复制移动；每次已确认的复制移动由一次 Undo 撤销。

## 描边

- `Shift+O` 打开描边。有选区时只描边选区内的当前图层内容；没有选区时自动描边当前图层的全部非透明内容。弹窗打开期间 `Enter` 始终优先应用描边并关闭弹窗，即使键盘焦点仍停留在画布；不得把同一次按键解释为确认选区。
- 选区描边与图层样式描边共享宽度、内部/外部/两侧位置、圆形/方形/水平/垂直快捷形状、八方向像素开关和智能色相。智能色相开启时，外部描边使用当前方向与形状范围内最近的可见源像素颜色，内部描边使用被覆盖位置自身的源颜色，再按深色系数压暗；描边透明度仍取描边颜色设置，实时预览与最终写入必须使用同一批目标像素和参考颜色。
- 描边颜色、宽度、位置、像素方向、快捷形状、智能色相、深色系数和实时预览开关属于当前工程设置，成功应用后随 `.moonsprite` 保存并在下次打开工程时恢复。
- `Alt` 在普通工具输入和框选开始前保留临时吸色，不用于选区复制；矩形或椭圆框选拖拽已经开始后，`Alt` 改为调整当前框选的旋转方向。

## 缩放与旋转

- 四角缩放手柄始终可见且位于内容上层。
- 所有工具下都为有效普通选区显示一个固定 `18 x 18 CSS px` 的黑白轴心标识，由 `9 x 9` SVG 像素图标按 `2x` 整数倍率绘制，默认位于当前变换后选区中心对应的单个文档像素中心；偶数宽或高取右侧或下侧的中心像素。标识使用独立于缩放倍率的屏幕尺寸，并在视图旋转或镜像后仍精确贴合轴心位置。悬停标识保持软件默认指针，按住并开始移动后切换为移动指针；拖动按单个文档像素步进，只修改会话交互状态，不编辑像素、不创建文档撤销历史。选区属性栏提供左上、上、右上、左、中、右、左下、下、右下九个预设，每个预设都落在选区内对应位置的单个像素中心，不得落在像素边界交点；并可单独隐藏轴心标识，隐藏只影响显示与命中，当前轴心仍参与旋转、缩放和倾斜，且该开关不进入文档撤销历史。
- 手动设置的轴心用于后续选区旋转与倾斜，变换期间轴心固定，选框、八个控制点、遮罩和像素共同围绕该点变换。整体移动选区或随图层移动选区时，自定义轴心按同一位移移动；普通缩放时轴心保持在选区中的相对位置并随实时预览移动，跨边翻转时同步翻转，不得重置为中心；`Alt` 轴心缩放期间轴心固定在原文档坐标。新建、替换、清除选区或切换动画帧后恢复为新选区中心。
- 拖动已有选区的缩放点时，`Alt` 固定当前轴心并让相对两侧围绕该点同步变换，跨过轴心后才翻转对应轴；未手动调整时轴心就是默认选区中心。`Shift` 固定原始宽高比，`Ctrl` 将宽高分别吸附到原始像素尺寸的整数倍，三者可以组合使用。修饰键在鼠标按住期间按下或松开都必须实时更新预览；缩放点操作不得因 `Ctrl` 复制选区内容，也不得因 `Alt` 切换为临时吸色。
- 使用矩形或椭圆框选工具时，鼠标按住并开始拖动后，`Ctrl` 以首次按下位置为中心向两侧框选，`Shift` 保持 1:1 比例，`Ctrl+Shift` 执行居中等比例框选；`Alt` 按住时只调整当前框选的旋转方向，保持鼠标左键不松并松开 `Alt` 后，鼠标立即恢复控制当前旋转框选的宽高，并以松开 `Alt` 瞬间的旋转中心为固定中心，将单侧半径的像素变化同步应用到相对的另一侧，不得因斜角投影取整导致中心漂移。已经用 `Alt` 改变角度后再按 `Ctrl` 时，必须保留当前角度和精确宽高，只把中心临时移回首次按下点并从当前指针继续双向调整；此时单独的 `Ctrl` 不得额外触发 1:1，只有 `Shift` 或形状工具显式启用的固定比例继续约束宽高。松开 `Ctrl` 后必须恢复按下 `Ctrl` 前的边界、方向和中心，并以松开时的当前指针作为后续调整基准，不得永久保留临时居中的结果。`Space` 以按下时的指针为基点移动当前框选，且指针不切换为抓手，松开 `Space` 后继续调整时不得跳变。松开鼠标后的最终选区必须与最后预览一致。
- 矩形与椭圆形状工具复用上述 `Ctrl`、`Shift`、`Alt` 和 `Space` 交互；矩形填充与矩形轮廓共享属性栏中的圆角开关和半径，关闭时保持直角，开启后按短边限制有效半径。旋转后的填充与轮廓使用同一像素栅格结果完成预览和提交，矩形不得重新出现孤立角点，椭圆轮廓不得填实中心。
- 已有选区且画布没有文本输入或弹窗控件焦点时，方向键每次把选区内容和边界向对应方向移动 1 个文档像素。第一次移动进入与鼠标拖动相同的浮动状态，连续按键始终从首次捕获的内容与背景重建；确认后整段连续移动生成一次文档历史，取消则完整恢复原内容与经过区域的背景。
- 旋转命中区位于四角外侧，与缩放手柄分离。
- 旋转命中区不显示额外蓝色控制点。四角旋转区紧邻斜向缩放区，并限制在角点周围 28 CSS px 内；离开外侧 5 CSS px 斜向缩放区后立即进入旋转，不留默认指针空带。超过紧凑旋转区后恢复普通套索输入，使已有选区周边仍可继续框选。
- 旋转选区时按住 `Shift` 将角度吸附到每 45° 一个方向，即 0°、45°、90° 等八向角度；松开后恢复连续旋转。
- 选区内没有任何非透明图层像素时仍允许移动、缩放、旋转和倾斜选区边界；这类操作不创建像素编辑，但确认后必须作为一次可撤销的选区变化记录。
- 拖动旋转期间暂时隐藏蚂蚁线，八个缩放控制点按当前变换矩形和角度同步旋转；松开后恢复蚂蚁线，但八个控制点继续停留在最终旋转位置并沿旋转后的局部轴命中，直到确认或取消浮动变换。四角旋转指针按控制点相对变换中心的当前显示方向动态选择，不与控制点原始的左上、右上等语义固定绑定；控制点靠近垂直中轴时分别使用上方或下方旋转指针。
- 确认旋转、缩放或倾斜后，最终选区必须裁掉掩码四周完全未选中的空白行列；八个控制点、命中区域和下一次变换使用该紧贴范围，不得继续包围变换矩形产生的空白区域。
- 四边中点缩放区外侧提供紧凑倾斜命中区，最远距离与旋转一致为 28 CSS px，且不显示额外控制点。倾斜方向始终沿当前四边形的对应边：上、下边沿当前顶边方向，左、右边沿当前侧边方向；指针按实际显示方向在水平、垂直、左上右下和右上左下四种倾斜图标之间切换。连续拖动不同边时，新倾斜以当前四边形和轴心为基准累计，不得退回原始矩形坐标或让先前倾斜自动复位。拖动期间指针切换为移动，选区遮罩、像素预览、最终内容和一次撤销必须共享同一倾斜映射。
- 变换的选框、内容和预览必须使用同一个变换矩阵。
- 缩放手柄可以跨过对侧边界；水平跨越时切换水平镜像，垂直跨越时切换垂直镜像，双轴跨越时同时切换。翻转轴取被拖动的边；角点斜向跨越时，水平和垂直轴分别取被拖动角点的两个坐标，不退回使用目标矩形中心。预览、提交和一次撤销使用同一个翻转状态。
- 视图旋转只改变显示，不改变文档选区和变换坐标。
- 调整弹窗打开期间，选区移动、变换、加选和减选必须先移除调整的临时像素预览，再在新的选区或变换结果上重新应用原数值；调整数值保持不变，背景和选区外像素不得被调整。

## 粘贴与画布外内容

- 内部复制保留原选区坐标；原选区中心在当前视口内的轴保持原坐标，不在视口内的轴单独居中到当前视口。外部图片居中到当前可见画布区域，连续粘贴不增加级联偏移。小于画布的内容允许部分越界，但至少保留一个像素在画布内；任一尺寸不小于画布时从画布原点侧约束。
- 粘贴后默认进入可移动状态，内容完整保留，不按当前画布边界提前裁剪。
- 图层数据允许存在负偏移或超出画布的区域，移动回来后像素仍存在。
- 显式执行“裁掉画布外内容”时才允许永久删除边界外像素。
