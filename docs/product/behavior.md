# 产品行为契约

中文 | [English](behavior.en.md)

本文件定义 MoonSprite 当前开发版的稳定用户行为。细节交互由 `docs/interactions/` 补充，代码实现不得在没有更新契约和测试的情况下改变这些规则。

## 项目与文件

- 用户可同时打开多个项目，并在顶部项目栏切换或复制视图。
- 顶部“窗口”菜单集中管理视图辅助、栏目显示和工具栏位置；栏目布局修改实时保存到当前工作区。
- “帮助 > 未来计划”以中英文列表展示已经确定的长期方向和完成状态；抖动笔刷、主题修改、切片工具、动画循环节与关联图层标记完成，铅笔平滑不再列入计划，已完成项目自动排在最上方。
- “帮助 > 更新日志”和首页“新闻”只展示最近一次正式打包版本的内容，不得混入根 `CHANGELOG.md` 的“未发布”内容。首页新闻显示该版本的版本号、发布日期和简短摘要，点击后打开与“帮助 > 更新日志”相同的完整更新内容；两处内容统一来源于对应的 `docs/changelog/<版本>.md` 归档。
- `.moonsprite` 保存完整项目状态，并可通过文件选择、Windows 文件关联或从资源管理器拖入打开；拖入统一经过平台服务，HTML、Tauri Webview、Window 与 Rust 窗口事件互为兜底，单个通道失效时在窗口重新获得焦点后重试。所有通道共用格式过滤和路径去重，拖入成功后必须直接进入对应编辑器，不得仍停留在首页。
- MoonSprite 程序根目录下默认创建 `gallery` 与 `exports` 文件夹：新项目首次保存或另存为默认打开 `gallery`，图片、GIF、缩时视频和调色板图片默认打开 `exports`。另存为弹窗提供文件名称、保存格式和保存位置，位置按钮选择的目录作为系统保存窗口的默认路径。导出设置以“导出区域”区分画布、帧和切片；选择切片后可继续导出全部切片或指定的单个切片。首选项可分别覆盖默认保存位置和默认导出位置；清除覆盖后重新跟随根目录默认文件夹，已有文件的普通保存始终写回原路径。
- `.ase` 与 `.aseprite` 可通过文件选择、拖放和文件关联打开；保存或导出必须遵循用户明确选择的格式。
- PNG、JPEG、WebP、BMP 与 GIF 可通过文件选择或拖放作为单层像素文档打开；动画 GIF 按原顺序将每个图像帧导入为对应的时间轴帧与 cel，并尽可能保留帧时长、透明合成和循环设置。图片导入后保留来源路径；只在原始单图层、单帧内继续绘制时，普通保存直接按原格式原路径覆盖来源图片。新增图层、图层组、帧、蒙版、文本、图层样式、切片、项目画笔或缩时记录等图片无法保存的工程结构后，普通保存必须改为 `.moonsprite` 工程；“另存为”仍遵循用户明确选择的格式和路径。
- 从文件关联启动时应直接进入目标工程，不应只停留在首页。
- 打开或保存的 `.moonsprite`、`.ase`、`.aseprite`、PNG、JPEG、WebP、BMP 与 GIF 进入最近列表；首页和“文件 > 最近打开文件”始终显示真实文件名及后缀。最近记录的原路径不存在时提示用户并自动移除该记录；路径存在但无法解析的文件继续保留原文件和最近记录，并显示“从最近移除”供用户明确处理。画廊中的“删除工程”是独立危险操作，必须二次确认后才删除磁盘文件。
- 首页先显示完整文件列表，再以最多 3 个任务并发渐进读取缩略图；单项读取失败不得阻塞其他项目。`.moonsprite`、`.ase`、`.aseprite`、PNG、JPEG、WebP、BMP 与 GIF 都必须显示缩略图；普通图片直接生成最大边长 512 像素的平滑预览，工程缺少内嵌预览图时在后台串行生成相同上限的缩略图，成功结果按文件指纹写入磁盘缓存并在当前会话复用，不得同时解码多张大图拖慢首页。恢复记录同样渐进生成封面，但不得因此把完整预览重新写入自动保存文件。首页封面统一使用平滑缩放；右键任一普通项目卡片直接打开对应文件所在文件夹。首页按 `Ctrl+滚轮` 在小、中、大三档项目布局间切换并持久化：小号使用只保留标题和路径的紧凑单行列表，中号保持标准缩略图列表，大号使用每行四项的放大封面卡片并显示标题、文件信息、路径和时间。首页栏目管理允许选择任意文件夹作为同级自定义栏目，只读取该文件夹第一层中软件支持的工程与图片；最近、画廊、恢复和全部自定义栏目可统一拖动排序并持久化，自定义栏目可从首页移除但不得删除磁盘内容。首页右上角提供 QQ 群、Steam、GitHub 和语言四个像素按钮；前三项使用系统浏览器打开对应页面，语言按钮打开正式选择弹窗，确认后持久化简体中文或 English。
- 打开新建工程弹窗时，如果系统剪贴板包含图片，应立即读取图片头部宽高并填入尺寸；此步骤不得解码或跨进程传输整张像素数据。新建成功后焦点必须进入新项目对应画布，不得落到调色板或其他栏目控件，并默认隐藏瓦片集栏目。
- 程序根目录下的 `brushes` 文件夹保存全局图片笔刷；笔刷库默认作为右侧栏目显示，可通过添加按钮、文件拖放或 `Ctrl+B` 从选区写入 PNG 笔刷。导入和选区笔刷保留 RGBA 与原始尺寸，宽高上限均为 `256px`，手动排序独立保存且不进入项目 dirty 或撤销历史。系统纹理只提供给油漆桶，铅笔、橡皮擦和直线只使用基础形状或图片笔刷。
- 异常关闭工程进入恢复栏目；从恢复栏目打开草稿只创建对应编辑会话，不删除原恢复记录，之后再次异常退出仍可从同一记录恢复。关闭该会话或在未保存提示中选择放弃也不得移除原恢复记录；只有用户在恢复栏目明确删除，或对应项目完整保存成功后才允许删除。用户明确删除后不得反复提示或自动恢复。恢复数据默认保留 7 天，用户可在“首选项 > 文件”设置 `1-365` 天；软件启动时即使上次正常关闭，也必须成对清理超过保留期的恢复描述与工程数据文件。
- 像素网格和自定义网格的开关以及自定义网格参数属于当前项目显示设置；保存并重新打开项目后恢复原状态，不复用其他项目的网格状态。缩放、平移、旋转、镜像和“图像 > 绘制视角”的当前选择仍只属于当前会话，默认使用默认视角。“首选项 > 工具 > 对齐”提供全局网格对齐、智能对齐、对齐辅助线显示和 `1-32 CSS px` 对齐阈值，三个开关默认关闭且阈值默认为 `6 px`；“窗口 > 对齐”同步提供三个布尔开关。高倍缩放时检测范围最低覆盖相邻 `1` 个文档像素。网格对齐只在自定义网格可见时生效，将移动图层、选框和选区内容的外边缘吸附到当前网格线；智能对齐使用画布边缘与中心、其他可见图层的内容边缘与中心作为目标，命中时按偏好显示裁切在画布内的蓝色辅助线。隐藏辅助线不关闭吸附；辅助线、偏好切换和阈值不进入工程 dirty 或文档撤销。Tilemap 选区继续优先按瓦片宽高整格移动。选择 ISO视角后自动显示两组斜向参考线；阶数控制每移动 `1` 个纵向像素时连续绘制的横向像素数，参考线样式可选择连续实线或逐格显示的像素线条，参考线位置、单位尺寸、样式、颜色、粗细和“强制线条对齐”保存为全局编辑偏好。强制对齐开启时，直线工具以及铅笔、橡皮擦的单次拖动画线和直线连接只能生成水平、垂直或当前 `N:1` 阶数的平衡阶梯线，曲线工具保持原行为。
- 新建画布弹窗提供“记录绘画过程”开关，其默认状态由首选项控制且初始默认关闭。“文件 > 缩时视频”按项目控制录制方式、画质、导出帧率和播放倍率；开启后每个已提交的绘画或内容编辑操作参与录制，不按现实时间计时，也不记录缩放、平移和栏目操作。录制方式可选“全程录制”或“智能裁剪”：全程录制保留每个操作帧；智能裁剪先逐帧记录，已保留帧数达到约 120 帧后把采样间隔翻倍，并将已有记录按二分之一频率重新抽样，之后每次再次达到约 120 帧都重复该过程，正常情况下让记录量维持在约 60–120 帧，适合特别长的绘制过程。已保留的快照不因切换录制方式而静默删除，智能裁剪只会在后续录制达到档位边界时压缩已有记录；全程录制不设固定快照数量上限，智能裁剪以分级采样控制记录量，并随 `.moonsprite` 保存；可清空并按固定导出帧率均匀采样导出 MP4、WebM，或按记录顺序导出 PNG/JPG 图片序列。
- “文件 > 项目信息”显示画布、颜色模式、图层/组/帧数量、笔画数、编辑操作数、有效绘画时长、创建与修改时间以及缩时记录帧数。
- 程序根目录下的 `scripts` 文件夹保存全局 Lua 脚本；“文件”菜单最底部的“脚本”子菜单按名称列出该文件夹第一层的普通 UTF-8 `.lua` 文件，并在打开“文件”菜单时刷新，底部提供“打开脚本文件夹”。菜单只向平台层传递脚本文件名，平台层必须拒绝目录穿越、子目录、符号链接和非 Lua 文件，不再通过系统文件选择器运行任意路径。脚本兼容层提供 `Point`、`Rectangle`、支持 RGB/HSV 字段的 `Color`、`Image`、当前选区、活动 `Sprite/Layer/Cel`、`app.pixelColor`、`app.transaction`、`app.refresh`、`app.useTool` 的直线与橡皮擦、`print`、`app.alert` 和通用 `Dialog` 控件；`Dialog` 支持颜色、单选等常见控件，`show()` 可以阻塞等待关闭，`show { wait = false }` 可以打开非阻塞脚本弹窗，控件事件继续在原 Lua VM 中执行。`Sprite(width, height)` 可创建新文档，活动 Sprite 的 `newLayer()` / `newCel()` 可创建普通像素图层；这些结构变化必须以类型化的新图层或新文档结果交给 Store，不能回写整份工程。初始像素目标限定为当前帧的当前普通像素图层；文本、Tilemap、自由瓦片、图层蒙版、锁定目标以及超过 `4,194,304` 个局部像素的图层会明确拒绝执行。Lua 不开放文件、网络、进程、包加载和调试库，并受内存、单图像、会话累计图像分配、修改量、指令数、运行时间、源码大小和输出大小限制。每个成功的 `app.transaction` 独立形成一个撤销步骤，事务外写入按脚本文件名合并；局部绘制提交像素差量，`app.activeCel.image` 和 `position` 变化作为同一 Cel 表面历史原子提交，脚本创建的活动文档图层也通过可撤销 Store 历史加入。未捕获错误不应用本次调用的任何结果，被 `pcall` 捕获的失败事务只回滚该事务且保留之前成功的事务。持久脚本弹窗每次回调前必须确认仍是原文档、原图层和原帧，再以当前 Cel 表面、revision、选区与前后景色重建 Lua 基线，因此同一目标上的撤销、重做或其他已提交编辑不会让弹窗失效；回调结果仍须严格匹配这份新基线，文档、图层或帧切换则拒绝应用并销毁会话。脚本有 `print`/`app.alert` 输出或执行失败时显示结果弹窗，无输出成功时只在底部状态栏反馈。
- 程序根目录下的 `extensions` 文件夹保存已安装的 `.msext` 扩展包。扩展包是 ZIP 容器，根目录必须包含 `manifest.json`；`schemaVersion: 1` 保留给受限 Lua/MSE 命令和宿主渲染的声明式栏目，`schemaVersion: 2` 可声明 `apiVersion: "1.0.0"` 的 Extension Runtime v1、常驻 sandbox HTML/JavaScript、权限、资源、自有设置、菜单和 owner-bound 附属窗口。安装前限制包大小、文件数、贡献数量和解压总量，并拒绝目录穿越、绝对路径、重复路径、符号链接、无效资源引用、重复贡献 ID、未知权限及无效清单。首选项“扩展”页面只负责安装、打开文件夹、启用/禁用和卸载；扩展自己的业务设置由宿主组件清单或 sandbox HTML 回退承载。启用状态和扩展存储均按扩展 ID 隔离，不进入工程 dirty 或撤销历史。资源管理器双击 `.msext`、从启动参数传入或拖入 MoonSprite 时都走同一套原子 staging 安装流程，替换版本失败会保留原安装。MoonSprite 不显示固定的顶层“扩展”菜单；只有已启用扩展的菜单、Runtime 和窗口存在，停用、卸载、替换或安全校验失败时必须同步销毁。Lua 命令使用 `entry`，Runtime 命令使用 `runtimeEvent`，设置命令使用 `opensSettings`，三者每项只能选择一种。Runtime 只能通过清单授权的版本化 `window.moonsprite` 桥访问 commands、menus、ui、windows、workspace、document、events、storage、resources、tools、io、clipboard、notifications、network 和 diagnostics 等能力，不能访问 React、Zustand Store、Tauri、安装目录或内部文档对象；Renderer 只获得扩展、命令、权限和资源的不透明 ID。复杂文档写入继续由受限 Lua 命令经过脚本快照和 Store 事务提交。Runtime v1 扩展要求宿主支持对应 API，独立扩展不代表可以在缺少该 API 的旧版 MoonSprite 中运行。
- Runtime 清单中的权限名不等于已经存在同名调用；扩展必须以 `runtime.getCapabilities()` 返回的方法为准。`menus` 与 `io` 在 Runtime v1 中仅为保留权限名，当前没有可调用方法；`notifications.show` 当前映射为 MoonSprite 应用内消息，不发送系统通知。
- 扩展界面默认使用宿主组件贡献：菜单、栏目和 `settingsUi` 均由 MoonSprite 组件库渲染并跟随当前主题；`settingsUi` 支持复选、数值、文本、选择和命令按钮，字段值写入扩展隔离存储并通知 Runtime。只有宿主组件清单无法表达的自定义画布、媒体和复杂交互才使用 sandbox HTML；扩展不能直接导入 React 或获得宿主组件实例。
- 在上述兼容层之外，脚本运行时还提供 `mse.*` MoonSprite 专属命名空间。`mse.apiVersion`、`mse.status`、`mse.capabilities` 和 `mse.isSupported()` 用于能力探测；当前 `0.2.0` 能力表中的文档、图层、动画循环节、调色板、瓦片、自由瓦片、图案笔刷、选区、切片、图层样式、工作区栏目、文件操作和通用 UI 方法均为真实实现，不保留只报错的规划占位端点。查询读取脚本启动时的结构快照；写入必须经过当前 `app.transaction()`、Store 领域命令或文档事务，并同步遵守撤销、dirty、失效和失败回滚规则。
- “文件 > 导出”提供“导出为”“导出所有帧”和“导出精灵表”。“导出为”打开现有导出设置；PSD 是可通过“另存为”或“导出为”写出的 Photoshop 工程格式，当前不作为打开或导入格式，只写出当前帧和完整画布，保留图层/图层组层级、名称、可见性、不透明度、受支持的混合模式、剪贴关系、锁、当前帧蒙版及可映射的图层样式，文本和 Tilemap 以栅格图层写入，不伪造 Photoshop 动画时间轴；“导出所有帧”复用现有格式、缩放和导出目录设置，将时间轴各帧按顺序合成为独立图像并以连续序号命名，PSD 与 GIF 不作为逐帧批量格式；“导出精灵表”先打开包含“布局、精灵图、输出”的设置弹窗，三个选项一次只显示当前设置区。布局支持水平条幅、垂直条幅、默认按行和按列；按行可选择无、固定列数或固定宽度，按列可选择无、固定行数或固定高度，无限制时按行把全部帧排成 1 行、按列把全部帧排成 1 列，固定像素尺寸小于单帧或导出区域时自动按其最小宽度或高度生成。开启“合并重复项”后像素完全相同的帧共享同一个精灵表矩形区域，开启“忽略空缺项”后全透明帧完全不占用矩形。精灵图可选择完整画布或具名切片、可见/所有/已选图层和全部/已选/指定循环节帧；拆分图层或循环节时，各目标仍按当前布局独立生成，但按图层与循环节顺序纵向追加在同一张精灵表下方，不创建额外文档或文件，完全透明的拆分目标在忽略空缺项时直接省略。开启预览时自动生成并打开随设置刷新的临时精灵表；刷新设置只替换预览内容，保留当前缩放、平移和视图方向；关闭预览或设置弹窗时自动关闭临时结果且不影响源项目。关闭“输出文件”时，正式结果打开为一个未保存的 RGBA 单图层文档；开启后展开完整 PNG 文件名输入、文件夹选择按钮和下方的导出位置提示，将同一结果原子写为一个 PNG。所有导出不再按系统当前可用内存或像素缓冲预估提前拒绝；桌面端 PNG 导出只在 Renderer 生成未缩放的合成像素，平台层按目标尺寸逐行最近邻缩放并流式压缩到原子临时文件，不创建完整缩放画布或完整编码缓冲；其他格式直接尝试合成、编码与写出，只在实际分配、编码或写入失败时反馈错误。

## 编辑与历史

- “历史记录”栏目按时间顺序显示历史起点和当前文档可到达的每次操作，当前节点高亮；已撤销的未来记录弱化显示但仍可点击，并通过现有撤销、重做流程顺序跳转到对应状态。
- 从较早节点继续编辑时清除其后的未来分支。缩放、平移、旋转、镜像、栏目布局和其他视图状态不出现在历史记录中，也不得因点击历史节点而改变。
- 可编辑文本支持选择字符后单独设置字号、行间距、字间距和颜色；选择范围内存在混合值时对应控件显示为空，输入新值后统一覆盖该范围。字体间距使用字体字面框与默认行高，实际间距按最终可见像素边界计算，`0px` 时相邻字符或行的可见像素直接相接。

### 瓦片工作流

- “窗口 > 平铺预览”提供关闭、包围平铺、X 轴平铺和 Y 轴平铺。包围平铺固定显示 3 x 3 画布，X 轴平铺固定显示 3 x 1，Y 轴平铺固定显示 1 x 3；开启后自动缩放到完整显示全部副本。该模式把重复副本上的编辑指针映射回原画布对应坐标；框选内容或图层移动越过原画布边界时，越界部分必须在已启用方向的相邻副本中连续显示。平铺预览只属于当前视图，不改变工程 dirty，不进入撤销历史，也不写入 `.moonsprite`。
- 新建 Tilemap 图层弹窗允许填写图层名称和瓦片宽高，并可调整弹窗尺寸；“瓦片集”默认选择“新增瓦片集”，也可选择当前工程已有的 Tilemap Tileset。选择已有 Tileset 后自动采用其瓦片宽高，创建的每个动画帧使用相同网格规格并保持空白，同时复用该 Tileset；未选择已有项时才新建包含透明首瓦片的项目 Tileset。创建后自动打开瓦片集栏目，并默认进入“混合编辑”模式。多个 Tilemap 图层可以共享同一个 Tileset，编辑瓦片时所有引用同步更新；共享时 Tileset 名称不再跟随任一单独图层改名，只有唯一引用图层才同步名称。Tileset 下拉名称使用 Tileset 名称；选择下拉项时同步选择其代表图层，删除图层时仅在没有其他引用时删除 Tileset，撤销删除时一并恢复。瓦片集栏目由 Tilemap 与自由瓦片共用；只有当前工程两类图层都不存在时才自动隐藏，切换工程、删除、撤销和重做都按活动工程重新同步显隐。
- 普通栅格图层和背景图层可通过“转换为瓦片图层”打开同一尺寸弹窗；确认后以画布原点为网格起点裁切全部动画帧，画布外内容丢弃，边缘不足一个单位的部分补透明，相同瓦片在当前图层的全部帧中复用。转换后保留原图层位置、层级和显示属性，移除背景身份，自动选择新 Tileset、打开瓦片集栏目并进入“混合编辑”；整个转换及名称修改只产生一个可撤销步骤。文本图层和启用图层样式的图层必须先转换为普通图层。
- Tilemap 有“原位编辑、变体创建、混合编辑、绘制瓦片”四种会话编辑模式；前三种按此顺序使用栏目内右对齐的图标分段控件，绘制模式使用删除按钮旁的专用绘制图标切换，属性栏始终显示当前工具自身的属性。“变体创建”保留原有新增逻辑：所有普通像素工具和原有修饰键都可修改格子，最终结果会精确复用或创建瓦片并只替换当前格引用，原瓦片及其余引用保持不变。“混合编辑”在已有格内绘制时直接修改其原瓦片并同步刷新所有引用，进入空格并产生新内容时才精确复用或创建结果瓦片。“原位编辑”允许从画布外或有效瓦片外按下后拖入已有瓦片，并按住连续跨越多个已有格子绘制，每个格子的修改都写回对应瓦片并同步刷新全部引用；按住 Shift 的直线预览也必须同时显示在所有引用位置。若 Tileset 仍只有初始透明瓦片，首次在原位编辑中按住绘制时临时开放整个 Tilemap 网格，允许一次手势连续跨越多个单元格；松开后保留初始透明瓦片，并按每个实际改动单元格的结果创建或复用瓦片。框选并移动单个瓦片内容时仍以该瓦片为编辑目标，移出单位边界的像素直接丢弃。“绘制瓦片”以完整格子铺设当前瓦片，选区工具把所有触及区域扩展为完整瓦片格；移动选区内容时按瓦片宽高整格吸附并实时迁移格子引用，不修改 Tileset 像素，也不创建新瓦片。悬浮与绘制中预览遵循铅笔的笔刷预览设置，并以替换而非叠加方式显示完整瓦片；透明像素和橡皮擦都直接清除旧格内容，快速拖动补齐经过且位于选区内的格子。瓦片集左键设置前景瓦片、右键设置背景瓦片，点击任一实际瓦片后立即切换到“绘制瓦片”模式，画布左右键分别使用前景和背景瓦片；绘制瓦片时吸管默认吸取所在格的瓦片引用，颜色栏目底部同步显示前景和背景瓦片。一次按下到松开只产生一个同时覆盖 Tileset 或格子引用与选区位置的撤销步骤，瓦片集栏目不提供独立像素编辑区。
- 框选内容移动在“变体创建”中始终按移动后的每格结果复用或创建对应瓦片，不回写原瓦片；在“混合编辑”中，完整矩形瓦片选区按整格单位平移时只迁移格引用，不新增或修改瓦片，其余非整格、局部、带蒙版或变换后的移动均按结果生成变体，原瓦片及其他引用保持不变。
- 瓦片在瓦片集内使用与调色板一致的方格间距、默认描边、悬浮和选中反馈，每个方格完整显示一个瓦片单位，栏目当前可见范围内的空槽也可作为放置目标。左键选择产生独立于前景/背景瓦片的临时选中框，`Ctrl` 点击增减选择，`Shift` 点击连续选择，焦点离开瓦片集后清除；`Delete` 或 `Backspace` 一次删除当前临时选中的全部瓦片，没有临时多选时删除当前前景瓦片，整批删除只产生一个撤销步骤；Tileset 始终至少保留一个瓦片，全选删除时保留首个瓦片。`Ctrl+滚轮` 使用与调色板相同的五档尺寸调整并记住结果。只有指针命中临时选中框边缘时才可拖动，单个或多个选中瓦片均可保持二维相对槽位关系移动到任意空槽或已有瓦片位置；落到空槽时原位置留空，落到已有瓦片时被占用瓦片回填空出的槽位。槽位布局独立于紧凑 RGBA 图集，不改变稳定瓦片 ID、画布引用、瓦片编号或最终显示，并作为一个可撤销工程操作保存。按住 `Ctrl` 时，瓦片集与画布中的非空瓦片同步显示按当前 Tileset 稳定顺序从 `0` 开始的编号，画布标记使用 `#0000FF` 纯色底和白色数字；松开后全部隐藏，编号提示只属于视图状态。
- 使用移动工具移动整个 Tilemap 图层时只修改所选动画 cel 的偏移坐标；Tileset、瓦片像素、格子引用与网格规格始终保持不变，瓦片网格随图层偏移继续存在。该移动在四种 Tilemap 编辑模式下行为一致，并与普通图层移动一样形成一个只记录坐标变化的撤销步骤。框选内容的移动仍按对应编辑模式的格子或瓦片规则处理。
- 调整画布大小时，所有 Tilemap 动画 cel 都按原网格相位补齐完整空白格，使新增画布区域立即可绘制；保留画布外内容时不丢弃原格子，启用裁切时只按完整瓦片格裁切，不生成非整格栅格缓存。该结构变化随画布尺寸操作一并撤销、重做和保存。
- Tileset 与 Tilemap 格子属于工程内容。复制图层、复制动画 cel、跨项目粘贴和 Alt 拖动复制必须保留 Tilemap 源数据；跨项目粘贴会复制所需 Tileset、建立新的图层所有权并重映射稳定引用。删除或撤销粘贴时同时移除本次新增且仅由该批粘贴带入的 Tileset。常规合成、缩略图和图片导出继续读取 Tilemap 的栅格缓存，因此导出结果与画布显示一致。
- 新建自由瓦片图层只填写名称，不预设瓦片尺寸；“瓦片集”默认选择新增集合，也可以选择工程内已有自由瓦片集。选择已有集合时只新建独立图层、动画 cel 和实例列表，不复制源瓦片或 Tileset；创建后在共用的瓦片集栏目中显示该图层所引用的源瓦片页面。新增集合会自动建立一个透明源瓦片并进入“编辑源瓦片”；首次在画布绘制时自动放置该源的实例，源尺寸按本次实际非透明内容裁切生成。需要绘制另一种可复用内容时点击“新增源瓦片”，再在画布中编辑新的透明源。栏目下拉按自由瓦片图层切换，选择下拉项同步选择所属图层；切换活动图层时，同一个栏目在普通 Tilemap 页与自由瓦片源页之间切换，不存在独立“自由瓦片组”栏目。
- 每个自由瓦片图层引用一个自由瓦片集，同一集合可以被多个图层使用；集合内每个源使用独立单瓦片 Tileset 保存像素，并具有名称、显示颜色、可见性与锁定。源增删、源属性和源像素修改会同步到该集合的全部图层及其全部实例，但各图层的实例列表、动画、位置和普通图层属性保持独立。源数据仍保留描述、整数像素偏移、不透明度和混合模式字段以兼容旧工程和内部定位，但源属性弹窗只显示名称、颜色、显隐和锁定，也不显示图标与尺寸摘要栏。新建自由瓦片集或新增源瓦片时自动分配一个图层颜色预设；双击或右键源瓦片可打开属性。源属性和实例属性均随输入实时预览，关闭按钮、遮罩、`Esc` 或 `Enter` 会把最终值作为一个文档历史步骤提交，弹窗不显示取消和保存按钮。“显示瓦片实例”和“锁定瓦片实例”分别控制该源全部实例的可见性与编辑锁定，并提供悬浮说明。实例不再显示在瓦片集栏目下；实例图层默认使用独立栏目，也可从实例图层标题栏设置切换为原有的图层栏目内子视图，两种视图都保留该设置入口。独立模式下，当前自由瓦片图层的活动帧存在实例时自动打开栏目，并始终紧邻图层栏目：图层在底部时位于右侧，图层在左右侧时位于下方；活动目标没有实例时自动隐藏。点击自由瓦片图层右侧图标会选择该图层并打开对应实例列表，活动帧没有实例时保持普通图层视图并给出提示。实例列表不显示独立时间轴，只列出外层自由瓦片图层当前活动帧中的实例；帧切换、cel 关联和动画由外层自由瓦片图层统一控制。每次“放置实例”新增一行，行顺序对应实例的前后合成顺序，并提供与普通图层一致的选中、显隐、锁定、属性、拖拽排序、右键和删除操作，实例行复用源瓦片的图层颜色标识。普通点击选择单行，`Ctrl` 点击增减选择，`Shift` 点击按当前显示顺序连续选择；每次有效点击都会重新触发该实例在画布中的提示闪烁，即使该行已经是唯一选中项。在多选中的任一实例打开属性时，只把本次实际修改的字段应用到全部所选实例，并合并为一个撤销步骤；`Delete`、`Backspace` 和右键删除会一次移除全部所选实例并只产生一个撤销步骤，选择中包含锁定实例时整批不执行。实例行的眼睛与锁直接复用普通图层手势：按住拖过多行连续应用同一状态，移出范围恢复原值，`Alt` 点击批量作用于活动帧全部实例，并各自只形成一个撤销步骤。实例属性直接按“混合模式、不透明度、旋转、镜像、X、Y”排列，不保留额外的实例标题信息栏；右键可顺时针旋转 `90°` 或切换水平、垂直镜像，这些变换只属于当前实例，不修改共享源，源后续变化仍按该实例变换同步显示。实例右键“仅显示”会显示当前实例并隐藏当前帧的其余实例，整次显隐变化作为一个历史步骤。单击实例选择该实例并自动切换为“编辑源瓦片”，双击同样进入源编辑并收敛为单选；只有选择实例进入实例编辑后，移动工具才单独选择并移动未锁定实例，未选择实例时移动工具仍选择和移动整个自由瓦片图层。源编辑存在实例选择时始终以该实例作为坐标锚点，重叠区域不会改用上层实例，但源像素仍同步刷新全部同源实例。隐藏实例不参与合成或画布命中，锁定实例仍可切换显隐但不能移动、排序、变换或删除。源属性与源像素会作用于该集合内该源的全部实例，但实例位置、朝向和层级彼此独立；自由瓦片图层本身仍独立保留普通图层的位置、可见性、锁定、不透明度、混合模式、分组和动画属性。
- 自由瓦片的“放置”模式使用当前前景或背景源瓦片，以指针所在像素为中心任意放置实例，不吸附 Tilemap 网格，并允许实例互相重叠；实例数组顺序就是从后到前的合成顺序。切换到放置模式时自动清除实例选择，框选工具和 `Ctrl+T` 均不执行；切回“源编辑”时自动选择当前帧中一个可见、未锁定且源可编辑的实例。橡皮擦删除指针下最上层实例，吸管选择指针下最上层实例引用的源瓦片，快速拖动按像素路径补齐放置或擦除。完整源瓦片预览遵循笔刷预览设置，透明源瓦片仍显示可见边框。一次按下到松开只产生一个实例历史条目，取消操作恢复按下前全部实例。
- 自由瓦片的“源编辑”模式在画布中的任一实例上直接使用铅笔或橡皮擦编辑其源瓦片，也允许从尚未放置的新源开始绘制；`Shift` 直线与普通图层使用相同的上次落笔逻辑。已有选区只限制实际写入像素，落笔允许从选区外开始并进入选区。预览期间同一集合内所有图层、全部帧中引用该源的实例实时刷新。选中一个实例后，矩形、椭圆、套索和多边形套索可在画布任意区域建立选区，魔棒从当前实例内容取样；`Ctrl+T` 只以当前实例的可见边界建立变换选区。部分选区的移动、缩放、旋转、倾斜、删除、剪切和复制以该实例作为文档坐标锚点，并按当前实例的旋转与镜像朝向显示和操作临时栅格，确认时再反向映射回共享源；删除或剪切必须写回源像素，不能只临时清除当前实例缓存。若选区完整覆盖当前实例，拖动内容只改变该实例位置并同步移动选区与轴心，不修改共享源，也不移动其他同源实例。移动框选内容的预览必须随每次指针更新立即刷新，不得额外落后一帧；共享源变化时全部同源实例实时更新，但蚂蚁线、轴心和变换控制点只显示在当前实例。一次完成的实例位置或源像素变换与选区位置共同形成一个撤销步骤。源被擦除为全透明时仍保留当前实例作为可编辑锚点，下一次绘制可从该实例继续扩展源，不得因透明裁切为 `1 x 1` 而失去编辑入口。首次源编辑与首次实例放置合并为一个历史步骤，后续确认只产生一个源瓦片历史条目，取消则恢复源图和本次临时放置。源瓦片像素、属性、实例位置、朝向和引用属于工程内容并随复制、粘贴、动画与 `.moonsprite` 保存；派生 surface 只供合成、缩略图和导出使用。调整画布大小时实例保持任意像素坐标并让新增区域可继续放置，裁切只移除完全位于新画布外的实例；调整图像大小时全部源尺寸、源偏移、实例坐标和缓存按同一比例同步缩放。
- 从普通栅格图层复制的画布选区可以粘贴到自由瓦片图层的画布中；未选择实例时，粘贴按原画布坐标裁掉透明边缘，为每个不超过 `256 x 256` 的内容块新建独立源瓦片并放置实例。已选择实例时，粘贴直接覆盖该实例共享的源瓦片像素，不新建源、Tileset 或实例，并同步刷新全部同源实例。两种路径都只形成一个可撤销步骤。普通图层的动画帧或 cel 不转换为自由瓦片，也不能直接粘贴到实例图层的帧格或单元格中。实例图层中的选择独占 `Delete` / `Backspace`，一次删除全部所选实例；删除后自动选择显示顺序中的相邻实例，删除最后一个实例后清空实例选择并自动切换为“放置实例”，仍停留在实例子视图，后续删除命令不得误删所属自由瓦片图层。

### 动画时间轴

- 动画采用 Aseprite 式图层/cel 模型：图层栏中的每个普通图层是一条跨帧轨道，图层右侧的每个帧格是该图层在对应帧的 cel；图层名称、可见性、锁定、透明度、混合模式、分组和顺序跨帧共享，像素、位图尺寸与偏移属于 cel。
- 播放控制、帧增删复制、帧时长、循环设置和帧列全部集成在图层栏目内，不提供重复的独立时间轴栏目。第一帧紧邻图层名称区域左侧，名称区与帧列之间的分隔线允许拖动并持久化宽度；帧从左到右排列并与图层行严格对齐，选中帧以覆盖帧头和全部 cel 行的整列蓝色外描边反馈，边框四边必须连续。当前图层与当前帧交叉格只保留深色活动背景，不显示额外内部蓝框；帧数超出栏目宽度时在同一区域横向滚动。
- 图层设置提供“隐藏时间轴”。开启后保留工程中的全部帧与 cel 数据，但图层栏目只显示普通图层列表，时间轴网格和图层栏动画按钮不再显示；帧切换、播放、洋葱皮、帧增删及对应快捷键和预览播放同时停用并显示禁用状态。关闭后恢复原时间轴及其数据。
- 图层栏目中的“新增帧”默认复制当前帧并创建互不影响的独立 cel；右键帧头可打开帧属性、复制当前帧、新建默认 `100 ms` 的空白帧或删除帧。在循环节范围内创建空白帧、复制帧或关联帧时，新帧继续属于对应循环节；从循环节末帧创建时自动扩展该循环节的右边界，并与帧创建作为同一个撤销步骤。每一帧独立保存毫秒时长并直接显示在帧头，不在栏目工具栏提供全局时长输入。动画至少保留一帧。
- 多选一个或多个帧后，可从帧头右键菜单创建命名循环节。循环节以独立括号轨道显示在图层栏目标题栏内、播放控制所在区域的下沿，括号横跨起止帧并在线条上显示名称，不占用或嵌入帧头区域；括号左右两侧线端是可拖拽的范围边界，指针移到任一侧时显示左右调整指针，拖动后实时预览新的起止帧，松开只产生一次循环节修改历史；起止帧不能交叉且至少保留一帧。互相包含的循环节按父子关系嵌套，子循环节显示在父循环节括号内部，只有部分交叠但不包含的范围才分配到外部轨道。单击括号选中对应连续帧，双击打开属性，右键可独立播放、编辑或删除。属性可设置名称、起始帧、结束帧、正向或反向播放，以及有限重复次数或无限重复。循环节独立播放仍使用各帧保存的持续时间和公共播放倍率；正向从起点到终点，反向从终点到起点，有限循环在最后一次的终止帧完整显示后停止。循环节定义随工程保存并可撤销，播放目标与当前重复进度只属于会话状态。
- 帧头和 cel 使用一致的外描边多选反馈，并均使用与图层相同的指针拖拽语义完成排序或跨位置移动：移动超过阈值后全部源对象半透明，帧显示插入位置，cel 显示目标格，松手后只产生一次撤销。帧头存在选择时，`Delete` 或 `Backspace` 删除全部所选帧；批量删除只产生一次可撤销操作，并始终至少保留一帧。双击帧头打开该帧时长属性，双击有内容 cel 打开单元格不透明度属性；无内容 cel 的属性、复制和删除命令禁用，但已有 cel 剪贴板时仍可粘贴。单元格不透明度复用图层属性的滑块、数值输入和百分比布局，属性弹窗使用 `Enter` 提交并关闭、`Esc` 放弃并关闭。播放期间隐藏帧与 cel 的选择描边，但保留选择状态。
- 复制帧时复制所选帧的时长及全部图层 cel，粘贴到最末选中帧之后；副本像素必须独立。复制 cel 只处理所选单元格。帧与 cel 的右键菜单必须在复制、粘贴和删除命令中明确写出操作对象。
- 图层栏和预览栏共用同一套播放状态与右键设置菜单，可设置 `0.25x`、`0.5x`、`1x`、`1.5x`、`2x` 或 `3x` 播放速度、单次或循环播放，以及停止时是否返回开始播放的帧；左键继续执行播放或暂停。默认按 `Enter` 播放或暂停，但只有在焦点不属于输入控件、没有正式弹窗或菜单、没有选区或文本变换、且当前画布操作未占用 `Enter` 时才触发。没有选区时，无修饰键的左右方向键切换上一帧或下一帧；逗号和句号键无论是否存在选区都切换上一帧或下一帧，切帧后保留画布选区，到达首尾后循环到另一端。播放期间第一次按下上述任一切帧键只停止在当前帧，不受“停止时返回开始帧”影响，并清除旧的帧或单元格多选，只保留当前帧单选；暂停后再次按下才切换帧。播放计时器只在编辑器公共层运行一个实例，两个栏目同时显示时不得重复推进帧。切帧、播放速度、开始帧和停止返回开关属于会话状态，不改变工程 dirty，不进入撤销历史。
- 鼠标位于图层栏目时，`Ctrl+滚轮`在紧凑、标准、详细、扩展、大型和巨型六档显示密度间切换并持久化：紧凑档保留按钮、图层名称和帧；标准档显示混合模式与不透明度；详细及更大三档显示缩略图并逐级放大图层行和帧格。cel 缩略图始终使用方形容器，整个容器以透明棋盘格填充；可见内容按自身边界等比放大到合适尺寸并居中，文档边界外像素仍被裁掉。`Alt+滚轮`横向滚动帧区。图层栏目停靠在左侧或右侧时必须为帧区保留可操作宽度，普通绘画不会在非详细档生成缩略图。
- 绘画、填充和普通图层像素操作只修改当前帧的当前图层 cel；直接选择图层组时填充工具及“填充前景色”命令均不可用，工具栏、工具快捷键和默认 `F` 快捷键都不得修改任何组内图层。选区内容变换可同时作用于所有已选普通像素图层或所选图层组的后代图层；存在帧多选时，目标扩展为已选图层与已选帧的全部组合。全部目标共享一个选框但分别保留各图层像素、顺序与层级，并作为一个操作统一撤销。多选中包含文本、Tilemap、自由瓦片、隐藏或锁定图层时整体阻止组合变换。图层的新建、复制和删除同步维护全部帧轨道。复制图层复制全部帧 cel，删除图层删除全部对应 cel。
- 文本工具单击画布后按原方式创建自适应尺寸文本；按住左键拖拽会先实时框出固定区域，松开后打开文本编辑弹窗，尚未输入文本时该区域仍持续显示。文字超过区域宽度时自动换行并裁切在区域高度内；实际间距模式让可见文字紧贴区域边缘。固定区域文本只要其图层被选择，就持续显示统一的区域轮廓和八个交互点；文本工具悬停在区域内部时显示移动指针，单击打开当前文本编辑，按住拖动移动区域和文字，拖动交互点则调整区域位置或大小并实时重新换行，不缩放字形，也不写入栅格变换。文本框轮廓和交互点颜色默认是 `#0000FF`，可在首选项的画布颜色中修改。固定区域文本不响应 `Ctrl+T`，自适应尺寸文本仍使用 `Ctrl+T` 进入与普通图层相同的缩放、旋转和倾斜变换。字体在左侧按行选择，“导入”使用组件库下拉并自动读取系统已安装字体，“选择”用于从本地选择字体文件并复制到 MoonSprite 的 `fonts` 目录。右侧可设置多行文本、字号、行间距、字间距及锯齿或平滑渲染；输入区保持紧凑，实时预览默认开启，关闭预览或取消时恢复原画面，确认只产生一次正式历史。确认后在点击位置创建独立文本图层，图层行显示文本标识；每个文本 cel 同时保存可编辑文本参数和用于合成的栅格缓存。双击文本图层或其 cel 可重新编辑，空白文本 cel 也可通过双击创建内容；选择文本图层时，文本、移动、吸色、抓手、缩放和旋转工具保持可用，框选、画笔、形状、直线、喷枪和填充等栅格编辑工具会禁用，必须先转换为普通图层。文本 cel 只能与文本图层互相复制、粘贴或移动，普通像素工具和普通像素粘贴不得直接破坏其可编辑源。之后重新编辑文本仍保留已完成的变换；右键“转换为普通图层”会保留当前栅格结果并删除可编辑文本数据。上述创建、编辑、变换和转换均可撤销，并随 `.moonsprite` 工程保存；工程只记录字体名称，跨电脑打开时需安装或导入同名字体才能保持一致。
- cel 右键菜单可新建或删除“图层蒙版”，图层或图层组行的右键菜单会为该对象所有已有内容的帧批量创建对应蒙版；图层组使用“图层组蒙版”名称，两者都按帧独立保存。新建蒙版是一张透明空白的独立灰度表面：透明像素表示未绘制且等效为白色，白色完全显示、黑色完全隐藏、灰色按比例降低所有者的最终透明度；绘制任意颜色时统一转换为不透明黑白灰，橡皮擦恢复透明未绘制状态。创建后在所有者正上方显示独立蒙版轨道，轨道使用普通图层行高，蒙版单元格与普通 cel 使用相同尺寸、间距和边框；详细及以上档位显示实际黑白灰缩略图。普通点击会选择蒙版单元格并将其设为当前绘制目标，主画布仍显示应用蒙版后的合成结果；编辑期间单元格高亮保持，但只有进入独立蒙版视图时持续显示变换边框。按住 `Alt` 悬停时使用项目打开指针，`Alt+左键`进入独立蒙版视图，`Shift+Alt+左键`加选并进入最后点击的蒙版。进入独立视图后主画布切换为白底灰度画面，只显示蒙版本身；吸色、绘制预览和粘贴都读取同一灰度视图。点击任意图层或图层组行、切换帧或普通选择 cel 会退出蒙版编辑。蒙版单元格可独立多选、复制、粘贴、链接、断开链接和拖动，目标始终限制在蒙版轨道，不得改写普通 cel 像素；断开链接时保留当前解析后的灰度内容。复制帧、复制图层或图层组时，其逐帧蒙版独立复制，不与原对象共享像素。
- 新增、复制、删除帧、修改帧时长以及创建、编辑或删除循环节属于可撤销文档编辑。切帧、播放、暂停、播放位置、播放范围模式、当前循环节播放目标和重复进度属于会话状态，不改变 dirty，不进入撤销历史；在其他帧执行撤销时，历史仍必须修改原操作所属帧。
- 播放严格使用每帧保存的毫秒持续时间和会话播放倍率。右键播放按钮可选择“播放一次”“循环播放全部帧”或“播放标签并重复”：单次播放无论从哪一帧启动，都从第一帧播放到最后一帧，最后一帧完整显示自身时长后停止；全部循环在末帧后回到首帧；标签循环在当前帧位于一个或多个循环节内时选择范围最小的最内层循环节并无限重复，当前帧不在任何循环节内时按全部帧循环。标签循环沿循环节配置的正向或反向播放，但不受循环节有限重复次数限制；播放期间手动点击其他帧不会暂停，标签循环会立即切换到该帧所在的最内层循环节并从所选帧继续。右键循环节执行“播放循环节”仍严格遵循该循环节自身的重复次数。开启“停止时返回开始帧”时回到播放前选择帧，关闭时单次播放完成后自动回到第一帧，人工暂停则停在当前帧。播放期间不接受绘画输入，但画布平移与缩放继续可用；暂停后继续编辑当前帧。

- 文档像素、图层结构、图层属性、选区内容变换和调整属于可撤销编辑。
- 画布平移、缩放、旋转视图、面板布局和工具切换不是文档编辑，不得改变 dirty 状态。
- 无可撤销操作时按 `Ctrl+Z` 不得把工程标记为未保存。
- 一个用户动作应对应一个历史步骤，例如复制图层并移动后一次撤销应整体撤销。
- `Delete` 和 `Backspace` 根据用户最后点击或键盘聚焦的画布、图层、调色板、瓦片集或笔刷库区域执行；`Ctrl+C` 和 `Ctrl+V` 根据画布、图层或调色板焦点执行。`Backspace` 与当前可用的删除操作等价，文本输入中仍保留正常退格；遗留选区不得抢占图层、调色板、瓦片集和笔刷库命令。跨项目复制单层、多层或图层组时保留顺序、偏移、图层属性和父子组结构。粘贴图层、图层组或组合时，放到当前最上方选中对象同级的正上方；复制组内部的父子结构保持不变。粘贴完成后整批图层和图层组都进入选中状态，整批粘贴或删除只产生一个撤销步骤。
- 复制图层组时同时保存组的展开或折叠状态；粘贴后恢复相同状态，并选中新组、嵌套组及全部后代图层，使批量拖拽、删除和属性设置立即作用于完整副本。

## 图层与选区

- 根层顶部和底部拖放目标按实际可见行坐标计算，即使全部可见行都是拖动源，仍允许按住 `Alt` 复制到最底部；底部蓝线必须紧贴最后一个可见图层或图层组下方，不得落在栏目容器底边，并与普通插入线一样在左右两端显示三角端点。
- 图层拖拽悬浮预览最多逐行展示四个可见选中对象；未逐行展示或位于折叠组内的选中对象以 `+N` 准确汇总，结构操作仍只处理未被父组选中覆盖的顶层对象。
- 图层和文件夹支持嵌套、统一排序、拖入与拖出；所有组都使用持久排序锚点，允许夹在普通图层之间并在保存重开后保持。新建图层位于最上方选中对象同级的正上方；多选图层创建组时，新组占据所选图层中最上方图层的原位置，并保留成员原有上下顺序；选中组内图层时新图层与该图层同组，直接选中图层组时新图层位于该组外并与其同级，创建新组时则生成该组的空同级组。拖出图层栏上方或下方时分别落到根层最上方或最下方，顶部和底部蓝线与最终落点必须使用同一目标，即使首项或末项为组也允许放到组外。组标题行上、下四分之一区域分别生成同级插入线，中部才显示拖入组的整行蓝框；指针命中组内子层时不得提前提升为父组蓝框。该规则适用于任意嵌套深度，蓝线左边必须与最终层级对齐。只选中一个组拖动时，结束后仍保持单组选中语义，不把后代改成显式选中。图层与图层组使用相同的选中背景；眼睛、锁和组文件夹拥有独立交互区，不得误触属性面板。按住眼睛或锁拖动时，以按下图标为起点、当前指针所在同类图标为终点形成连续动态范围；范围内统一应用起点点击后的状态，往回划缩小范围时，离开范围的对象实时恢复按下前状态，整段手势合并为一次撤销。普通单击松开后立即结束手势，后续悬浮不得继续修改。`Alt+眼睛/锁`一次作用于当前对象所在层级的全部图层和图层组。普通图层行只有在 `Alt` 拖动实际开始后才显示复制指针，单独按住 `Alt` 不改变指针。栏目标题只保留新建图层、新建组和删除，合并与解组从菜单执行。
- 普通且不透明度为 `100%` 的图层组使用穿透合成，组内图层继续按各自混合模式与组外下方内容逐层计算，创建或解除图层组不得改变画面；组自身使用非正常混合模式或低于 `100%` 不透明度时，才先隔离合成组内内容，再以组属性合成到外部。图层组可单独开启“累积混合”：先让组内成员直接与组外下方内容合成，再将得到的完整结果按组混合模式和组不透明度与同一外部背景合成一次；该开关默认关闭，并作为可撤销的工程属性保存。
- 图层和图层组可从右键菜单开启剪贴蒙版。开启后，该对象的显示内容受同一层级紧邻下方对象的形状、像素透明度和对象不透明度限制，图层栏名称左侧显示剪贴蒙版图标；没有同级下方对象时保持原显示，移动到有效基底上方后自动生效。剪贴蒙版属于可撤销的工程属性，随复制粘贴和 `.moonsprite` 保存。
- 图层和图层组的右键菜单提供“图层样式”，可独立启用描边、阴影、内发光、颜色叠加和渐变叠加；弹窗标题使用“对象名称 图层样式”，效果内容区不重复显示效果标题或说明。描边复用普通描边功能的宽度、内部/外部位置、圆形/方形/水平/垂直快捷形状及八方向像素开关，并额外支持“两侧”。描边开启“智能色相”后隐藏手动颜色字段：外部描边逐像素读取最近的可见源色，内部描边读取当前位置的可见源色，并按统一 RGB 系数压暗以保留原色相。阴影开启“智能阴影”后同样隐藏手动颜色字段，并将阴影下方的实时背景按统一 RGB 系数压暗，因此背景变化时阴影颜色同步变化。两种深色系数均为 `0%` 保持原色、`100%` 变为黑色。渐变叠加复用渐变工具的平滑、Bayer 和方向抖动模式及像素预览。图层样式跨帧共享，图层组样式作用于每帧的组内合成结果；两者都基于应用自身蒙版后的可见轮廓实时计算，不改写原像素。阴影和外部描边位于内容后方，颜色叠加、渐变叠加、内发光及内部描边作用于内容内部，之后再应用所有者的不透明度、混合模式和剪贴蒙版。索引和灰度文档中的固定及智能生成样式颜色都按当前文档颜色规则解析。只有对象保留任一图层样式配置时，右键菜单才显示“启用图层样式”或“停用图层样式”；停用只让整组样式暂时退出合成和输出边界计算，不改写任何子效果参数；再次启用后恢复原设置，并与多选对象一起作为一个撤销步骤处理。弹窗支持实时预览，取消恢复打开前状态，应用只生成一个撤销步骤；只要对象仍保留任一图层样式配置，图层或图层组右侧的可点击样式图标就始终显示，不因整体停用而消失。复制、粘贴、重复和保存工程都必须深拷贝并保留样式及整体启停状态。文本图层或保留了样式配置的普通图层可执行“栅格化图层”：仅含文本时保留现有栅格表面与蒙版并移除可编辑文本；样式整体启用时，把每一帧当前样式及蒙版结果合并为独立像素，同时移除样式、蒙版与 cel 链接。两种情况都由一次撤销完整恢复。
- 图层右键菜单使用“转换为”子菜单统一提供背景图层、瓦片图层和普通图层；普通图层目标取代原“栅格化图层”，会移除背景身份，或把文本、Tilemap 与图层样式结果烘焙为普通像素。普通栅格图层可转换为背景图层并随时转换回普通图层；转换为背景图层时自动脱离原图层组并移动到根层绝对最底部，背景身份与位置变化合并为一个撤销步骤；文本图层必须先转换为普通图层。右键菜单把新建图层、新建图层组和新建背景图层统一归入“新建”悬浮子菜单，其中新建背景图层固定排在子菜单最下面；选择新建背景图层后打开正式弹窗，从纯色、网格、条纹、菱形 1、菱形 2 或圆形预设中选择，纯色固定排在首位、默认使用 `#e4e4e4` 并作为默认选项。新背景在根层最底部创建，已有动画帧默认共享同一预设内容。背景图层名称始终带贴近文字的下划线，右侧使用 `image` 像素图标标识。背景图层仍可使用普通像素工具编辑并正常参与显示和导出；选择普通图层吸色时，所有背景图层都视为透明，半透明前景色保留自身透明度，选择背景图层后则恢复完整合成吸色。扩大任意画布边界时，每个背景图层的活动帧与非活动帧都以扩大前可见画布为平铺单位、按当前锚点相位一次性填满新画布；转换时不会重复当前内容，后续编辑直接修改已经生成的普通像素。新建、转换和扩大画布都可撤销，背景属性随复制、粘贴和 `.moonsprite` 保存。
- 普通栅格图层的右键菜单提供“创建关联图层”。新图层与来源图层在每个对应动画帧共享同一份实际像素内容，编辑任一成员的绘制、擦除、选区变换、颜色调整或其他栅格结果时，其余成员立即同步；各成员的名称、层级、位置、显隐、锁定、不透明度、混合模式、图层样式和描述保持独立，显示颜色则由整个关联组共享。第一次创建关联图层时，最初的来源图层保留原名称，新图层默认命名为“原名称 关联1”；之后无论继续右键创建、普通复制、Alt 拖动复制还是复制粘贴，同一关联组的新成员都沿用原名称并依次命名为“关联2”“关联3”等，跨工程粘贴形成的新关联组则从“关联1”重新编号。用户仍可独立修改各成员名称，自动编号只作用于新创建成员。第一次创建时，来源图层和新图层还会同时从首选项图层颜色中选择当前图层栏尚未使用的同一个颜色；全部预设都已使用时选择使用次数最少的颜色。后续新增关联成员沿用组内颜色，修改任一成员的显示颜色会同步全部成员，撤销和重做也始终保持整组一致。关联成员右侧始终显示关联图层像素图标。普通复制、重复和同工程粘贴继续加入原关联组；跨工程粘贴会为本批次创建新的关联身份，同批复制的关联成员仍互相关联，但不得引用来源工程。背景、文本、Tilemap 与自由瓦片图层不能直接创建关联图层；普通关联成员转换为这些特殊图层时只让该成员脱离关联，其他成员保持原内容和关系。创建、复制、粘贴、脱离、像素编辑及其撤销重做都必须保持每帧共享关系，不得把关联成员静默变成独立副本。
- 图层选择使用 Photoshop 式修饰键：`Ctrl` 在图层和组之间离散增减选，`Shift` 从最近选择锚点到目标对象按当前完整图层树的可见行执行连续范围选择，范围内的图层和组都进入选择。混合选中的图层与图层组是一个操作单元，可统一拖拽、按住 `Alt` 复制、删除和右键批量设置名称、混合模式、不透明度、显示颜色及描述；拖拽、复制和删除等结构操作只处理未被父组选中覆盖的顶层对象，批量属性则必须作用于用户明确选中的每个图层和组，不得因父组同时选中而漏掉后代。拖放前后严格保持所有顶层选中对象从上到下的相对顺序和完整选择状态，每个用户动作只生成一次撤销。拖拽悬浮预览按图层栏顺序列出全部可见选中行；复制模式允许把源行自身作为上方或下方插入锚点并显示蓝线，普通移动仍拒绝无意义的自身落点。多选后普通单击任意图层或组会清除多选并只选择该项；`Delete` 一次删除全部选中图层、选中组及组内后代，并由一次撤销完整恢复。单对象图层属性实时预览；批量属性的表单值立即反馈，文档预览按约 40 ms 合并到最后一次输入，停止操作或关闭时强制应用最终值。批量属性只覆盖用户实际修改过的字段，关闭按钮、遮罩或 `Esc` 保存预览结果并关闭面板，整批属性变化只生成一次撤销。
- 只要文档中仍有图层，图层栏就始终保留一个有效选择，不允许进入“未选择图层”状态。点击图层栏空白区域会清除多选、组选择和蒙版选择并回到当前活动图层；减选最后一个图层时继续保留该图层，删除活动图层后自动选择相邻的剩余图层，撤销和重做后同样保证选择有效。空图层组允许使用 `Delete` 删除；锁定图层、锁定组及其所有后代不得修改像素、混合模式、不透明度、结构、排序或删除，但仍允许编辑名称、显示颜色和描述。组锁定后，其所有后代显示有效锁定状态且不能单独解锁；包含任意显式锁定后代的祖先组也不得删除。
- 图层和图层组的可见性、锁定等内容属性随工程正常保存；图层栏的活动图层、多选行、选择锚点和组展开状态按工程路径即时记忆，关闭并重新打开软件后恢复。图层栏选择或展开变化不改变工程 dirty，也不进入撤销历史；工程文件在下次正常保存时同时携带当时的图层栏上下文，失效引用自动过滤并回退到有效活动图层。
- 帧和 cel 的显式选区互斥：选择帧会清除 cel 选区，选择 cel 会清除帧选区。帧选择可与图层或图层组多选同时存在，先选择任一侧再选择另一侧都不得清除已有选择；每个“已选图层 × 已选帧”的时间轴单元格派生显示组合高亮，但不得写入 cel 选区。当前活动图层与活动帧仍决定当前 cel，图层栏空白区域或时间轴外的普通操作按原规则清理对应选择。多选图层自动映射出的当前帧单元格只显示图层多选背景，不显示额外蓝色单元格外框；用户继续跨帧显式加选单元格后才显示外框。长按范围选择只维护当前操作类型的实时临时预览；帧范围拖选进入 cel 行后仍按指针所在列继续扩展。
- 调色板槽位按栏目可见宽高自适应填满：栏目变宽或变高时补充右侧和下方空槽，缩小时只移除完全空白的边缘；若右侧或下方已有颜色则保留其二维坐标并启用组件库统一的横向、纵向滚动条，不得重新换行打乱用户排列。`Alt + 滚轮` 用于横向滚动，`Ctrl + 滚轮` 在“较小尺寸 / 小尺寸 / 中尺寸 / 大尺寸 / 较大尺寸”五档（`22 / 30 / 40 / 52 / 64 px`）之间调整颜色格尺寸，向上放大、向下缩小。颜色格之间不留间隔。空槽可点击并作为拖放目标，默认及鼠标悬浮时均不显示背景框；每个已有颜色始终在格子边界显示一像素主题对比居中描边，相邻颜色共用同一位置的描边，使内部交界线与最外圈保持相同粗细；浅色主题使用深色描边，深色主题使用较柔和的中性描边。普通单击替换选择，`Ctrl` 离散增减选，`Shift` 按矩形槽位范围选择；点击空槽时使用与颜色相同的选中外框并清除原颜色选择，焦点离开整个调色板后取消当前颜色或空槽选择。当前选择显示一像素深色内线、三像素强调色描边和一像素深色外线。在格子内部按住约 360 ms 后进入框选，按住移动时实时改变外框范围，即使在计时完成前已经移动也不会取消框选。只有指针位于强调色外框边缘时才能拖动整组选区，拖动整组颜色时选中外框同步跟随预览位置并保持二维相对范围；落到空槽时原位留空，落到已有颜色时与被占用槽位交换。双击任意槽位会把当前前景色加入并移动到该槽位。槽位列数、位置与空位属于可撤销工程数据并随 `.moonsprite` 保存；保存到软件时始终可以“保存为新色板”，当前选择为非内置用户色板时还可明确“保存到当前色板”，两种操作都保留列数、二维位置和空槽，旧版紧凑色板载入时按顺序排列。颜色格同时反映前景色和背景色：前景色保留右上角角标，背景色保留左下角角标，颜色角色本身不随选择变化。从当前画面提取颜色，或从 PNG、Aseprite 及其他外部图像生成导入调色板时，颜色默认按感知亮度从暗到亮排列；原生 `.moonsprite` 工程中保存的二维槽位顺序保持不变。
- 前景色和背景色由整个应用共享，而不是分别存入项目标签；切换、新建或打开工程后继续使用最近选择的两种颜色。
- 图层和图层组默认不带显示颜色；属性底部可选择无颜色、预设色或自定义色，设置后仅在图层行最左侧显示竖条，不改变画布像素。预设色由“首选项 > 图层 > 图层属性颜色预设”全局管理，支持 1 至 12 个有效且不重复的 RGB 色，应用后所有工程的图层属性面板实时使用同一组预设。描述使用统一的固定尺寸多行输入，并通过自定义悬浮提示展示；两者属于可撤销并随工程保存的图层属性。
- 组的显示颜色覆盖其全部后代组和图层的行标识；嵌套时从最外层祖先开始选择第一个已设置的颜色，因此最外层组一旦设置颜色，其整棵子树始终显示该颜色。只有更外层祖先均未设置颜色时，才使用更内层组或图层自身的颜色。继承色条与普通图层色条同样位于眼睛图标左侧。批量属性面板中的预设显示颜色属于离散操作，第一次点击立即预览，不等待连续数值输入的合并计时器。
- 隐藏或锁定图层不可绘制，画布应显示禁止操作指针。
- 选区可以超出画布显示，但最终像素写入遵守文档和图层边界数据规则。
- 主工具、选区子工具和形状子工具都使用统一自定义悬浮提示，包含工具名称、简短用法与用户当前快捷键。主工具按钮与顶部属性栏始终显示当前选中的子工具图标和名称；所有子工具图片在工具栏挂载时以不可见 DOM 图像常驻并同步解码，不得在首次选择后延迟出现。选区工具栏以单行固定显示矩形框选、椭圆框选、套索、多边形套索和魔棒；多边形套索默认使用 `Shift+Q`。五种工具共享选区组合规则；右键默认减选，按住 `Shift` 开始选择时绕过已有选区的内容变换并执行加选，属性栏在按住期间临时显示对应的加选或减选模式，松开后恢复原模式。
- “套索选区预览闭合”默认关闭；吸管工具默认保持当前工具，只有开启“吸管取色后切回铅笔”后，正式取色才在松开时返回铅笔，临时吸色不受该偏好影响。
- 形状工具弹出栏以单排固定显示矩形描边、矩形填充、椭圆描边、椭圆填充、自由形状和多边形形状。自由形状复用套索路径，松开后直接创建填充形状；多边形形状逐点建立边界，通过双击、点击起点或 `Enter` 闭合并填充。“固定比例”只作用于矩形和椭圆，使用宽、高两个数值定义比例，持久值最多保留一位小数，开启后横向或纵向拖动都按主轴保持指定宽高比。矩形框选、矩形填充与矩形描边分别提供持久化圆角开关和 `0–256 px` 半径输入，实际半径不超过当前图形短边的一半；预览、旋转和提交共用同一圆角掩码。
- 渐变工具属性栏以相连按钮选择线性或径向模式。线性按起终点方向投影颜色；径向默认以拖拽起终点作为椭圆包围框的对角点，横向和纵向半径可独立调整，椭圆外保持终点颜色。径向拖拽按住 `Ctrl` 时以首次落点为中心向四周扩展，按住 `Shift` 时锁定为 1:1 圆形，两者可组合；预览、普通图层提交和自由瓦片源编辑必须共用同一几何。两种模式都复用现有容差、连续区域和平滑或抖动设置。
- 油漆桶和魔棒的“智能闭合”按阈值虚拟连接线稿断点；同一直线方向上由一个孤立线稿像素分隔出的连续两个缺口，只要每段缺口都不超过阈值，就必须分别连接该像素两侧形成完整边界，不得因中间线稿没有独立延伸方向而泄漏到全画布。孤立线稿像素最多承担两次方向相反的连接，避免向同一侧重复闭合无关区域；与画布边缘连通的外部非目标区域按背景处理，不得参与线稿端点搜索。开启智能闭合时，正常连续填充必须保持与普通填充一致，不得被外部背景切割。
- 直线是工具栏主工具，曲线放在直线的双项子工具弹出栏中；主按钮始终显示当前选择的直线或曲线图标。直线拖动创建，按住 `Shift` 约束方向；曲线在首次按住拖动时实时显示起终点基线，松开后依次移动控制锚点即可实时改变弯曲结果，单击固定当前锚点，完成属性栏设定的全部锚点后提交。锚点数可设置为 `1–8`，默认为 `2`。直线与曲线共享独立的线条笔刷预设，支持笔刷尺寸、形状、纹理、图像笔刷和笔刷模式；“完美像素”会清理路径折角处的多余像素。预览与最终提交使用同一套路径清理和笔刷印章规则。两个子工具各自拥有可配置快捷键。
- 铅笔、橡皮擦、五种选区、六种闭合形状、直线、曲线和油漆桶的属性栏共享水平、垂直、斜向三个独立复选框，可同时开启。轴线以画布中心为基准并显示蓝色辅助线；锁定对称轴后普通拖动不改变位置，按住 `Ctrl` 可临时移动锁定的对称轴；多轴组合对结果去重，同一手势只生成一次撤销。斜向轴沿左上至右下方向，矩形画布中超出边界的镜像像素丢弃。
- 移动工具开启自动选择图层后，命中其他图层的不透明像素时移动对应图层；命中透明位置时回退到当前选中图层。直接选择图层组后，移动工具把该组及所有后代图层的当前帧内容作为一个整体移动，并保持图层组选中状态。按住 `Shift` 点击画布内其他可编辑图层的不透明内容时，将活动帧中命中的 cel 追加到现有单元格选择，不清除其他图层或其他帧已经选中的 cel；拖动任意已选且当前可见的 cel 时，全部已选 cel 按同一位移统一移动，并在移动期间保持时间轴选中样式。多选后普通单击任意已选或其他图层内容会只保留点击图层及其活动帧 cel，单击透明位置会回到当前活动图层单选；直接拖动已选内容不因按下瞬间提前取消多选。未被选区、形状或旋转等上下文占用时，按住快捷键设置中的“临时移动工具”（默认 `Ctrl`）可临时执行相同行为；首选项可控制点击目标图层时是否短暂高亮其内容范围。
- “编辑 > 调整”有选区时只作用当前图层选区，没有选区时作用全部选中图层。弹窗打开期间改变选区或图层选择，实时预览必须先恢复旧目标基线，再对新目标重新计算；最终只生成一个撤销步骤。
- “图像 > 调整图像尺寸”可识别最终合成画面中由最近邻放大形成的主导整数像素块倍率；识别综合颜色边界周期与局部同色块连续长度，不要求画布宽高能被倍率整除，也不要求不同素材使用相同网格相位。少量未遵循倍率网格的文字、细节或异常像素不得阻止主体倍率识别。识别成功后显示倍率，并将宽高除以该倍率后取最近整数，插值算法切换为最近邻；纯色画布或不存在可靠主导倍率时不得猜测结果。
- 色相/饱和度调整同时提供色相、饱和度和 HSL 明度；明度 `+100` 收敛到白色，`-100` 收敛到黑色，不得与 RGB 亮度复用同一计算语义。
- 粘贴内容和第一次移动后的选区内容在确认前保持浮动，可继续移动到合适位置，不应因当前画布视口而提前裁剪或覆盖经过区域的原背景。“编辑 > 选择性粘贴”提供“粘贴为新项目”和“粘贴为新图层”；新图层默认使用 `Ctrl+Shift+V`。来源坐标与当前可见视图相交时保留原位，否则以当前视图中心放置。
- 预览栏目先缓存带透明通道的作品像素，再按最终显示比例独立绘制透明棋盘格；规则与主画布一致，格子小于 `2 CSS px` 时退化为统一浅色，不得把高频棋盘纹理降采样进作品缓存而产生条纹或摩尔纹。预览栏标题区在关闭按钮左侧提供播放/暂停按钮，左键按当前设置循环或单次播放，右键打开与图层栏完全相同的播放设置菜单。缩时视频弹窗提供逐帧预览、播放控制和进度定位；“导出格式”置于设置第一项，支持 MP4、WebM、PNG 和 JPG。视频格式显示视频尺寸与画质、导出方式、时长/倍速；图片格式隐藏视频专属设置，改为显示导出倍率并按记录顺序写出带连续序号的图片文件。视频按目标时长或缩时倍率生成固定帧率的均匀采样帧，避免记录帧很多时短时长导出仍只显示少量变化；视频尺寸档位使用接近目标范围的最大整数像素倍率，不拉伸作品比例；编码格式要求偶数尺寸时只在边缘补最多 1 像素。输出概览实时显示实际尺寸、记录帧数、速度倍率和预计时长；导出期间复用文件操作进度弹窗，完成状态保持在视觉顶层并等待用户确认。导出前检查运行环境的视频编码能力，不支持时提示失败且不生成伪装格式的文件。

- 图层栏空白区域右键直接打开“新建”菜单，菜单内容与图层右键菜单中的“新建”子菜单一致，提供新建图层、新建图层组、新建瓦片图层、新建自由瓦片图层和新建背景图层；选择后沿用当前选中对象的插入与创建规则。

## 工作区与设置

- 正式弹窗的八向缩放使用以可见边框为中心的紧凑连续命中带，不得覆盖附近正文控件。拖动或缩放到软件窗口边缘时保持指针捕获并暂停尺寸观察反馈，不得闪烁或跳回；拖动期间直接更新视觉位置，松开后再保存状态，向下移动时允许标题以下的内容移出窗口，但必须保留完整标题栏供用户找回。快捷键设置的分类栏和正文随可用高度伸展，底部操作栏始终贴底。
- 用户始终有一个当前工作区；布局变化实时写入当前状态。
- 工作区同时保存创建时布局和当前布局；复位只恢复创建时布局。
- 默认工作区不可删除。
- 首选项和快捷键在重启后保留。每项命令支持多个快捷键；打开设置时编辑独立草稿，只有点击完成才整体提交，关闭或取消必须丢弃本次改动。新增或修改按键时显示当前占用命令，同一上下文中的普通冲突直接把该绑定转移到新命令；工具之间允许共享按键并在连续按下时循环切换，手势修饰键只在各自上下文内生效。导入合法快捷键配置后必须在弹窗内显示成功状态，读取或解析失败时显示明确错误。
- 快捷键用户配置使用带版本的差量数据保存，旧版单快捷键配置必须自动迁移；菜单和紧凑工具栏显示主绑定，实际命令匹配全部绑定。喷枪默认使用 `J`，切片工具默认使用 `Shift+C`。快捷键录入控件优先消费键盘、滚轮、鼠标中键和两个标准鼠标侧键输入，支持“滚轮向上”“滚轮向下”及任意 `Ctrl`、`Alt`、`Shift` 多键组合，文本输入中的编辑按键不得误触发文档命令。组合键或鼠标辅助键松开后必须立即同步真实按下状态，不得残留临时移动、平移或调整状态。滚轮快捷键只在画布区域触发；没有匹配绑定时继续执行原有画布缩放或笔刷尺寸调整。鼠标辅助键只有匹配已分配快捷键时才覆盖原操作，未分配时保留中键平移、标签中键关闭等既有行为。
- 快捷键设置必须覆盖菜单、工具及其固定子模式、右键菜单、资源栏目和动画控制中所有无需额外参数即可确定执行目标的编辑命令；新增命令默认可不分配按键，避免与用户现有设置冲突。指针拖拽手势、连续数值调整、按名称动态生成的脚本或扩展命令，以及必须先选择动态目标的操作继续由各自上下文处理，不生成固定快捷键条目。
- “界面缩放”只表示 MoonSprite 自身的缩放比例，桌面端必须抵消当前显示器的系统 DPI 缩放；Windows 显示缩放变化或窗口移到不同 DPI 的显示器时，界面的实际视觉尺寸不得随系统倍率再次放大或缩小。主窗口的默认尺寸和最小尺寸使用物理像素，并只随 MoonSprite 自身的界面倍率变化，不得被 125%、150%、175% 等系统 DPI 再次放大；最大化状态下调整界面倍率不得改变窗口位置或退出最大化。主窗口使用固定 `32 px` 的 Windows 原生外观标题区，保留拖动、双击最大化、最小化、最大化/还原和关闭交互，并显示 `MoonSprite` 与当前版本；标题栏只有在主键仍按下且指针实际移动后才能进入原生拖动，从其他窗口点击标题栏激活 MoonSprite 时不得在松键后继续吸附鼠标或移动窗口。双击完成最大化或还原后必须立即恢复普通指针，不得残留 Windows 顶部边框的上下缩放指针。标题区不得被系统 DPI 二次放大。MoonSprite 软件指针的像素位图和热点坐标使用同一套 DPI 补偿，系统显示缩放不得改变其实际视觉尺寸或命中位置。主画布的百分比缩放独立于界面缩放；画布 `100%` 时一个文档像素必须对应一个设备像素，界面设置为 `150%` 等倍率时也不得产生交替宽度、错位或平滑采样。
- 快捷键设置导出必须先打开系统原生 JSON 保存对话框，用户确认路径后以 UTF-8 原子写入；取消对话框不创建文件，写入失败时在弹窗内显示错误。
- 数值输入组件只接受数字、小数点、空格、科学计数法中的 `e/E`、括号及 `+ - * /` 表达式字符，键入或粘贴的其他字母、中文和无效符号会被过滤；回车或失焦后按标准运算优先级计算，再应用字段本身的最小值和最大值。
- “文件”首选项使用一个“自动保存恢复数据”时间预设控制恢复写入；恢复数据严格按所选间隔保存，不因窗口失焦额外触发，选择关闭时不得注册定时保存。
- 首选项底部提供“应用”，保存当前设置但保持首选项窗口打开；“确定”保存并关闭，“取消”放弃本次未应用修改。
- “恢复所有初始设置”必须二次确认，且只清除 MoonSprite 的本地软件配置；不得删除用户创建的工程、笔刷、色板、工作区文件或其他磁盘文件。软件通过统一语言目录读取可翻译文案，未知语言偏好回退到简体中文；当前可在首选项中选择简体中文或英语，应用后当前界面、Windows 原生文件对话框与后续核心操作提示实时切换，用户输入和工程内容不得被翻译。
- 颜色值按钮显示颜色样本、HEX 和颜色角色；完全不透明的颜色使用六位 HEX，存在透明度时使用八位 HEX。打开后默认进入 RGB，可切换 RGB、HSV、HSL、Gray。模式、HEX 与当前色在顶部同一行，每个通道使用一条彩色滑轨和右侧直接数值输入，所有模式均支持透明度。调色盘底部前景色/背景色与背景首选项复用同一组件。
- 前景色和背景色的颜色值弹窗标题显示“颜色编辑 前景色/背景色”，可通过关闭按钮关闭。未移动时失焦自动关闭，标题栏真实拖动后转为常驻；两者拥有独立尺寸记忆、统一最小/最大尺寸，可八向缩放并同时打开，关闭后再次打开回到各自触发按钮附近的默认位置。调整高度时通道色条随内容区自适应，色条与数值输入框保持等高。默认显示 HSV、RGB、LAB、GRAY、PLT 五种模式，其中 PLT 按当前项目调色板顺序直接选色；右侧吸管按钮进入临时吸色，完成后恢复原工具。
- “光标”首选项中的“使用本地指针”默认关闭；开启时优先使用电脑系统指针，系统没有对应语义的旋转等特殊操作回退到 MoonSprite 指针，并禁用只作用于 MoonSprite 指针的光标比例。关闭时所有场景使用 MoonSprite 指针。“工具预览”默认使用完整笔刷预览；只有选择“完整预览并显示边缘”时才显示“绘制时显示笔刷边缘”，并可控制落笔期间是否保留边缘轮廓。框选时是否显示真正的鼠标十字指针独立控制且默认关闭，此时框选只显示当前像素四角角标。“背景”首选项统一控制可直接输入 `1-256 px` 的透明棋盘格大小和并排显示的两种颜色；“图层属性颜色预设”使用相同的普通颜色设置布局，不得伪装成独立栏目。“编辑”首选项控制滚轮缩放、铅笔直线实时预览、默认开启的“直线算法优化”和直线斜向阶梯数值；该算法同时用于画笔直线和多边形套索边界，`Shift+Ctrl` 方向约束在阶梯数值为 `1` 时提供 8 个方向，数值大于 `1` 时提供 12 个方向。“默认缩放模式”控制缩放工具拖动时使用平滑或百分比缩放。
- “视图拖拽灵敏度”提供 `0.5x`、`0.75x`、`1x`、`1.5x` 和 `2x` 五档，默认 `1x`；抓手、空格临时拖拽、中键拖拽与预览栏目的手动平移必须使用同一档位，不改变选区边缘自动滚动速度。
- 启用取色放大镜后，可在首选项选择最小、小、中、大四档尺寸，分别对应当前放大镜资产的 `50%`、`75%`、`100%` 和 `125%`；默认中等并保持镜片、像素外框、颜色遮罩与指针中心同步缩放。
- 首选项中的尺寸预设、导出倍率预设与图层属性颜色预设统一使用组件库 `DeleteIconButton`；紧凑预设行使用 `28 px`，颜色预设与删除按钮统一使用 `34 px` 高度，并共享危险悬浮与禁用状态。
- 同一表单或弹窗内存在多个文本、数字输入框时，`Tab` 和 `Shift+Tab` 分别按界面顺序向前、向后切换输入焦点，并默认全选新输入框内容。
- 状态提示位于顶部工具属性栏下方的画布视图上部，与属性栏保留明确间距且不遮挡视图中央；调整、画布大小和图像大小弹窗默认位于视图中心与右侧边缘之间的中点。所有正式模态弹窗复用统一外壳，可拖动、通过边框外侧的八向把手调整大小，并记忆各自的位置和尺寸；每类弹窗设置能保持内容完整的最小尺寸与适合当前视口的最大尺寸，外壳不产生横向或重复滚动条，默认尺寸以 1080p 下不压迫画布为准。
- 画布大小弹窗底部选项区在“裁掉画布外的内容”右侧提供“同步四边”复选项；开启后修改左、上、右、下任意边距时，其余三边同步为同一数值，开启动作本身不改变当前边距。
- 每个项目画布的上方各自悬浮一个快捷指令栏，不占用画布布局高度；首次使用默认折叠，用户最后一次主动展开或折叠会保存为本地界面偏好，之后新打开的项目以及下次启动沿用。多个项目分栏或浮窗同时显示时，每个画布保留自己的快捷栏，非活动画布只暂时收起且不改写已保存状态。快捷栏默认半透明，可在首选项关闭半透明显示；开启时悬浮或键盘聚焦会恢复完全不透明。折叠按钮在展开前后保持固定高度，指令区使用水平收放与透明度动画。默认以单排提供水平/垂直选区镜像、水平/垂直画布镜像、反选、自定义网格和相对明暗；末尾固定提供设置按钮，可直接打开首选项的独立“快捷指令栏”分类。该分类可隐藏整个快捷栏，并可从撤销、重做、全选、取消选择、像素网格、选区边框、相对明暗、重置视图、填充前景色、删除选区内容、交换前景色与背景色、从选区创建笔刷以及顺/逆时针旋转视图等候选中勾选按钮和拖动排序。快捷指令与颜色模式排序均复用首页项目排序的连续列表、拖动手柄和按住反馈；带有相关设置的按钮可通过右键直接打开对应弹窗，并在悬浮描述中明确提示。选区相关命令在没有选区时禁用，画布镜像与网格按钮显示所属项目的当前开关状态，并与顶部菜单及快捷键调用同一命令。
- 整数与非整数缩放必须使用稳定一致的画布几何和取样原点；在 313% 等非整数缩放下开始或继续绘制时，不得因切换缓存绘制路径而使已有像素发生局部跳动。
- 顶部任一主菜单打开后，鼠标横向移入其他主菜单应直接切换并展开；没有菜单打开时，普通悬停不得自行展开菜单。

## 兼容与安全

- 未知 `.moonsprite` 格式版本应拒绝打开，不得猜测解析。
- 保存使用临时文件和替换策略，失败时不得损坏原文件。
- 恢复、画廊、笔刷和工作区目录属于用户数据，不进入源码仓库。
# 视觉与保存行为

## 视图镜像

水平镜像和垂直镜像只改变观察方式，不改变画布内容或编辑方向。画布左下角显示当前镜像状态，输入坐标使用显示矩阵的逆变换。
镜像画布放大至视口边缘时，四周像素必须完整显示，不得因离屏场景仍使用镜像前边界而被裁切。

预览栏目滚轮缩放以鼠标位置为锚点，缩放前后鼠标下的作品位置保持不变，并固定复用主画布的百分比倍率档位和像素采样规则，不提供 `125%` 与 `150%` 档位；工具栏缩放按钮仍以预览中心为锚点。开启“跟随画布视窗”后，预览平滑同步主画布当前查看的位置，同时保留自己的独立缩放倍率和缩放操作；跟随位置必须限制作品边缘不越过预览视窗边缘，作品小于视窗时最多移动到对应边缘贴合，作品大于视窗时不得露出作品范围外的空白。在预览中开始手动平移会从当前跟随位置继续拖动并自动关闭跟随，直接关闭跟随后同样保持当时的预览位置。多帧项目中，预览栏目停止播放时始终显示当前手动选中的活动帧，主时间轴播放时同步显示当前播放帧；预览栏自身播放期间保持独立播放进度，不被时间轴选帧打断。

“窗口 > 旋转视图”提供顺时针和逆时针 90° 旋转命令；两项命令可在快捷键设置中绑定，且只修改视图，不进入文档撤销历史。

## 保存

普通保存、首次保存、另存为和导出都必须在实际编码或写入开始后显示紧凑进度反馈，并在成功后自动关闭。桌面端流式 PNG 导出必须按已处理的输出行持续更新进度，单图与批量导出都不得在进入原生缩放、压缩和写盘阶段后长期停留在固定百分比。需要 Windows 文件选择器的操作必须先等待选择器返回，用户取消时不显示进度。

已打开 `.moonsprite` 工程再次保存时，只重新编码发生变化的 cel、图层、蒙版和必须刷新的工程元数据，未修改的像素块与缩时快照直接复用原文件中的压缩数据。增量保存必须继续通过同目录临时文件原子替换；原文件被外部改变、复用校验失败或合并失败时自动完整保存，不得留下不完整工程。

“另存为”默认选择“首选项 > 文件 > 默认保存格式”。选择 PNG、JPEG 或 WebP 时必须明确提示该格式不会保留图层和工程结构；用户确认的扩展名、Windows 保存类型和实际编码格式必须一致。

“导出设置”的文件名始终显示当前格式后缀，切换格式时保留名称主体并同步后缀。每次导出可单独选择目录、切换到本地展馆目录，或从最近成功导出的完整文件路径中复用其所在目录；弹窗选择的目录优先于首选项默认导出位置。导出设置已经显示明确目录时，点击“导出”直接写入该目录，不得再次打开系统原生保存或目录选择框；“导出并打开文件夹”执行相同导出，并在成功后打开目标目录。每个工程只在成功写入后记录自己的最后一次导出名称、实际路径、格式、缩放、目标、GIF 选项和已选择预设，再次打开同一工程时恢复这些设置；取消或失败的导出不得覆盖记录。导出预设必须持久化完整格式、缩放、GIF 范围与方向、文件名和目录设置，读取旧预设时不得丢弃已经支持的导出格式。
