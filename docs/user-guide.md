适用版本：`1.0.0-beta4` 当前开发版。整理日期：2026 年 9 月 19 日。

## 1. 先认识 MoonSprite 的特色功能

### 1.1 与 Aseprite 的对比范围

以下对比针对 Aseprite 官方稳定版的内置功能，以 2026 年 9 月 19 日核对的官方文档、路线图和发布记录为依据。官方最新稳定版记录为 `1.3.18.5`；第三方脚本、扩展和未来版本不纳入“内置”的判断。[Aseprite 发布记录](https://www.aseprite.org/release-notes/)

| 优先了解的功能 | MoonSprite 的用途 | 对比依据与表述范围 |
| --- | --- | --- |
| 逐帧图层蒙版、图层组蒙版 | 用黑白灰控制显示范围，保留原像素，并让每帧拥有不同蒙版 | Aseprite 官方路线图仍将蒙版图层列为后续方向。[官方路线图](https://www.aseprite.org/roadmap/) |
| 可持续编辑的文本图层 | 保存文字内容、字体和排版，之后仍可修改文字 | Aseprite 的插入文字能力不等同于持久文本图层；后者仍列在路线图中。[官方路线图](https://www.aseprite.org/roadmap/) |
| 实时图层样式 | 描边、阴影、内发光和颜色效果随原图变化，原像素不必重画 | Aseprite 路线图仍列有实时效果层；不能把普通滤镜等同于这一工作流。[官方路线图](https://www.aseprite.org/roadmap/) |
| 自动生成补间帧 | 根据终点位置、旋转、缩放和透明度生成动画过渡 | Aseprite 官方路线图仍列有 Tweening。[官方路线图](https://www.aseprite.org/roadmap/) |
| 自由瓦片 | 把可复用图案作为可重叠、任意位置的实例摆放，统一修改源图 | Aseprite 官方 Tilemap 是按网格单元引用瓦片；这里强调自由实例工作流的差异，不把普通瓦片地图称为独有。[官方 Tilemap 说明](https://www.aseprite.org/docs/tilemap/) |
| 跨图层关联内容 | 多个图层同步像素，同时保留各自的位置和显示属性 | 与 Aseprite 已有的同图层跨帧关联 cel 区分；其官方仓库另有跨图层关联需求。[关联 cel 文档](https://www.aseprite.org/docs/linked-cels/)、[跨图层需求](https://github.com/aseprite/aseprite/issues/2954) |

下文还优先介绍内置缩时记录、液化和 ISO 绘制辅助。这些是 MoonSprite 的重点工作流；未找到同等内置功能的官方说明，不据此断言 Aseprite 及其扩展完全无法实现。普通动画、瓦片地图、洋葱皮、图案笔刷、分屏和脚本也不属于本手册宣称的独有能力。[Aseprite 文档目录](https://www.aseprite.org/docs/)

### 1.2 自由瓦片：画一次，多处复用

**用途：** 制作树木、石块、角色零件、装饰物等重复元素。实例不需要对齐固定网格，可以重叠；修改源瓦片会同步更新全部引用。

1. 右键图层，选择“新建 > 新建自由瓦片图层”。填写名称，选择新增集合或已有集合。
2. 新集合会准备透明源瓦片并进入“编辑源瓦片”。直接在画布绘制，首次绘制会自动产生实例。
3. 在瓦片集栏目选择源，切换到“放置实例”，在画布单击或拖动摆放。
4. 在实例图层栏目选择实例，再用移动工具改变位置。实例属性可设置 X、Y、旋转、镜像、不透明度和混合模式。
5. 需要改所有同类物体时，选择一个实例进入源编辑，使用铅笔、橡皮擦或选区工具修改共享源。
6. 需要另一种图案时，点击“新增源瓦片”，绘制新源后再放置。

**源与实例的区别：** 源保存图案；实例保存这份图案放在哪里、以什么朝向显示。编辑源会影响同一集合中全部图层、全部帧里的引用；移动、旋转或镜像某个实例只影响该实例。

实例列表支持 `Ctrl` 增减选择、`Shift` 连续选择、拖动排序、显隐、锁定、批量属性与批量删除。右键“仅显示”可只显示当前实例；实例列表既可独立显示，也可通过标题栏设置放回图层栏目内。

放置模式中，橡皮擦删除指针下最上面的实例，吸管选择该实例的源。此模式不使用框选或 `Ctrl+T`；返回源编辑并选中可编辑实例后，才能操作其选区。

在源编辑中，局部选区变换会修改共享源；完整选中一个实例后拖动内容，则移动实例位置。粘贴普通像素选区时，没有选中实例会创建新源和实例；已经选中实例则覆盖其共享源，并同步其他引用。较大的新内容会按不超过 `256 × 256` 的块拆分。

### 1.3 蒙版：隐藏内容而不擦除原图

**入口：** 右键 cel 创建图层蒙版；右键图层或图层组，可为该对象已有内容的帧批量创建蒙版。

1. 创建后，在对象上方找到蒙版轨道，点击对应帧的蒙版格。
2. 用黑色隐藏、白色显示、灰色部分显示。彩色笔触会转为灰度。
3. 用橡皮擦恢复“未绘制”状态，未绘制区域等效于白色，原图仍显示。
4. `Alt+左键` 点击蒙版格，进入白底灰度的独立蒙版视图，便于检查遮罩。
5. 点击普通图层、cel 或切换帧，退出蒙版编辑。

蒙版按帧独立保存，可多选、复制、粘贴、拖动、链接和断开链接。图层组蒙版作用于整个组的合成结果。蒙版并非普通图层上的黑白画稿，不会直接改掉原图像素。

### 1.4 图层样式：随内容变化的效果

**入口：** 右键图层或图层组 > 图层样式。

选择并启用效果，调节参数，观察实时预览，应用后生效；取消恢复原画面。

| 效果 | 作用与操作要点 |
| --- | --- |
| 描边 | 设置宽度、内部/外部/两侧、轮廓形状和八方向开关；“智能色相”根据邻近原图颜色生成描边 |
| 阴影 | 调节阴影参数；“智能阴影”根据阴影下方的背景生成深色，背景改变时随之更新 |
| 内发光 | 在图案内部边缘产生发光效果 |
| 颜色叠加 | 用设定颜色为内容统一着色 |
| 渐变叠加 | 叠加渐变，可选择平滑、Bayer 或方向抖动 |

智能描边或阴影的深色系数 `0%` 保持来源颜色，`100%` 变黑。样式配置跨帧共享，但每帧按自己的内容计算效果。

已有样式可从右键菜单停用、启用、复制、粘贴或清除。停用保留参数。要把效果变成可直接绘制的普通像素，使用“转换为 > 普通图层”；转换后不再保留相同的实时编辑方式。

### 1.5 可编辑文本与自动换行

**入口：** 文本工具 `T`。

1. 单击画布创建随文字大小变化的文本，或拖出固定区域创建自动换行文本框。
2. 输入文字，选择字体，设置字号、字间距、行间距和锯齿/平滑渲染。
3. 选中部分字符，可单独修改其字号、间距或颜色。
4. 确认后生成文本图层。双击文本图层或文本 cel，继续编辑。

固定文本框内的文字自动换行，超出框高的部分被裁切。用文本工具拖动框体可移动，拖动控制点可改框大小并重新排版，不会拉伸字形。固定文本框不使用 `Ctrl+T`；自适应文本可使用变换。

字体列表的“导入”读取系统字体；“选择”从文件导入字体到软件字体目录。工程记录字体名称，不内嵌字体，换电脑需准备同名字体。

文本层不直接接受普通画笔和像素粘贴。需要逐像素修改时，右键“转换为 > 普通图层”；之后文字将按像素编辑。

### 1.6 自动补间：生成移动、缩放与旋转动画

**入口：** 右键时间轴帧头或 cel > 生成补间帧。

1. 选择含可见内容、未锁定的普通像素图层和起始帧。
2. 选择“单帧”或“循环节”作为补间来源。
3. 设置新增帧数、每帧时长、终点水平/垂直位移、旋转角度、缩放比例和相对不透明度。
4. 选择匀速、加速、减速或先加速后减速；拖动预览滑块检查过渡。开启终点预览后，也可用移动工具拖动半透明原图定位终点。
5. 点击“生成”，把新帧插入时间轴；原有后续帧顺延。

单帧来源中，其他图层沿用起点内容；循环节来源中，软件循环取用来源帧并叠加补间变化，跳过禁用帧，新帧放在来源循环节之后。“新增帧数”包含终点帧。旋转与缩放围绕内容中心进行。

预览不包含蒙版、图层样式和混合效果。文本、瓦片和背景图层需先转换为普通图层；这项功能生成几何与透明度过渡，不会自动重画角色的中间姿态。

### 1.7 关联图层：同步画稿，分别摆放

**入口：** 右键普通像素图层 > 创建关联图层。

创建后，两个图层在各自对应帧共享像素。修改任一成员的绘制、擦除或颜色，其他成员同步更新；位置、名称、层级、显隐、锁定、不透明度、混合模式和样式可分别设置。关联图标和共同的显示颜色帮助识别同组成员。

适合重复装饰、对照摆放或为同一内容设置不同显示效果。同一工程内复制关联成员仍加入原关联组；跨工程粘贴会创建独立于来源工程的新关联组。背景、文本、Tilemap 和自由瓦片不能直接创建这种关联图层。

“关联图层”连接不同图层，“关联 cel”连接同一图层的不同帧，使用时应区分二者。

### 1.8 缩时记录：自动保留绘画过程

**入口：** 新建时勾选“记录绘画过程”，或打开“文件 > 缩时视频”设置录制。

1. 选择全程录制或智能采样。
2. 正常绘画。记录跟随已提交的内容操作，不记录停顿、缩放、平移和栏目拖动。
3. 需要把修改过程也录下时，启用“记录撤销步骤”。
4. 打开缩时视频窗口，用播放和进度定位预览过程。
5. 选择 MP4、WebM 或 PNG/JPG 序列；视频可设置尺寸、画质及目标时长或倍速，图片序列设置导出倍率。

全程录制保留每次记录；智能采样逐步精简较早记录并保留近期变化，切换模式本身不删除已有记录。

安装版录像通常保存在本机录像库。**分享或换电脑时，在“另存为”勾选“携带缩时录像”**，将录像随工程带走。仅拷贝普通保存的工程不保证录像可用。

清空记录不会删除画作，但不能撤销，也不会释放本机录像库已经占用的磁盘空间。视频输出取决于当前环境的编码支持；无法编码时可使用图片序列。

### 1.9 液化与像素轮廓整理

**入口：** 液化工具 `Y`。

选择推动、膨胀、收缩、顺时针扭转或逆时针扭转，设置半径和强度，然后在需要变形的区域拖动。推动用于改变轮廓走势；膨胀与收缩改变局部大小；扭转改变局部旋向。可先框选目标，限制作用区域。

推动模式的平滑算法更适合纯色、细节简单的区域。操作会改变像素，可用撤销恢复。精细边缘整理还可使用平滑笔刷或“编辑 > 自动抗锯齿”，见后文。

### 1.10 ISO 绘制辅助

**入口：** 图像 > 绘制视角 > ISO视角；参数在“ISO绘制视角设置”中调整。

设置阶数、参考线位置、单位尺寸、颜色与样式。阶数 `N` 表示每移动一个纵向像素，对应连续 `N` 个横向像素。开启“强制线条对齐”后，直线及铅笔、橡皮擦画线会限制在水平、垂直和当前 ISO 阶梯方向，方便绘制地砖、建筑和等距场景。

视角辅助不会自动把平面图变成三维模型；关闭强制对齐即可恢复自由画线。

## 2. 从新建到完成第一张作品

1. 按 `Ctrl+N`，输入名称与画布宽高，选择颜色模式；一般自由绘画可先选 RGBA。
2. 在颜色栏目选择前景色，按 `B` 使用铅笔，左键拖动绘制。
3. 按 `E` 擦除；滚轮缩放，按住 `Space` 拖动画布。
4. 用 `Shift+N` 新建图层，将线稿、颜色和装饰分开。
5. 用 `M` 框选内容，拖动内容或按 `Ctrl+T` 变换；按 `Enter` 确认。
6. 按 `Ctrl+S` 保存为 `.moonsprite`，保留图层及可编辑数据。
7. 按 `Ctrl+E` 打开导出设置，选择 PNG、倍率与目录，导出用于分享的图片。

准备做动画时，在图层栏新增帧，逐帧修改；完成后导出 GIF 或精灵表。绘画内容通常写入“当前图层 × 当前帧”的单元格，而不是自动修改所有帧。

## 3. 工程、首页与文件管理

### 3.1 新建与打开

“文件 > 新建”可设置画布、颜色模式及是否记录绘画过程。剪贴板存在图片时，新建窗口会采用图片尺寸作为初始值。

“文件 > 打开”、`Ctrl+O` 或从资源管理器拖入，可打开 `.moonsprite`、`.ase`、`.aseprite`、PNG、JPEG、WebP、BMP 和 GIF。动画 GIF 会导入为多帧工程，保留可读取的帧顺序、时长与循环信息。

多个工程可同时打开，通过顶部标签切换。`Ctrl+W` 关闭当前工程；存在未保存内容时按提示保存或放弃。

### 3.2 首页、画廊与自定义文件夹

首页提供最近、画廊和恢复等栏目。点击项目卡片打开，右键普通卡片打开所在文件夹；`Ctrl+滚轮` 切换列表大小。

在首页栏目管理中添加文件夹，可直接浏览该文件夹第一层支持的工程和图片；栏目支持拖动排序。移除自定义栏目只移除入口，不删除文件。画廊的“删除工程”会删除磁盘文件，需要确认；与“从最近移除”不同。

默认工程目录为程序根目录的 `gallery`，默认导出目录为 `exports`，可在首选项修改。

### 3.3 恢复与项目信息

异常关闭后，从首页“恢复”打开草稿，检查内容并正式保存。打开或关闭恢复草稿不会立即删除原恢复记录；完整保存成功或明确删除记录后才移除。

“首选项 > 文件与恢复”设置自动保存恢复数据的间隔和保留天数。恢复数据默认保留 7 天，可设为 1–365 天。自动恢复数据不能代替主动保存工程。

“文件 > 项目信息”可查看尺寸、颜色模式、图层/组/帧数量、笔画与编辑次数、有效绘画时长、创建修改时间及缩时记录数量。

## 4. 画布导航与绘制辅助

### 4.1 缩放、平移、旋转与镜像

| 操作 | 方法 | 作用 |
| --- | --- | --- |
| 缩放 | 滚轮或缩放工具 `Z`；拖动缩放时 `Shift` 临时按倍率档位缩放 | 改变观察大小，不修改作品尺寸 |
| 平移 | 抓手 `H`、`Space+拖动` 或中键拖动 | 改变视窗位置 |
| 旋转视图 | 旋转工具 `R`，或“窗口 > 旋转视图” | 改变观察角度，便于落笔 |
| 镜像视图 | “窗口 > 镜像视图” | 检查比例与构图，不翻转原像素 |
| 复位 | “窗口 > 复位视图” | 恢复预设观察状态 |
| 全屏/高级模式 | “窗口”菜单中的相应命令 | 减少界面占用；高级模式可用 `Ctrl+F` 切换 |

视图变化不进入绘画撤销历史。真正改变输出尺寸要用“调整图像尺寸”，真正翻转像素要用“选择 > 变换”中的翻转。

### 4.2 网格、对齐与相对明暗

“窗口 > 显示”分别控制像素网格、自定义网格、切片边框和相对明暗。像素网格用于辨认单像素；自定义网格用于格子、图块和版面，参数在“窗口 > 网格设置”中调整。

“窗口 > 对齐”可开启网格对齐、智能对齐和辅助线。网格对齐需要自定义网格可见；智能对齐会参考画布与其他可见图层的边缘、中心。隐藏辅助线不会关闭吸附。吸附距离可在首选项设置。

“查看相对明暗”以灰度明暗关系检查作品，便于发现颜色不同但亮度过近的区域，不会把工程转换为灰度模式。

### 4.3 无缝平铺

打开“窗口 > 平铺预览”，选择包围平铺、X 轴或 Y 轴。软件分别显示 `3 × 3`、`3 × 1` 或 `1 × 3` 副本。

可直接在相邻副本上绘画，结果映射回原画布；跨接缝检查线条与图案是否连续。副本只是编辑视图，导出仍按原画布或所选区域进行。

## 5. 绘画工具与笔刷

### 5.1 工具用途与操作

| 工具 | 操作 | 用途与主要设置 |
| --- | --- | --- |
| 铅笔 `B` | 按住拖动；`Shift` 连接上一次落笔点 | 像素绘画；调尺寸、形状、不透明度、间距、完美像素及笔刷动态 |
| 橡皮擦 `E` | 左键拖动擦成透明 | 在默认右键配置下，右键把与前景色完全相同的像素替换为背景色 |
| 喷枪 `J` | 按住喷涂，静止也继续喷 | 粒子半径控制颗粒大小，散布半径控制范围，密度控制数量，频率控制间隔 |
| 直线 | 按下拖出起终点 | 使用线条笔刷绘线；`Shift` 约束方向 |
| 曲线 | 拖出起终点后，移动并单击固定控制锚点 | 锚点可设 1–8 个，完成全部锚点后提交 |
| 形状 `U` | 选择子工具后拖动，或逐点绘制 | 矩形/椭圆的描边与填充、自由形状、多边形形状 |
| 油漆桶 `G` | 点击区域填充 | 容差、连续区域、智能闭合、纹理、对称 |
| 渐变 `Shift+G` | 设前背景色，再拖动定义渐变 | 线性/径向，平滑或抖动，连续区域与容差 |
| 吸管 `I` | 点击或拖动取色 | 默认左键取前景色、右键取背景色；`Alt` 临时吸色 |
| 平滑笔刷 | 选择工具后沿需要整理的区域涂抹 | 整理已有像素边缘与线条，建议局部使用并对比结果 |
| 液化 `Y` | 选择模式、半径和强度后拖动 | 推动、膨胀、收缩与扭转，见特色功能 |
| 文本 `T` | 单击或拖框后输入 | 创建可再次编辑的文字，见特色功能 |

多子工具按钮可展开选择具体工具。形状中的自由形状拖动闭合后填充；多边形逐点点击，以双击、点击起点或 `Enter` 完成。矩形和椭圆可设固定比例，矩形还可开启圆角。

绘画通常使用左键前景色、右键背景色；若在平板与触控首选项中自定义了右键动作，则遵循自定义设置。

### 5.2 基础笔刷与完美像素

基础笔刷提供圆形、方形和线形。用属性栏选择形状与尺寸，也可用 `[`、`]` 改尺寸。铅笔、橡皮擦及线条分别保留相应参数。

“完美像素”清理路径折角处的多余像素，适合单像素线稿。直线阶梯设置用于均衡斜线的像素段；默认 `Shift+Ctrl` 连接线时约束到允许方向，阶梯数值可在铅笔属性栏或编辑首选项调整。

### 5.3 抖动笔刷与图片笔刷

基础笔刷旁的抖动按钮可选棋盘、方向或 Bayer 模板，再用步进按钮切换密度阶段；再次点击当前模板关闭。抖动图案按画布像素对齐，并受笔刷形状限制。

打开“窗口 > 栏目 > 图案笔刷”，通过添加按钮或拖入图片导入。选中图片笔刷即可绘制；再次点击唯一选中的笔刷，或切回基础形状，可退出图片笔刷。

也可先建立选区，按 `Ctrl+B` 创建图案笔刷。新笔刷保留原图颜色与透明度，成功后自动切换到铅笔。导入与创建的笔刷宽、高均不能超过 `256 px`，按原始尺寸使用。

| 图片笔刷模式 | 效果 |
| --- | --- |
| 油漆笔刷 | 沿路径盖章，后一个图案覆盖前一个图案的非透明区域 |
| 图案与来源对齐 | 图案固定在来源坐标，同一位置保持相同纹理 |
| 图案与目标对齐 | 用首次落点确定图案平铺起点 |

普通导入图片保留自身颜色；从选区生成的笔刷在改变绘画颜色后，可将浅色映射前景色、深色映射背景色。图案笔刷支持多选、排序和删除，删除本地笔刷文件前会确认；新建的本地笔刷不自动打包进当前工程。

### 5.4 压感与速度动态

在铅笔或橡皮擦的笔刷动态设置中，分别给大小、强度等效果选择压力或速度输入，设置输入范围、输出范围、曲线及正反方向。铅笔还可设置从背景色到前景色的动态渐变和抖动。

例如让压力控制大小与不透明度，可得到轻压细浅、重压粗实的笔触。颜色渐变 `0%` 对应背景色，`100%` 对应前景色。图片笔刷保持固有尺寸，但仍可使用适用的强度和颜色动态。

需要使用笔压时，同时检查“首选项 > 平板与触控”的笔压开关。鼠标没有真实笔压时，不能用其默认压力值代替压感笔。

### 5.5 对称绘制

在工具属性栏启用水平、垂直、斜向或旋转对称；可组合使用。拖动轴线或中心改变对称位置，在更多设置中调整轴线外观、锁定或复位中心。

对称绘画会把操作映射到对应位置。选区工具也支持其可用的对称轴。矩形画布中超出有效范围的镜像部分不会写入；对称预览的指针不一定在每个副本重复显示。

### 5.6 填充、智能闭合与纹理

油漆桶的连续模式只填相连区域，关闭连续后可处理相同条件的分散区域。容差越高，允许纳入的颜色差异越大。先框选再填充，只影响真实选区内像素。

线稿有小缺口时，启用智能闭合并调整阈值，软件按虚拟边界限制填充；魔棒也可使用智能闭合。若范围不合适，先撤销，再减小阈值或补线。

裂纹、木纹、颗粒与程序纹理从油漆桶属性中选择；按纹理类型调整尺寸、抖动和抗锯齿。系统纹理用于区域填充，与铅笔的图片笔刷是不同功能。

径向渐变默认拖出椭圆包围范围，`Ctrl` 从首次落点向四周扩展，`Shift` 锁为圆形；两键可组合。线性渐变沿拖动方向过渡。

## 6. 颜色与调色板

### 6.1 选色与前背景色

颜色栏目可切换月环、饱和度/明度方形、色相/饱和度方形、色轮和法线调色盘。色相吸附限制可选色相段，颜色级数限制饱和度、明度或透明度层级，适合有限色创作。

点击前景色或背景色色块打开数值编辑器，输入 HEX 或使用颜色通道。常用模式包括 HSV、RGB、LAB、GRAY 和按项目调色板取色的 PLT；其他模式可在首选项启用。`X` 交换前背景色；两种颜色在工程之间共享。

颜色弹窗默认失焦关闭；拖动标题后可保持常驻。HEX 可使用六位颜色或带透明度的八位值，右键 HEX 输入框可读取合法剪贴板颜色。

### 6.2 整理调色板

左键色格设前景色，右键设背景色。解锁调色板编辑后可编辑、添加和删除颜色；使用 `Ctrl`、`Shift` 多选，再排序、反向排列或生成渐变。自定义布局可按二维位置摆放色格并保留空槽。

“排序与渐变”提供色调、饱和度、明度、亮度、RGB 通道和 Alpha 排序，以及升序/降序、普通渐变和色调渐变。`Ctrl+滚轮` 改变色格大小。

“提取颜色”从当前画面生成色板，可新建临时色板、替换当前色板或追加颜色，并限制数量。新色板要通过“保存色板”写入本地才能长期复用，也可保存为 PNG 色卡。本地色板选择器支持打开目录和刷新，内置色板不可删除。

### 6.3 同步颜色与替换颜色

“调色板操作 > 同步颜色”开启后，修改色板颜色会替换全部未锁定图层和帧中 RGBA 完全相同的像素。索引模式通过色板直接改变所引用颜色。

“编辑 > 替换颜色”（`Ctrl+Shift+K`）可选择来源色和替换色，并选择文档、选区、所选图层、帧、cel、调色板或已有循环节等可用范围。先确认目标范围，再按需开启预览并执行。

吸管属性栏的“当前图层替换”和“全局替换”直接按前景色 → 背景色替换。按住 `Alt+S` 后左键取色，可以把最终前景色加入调色板。

### 6.4 三种颜色模式

| 模式 | 用途 |
| --- | --- |
| RGBA | 直接编辑颜色与透明度，适合自由绘画和半透明效果 |
| 索引 | 像素引用调色板颜色，适合色板管理与有限色作品 |
| 灰度 | 以灰阶进行绘画，适合明暗稿和灰度素材 |

通过“图像 > 颜色模式”转换。转换会改变工程颜色数据；仅检查明暗时，应使用相对明暗视图。

## 7. 选区、移动与变换

### 7.1 建立与组合选区

| 工具 | 方法 |
| --- | --- |
| 矩形 `M`、椭圆 `Shift+M` | 拖动创建；`Ctrl` 中心创建，`Shift` 在创建过程中约束比例；矩形可设圆角 |
| 套索 `Q` | 拖动勾勒任意轮廓，松开闭合 |
| 多边形套索 `Shift+Q` | 单击逐点，点击起点、双击或 `Enter` 完成，`Esc` 取消 |
| 魔棒 `W` | 点击按颜色取样，设置容差、连续性和智能闭合 |

属性栏可选新建、加选、减选和交集。开始选择前按住 `Shift` 临时加选；右键默认减选。从已有选区内部加选时也适用。

`Ctrl+A` 全选、`Ctrl+D` 取消选择、`Ctrl+Shift+I` 反选。`Ctrl+H` 仅隐藏蚂蚁线，选区仍限制绘画。

矩形框选双击可选择当前网格单元，第二次按下后继续拖动可选连续单元。时间轴中 `Alt+左键` 点击 cel 可选中其非透明内容，`Shift+Alt` 将其加入现有选区。

### 7.2 移动与复制

拖选区内部移动像素，拖选框边缘只移动选框；`Ctrl+拖动` 复制选区内容，`Shift` 约束水平或垂直方向。确认前内容保持浮动，可继续调整位置；`Enter` 确认，`Esc` 取消当前变换。

移动工具 `V` 移动图层当前帧内容，开启“自动选择图层”后可按画布内容命中图层。`Shift` 点击追加 cel 选择，拖动已选内容可统一移动；`Alt` 拖动可复制图层。

`Ctrl+C`、`Ctrl+X`、`Ctrl+V` 复制、剪切、粘贴。`Ctrl+Shift+V` 粘贴为新图层；“编辑 > 选择性粘贴 > 粘贴为新项目”创建独立工程。删除选区内容会清除像素，不只是去掉选框。

### 7.3 缩放、旋转与翻转

`Ctrl+T` 进入内容变换。拖控制点缩放，在旋转区域拖动旋转；按当前交互位置也可进行倾斜。缩放时 `Shift` 保持比例、`Ctrl` 按整数倍、`Alt` 围绕轴心两侧变换；旋转时 `Shift` 按 45° 吸附。

“选择 > 自由变换”是另一种已有选区的四角自由比例缩放入口，只保留四个角点，不用于旋转或倾斜。

“选择 > 变换”的水平/垂直翻转会实际翻转内容，默认 `Shift+H` / `Shift+V`。多选普通图层或图层组，再选择多个帧，可统一变换这些图层与帧的组合，保留各自图层结构。混入文本、瓦片、自由瓦片、隐藏或锁定目标时，组合变换会被阻止。

### 7.4 描边、抗锯齿与选区转换

不建立画布选区时，也可以先在图层栏或时间轴选择目标，再用 `Shift+H` / `Shift+V` 批量镜像：选中单元格只处理这些格子；仅选图层处理这些图层的全部帧；普通单击帧头会替换原图层选择，处理所选帧的全部可编辑图层；选中图层后按 Ctrl/Shift 追加帧时处理两者交集。整批操作只需一次撤销，镜像后保留原选择和当前帧。普通像素围绕各 cel 自身表面翻转并保持位置；关联内容不会重复翻转。隐藏、锁定及文本图层不参与这项整格操作；自由瓦片保持实例镜像语义。

“选择 > 描边”（`Shift+O`）为选区内内容描边；没有选区时处理当前图层的非透明内容。设置颜色、宽度、内外位置、形状和像素方向；智能色相可按来源颜色生成描边。与图层样式的区别是，这里产生实际像素编辑。

“编辑 > 自动抗锯齿”根据轮廓生成过渡像素，可使用自动选色、设置不透明度、选择画布或调色板颜色，并决定是否处理内部颜色边界。先用选区限制范围，预览满意后应用。

“选择 > 转换为”可创建图案笔刷或背景预设。背景预设保存当前可见合成内容，非矩形选区外保持透明，之后可用于新建背景图层。

## 8. 图层、图层组与背景

### 8.1 图层管理

用“图层 > 新建图层”或 `Shift+N` 创建。点击图层行选择，`Ctrl` 增减选择，`Shift` 按显示顺序连续选择。拖动排序，拖到组中归组，按 `Alt` 拖动复制。

眼睛控制显示，锁控制编辑。按住眼睛或锁拖过多行，可连续设置；`Alt` 点击可批量作用于同级对象。双击或从右键打开属性，修改名称、不透明度、混合模式、显示颜色和描述。

显示颜色只用于图层列表标识，不会改变作品像素。多选后打开属性，只把实际修改的字段应用到所选对象。

### 8.2 图层组与剪贴蒙版

选择对象后按 `Ctrl+G` 建组，或用“图层 > 新建图层组”。图层组可嵌套，统一移动、复制、显隐、锁定或添加样式；`Ctrl+Shift+G` 解组并保留成员。

右键图层或组启用剪贴蒙版，将其显示范围限制在同级紧邻下方对象的可见形状内。适合在底色轮廓内画阴影、高光；将剪贴对象放到正确基底上方即可。

普通且完全不透明的组按穿透方式合成；修改组不透明度或混合模式可让组整体参与合成。“累积混合”提供另一种组与底部内容的混合计算方式，可开启后观察效果。

### 8.3 复制、删除与合并

复制图层包含全部帧内容；删除图层移除整条轨道。跨工程复制图层或组会保留可支持的层级、位置和属性。`Delete` 的对象取决于最后操作区域，删除前应确认焦点位于图层栏。

| 命令 | 操作结果与条件 |
| --- | --- |
| 向下合并 | 将当前图层与同级下方图层合成；当前开发版逐帧保留合并结果 |
| 合并所选图层 | 合并同级、连续、可见且未锁定的所选图层，逐帧生成结果 |
| 合并图层组 | 将所选组的内容合成为一个图层 |
| 合并可见图层 | 合并参与显示的图层 |
| 解组 | 移除分组关系，保留独立图层 |

当前实现中，“合并图层组”和“合并可见图层”仍按活动帧生成结果；多帧动画需要保留其他帧时，请使用已逐帧处理的向下合并或合并所选图层，不要把这两项当作全动画合并。

### 8.4 背景图层与类型转换

右键“新建 > 新建背景图层”，选择纯色、网格、条纹、菱形、圆形或已有预设。背景位于根层底部，名称带下划线，仍可绘画、显隐和导出。

普通像素图层可转换为背景；扩大画布时，背景按既有重复单位延展。吸管从普通图层取色时忽略背景，以便保留前景透明度；选择背景图层后可正常取背景合成色。

“转换为”可选择普通图层、背景图层或瓦片图层。转换为普通图层将文本、瓦片或启用的样式结果烘焙成像素，适合后续直接绘画。转换可撤销，但保存为普通图片后不能恢复这些工程结构。

## 9. 动画、单元格与循环节

### 9.1 理解图层、帧和 cel

图层是横向贯穿动画的轨道；帧是一列完整画面；cel 是一个图层在一帧中的内容。绘画修改当前 cel，删除帧则删除该列各图层的内容。

动画控制与帧格集成在图层栏目中。看不到帧列时，在图层设置关闭“隐藏时间轴”；隐藏期间播放和相关操作停用，但帧数据仍保留。

### 9.2 创建、排序与播放

新增帧按钮默认复制当前帧，产生可独立编辑的副本。右键帧头可新建空白帧、复制或删除；空白帧默认 `100 ms`。双击帧头修改时长；多选帧后可批量处理或拖动排序，至少保留一帧。

按 `Enter` 播放/暂停；选区变换、文本输入或弹窗会优先使用该键。逗号、句号切换前后帧；没有选区时左右方向键也可切帧。播放中第一次按切帧键先停止，再按才切换。

右键播放按钮可选播放一次、循环全部帧、播放标签并重复，设置 `0.25x–3x` 倍率和停止时返回开始帧。倍率只影响预览速度，不改写每帧保存的时长。

禁用帧会保留内容供编辑，但正常播放跳过它；可从帧相关命令重新启用。

### 9.3 cel 的选择、复制与关联

在帧格选择一个或多个 cel，通过右键复制、粘贴、删除或拖到目标格。复制帧包含该帧所有图层，复制 cel 只处理选中的格子。双击有内容的 cel 可设置单元格不透明度；文本 cel 双击进入文本编辑。

关联 cel 共享内容，修改任一关联成员会同步同组帧。使用关联帧或链接命令建立关系；需要独立修改时断开链接。普通复制产生独立副本，适合逐帧改画。

### 9.4 洋葱皮

在图层栏开启洋葱皮，用淡色叠加相邻帧作为动作参考。设置显示范围、透明度、前后帧颜色，以及播放期间是否显示。洋葱皮仅供观察，不会进入最终图片。

### 9.5 循环节

选择连续帧，右键帧头创建命名循环节，例如“待机”“行走”。双击循环节括号编辑名称、起止帧、正反方向和重复次数；拖动括号边界可调整范围。

右键循环节“播放循环节”按其次数播放。右键播放按钮选择“播放标签并重复”，则根据当前帧选取最内层循环节并持续循环；当前帧不在循环节内时循环全部帧。

在循环节内新增帧会延续其范围。循环节也可作为 GIF、精灵表或补间的来源范围。

## 10. Tilemap 瓦片地图

### 10.1 创建图层与复用瓦片集

右键图层 > 新建 > 新建瓦片图层，输入名称和瓦片宽高。选择已有瓦片集时沿用其尺寸，并让多个图层共享；选择新增则建立新的瓦片集。

普通或背景图层可通过“转换为 > 瓦片图层”按网格切分全部帧；相同图块复用，边缘不足一块时补透明，画布外内容不保留。文本或启用样式的内容应先转为普通图层。

### 10.2 四种编辑模式

| 模式 | 怎么操作 | 对其他引用的影响 |
| --- | --- | --- |
| 原位编辑 | 用像素工具直接修改已有瓦片 | 所有引用该瓦片的位置同步更新 |
| 变体创建 | 修改当前格子的图案 | 创建或复用变体，只替换当前格引用 |
| 混合编辑 | 在已有格中改图，在空格中绘制新内容 | 已有瓦片改动同步引用，空格结果创建或复用瓦片 |
| 绘制瓦片 | 从瓦片集选图块，在画布按整格铺设 | 修改格子引用，不修改瓦片原图 |

新建后默认混合编辑。点击瓦片集中的实际瓦片会进入绘制瓦片；左键选择前景瓦片，右键选择背景瓦片，画布左右键分别铺设。该模式的吸管拾取瓦片引用，橡皮擦清除格子。

### 10.3 整理与移动

瓦片集支持多选、删除、拖动调整槽位与 `Ctrl+滚轮` 改显示大小；拖动排序不会改变画布引用。按住 `Ctrl` 可查看瓦片编号。瓦片集至少保留一个瓦片。

绘制瓦片模式下，选区会扩展为整格，移动按瓦片宽高吸附。移动整个图层只改变当前 cel 的位置，不改变瓦片原图和格子规格。

同一瓦片集可被多个图层引用，编辑前先确认模式，避免本想制作单个变体却改动所有引用。自由瓦片的任意位置实例工作流见第 1 章。

## 11. 图像调整、滤镜与尺寸

### 11.1 色彩调整

从“编辑 > 调整”打开工具，设置参数并检查实时预览，确认后形成一次可撤销修改。有选区时限制在当前图层选区；没有选区时处理所选图层。

| 调整 | 作用 |
| --- | --- |
| 色彩平衡 | 分别调整阴影、中间调和高光中的青/红、洋红/绿、黄/蓝，可保持明度 |
| 亮度/对比度 | 改变整体亮暗及明暗差距 |
| 色相/饱和度 `Ctrl+U` | 调色相、颜色浓度和 HSL 明度；明度两端趋向黑与白 |
| 曲线 `Ctrl+M` | 点击添加控制点、拖动改变色调关系，可分通道调整并删除中间点 |

### 11.2 显示器风格滤镜

“编辑 > 滤镜”提供 CRT 经典隔行、RGB 荧光栅、交错栅格、VHS 色彩偏移、暗角和荧光绿辉光。预设产生效果图层，可通过图层显隐、不透明度或混合模式调整强度。

LCD 屏幕滤镜需选择一个图层，再设置通道偏移宽高和扫描线类型。应用后生成可管理的效果结构；可从历史记录撤销。它用于视觉风格处理，不是画布显示缩放选项。

### 11.3 画布大小、图像大小、裁切和修剪

| 命令 | 用途与操作 |
| --- | --- |
| 调整画布尺寸 `C` | 改工作边界，设置尺寸、锚点或四边边距；“同步四边”统一边距。开启“裁掉画布外的内容”才明确丢弃越界内容 |
| 调整图像尺寸 `Ctrl+Alt+I` | 缩放整幅内容，设置宽高和插值。保留像素边缘时选最近邻，需要平滑时选双线性 |
| 检测像素倍率 | 在图像尺寸窗口识别已被整数放大的像素图，识别后按倍率缩回并采用最近邻；纯色或缺少可靠特征时可能无法判断 |
| 图像 > 裁切 | 以当前选区确定画布范围 |
| 图像 > 修剪 | 以当前帧或所有帧的有效内容去掉透明边缘 |

动画需要统一边界时使用“按所有帧修剪”，避免按单帧范围排除其他帧的内容。

## 12. 切片与素材拆分

切片用于给画布区域命名，并按区域导出图标、按钮或其他素材，不会自动切开原图层。

1. 选择切片工具 `Shift+C`，在画布拖出区域。
2. 选中切片，在属性栏或切片属性中修改名称、位置和尺寸。
3. 拖动切片或其边界调整范围；用全选及删除等命令管理切片。
4. 规则素材表可打开“自动切片”，设置切片尺寸、起始位置和水平/垂直间距，检查预计数量后创建。
5. 导出时把区域设为切片，再选全部切片或指定切片。精灵表也可使用具名切片作为区域。

通过“窗口 > 显示 > 显示切片边框”控制辅助边框。切片批量输出目前不使用 GIF 动画格式。

## 13. 保存、图片导出与精灵表

### 13.1 选择合适的文件格式

| 格式 | 主要用途 | 需要了解的限制 |
| --- | --- | --- |
| `.moonsprite` | 保存完整可编辑工程 | 跨电脑携带本地缩时录像时需另存并勾选携带录像 |
| `.ase` / `.aseprite` | 与 Aseprite 交换支持的图层和动画内容 | 不应作为 MoonSprite 专有数据的唯一原稿，原稿另存 `.moonsprite` |
| PNG 自动索引 / PNG RGBA | 透明静态图片 | 图片不能保留全部工程编辑结构 |
| JPEG | 不需要透明度的展示图 | 有损格式，透明区域使用不透明背景 |
| WebP | 静态图片分享 | 根据导出结果用途选择；不等同于工程文件 |
| SVG | 输出矢量容器形式的像素画 | 不是把像素图自动识别成可编辑曲线路径 |
| GIF | 帧动画 | 受 GIF 的颜色和透明度表达限制 |
| PSD | 与 Photoshop 交换当前帧的图层结构 | 当前仅导出、不支持打开；不输出动画时间轴，文本和瓦片写为栅格 |

直接打开单层单帧图片后，如果只改像素，普通保存可覆盖来源图片；添加图层、帧、文本、蒙版等结构后，普通保存会转为工程保存。另存为始终按明确选择的格式进行。

### 13.2 导出单图、区域与 GIF

1. 打开“文件 > 导出 > 导出为”（`Ctrl+E`）。
2. 选择文件格式、文件名和目录。
3. 选择导出区域和可用的图层范围；按需选择画布、帧或切片。
4. 设置倍率及修剪方式。像素展示图通常使用整数倍率。
5. GIF 选择所有帧、指定帧范围或循环节，并设置正向、反向或往复方向。
6. 点击“导出”，或选择“导出并打开文件夹”。

“单独修剪”分别去掉各目标透明边缘；“统一修剪”让本批目标使用同一边界，适合保持动画对齐。导出预设可保存常用格式、倍率、范围和路径等配置。工程会记住成功导出的设置。

PSD 只支持当前帧完整画布，可保留支持的组层级、显隐、透明度、混合模式、剪贴关系、蒙版和可映射样式。

### 13.3 导出所有帧

“文件 > 导出 > 导出所有帧”按时间轴顺序生成连续编号的独立图片，复用相应格式、倍率和目录设置。适合引擎导入、后期合成或逐帧交付；GIF、PSD 不作为此命令的逐帧图片格式。

### 13.4 导出精灵表

打开“文件 > 导出 > 导出精灵表”，依次设置：

| 设置区 | 操作 |
| --- | --- |
| 布局 | 选择水平条幅、垂直条幅、按行或按列；可限制列数、行数、总宽度或总高度 |
| 精灵图 | 选择画布或切片，图层范围以及全部/已选/循环节帧；按需要拆分图层或循环节 |
| 输出 | 选择预览与是否输出文件，设置 PNG 名称和目录 |

“合并重复项”让相同帧共用一个矩形；“忽略空缺项”不为透明空帧分配区域。拆分目标按设置排列并追加在同一张精灵表中，不是自动输出多个文件。

开启预览可查看排版，修改设置会刷新临时结果；关闭窗口后临时预览关闭。关闭“输出文件”时生成一个未保存的单图层工程，便于继续处理；开启则写出 PNG。此流程不应被理解为自动生成游戏引擎专用动画配置。

## 14. 工作区、分屏与预览

### 14.1 栏目与工作区

通过“窗口 > 栏目”显示颜色、调色板、图层、历史记录、图案笔刷、瓦片集和预览。右键栏目标题可隐藏、停靠到左右或底部，或设为悬浮；拖动标题和分隔线也可调整。

使用工作区管理入口保存当前布局、切换或复位。布局修改自动保存；复位恢复该工作区创建时的布局，默认工作区不能删除。

默认数字键 `1–6` 分别临时呼出颜色、调色板、图层、预览、瓦片集和图案笔刷。点击外部、按 `Esc` 或再次触发即可收回，不改变原停靠布局；已经悬浮的栏目不使用这种临时呼出方式。

工具栏可从“窗口 > 工具栏位置”放在四边。首选项中的快捷指令栏设置可配置显示、按钮和排列；按钮作用于所属工程。

### 14.2 工程分屏与浮窗

将项目标签拖入画布的上、下、左、右区域，出现停靠提示后松开，建立分屏；拖分隔线改变比例。点击某个画布后，其工程成为当前编辑目标。

右键项目标签可把视图浮出为工作区内的项目窗口，也可从浮窗返回标签栏。分屏、浮出与返回改变显示位置，不复制磁盘文件。

### 14.3 预览与历史记录

预览栏目可独立缩放，适合一边放大修像素，一边观察整体。开启“跟随画布视窗”会跟随主画布位置；手动拖动预览会退出跟随。预览的播放按钮可独立检查动画。

历史记录栏目显示可到达的编辑步骤，点击某项顺序撤销或重做到该状态。退回较早状态后继续绘画，会清除后续分支。缩放、平移、镜像和布局不属于作品修改，不在此撤销。

### 15.2 主题

在主题设置选择现有主题，或新建、复制自定义主题。编辑基础色可调整界面配色；网格、棋盘格、洋葱皮等辅助视觉可单独覆盖或恢复“跟随主题”。

内置主题只读，编辑时建立自定义副本。使用导入、导出保存和分享主题配置。

### 15.3 快捷键

“编辑 > 快捷键设置”按分类查找命令，录入一个或多个组合，可包含键盘、鼠标中键/侧键和滚轮。每种工具还有“快速选择”项，按住临时切换，松开恢复。

修改冲突时留意占用提示；工具之间共享按键可用于循环切换。点击完成才提交整个草稿，取消不保存。快捷键配置可导入、导出 JSON。

画布内滚轮快捷键只在画布区域触发，输入框中的编辑键保持输入行为。右键绘画/擦除等动作通过设备设置配置，不作为普通快捷键录入。

## 16. 脚本与扩展

### 16.1 运行 Lua 脚本

打开“文件 > 脚本 > 打开脚本文件夹”，把 UTF-8 的 `.lua` 文件放在该目录第一层，再重新打开文件菜单，从脚本列表执行。

脚本可提供批量绘制、资源处理或自定义弹窗。MoonSprite 支持部分 Aseprite 风格 Lua 接口和专用 `mse.*` 接口，但并非所有 Aseprite 脚本都能直接运行。普通像素目标、图层类型和当前帧等限制会影响可执行范围，失败时查看结果提示。

详细接口与示例见 [Lua 脚本说明](scripting/README.md)。脚本受到宿主限制，不直接开放任意系统文件、网络或进程能力。

### 16.2 安装与管理扩展

1. 在“首选项 > 扩展与脚本”的扩展管理中安装 `.msext`，也可将包拖入软件；已配置文件关联时可双击安装。
2. 启用扩展后，在其声明的位置找到菜单、栏目或窗口。
3. 使用扩展自己的设置入口调整业务参数。
4. 需要停止时禁用，或在扩展管理中卸载、打开扩展文件夹。

扩展可能提供 Lua 命令、宿主栏目或常驻界面，具体功能取决于安装的包。软件没有固定的顶层“扩展”菜单，入口由扩展贡献决定；新运行时扩展需要匹配宿主版本。

开发或制作扩展见 [.msext 扩展说明](extensions/README.md) 与 [Runtime API](extensions/runtime-api.md)。

### 16.3 帮助与诊断

“帮助”提供关于、更新日志、未来计划和诊断日志入口。更新日志说明已发布版本，未来计划不等于当前可用功能。遇到问题时记录软件版本、复现步骤与相关提示，再按需打开诊断日志。

首页提供项目主页、社区等外部链接及语言切换。使用统计等辅助功能可从相应设置入口查看或控制，不影响画稿内容。

## 17. 常见问题

| 现象 | 检查或处理 |
| --- | --- |
| 画笔画不出来 | 检查图层是否隐藏/锁定、是否选中组、是否停在文本层、是否有很小或隐藏的选区，以及动画是否正在播放 |
| 改一处，其他位置也变了 | 检查关联图层、关联 cel、共享瓦片和自由瓦片源；需要只改一个格时使用瓦片变体模式 |
| 取消蚂蚁线后还是只能画局部 | `Ctrl+H` 只隐藏边框；按 `Ctrl+D` 才取消选区 |
| 移动选区却没有移动图像 | 可能拖到了选框边缘；拖内部移动内容，或用移动工具移动图层 |
| 删除了意料之外的对象 | 删除、复制和粘贴按当前焦点解释；先点击画布、图层、色板或瓦片集中的目标区域 |
| 新增帧不是空白 | 新增按钮默认复制当前帧；右键帧头选择新建空白帧 |
| 动画时间轴不见了 | 检查图层设置的“隐藏时间轴”，不是删除了帧 |
| 导出的图没有图层 | PNG、JPEG 等是图片；保留原稿请保存 `.moonsprite` |
| PSD 打不开 | 当前支持输出 PSD，不支持将 PSD 作为输入工程 |
| 换电脑后文字外观变化 | 安装或导入工程使用的同名字体 |
| 换电脑后缩时记录不可用 | 在原电脑另存为并勾选携带缩时录像；普通保存可能只引用本机录像库 |
| 清空缩时记录后磁盘空间没增加 | 清空只移除工程记录清单，不删除本机录像库数据 |
| 旋转/镜像后导出仍是原方向 | 使用的是视图命令；要改变像素应使用内容变换 |
| Ctrl+Y 没有重做 | 默认 `Ctrl+Y` 为相对明暗，重做是 `Ctrl+Shift+Z` |
