# 坐标与渲染契约

中文 | [English](coordinates-rendering.en.md)

## 坐标空间

- 屏幕坐标：窗口指针事件的 CSS 像素。
- 视图坐标：画布工作区内部、应用平移前的 CSS 像素。
- 画布坐标：文档像素坐标，受缩放和视图旋转影响。
- 图层坐标：画布坐标减去图层偏移，可存在于画布边界之外。

转换方向固定为：

```text
screen -> viewport -> inverse view rotation -> canvas -> layer
layer -> canvas -> view rotation -> viewport -> screen
```

## 不变量

- 所有工具、选区、预览、吸色和指针命中必须复用同一转换函数。
- 视图旋转的几何中心由“指针附近”或画布中心模式决定。“指针附近”在按下旋转时固定指向标，并以该指向标为旋转中心；画布中心模式继续使用平移后的画布中心。指向标必须限制在视口内，旋转过程不得随指针漂移。
- 缩放围绕指定锚点进行，切换抓手或旋转工具后不得出现视图回弹。
- 主画布平移在所有缩放倍率下统一使用 `50%` 边界：画布大于视窗时，四边最多移动到视窗中心；画布小于视窗时，四边最多移出自身的一半。旋转与镜像状态按最终显示外接范围计算限制。
- 视图镜像仅应用于主画布和选区叠加层的最终渲染；即使旋转角度为零也必须立即生效。输入先反解旋转再反解镜像，因此画笔、选区、吸色、平移和缩放仍落在用户看到的位置，不修改文档像素。水平和垂直镜像可以独立组合。
- 平铺预览先复用统一的屏幕到画布逆变换，再只对启用的水平或垂直轴执行正模取余。关闭时坐标保持恒等；重复副本的可见偏移、当前指针所属副本与输入回绕必须由 `core/tilemap.ts` 的统一几何函数计算，组件不得各自推导。工具实时像素、边缘和操作线预览显示在全部可见平铺副本，鼠标指针本身只显示一份；指针捕获期间即使越过最外侧可见副本也继续回绕，直到松开后恢复普通命中。跨重复边界的 Tilemap 拖动按环形网格最短路径补齐格子，不能在原画布中间产生一条长连线。
- ISO 参考线和直线吸附统一由 `core/isometric.ts` 提供。参考线先在文档坐标中按全局配置的阶数、参考线位置和单位尺寸生成两组 `N:1` 线段，再使用每个平铺副本的画布原点和当前缩放映射到视图；旋转与镜像继续由画布最终显示变换统一处理，组件不得另算另一套 ISO 坐标。强制对齐必须使用同一阶数，先在当前重复副本对应的文档坐标中确定端点，再沿现有平铺回绕和像素写入路径提交。
- 图层与选区移动吸附统一由 `core/alignment.ts` 在文档坐标中计算。输入只接收移动语义边界、预先收集的目标边界、画布尺寸、自定义网格和经 `CSS 阈值 / zoom` 换算的文档阈值；整数拖拽下该阈值最低为 `1` 个文档像素，避免高倍缩放时没有任何非零整数候选。组件不得按旋转、镜像或屏幕方向重建候选。智能吸附匹配外边缘与中心，网格吸附只匹配外边缘，任何候选都必须保持整数文档位移；`Shift` 轴锁在吸附前确定，未锁定轴不参与候选。辅助线复用 `createCanvasRenderPlan` 的画布原点与 selection overlay 的最终旋转/镜像变换，且不写入合成缓存、工程数据或撤销历史。
- 视图变换的正向顺序固定为“绕同一枢轴旋转，再执行水平/垂直镜像”；缩放锚点补偿必须复用该顺序，不能在组件内自行交换矩阵步骤。
- 像素写入使用向下取整后的文档坐标；选区手柄、边缘和旋转区命中使用未取整的连续文档坐标，禁止先取整再判断屏幕距离。输入命中与预览必须共享同一视图逆变换。
- 自由瓦片实例位置使用 cel surface 本地整数像素锚点，源自身的整数偏移与源像素坐标先绕该锚点执行顺时针整 `90°` 旋转，再执行水平和垂直镜像；反向命中按严格相反顺序映射。实例边界、像素合成、命中、闪烁提示和源编辑必须统一复用 `core/free-tile.ts` 的正反变换，非正方形源在 `90°` 或 `270°` 时交换显示宽高。文档命中先减去 surface 偏移，再按实例数组从后向前选择最上层实例；属性变换通过补偿实例锚点保持用户看到的外接框左上角不跳动。放置原点由指针文档像素、源动态宽高、源偏移与同一 surface 偏移统一计算，不得吸附 Tilemap 网格或在组件内维护另一套坐标。实例选区变换保持选区与控制点使用文档坐标，只在进入共享源编辑时通过 `core/free-tile-edit.ts` 按当前实例朝向生成临时源栅格，翻转轴坐标也必须随同转换；源结果裁切后执行逆变换写回规范源坐标，再通过源偏移同步到全部实例，兄弟实例不得生成额外选区坐标。图层或动画 cel 移动只改变 surface 偏移；源编辑裁切透明边缘时通过源偏移保持既有实例的视觉锚点；调整画布或图像尺寸时由核心自由瓦片模块统一重映射源、实例并重新生成派生 surface。
- 画布旋转后不得出现像素内部描边、白线或图块接缝。
- 高 DPI 工具预览的相邻文档像素必须共享同一设备像素边界；矩形边界按 `devicePixelRatio` 对齐后再换回 CSS 坐标。旋转离屏画布回绘时使用实际 backing 尺寸除以 DPR，不得把向上取整后的设备像素再次压回理论 CSS 尺寸。
- 主画布逻辑视口使用抵消界面倍率后的设备像素单位：CSS 视口尺寸和指针坐标先乘界面倍率，Canvas backing 比例使用浏览器 `devicePixelRatio / 界面倍率`。因此界面倍率不得进入文档缩放语义，画布 `100%` 始终保持一个文档像素对应一个设备像素；平移、旋转、缩放锚点、选区命中和自动平移必须共用同一补偿。
- 蚂蚁线和变换手柄使用屏幕像素绘制，缩放后保持清晰，不参与像素图层合成。蚂蚁线固定使用 `1 CSS px` 线宽和 `6 CSS px` 明暗节距；短边界段按屏幕位置错开动画相位，禁止在低缩放的大画布上同步闪烁或随画布倍率变细。
- 画布左下角尺寸和镜像提示共用同一前景色；根据提示位置下方的合成像素、透明棋盘或工作区背景亮度选择深色或浅色，不写入文档像素。
- 曲线调整器的直方图只从调整开始时的活动图层快照统计，作为半透明编辑辅助，不写入文档、不参与调整结果。

## 渲染层次

推荐顺序：背景、画布边界、合成像素、网格、选区预览、变换预览、工具预览、指针辅助。每层必须独立控制更新频率，平移和缩放不得重复重算不变的像素数据。

- `core/canvas-render-plan.ts` 统一计算反解旋转与水平/垂直镜像后的可见范围、离屏场景边界、画布原点和可见文档像素；组件不得再复制这些计算。镜像枢轴偏离视口中心时，离屏场景也必须覆盖镜像后的完整视口。
- 调整画布尺寸预览固定按“新增区域棋盘、图层内容、旧画布外黑色遮罩、边界线”绘制，确保原本位于画布外的图层像素可见但仍明确标识为新增画布区域。
- `CanvasStage` 的绘制尺寸由 `ResizeObserver` 缓存。Canvas 元素的 CSS 显示尺寸必须固定为最后一次实际绘制使用的 CSS 像素尺寸，直到下一次重绘再同步更新，禁止在分栏或浮窗缩放期间把旧 backing bitmap 非等比拉伸。指针命中仍读取实时屏幕边界，避免停靠布局变化后坐标失真。
- `CanvasCompositeCache` 的最终显示来源必须是一张连续表面，禁止把 128 px tile 分别缩放后直接提交到主画布。小中型文档复用完整表面并按脏矩形局部更新；超出完整表面上限的文档先把当前可见文档区域合成为单张临时表面，再用一次 `drawImage` 输出。
- 平铺预览的每个可见副本复用同一文档合成缓存，只改变画布原点和可见文档范围；棋盘格、洋葱皮、像素网格和自定义网格必须与各副本使用相同的裁剪边界。选区变换与图层移动的临时合成按启用轴生成文档宽高的周期偏移，使越界内容出现在相邻副本；重复显示不得复制文档像素或产生额外历史状态。
- ISO 参考线与像素网格、自定义网格处于同一视图辅助层，每个可见平铺副本独立裁剪但共用同一参考线偏好。实线样式使用连续线段；像素线条样式使用与阶数和单位尺寸一致的可重复像素阶梯图案，并按画布缩放以最近邻方式显示。单个文档像素不足一个屏幕像素时允许回退到实线，低缩放时只按参考线单位尺寸的整数倍增加显示间距，不改变配置的 `N:1` 方向或参考线位置；参考线不得写入合成缓存、导出结果、工程数据或撤销历史。移动对齐辅助线位于选区叠加层并裁切到原画布，必须与选框延迟预览一起刷新；旋转与镜像继续由叠加层最终显示变换统一处理。
- 非整数缩放、连续绘制和半透明图层必须经过同一连续表面路径。缓存分块可以作为内部计算策略，但不得成为最终显示边界，也不得在邻接处重复叠加透明像素。
- 自由瓦片按实例顺序和各自旋转、镜像、混合模式、不透明度将源瓦片叠加到连续 cel surface，透明像素不覆盖下方实例；源瓦片变化后必须重绘所有引用该源的 cel，再由现有合成缓存统一显示。主画布、预览、缩略图和导出不得各自解释实例元数据。
- 画布性能探针默认不工作，只有自动基准注入 `window.__moonSpriteCanvasProbe` 时才记录主绘制和指针处理耗时。

任何坐标 Bug 修复都应包含未旋转、旋转、不同缩放、图层偏移和画布外内容五类测试。
