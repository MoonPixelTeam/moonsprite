# MSE API

中文 | [English](mse-api.en.md)

MSE（MoonSprite Extension）是 MoonSprite 的专属 Lua API。当前 API 版本为 `0.2.0`，处于 `experimental` 阶段；该版本描述 Lua 命名空间契约，不等同于软件版本号。

## 执行模型

- 查询方法立即返回脚本启动时的结构快照。持久对话框每次派发事件前会重新取得当前快照。
- 写入方法序列化参数并排队后返回 `true`；领域参数校验和实际执行发生在宿主应用事务时。它们不会把 Renderer 的可变 Store、DOM 或原生命令交给 Lua。
- `app.transaction(label, fn)` 中的像素修改和 `mse` 文档写入作为一个撤销步骤提交。任一操作失败时，当前事务内已经提交的文档改动会回滚。
- 创建或打开工程、保存、导出、导入本地笔刷、消息通知和栏目布局属于文档外操作，不进入当前工程撤销历史。
- 查询返回的表是副本。修改返回表本身不会修改工程，必须调用对应写入方法。
- 颜色使用 `{ r, g, b, a }`，通道范围为 `0-255`；图层不透明度也使用 `0-255`。
- ID 区分大小写。帧参数可以使用稳定帧 ID，也可以使用从 `1` 开始的帧序号。

## 能力发现

```lua
print(mse.apiVersion)                    -- "0.2.0"
print(mse.status.stage)                  -- "experimental"
print(mse.capabilities.layers.status)    -- "stable"
print(mse.isSupported("tiles.createLayer")) -- true
```

`mse.capabilities` 的每个模块包含：

- `status`：当前为 `stable`。
- `readOnly`：整个模块是否只读。
- `methods`：方法名称、`implemented` 和 `readOnly`。

## 文档 `mse.document`

### `info()`

返回当前文档及活动图层摘要：

```lua
local info = mse.document.info()
-- info.id, name, filePath, width, height, colorMode, frame, activeLayer
```

### `activeLayer()`

返回活动图层的结构信息，包括 `id`、`name`、`kind`、位置、尺寸、不透明度、混合模式、可见性、锁定、样式和瓦片资源 ID。

### `create(spec)`

新建工程：

```lua
mse.document.create {
  name = "Sprite",
  width = 64,
  height = 64,
  colorMode = "rgba" -- rgba / grayscale / indexed
}
```

### `open(path?)`

传入路径时打开该文件；省略路径时打开软件文件选择器。打开后的工程由 MoonSprite 正常解码和校验。

### `save(spec?)`

保存活动工程。`{ saveAs = true }` 使用“另存为”；也可通过 `options` 传入现有另存为设置模型。

## 图层 `mse.layers`

### `list()` / `get(id)`

返回普通、文本、瓦片和自由瓦片图层的结构信息。不会复制全部图层像素；当前活动图层的像素继续通过 `app.activeImage` 编辑。

### `create(spec?)`

创建空白普通图层，可设置 `name` 和 `opacity`。

### `duplicate(id)` / `remove(id)`

复制或删除指定图层，沿用软件现有的动画 Cel、共享资源和锁定检查。

### `update(id, patch)`

```lua
mse.layers.update(layerId, {
  name = "Outline",
  opacity = 192,
  blendMode = "multiply",
  visible = true,
  locked = false,
  x = 4,
  y = 8,
  description = "Generated by Lua",
  displayColor = { r = 41, g = 121, b = 255, a = 255 }
})
```

## 动画 `mse.animation`

- `frames()`：返回 `{ id, number, duration, disabled, active }[]`。
- `setFrame(frame)`：切换活动帧。
- `loops()`：返回动画循环节。
- `createLoop(spec)`：创建循环节。
- `updateLoop(id, spec)`：更新循环节。
- `removeLoop(id)`：删除循环节。
- `play(id?)`：传入循环节 ID 时播放该循环节；省略时播放全部动画。

循环节参数：

```lua
{
  name = "Walk",
  start = 1,       -- 或 startFrameId
  ["end"] = 8,    -- 或 endFrameId
  direction = "forward", -- forward / reverse
  repeatCount = 1         -- 省略/nil 当前默认重复一次
}
```

当前 Lua 写入适配器的循环方向仅处理 `forward` 和 `reverse`；界面已有的 `ping-pong` 与 `ping-pong-reverse` 不能据此推断为 Lua 写入能力。其他方向会落到正向默认值，脚本应只传本节列出的受支持值。

## 调色板 `mse.palette`

- `list()` / `get(id)`：查询调色板颜色。
- `create(spec)`：`{ color = color }`，也可以直接传颜色表。
- `update(id, patch)`：更新 `color` 或 `name`；第二个参数也可以直接使用颜色表或 `Color(...)`。
- `remove(id)`：删除颜色。
- `extract(spec?)`：从当前合成图像提取颜色。`limit` 为 `1-4096`；`mode` 为 `replace` 或 `append`。

## 瓦片 `mse.tiles`

### `listSets()` / `getSet(id)`

返回 Tileset 名称、网格尺寸、布局和稳定瓦片 ID。资源总像素不超过脚本快照预算时还会返回打包 RGBA `pixels`；超出预算时该字段为 `nil`，避免一次脚本复制超大资源。

### `createSet(spec)`

```lua
mse.tiles.createSet { name = "Terrain", tileWidth = 16, tileHeight = 16 }
```

### `createLayer(spec)`

```lua
mse.tiles.createLayer {
  name = "Ground",
  tileWidth = 16,
  tileHeight = 16,
  tilesetId = existingTilesetId -- 可省略
}
```

### `place(spec)`

在指定 Tilemap Cel 放置或清除一个单元格：

```lua
mse.tiles.place {
  layerId = layerId,
  frame = 1,
  column = 2,
  row = 3,
  tilesetId = tilesetId,
  tileId = tileId,
  rotation = 0,
  flipHorizontal = false,
  flipVertical = false,
  clear = false
}
```

### `edit(spec)`

替换一个瓦片的 RGBA 像素。`pixels` 可以是每像素一个打包 RGBA 整数、颜色表数组，或 `width * height * 4` 个通道值。

## 自由瓦片 `mse.freeTiles`

- `listSources()` / `getSource(id)`：查询当前活动自由瓦片图层的源瓦片。
- `createLayer(spec)`：创建自由瓦片图层；`freeTileSetId` 可复用工程内已有源集。
- `createSource(spec)`：在 `layerId` 指定的自由瓦片图层创建源，可设置名称。
- `place(spec)`：使用 `sourceId` 在 `layerId`、指定帧的 `(x, y)` 放置实例。
- `edit(spec)`：使用 `sourceId`、尺寸、偏移与 `pixels` 替换共享源；全部实例随源同步更新。

## 图案笔刷 `mse.brushes`

- `list()` / `get(id)`：返回工程笔刷和本地笔刷。工程笔刷在预算内会包含 `coverage` 与 `colors`。
- `importImage()`：打开图片选择器并导入本地图案笔刷。
- `createFromSelection()`：从当前选区创建工程笔刷。
- `remove(id)`：删除工程笔刷或已列出的本地笔刷。

脚本不能读取任意笔刷文件路径或原始文件字节。

## 选区 `mse.selection`

### `info()`

返回 `exists`、`empty`、`hasMask`、`selectedPixels` 和 `bounds`。

### `set(spec)` / `clear()` / `invert()`

```lua
mse.selection.set { x = 4, y = 8, width = 16, height = 12 }
```

可选 `mask` 是 `width * height` 个 `0-255` 值。

### `transform(spec)`

支持 `dx`、`dy`、`flipHorizontal`、`flipVertical`，复用当前选区移动与翻转历史。

## 切片 `mse.slices`

- `list()` / `get(id)`：查询切片。
- `create(spec)`：使用 `x`、`y`、`width`、`height` 创建切片。
- `update(id, patch)`：更新名称或矩形。
- `remove(id)`：删除切片。

## 图层样式 `mse.styles`

- `get(layerId?)`：查询指定或活动图层样式。
- `apply(layerId, styles)` 或 `apply { id = layerId, styles = styles }`：应用完整样式模型。
- `copy(layerId)` / `paste(layerId)`：使用软件共享的图层样式剪贴板。
- `clear(layerId)`：清除样式。
- `setEnabled { id = layerId, enabled = true }`：启用或停用现有样式。

样式对象与 `.moonsprite` 中的 `LayerStyles` 字段一致，非法尺寸、方向、颜色或枚举会被规范化或拒绝。

## 工作区 `mse.workspace`

- `listPanels()` / `getPanel(id)`：查询栏目 `visible` 和 `dock`。
- `showPanel(id)` / `hidePanel(id)`：显示或隐藏栏目。
- `setPanel { id, visible?, dock? }`：同时调整显隐和停靠。`dock` 为 `left`、`right`、`bottom` 或 `floating`。

栏目布局是本地界面状态，不写入文档历史。

## 文件操作 `mse.io`

- `open(path?)`：等同 `mse.document.open`。
- `save(spec?)`：等同 `mse.document.save`。
- `export(spec)`：使用软件现有导出模型，可设置 `name`、`format`、`directory`、`target`、缩放和 GIF 参数。路径与格式仍经过平台层校验。

## UI `mse.ui`

- `notify(text)`：在软件状态区显示消息。
- `alert(value)`：兼容 `app.alert`，文本会进入脚本结果提示。
- `dialog(options)`：创建与全局 `Dialog(options)` 相同的 MoonSprite 组件化对话框，支持现有回调与持久会话。

```lua
local dlg = mse.ui.dialog { title = "Options" }
dlg:number { id = "amount", label = "Amount", value = 4 }
dlg:button { text = "Apply", onclick = function()
  mse.ui.notify("Applied: " .. dlg.data.amount)
end }
dlg:show { wait = false }
```

## 安全边界

Lua 仍不能直接访问文件系统、网络、进程、调试库、DOM、React、原始 Store、历史栈或任意 Tauri 命令。文件选择、保存、导出与资源导入只能经过本 API 中明确开放的受控入口；像素和结构写入仍受目标身份、revision、尺寸、内存、指令数、执行时间与撤销校验保护。

## 参数细节与当前限制

[完整方法索引](../extensions/api-index.md)覆盖全部 68 个注册方法；[LuaLS 声明](mse-api.lua)给出结构参数和查询返回字段。get 查无对象返回 nil。创建方法返回排队确认而不是新 ID；引用新对象前，应在后续调用取得新快照。MSE 写入后立即查询仍读原快照。序列化拒绝不支持的值、非有限数、超过 24 层嵌套或 262144 个值；后续领域执行错误由宿主报告，不能靠前面的 Lua 调用/pcall 捕获。

- 动画 frame number 从 1 开始，duration 为毫秒，disabled 为布尔值。循环查询可返回往返方向，写入仍只支持 forward/reverse。updateLoop 会像创建一样补默认值，不是只修改传入字段的稀疏 patch；应传完整名称、范围、方向和次数。省略或 nil 的 repeatCount 在 Lua 表中成为缺失键，默认值为 1，不会编码成 JSON null；需要无限重复时，兼容层 Tag.repeats = 0 会显式排队 null。
- `tiles.edit { tilesetId, tileId, pixels }` 使用既有瓦片尺寸；tiles.place.rotation 是 0–3 个四分之一圈，不是角度，帧默认活动帧。打包 RGBA 为 `r | g<<8 | b<<16 | a<<24`，按行排列，也可传 RGBA 表数组或四通道数组。
- `freeTiles.createSource { layerId, name? }`、`place { layerId, sourceId, frame?, x, y }`、`edit { sourceId, width?, height?, offsetX?, offsetY?, pixels }`：编辑尺寸/偏移默认沿用原源。源查询仅覆盖活动自由瓦片图层。
- Tileset 快照共享 1,048,576 像素预算，超额条目不提供 pixels；工程笔刷 coverage/colors 使用同样的单数组长度上限。
- slices.create 使用矩形字段，自定义名称应在取得 ID 后使用 slices.update；styles.apply 使用 LuaLS 中完整 MseLayerStyles 模型，不是任意部分 CSS 对象。

## 保存与导出选项

document.save / io.save 接受 `{ saveAs?, options? }`，options 包含 name、format、scalePercent，以及可选 directory、includeTimelapse。工程另存为使用 includeTimelapse: true 携带可移植延时录像；普通保存使用本地录像库。非工程格式沿用软件兼容性确认。

| 导出字段 | 值与行为 |
| --- | --- |
| `name`、`format`、`scalePercent` | 默认取工程名称、png-auto、100%；缩放夹紧至 1–6400。 |
| `format` | png-auto、png-rgba、jpeg、webp、svg、gif、bmp、ico、psd、ase、aseprite；保存另支持 moonsprite。 |
| `target` | document（默认）、slices、frames、selection、layer；结构化工程导出要求 document 目标。 |
| `sliceId`、`layerId` | 限制对应目标；layer 目标未提供有效 layerId 时导出全部图层。 |
| `selection` | 由宿主管理；selection 目标使用执行时活动选区，覆盖传入的 mask。 |
| `directory` | 目标目录；省略时沿用宿主文件选择流程。 |
| `trim`、`trimMode` | 透明裁剪；模式 individual/common，具体受目标/格式约束。 |
| `gifFrameRange` | all、range、loop-section。 |
| `gifFrameStart`、`gifFrameEnd` | range 模式的含端点帧序号。 |
| `gifLoopSectionId` | loop-section 模式的既有循环 ID。 |
| `gifDirection` | forward、reverse、forward-ping-pong、reverse-ping-pong，与循环方向枚举名称不同。 |
| `presetName` | 保存的导出预设标签。 |

桥将选项交给 [document-file-service.ts](../../src/renderer/src/store/document-file-service.ts) 与 [export-settings.ts](../../src/renderer/src/core/export-settings.ts)，不返回最终保存路径；取消/失败通过宿主界面报告，之前的排队确认不代表文件已写入。
