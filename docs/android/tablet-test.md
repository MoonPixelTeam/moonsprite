# Android 平板测试版

基于上游 1.0.0-beta2（1177269），开发分支 android-tablet-test。复用 Tauri 2、React、Canvas 和原有工程格式，Windows 构建配置保留。

## 测试范围

- ARM64、Android 8.0（API 26）及以上，横屏平板为优先目标。
- 画布只接受笔和鼠标；手指可以操作界面，但不在画布绘画。双指手势暂未实现。
- 底部快捷栏提供画笔、橡皮、取色、平移、缩放、撤销、重做、保存、工程导出、PNG 和 GIF 导出。选择平移或缩放后使用笔在画布拖动。
- 保留原有外接键盘快捷键。笔压复用现有 Pointer Events 适配，需要三星真机验收，侧键及悬停不作为首版保证。
- 快捷栏“保存”写入应用私有图库；“导出工程”先保存内部工程，再通过 Android 系统选择器复制到指定位置。PNG/GIF 快捷入口始终打开系统选择器。
- 导入文件先复制到应用私有目录，编辑器不会把 content:// URI 当作文件路径；不会修改导入来源。没有可用文件名的提供方按文件头推断扩展名，具体文件仍由原有解码器校验。
- 测试版单文件导入上限 128 MiB。资源估算暂使用保守的应用预算，不代表设备实际内存。
- 每 30 秒为脏文档写入恢复数据；隐藏页面时尽力补一次。Android 强制终止可能来不及完成最后一次保存，开始长时间绘画前应验证恢复行为。

## 暂不支持

系统图片剪贴板、外部文件夹浏览和批量目录导出、字体导入、扩展安装、桌面文件关联及缩略图。内部复制粘贴继续复用 Store。
原桌面导出面板若指定应用内目录，仍可能仅保存到内部；首版请优先使用底部 PNG/GIF/导出工程按钮取出文件。

## 本地构建

需要 Node 22.13+（本机使用 24）、pnpm、Rust、JDK 17、Android SDK 36、NDK 27.2.12479018。构建环境本机放在仓库 artifacts/toolchain/，生成物与工具均被 Git 忽略。

PowerShell 中执行：

    . ./scripts/android-env.ps1
    pnpm install --frozen-lockfile
    pnpm android:init
    pnpm android:apk:windows

Windows 辅助脚本只在 Rust 已编译成功、随后创建符号链接失败时，复制本次原生库、去除打包副本的调试符号并调用 Gradle；其它构建错误直接终止，不会打包旧库。支持符号链接的环境也可使用 pnpm android:apk。

已有自定义工具链时可直接设置 JAVA_HOME、ANDROID_HOME、NDK_HOME 并使用相同 pnpm 命令；android-env.ps1 只是本机可选辅助。
android:prepare 会在每次打包前补入横屏和测试版名称，生成的 Gradle 工程不提交。

应用 ID 是 art.moonpx.moonsprite.tablettest，使用调试签名。连续安装须保持同一调试密钥，构建缓存之外应自行备份该密钥；不将密钥提交 Git。

## 真机验收顺序

1. 安装并启动，横屏进入示例工程或新建小画布。
2. 笔绘、压感、橡皮、取色、平移和缩放；手掌接触屏幕不能产生笔迹。
3. 图层与动画帧操作，再撤销和重做。
4. 保存内部工程，关闭并重开应用，从图库打开核对内容。
5. 导入 .moonsprite、PNG、GIF，编辑后保存；确认来源文件没有被覆盖。
6. 用快捷栏导出工程、PNG 和 GIF，在系统文件管理器里确认文件可打开且内容正确。
7. 测试取消选择器、存储空间不足、切换应用、锁屏、系统回收以及蓝牙键盘快捷键。

自动化检查不替代以上设备验收。仓库记录的构建结果与最终交付说明为准。
