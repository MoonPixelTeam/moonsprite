# 宠物伴侣（pet-companion）宠物包

本文属于 pet-companion 扩展。包结构、动画含义、校验、存储及导入行为由 `scripts/export-pet-package.mjs` 生成的扩展代码负责；软件提供与具体业务无关的表单文件选择和保存能力。

## 使用

在宠物管理中选择宠物，点击“导出宠物包…”并选择保存位置。点击“导入宠物包…”读取已有的 .mspet 文件。导入创建独立宠物，不覆盖已有宠物；完成后可从顶部“宠物”菜单开启显示。

## 格式

.mspet 是自包含 UTF-8 JSON 文件：format 为 moonsprite-pet，version 为 1；pet 包含名称、帧尺寸、帧数、逐帧时长、动画名到帧索引的映射、缩放倍率和镜像设置。sprite 为 PNG data URL，空宠物为 null。

包不包含本地 ID、素材存储键、显示开关、窗口位置或全局提醒配置。导出支持内置和用户创建的宠物。导入校验版本、体积、PNG 尺寸和帧索引，解码成功后保存；元数据写入失败会清理新素材，保留原有宠物。

## 宿主边界

宿主不解析 .mspet，不保存宠物业务字段，不定义动画槽位。扩展通过通用 file 节点的 accept 筛选文件，导出通过匹配用户操作 requestId 的 result.file 请求系统保存对话框。软件负责目的路径选择和原子写入。


## 条件动画槽

宠物管理 → 添加动画槽 → 选择触发条件、工具筛选、空闲时长和冷却时间 → 新增后上传动画。支持此前列出的全部 20 类条件；拖动拆分为开始与结束，共 21 个可选条件。条件和槽位文本有悬浮说明。每只宠物最多 30 个条件槽，加上 SHOW、IDLE 共 32 个槽；素材仍受每只宠物总计 240 帧及包体积限制。

条件动画播放一次后回到 IDLE；没有 IDLE 时使用 SHOW，二者均无素材时使用首帧。冷却大于 0 时，正在播放条件动画会忽略新的触发，不无限排队；同一事件多个槽按配置顺序选择首个有素材且冷却结束的槽。高频事件默认冷却 3 秒。空闲条件每次无操作周期触发一次；软件输入或宠物交互会重置空闲计时。未显示的宠物不接收宿主动画触发。宠物点击、拖动和移入仅作用于被交互宠物。

`.mspet` 可选 `pet.triggerSlots` 保存 `{id,event,tool,idleSeconds,cooldownMs}`。旧包缺少该字段时按无条件槽处理；条件、数值和重复 ID 均会校验。槽位可清除素材或删除，导入导出保留条件绑定。宿主仅提供通用事件和表单；条件目录、匹配、冷却和动画素材均属于扩展。

冷却时间支持 0：操作事件每次立即重播，可打断当前动画。多个空闲槽同时到期时，从有素材且冷却结束的候选中随机选择一个，本轮候选全部标记已处理，不在下一秒依次补播；再次操作重置空闲周期，较晚到期的槽仍可触发。目标工具仅在切换工具条件显示，空闲时长仅在空闲条件显示。
