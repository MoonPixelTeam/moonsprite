# 宠物伴侣（pet-companion）宠物包

本文属于 pet-companion 扩展。包结构、动画含义、校验、存储及导入行为由 `scripts/export-pet-package.mjs` 生成的扩展代码负责；软件提供与具体业务无关的表单文件选择和保存能力。

## 使用

在宠物管理中选择宠物，点击“导出宠物包…”并选择保存位置。点击“导入宠物包…”读取已有的 .mspet 文件。导入创建独立宠物，不覆盖已有宠物；完成后可从顶部“宠物”菜单开启显示。

## 格式

.mspet 是自包含 UTF-8 JSON 文件：format 为 moonsprite-pet，version 为 1；pet 包含名称、帧尺寸、帧数、逐帧时长、动画名到帧索引的映射、缩放倍率和镜像设置。sprite 为 PNG data URL，空宠物为 null。当前格式是明文 JSON，Base64 只用于编码图片，不提供加密、签名或授权保护；不适合作为商业 DRM。

包不包含本地 ID、素材存储键、显示开关、窗口位置或全局提醒配置。导出支持内置和用户创建的宠物。导入校验版本、体积、PNG 尺寸和帧索引，解码成功后保存；元数据写入失败会清理新素材，保留原有宠物。

## 宿主边界

宿主不解析 .mspet，不保存宠物业务字段，不定义动画槽位。扩展通过通用 file 节点的 accept 筛选文件，导出通过匹配用户操作 requestId 的 result.file 请求系统保存对话框。软件负责目的路径选择和原子写入。


## 条件动画槽

宠物管理 → 添加动画槽 → 选择触发条件、工具筛选、空闲时长和冷却时间 → 新增后上传动画。当前有 22 个可选条件：撤销、重做、吸色、保存成功、打开工程、新建工程、导出成功、完成绘制、填充完成、创建选区、切换工具、新建图层、删除图层、切换图层、播放动画、停止动画、点击宠物、开始拖动、持续拖动、结束拖动、鼠标移入和空闲。条件和槽位文本有悬浮说明。每只宠物最多 30 个条件槽，加上 SHOW、IDLE 共 32 个槽；素材仍受每只宠物总计 1024 帧（单个 GIF 最多 512 帧）及包体积限制。

条件动画播放一次后回到 IDLE；没有 IDLE 时使用 SHOW，二者均无素材时使用首帧。冷却大于 0 时，正在播放条件动画会忽略新的触发，不无限排队；同一事件多个槽按配置顺序选择首个有素材且冷却结束的槽。高频事件默认冷却 3 秒。空闲条件每次无操作周期触发一次；软件输入或宠物交互会重置空闲计时。未显示的宠物不接收宿主动画触发。宠物点击、拖动和移入仅作用于被交互宠物。

`.mspet` 可选 `pet.triggerSlots` 保存 `{id,event,tool,idleSeconds,cooldownMs}`。旧包缺少该字段时按无条件槽处理；条件、数值和重复 ID 均会校验。旧版本的“按住宠物”和“拖拽按住不动”槽位导入时分别迁移为点击和持续拖动，已有素材不会丢失。槽位可清除素材或删除，导入导出保留条件绑定。宿主仅提供通用事件和表单；条件目录、匹配、冷却和动画素材均属于扩展。

冷却时间支持 0：操作事件每次立即重播，可打断当前动画。多个空闲槽同时到期时，从有素材且冷却结束的候选中随机选择一个，本轮候选全部标记已处理，不在下一秒依次补播；再次操作重置空闲周期，较晚到期的槽仍可触发。目标工具仅在切换工具条件显示，空闲时长仅在空闲条件显示。

条件槽位支持右键编辑条件、工具、时长和冷却，保持槽位 ID 与素材绑定。持续拖动条件在开始拖动后循环播放，松开或取消时停止。移入条件使用当前显示帧的像素透明度判断；气泡使用当前整段动画所有帧的内容联合边界，仅切换动画时更新锚点，逐帧播放时固定；位置仍约束在软件内。


## 扩展内多语言

支持简体中文、英语、日语、韩语、德语、法语、西班牙语、巴西葡萄牙语和俄语。全部界面统一跟随软件语言，不再提供扩展独立语言选择；旧宿主缺少语言接口时退回系统语言。

翻译资源由 `scripts/pet-companion-localization.mjs` 管理，打包时嵌入扩展页面，不访问网络、不修改宿主语言资源。管理表单、动画条件及说明、操作反馈、校验错误、动态菜单和提醒气泡使用扩展语言；用户命名、动画 ID、宠物素材和 .mspet 数据保持原样。已有宠物会收到更新后的语言设置。

提醒总开关及各项时长位于宠物设置。扩展名称、描述、设置标签和说明由清单 translations 提供，宿主通用展示层按软件语言选择，停用扩展时仍生效。用户宠物名称和动画 ID 保持原样。


首次使用默认不显示宠物；此后软件启动或重新启用扩展时恢复关闭前的显示状态，保留语言、位置、缩放、镜像和提醒设置。切换工程或返回首页不会关闭本次已开启的宠物。

内置奶龙素材已更新：SHOW 为出场，IDLE 为待机，TOUCH 绑定指针移入（冷却 0），UNDO 绑定实际撤销（冷却 0）。保留源工程各帧时长；条件动画内部槽位 ID 为 TRIGGER_TOUCH、TRIGGER_UNDO。内置素材修订时会替换旧内置动画配置并保留缩放和镜像，用户创建的宠物保持原样。内置奶龙默认名称随扩展语言切换，用户自定义名称不翻译。

宠物菜单先显示可用宠物，再以横线分隔宠物管理和宠物设置入口。内置动画修订号由源工程 SHA-256 生成，避免新素材被旧内置元数据遮盖。


## 随软件更新内置扩展

宿主启动时比较内置包各文件的内容修订（文件名、ZIP CRC 与解压大小），而非只比较扩展版本号。内容改变时通过常规原子安装流程替换旧扩展；首次迁移旧的 seededBuiltin 记录时也会更新，因此同为 1.0.0 的修订可以生效。更新保留启用/禁用状态，不清空扩展的用户存储。安装失败时不记录新修订，错误会进入启动错误报告，后续启动可重试。

已经主动卸载的内置扩展不会恢复。内置包未变化时不重复安装；同 ID 的手动替换会保留到软件下一次携带不同内容的内置包。此逻辑只管理扩展程序文件，内置宠物动画迁移仍由扩展自身负责。

## 素材容量

新宿主通过扩展窗口的 `moonsprite.assets.get/set/remove` 将素材保存在宿主管理的 IndexedDB，与配置存储分离，并按扩展 ID 隔离。单项字符串 UTF-8 上限为 8 MiB，每个扩展合计 64 MiB；额度检查与写入在同一事务内完成。Base64 编码后的 PNG 长图计入额度，原 GIF 文件大小不代表最终素材大小。

旧配置存储中的宠物仍可读取，重新上传动画后使用新素材存储；旧宿主保留原配置存储限制。宠物包导入上限为 12 MiB，内部 PNG data URL 上限为 8 MiB。单动画 120 帧、单宠物 240 帧限制保留，合并长图不得超过 1600 万像素（RGBA 约 61 MiB，不含其他解码开销）。写入失败不会替换旧宠物元数据。

宠物交互与空闲条件排列在绘制、工程等操作条件之前。新增 `pet.hover`（悬浮）、`pet.holding`（按住尚未拖动）、`pet.drag-paused`（拖动后静止 350 毫秒）与 `pet.leave`（移出）。悬浮、按住、持续拖动与拖动静止可设置 `repeat`；新增槽位默认重复，旧持续拖动槽位缺省仍循环。其他条件保持单次播放。

重复播放在状态持续期间连续循环，退出、取消、丢失指针捕获或窗口失焦时停止。冷却从该槽位开始播放计时，仅限制再次进入；若重新进入时尚在冷却，则等待剩余时间，提前离开会取消等待。持续状态播放优先于绘制事件；不重复时仅在每次状态进入播放一次。未配置静止动画时，拖动停住继续保持原拖动动画。

拖动交互按开始、持续、结束衔接：有开始拖动素材时先播放一次，完成后进入持续拖动；提前松开会中断开始动画并处理结束拖动。结束动画完成后，指针仍悬浮时恢复悬浮状态。缺少对应素材时跳过该阶段。帧数提高后仍保留 1600 万总像素与包体积限制。

启用宠物伴侣后，可将 `.mspet` 文件拖入软件。扩展注册通用 `runtime.setFileDropTypes` 接口（需要 `io` 权限），接收 `files-dropped` 事件中的文件名与字节，不获取任意路径访问权。扩展负责打开宠物管理、等待管理窗口就绪、校验导入、更新列表及显示结果弹窗。未启用扩展时不接管该文件类型；同批拖入的工程和图片继续按原有流程打开。
