# 宠物伴侣（pet-companion）宠物包

本文属于 pet-companion 扩展。包结构、动画含义、校验、存储及导入行为由 `scripts/export-pet-package.mjs` 生成的扩展代码负责；软件提供与具体业务无关的表单文件选择和保存能力。

## 使用

在宠物管理中选择宠物，点击“导出宠物包…”并选择保存位置。点击“导入宠物包…”读取已有的 .mspet 文件。导入创建独立宠物，不覆盖已有宠物；完成后可从顶部“宠物”菜单开启显示。

## 格式

.mspet 是自包含 UTF-8 JSON 文件：format 为 moonsprite-pet，version 为 1；pet 包含名称、帧尺寸、帧数、逐帧时长、动画名到帧索引的映射、缩放倍率和镜像设置。sprite 为 PNG data URL，空宠物为 null。

包不包含本地 ID、素材存储键、显示开关、窗口位置或全局提醒配置。导出支持内置和用户创建的宠物。导入校验版本、体积、PNG 尺寸和帧索引，解码成功后保存；元数据写入失败会清理新素材，保留原有宠物。

## 宿主边界

宿主不解析 .mspet，不保存宠物业务字段，不定义动画槽位。扩展通过通用 file 节点的 accept 筛选文件，导出通过匹配用户操作 requestId 的 result.file 请求系统保存对话框。软件负责目的路径选择和原子写入。
